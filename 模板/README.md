# 模板

学习模块的标准模板集合。每个子目录都是**可直接复制、直接打开**的模块骨架：目录页、章节侧栏、右侧大纲、全站检索、学习进度都已接好；新建一门课只需要改一个结构文件 + 写正文。

```
模板/
├── 学习模块标准模板/      通用骨架（任意学科）
├── 数学类模板/            数学课件：先推导后定理，定理落到算法
├── 算法类模板/            算法竞赛教程：一节一个算法闭环
├── 要求模板（通用）.md    通用提示词范式（复制即用的“课程生成”模板）
├── 数学类要求.md          数学类模板的落地版提示词（含推导卡 / 落地卡 / 自检项）
└── 算法类要求.md          算法类模板的落地版提示词（含九段闭环 / 图解 / 自检项）
```

## 三个模板的区别

| | 学习模块标准模板 | 数学类模板 | 算法类模板 |
|---|---|---|---|
| 定位 | 通用骨架，什么课都能装 | 数学课件的版式与写作规范 | 算法竞赛教程的教学闭环 |
| 正文布局 | `sections/1-1.html`（一节一文件） | 同左 | `01.html`（平铺在根目录） |
| 引擎 | `style.css` + `app.js` + `theme.js` | 同一套引擎 **+ 自带 `course.css`** | 取自 `算竞教程`，参数化后复用 |
| 公式 | 可选（本地 MathJax 已就位） | 强制（定界符、转义、对齐都查） | 不用 MathJax，直接写 Unicode |
| 核心组件 | 通用盒：定义 / 例题 / 习题 / 一页纸 | **推导卡 → 定理 → 证明 → 算法落地卡** | 新函数拆解 / 逐行拆解 / 数学补给 / 挑战 2 |
| 图 | `figure.plot` | `plot` + `figure.fig`（几何示意 / 流程图） | **`figure.dia` 纯 HTML 图解** + `plot` |
| 目录模型 | Part → 章 → 节 | 同左 | 组 → 节（无章） |
| 侧栏 | 常驻左栏 + 右栏 | 同左 | 抽屉式章节栏 + 右侧本节目录 |
| 构建物 | `index.html` / `toc.js` / `search-index.js` | 同左 | 同左 + 各页锚点与本节目录回填 |
| 自检 | `tools/check.py`（结构） | 结构 + 数学陈述规范 + 推导/落地卡 | 教学闭环 + 代码逻辑图 + 目录锚点 |

## 用一份模板开新课程（通用 4 步）

1. **复制**：把模板目录整个复制成你的课程目录。
2. **改身份**：编辑 `tools/curriculum.py` 顶部的 `MODULE`（标题、图标、**存储键**）。存储键必须与其它课程不同，否则同一浏览器下进度会串。
3. **改结构**：数学类改 `PARTS` / `CHAPTERS`；算法类改 `GROUPS` / `CH2_FROM`。
4. **写内容**：数学类复制 `sections/_骨架.html`，算法类复制 `01.html`；然后

```powershell
python tools/build.py     # 生成目录页、章节数据、检索索引（算法类还会回填锚点与本节目录）
python tools/check.py     # 自检，全绿再提交
```

每个模板目录里的 `README.md` 有完整的组件速查表与验收清单；两份 `*要求.md` 是给“用模板批量生成课程”时直接复制的提示词。

## 约定

- **引擎不动**：`assets/style.css`、`assets/app.js`、`assets/theme.js` 由模板统一维护；课程只写 `curriculum.py` 与正文，新样式追加到课程的 `assets/course.css`。
- **生成物不手改**：`index.html`、`assets/toc.js`、`assets/search-index.js` 由 `build.py` 重建。
- **先构建再提交**：锚点与检索索引都在构建期生成，跳过构建会导致检索与定位失效。
- **资源本地化**：MathJax 在 `assets/mathjax/` 里，双击 `file://` 也能渲染公式。
