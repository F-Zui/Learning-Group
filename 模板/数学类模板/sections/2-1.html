最大公约数与 Bézout 恒等式

这一节把两个“看起来只是数论”的结论变成算法：第一，约分时可以把大数换成余数；第二，最大公约数一定能写成原数的整系数组合。前者给出 O(log n) 的 gcd，后者给出能解一次不定方程的 exgcd。

第 2 章 · 数论与算法 难度 ●●○ 前置：§1.1 极限的 ε-δ 定义（只用到“存在性 + 构造”的证明习惯） 关键词：gcd · Bézout · exgcd

一从“约分”说起

把 $\dfrac{240}{46}$ 约到最简，要除以它们的最大公约数。最笨的办法是枚举 $1$ 到 $46$ 的每个数，看谁同时整除两者——$46$ 次试除。如果分母是 $10^{18}$ 级别的呢？枚举就彻底失效了。

所以我们真正需要的是：能不能用两个数的一小部分信息，替换掉大数，而最大公约数不变？如果每次替换都能让数变小很多，几十次之内就能算完一个 $10^{18}$ 的数。

定义（整除与最大公约数）

若存在整数 $k$ 使 $b=ak$，称 $a$ 整除 $b$，记作 $a\mid b$。设 $a,b$ 不全为零，它们的最大公约数 $\gcd(a,b)$ 是同时整除 $a,b$ 的最大正整数。

写作 $\gcd(a,b)=d$ 时，默认 $d\gt0$；并且 $a,b$ 的公因数集合与 $d$ 的因数集合完全相同。

二把大数换成余数

推导在知道 Euclid 算法之前枚举太慢 → 观察余数 → 验证互推 → 落定理
问题　要算 $\gcd(240,46)$。枚举 $1\dots46$ 太慢，能不能把 $240$ 换成一个更小的、和它“GCD 相同”的数？
1
先做一次带余除法，看余数有没有用

$240=5\cdot46+10$，余数 $10$。逐个数验证：$2$ 同时整除 $240$ 与 $46$，也整除 $10$；$3$ 不整除 $46$，也不整除 $10$；$5$ 不整除 $46$，也不整除 $10$。好像两边总是同进同退。

观察　$10=240-5\cdot46$，它是 $240$ 与 $46$ 的整系数组合。所以任何同时整除二者的数，必然整除 $10$。
2
反过来问：整除 $46$ 与 $10$ 的数，会整除 $240$ 吗

会的：$240=5\cdot46+10$，若 $c\mid46$ 且 $c\mid10$，则 $c\mid5\cdot46+10=240$。于是“$a,b$ 的公因数”与“$b,r$ 的公因数”是同一个集合。

关键　两个集合相等，它们的最大元素当然相等——这一步不需要任何估计，只需要“互相整除”这个方向。
3
确认数真的在变小

余数满足 $0\le r\lt b$。只要 $r\ne0$，下一对 $(b,r)$ 的两个数都比原来小，最坏情况也只是每次减到原来的 $1/2$ 左右（连分数最坏情形是斐波那契数）。所以这个过程一定停。

验证　$240\to46\to10\to6\to4\to2\to0$：共 6 步就到底，而枚举要 46 次。停下来的那一刻，前一个非零余数就是答案。
于是我们得到：$\gcd(a,b)=\gcd(b,a\bmod b)$。下面写成定理，并补上“公因数集合相同”的完整证明。
定理（Euclid 算法的正确性）

设 $a,b\in\mathbb{Z}$，$b\ne0$，$a=qb+r$（$0\le r\lt|b|$），则 $\gcd(a,b)=\gcd(b,r)$。

证明

记 $S_1$ 为 $a,b$ 的公因数集合，$S_2$ 为 $b,r$ 的公因数集合。

若 $c\in S_1$，则 $c\mid a$、$c\mid b$，于是 $c\mid a-qb=r$，故 $c\in S_2$。

若 $c\in S_2$，则 $c\mid b$、$c\mid r$，于是 $c\mid qb+r=a$，故 $c\in S_1$。

所以 $S_1=S_2$，两边的最大元素相同，即 $\gcd(a,b)=\gcd(b,r)$。∎

读法

这条定理说：“最大公约数”只依赖两个数生成的整系数组合，而带余除法正是把大数换成“小一点的同类数”的唯一动作。反复做下去，数变小而 GCD 不变，最后当一边变成 $0$ 时，另一边就是答案。

三最大公约数能写成组合

推导在知道 Bézout 恒等式之前先看小例子 → 找最小组合 → 证明它整除两边 → 落定理
问题　$240x+46y$ 这种整系数组合能取到哪些数？能取到 $1$ 吗？能取到 $\gcd(240,46)=2$ 吗？
1
先枚举小例子，看组合能取到什么

取 $a=6,b=4$。$6x+4y$ 能取到 $2$（$x=1,y=-1$）、$4$、$6$、$8$……全是偶数；取不到 $1$。再取 $a=6,b=5$：$6\cdot1+5\cdot(-1)=1$，连 $1$ 都能取到。

观察　组合能取到的数都是 $\gcd(a,b)$ 的倍数；能不能取到 $\gcd$ 本身，取决于 $a,b$ 是否互素。
2
取“最小的正组合”当候选

令 $S=\{ax+by\gt0:x,y\in\mathbb{Z}\}$，它是非空的（取 $x=a,y=b$ 得 $a^2+b^2\gt0$）。由良序原理，$S$ 有最小元 $d=ax_0+by_0$。猜：$d$ 就是 $\gcd(a,b)$。

为什么要取最小　“最小”是唯一能用上的性质：任何更小的正组合都不存在，而带余除法的余数恰好是一个更小的组合。
3
用带余除法证明 $d$ 整除 $a$ 与 $b$

写 $a=qd+r$（$0\le r\lt d$）。则 $r=a-qd=a-q(ax_0+by_0)=a(1-qx_0)+b(-qy_0)$，仍是整系数组合。若 $r\gt0$，它比 $d$ 更小且属于 $S$，与 $d$ 的最小性矛盾；故 $r=0$，即 $d\mid a$。同理 $d\mid b$。

验证　$d$ 是公因数；而任何公因数 $c$ 都整除 $ax_0+by_0=d$，所以 $c\le d$。两边合起来，$d$ 就是最大公约数。
于是我们得到：存在整数 $x,y$ 使 $ax+by=\gcd(a,b)$。这个等式不但是存在性的保证，还指出了算法：把带余除法的每一步回代，就能把系数算出来。
定理（Bézout 恒等式）

对任意不全为零的整数 $a,b$，存在 $x,y\in\mathbb{Z}$，使

$$ax+by=\gcd(a,b)$$
证明

令 $S=\{ax+by:x,y\in\mathbb{Z},\ ax+by\gt0\}$。因 $a^2+b^2\gt0$，$S$ 非空；由良序原理取最小元 $d=ax_0+by_0$。

写 $a=qd+r$，$0\le r\lt d$，则 $r=a-qd=a(1-qx_0)+b(-qy_0)$ 也是整系数组合。若 $r\gt0$ 则 $r\in S$ 且 $r\lt d$，与最小性矛盾，故 $r=0$，即 $d\mid a$；同理 $d\mid b$。

设 $c$ 是 $a,b$ 的任一公因数，则 $c\mid ax_0+by_0=d$，故 $c\le d$。于是 $d$ 是最大公约数，恒等式成立。∎

易错

Bézout 的系数不唯一：$2=(-9)\cdot240+47\cdot46$，也可以写成 $2=37\cdot240+(-193)\cdot46$（差的都是 $(b/g,-a/g)=(23,-120)$ 的整数倍）。算法只要给出任意一组，不必求“最小系数”。

$a,b$ 有负数时，先取绝对值算组合，再把 $x$ 或 $y$ 的符号翻过来；C++ 的 % 在负数上的行为与数学上的余数不同，写代码时要用 ((a%b)+b)%b 或先取绝对值。

四把定理变成算法

代码 1 · gcd 与 exgcd（返回 $g$，并带回一组 $(x,y)$）C++17
long long gcd(long long a, long long b) {
    while (b) { long long t = a % b; a = b; b = t; }
    return a;                     // 定理 1：反复把大数换成余数
}

long long exgcd(long long a, long long b,
               long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }   // 边界：a·1 + 0·0 = a
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);   // 定理 1：换成 (b, a%b)
    x = y1;                                  // 定理 2：把下层的组合回代
    y = x1 - (a / b) * y1;
    return g;
}

算法落地：用 $\gcd(240,46)$ 把五步走一遍

算法落地从 $\gcd(240,46)$ 到一组 Bézout 系数覆盖：Euclid 定理 / Bézout 恒等式 / exgcd
需求　求 $\gcd(240,46)$，并给出 $x,y$ 使 $240x+46y=\gcd$。手算目标：$x=-9$、$y=47$。
1先算 $g=\gcd(240,46)$

$240=5\cdot46+10$，$46=4\cdot10+6$，$10=1\cdot6+4$，$6=1\cdot4+2$，$4=2\cdot2+0$，所以 $g=2$。

long long g = gcd(240, 46);   // 2
为什么　这一步只用定理 1：每做一次带余除法，$(\text{大},\text{小})$ 就换成 $(\text{小},\text{余数})$，GCD 不变；余数为 $0$ 时剩下的非零数就是 $g$。
2递归到底，再从 $b=0$ 的边界往回带系数

递归到 $\gcd(2,0)$ 时返回 $(g,x,y)=(2,1,0)$，因为 $2\cdot1+0\cdot0=2$。然后层层回代：$2=1\cdot2+0\cdot0$，$2=0\cdot4+1\cdot2$……直到 $2=1\cdot6-1\cdot4$ 这一层。

long long x, y;
long long g = exgcd(240, 46, x, y);   // g = 2
为什么　定理 2 只保证“存在”，而递归给出的是构造性的证明：把 $a=qb+r$ 代回 $bx_1+ry_1=g$，就得到 $a\cdot y_1+b\cdot(x_1-qy_1)=g$，于是新系数是 $(y_1,\ x_1-qy_1)$。
3拿到一组系数并回代验证

$x=-9$，$y=47$：$240\cdot(-9)+46\cdot47=-2160+2162=2$，等于 $g$。

if (240 * x + 46 * y != g) puts("bug");
为什么　回代是唯一能立刻暴露符号错误的一步。手写 exgcd 最常见的 bug 是 x = y1; y = x1 - (a/b)*y1; 两行写反顺序——用了已被覆盖的 x1。
4写出全部解（通解）

若 $(x_0,y_0)$ 是一组解，则全部解为 $x=x_0+\dfrac{b}{g}t$，$y=y_0-\dfrac{a}{g}t$，$t\in\mathbb{Z}$。本例 $g=2$，故 $x=-9+23t$，$y=47-120t$。

long long dx = 46 / g, dy = 240 / g;   // 23, 120
// 第 t 组解：x + dx*t, y - dy*t
为什么　两个解的差满足 $a\Delta x+b\Delta y=0$，即 $\frac{b}{g}\mid\Delta x$；所以最小正步长是 $b/g$，不会漏解也不会重复。
5把它用到同余上：$g=1$ 时就是模逆

若 $\gcd(a,m)=1$，则 $ax\equiv1\pmod m$ 有唯一解 $x$，即 $a$ 的模逆。对 $a=3,m=5$：$3\cdot2+5\cdot(-1)=1$，故 $3^{-1}\equiv2\pmod5$。

long long inv(long long a, long long m) {
    long long x, y; exgcd(a, m, x, y);
    return ((x % m) + m) % m;   // 负数取模必须修正
}
为什么　同余式 $ax\equiv1$ 等价于存在 $y$ 使 $ax+my=1$，这正是 Bézout 取 $g=1$ 的情形；C++ 的 % 可能返回负数，所以要加一次模再取模。
竞赛用法　看到“求 $ax+by=c$ 的一组整数解”“求模逆”“合并同余条件”就想到 exgcd：先判 $g\mid c$，有解则把解放大 $c/g$ 倍，再用 $b/g$、$a/g$ 写通解。复杂度 $O(\log\min(a,b))$，但中间量可能到 $10^{18}$ 量级，乘法一律用 __int128。
模型：一次不定方程 / 模逆复杂度：O(log min(a,b))常见坑：负数取模、乘法溢出

五例题

例 1 手算 exgcd：240 与 46

求 $x,y$ 使 $240x+46y=2$。

解　先做带余除法并回代：

$$2=6-1\cdot4,\quad 4=10-1\cdot6,\quad 6=46-4\cdot10,\quad 10=240-5\cdot46$$

从下往上代入：$2=2\cdot6-10=2\cdot46-9\cdot10=47\cdot46-9\cdot240$。所以 $(x,y)=(-9,47)$，验证 $240\cdot(-9)+46\cdot47=2$。

例 2 线性丢番图：$15x+25y=5$

求全部整数解。

解　$g=\gcd(15,25)=5$，且 $5\mid5$，有解。两边除以 $5$ 得 $3x+5y=1$；由 $3\cdot2+5\cdot(-1)=1$ 得一组解 $(2,-1)$。通解为

$$x=2+5t,\qquad y=-1-3t,\qquad t\in\mathbb{Z}$$

回代检验：$15(2+5t)+25(-1-3t)=30+75t-25-75t=5$，对任意 $t$ 成立。

如果 $g\nmid c$，方程 $ax+by=c$ 一定无解吗？能不能用“最小正组合”的论证直接说明？
引导　能。$ax+by$ 的每个取值都是 $g$ 的倍数（$g$ 整除 $a,b$），所以左边只能取 $g$ 的倍数；而 $g\mid c$ 是唯一的门槛，一旦满足就一定有解（把 Bézout 的解放大 $c/g$ 倍即可）。
进阶 · 为什么最坏情形是斐波那契数

Euclid 算法每两步至少让两个数中的较小者减半：由 $r_{k-1}=q_kr_k+r_{k+1}$ 且 $q_k\ge1$ 得 $r_{k-1}\ge r_k+r_{k+1}$，即余数序列至少按斐波那契速度增长。反过来，取相邻斐波那契数 $(F_{n+1},F_n)$ 时每一步的商都恰好是 $1$，步数达到最大 $\Theta(\log_\varphi n)$。

这条结论说明 $O(\log n)$ 的界是紧的，也解释了为什么“随便取两个 $10^{18}$ 的数”通常几步就结束，而相邻斐波那契数最慢。

六习题

  1. 求 $\gcd(1071,462)$，并给出一组 Bézout 系数。
    思路　反复做带余除法，再自下而上回代。
    答案　$1071=2\cdot462+147$，$462=3\cdot147+21$，$147=7\cdot21$，故 $g=21$；回代得 $21=462\cdot16-1071\cdot7$，即 $(x,y)=(-7,16)$。
  2. 用 exgcd 求 $17$ 在模 $31$ 下的逆元。
    思路　先算 $17x+31y=1$，再对 $x$ 取模 $31$。
    答案　$31=1\cdot17+14$，$17=1\cdot14+3$，$14=4\cdot3+2$，$3=1\cdot2+1$，回代得 $1=17\cdot11-31\cdot6$，故 $17^{-1}\equiv11\pmod{31}$。验证 $17\cdot11=187=6\cdot31+1$。
  3. 判断 $12x+18y=7$ 是否有整数解，并说明理由。
    思路　看 $\gcd(12,18)$ 是否整除 $7$。
    答案　$\gcd(12,18)=6$，而 $6\nmid7$，故无解。左边恒为 $6$ 的倍数，而 $7$ 不是。
  4. 若 $(x_0,y_0)$ 是 $ax+by=g$ 的一组解，写出 $ax+by=c$（$g\mid c$）的通解。
    思路　先把解放大 $c/g$ 倍，再加齐次方程 $a\Delta x+b\Delta y=0$ 的通解。
    答案　$x=\dfrac{c}{g}x_0+\dfrac{b}{g}t$，$y=\dfrac{c}{g}y_0-\dfrac{a}{g}t$，$t\in\mathbb{Z}$。
一页纸
  • $\gcd(a,b)=\gcd(b,a\bmod b)$：公因数集合完全相同，所以最大者相同。
  • Bézout：$ax+by=\gcd(a,b)$ 一定有解；系数不唯一，算法只需给出一组。
  • exgcd 的两个关键行：边界 x=1,y=0，回代 x=y1; y=x1-(a/b)*y1;。
  • 方程 $ax+by=c$ 有解 $\iff g\mid c$；有解时通解步长为 $(b/g,\,-a/g)$。
  • $g=1$ 时同余 $ax\equiv c$ 的唯一解就是 $x\equiv c\cdot a^{-1}$，模逆由此而来。
