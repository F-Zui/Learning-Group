# 数论入门

面向**信息竞赛学生**的基础数论教程。从整数的内部结构出发：整除、同余、素数；再走到数论函数、Möbius 反演、二次剩余与二次互反律；最后用 Pell 方程与猜想实验室收束。每个数学结论都有证明或证明梗概，每个算法都有 C++17 代码与逻辑流程图。

> 本课程由 `模板/数学类模板` 生成，保留其全部版式与交互：全站检索、深浅色主题、学习进度、右栏大纲、上一节/下一节。`assets/style.css`、`assets/app.js`、`assets/theme.js` 未改动；新增的 `assets/course.css` 负责代码块、算法流程图、定理推导卡与“算法落地”卡片。

## 一、适合谁

- 已会 C++ 基础语法、数组、循环与递归。
- 学过高中数学的集合、函数、充分必要条件；不要求竞赛数论基础。
- 目标是把“会背结论”变成“能证明、能手算、能写代码”。

建议每次课学 1 节：先读动机与定义，再跟手算例题，最后独立完成习题。每节末尾的“一页纸”用于复习，不用于第一次阅读。

### 先推导，后定理

每节在正式定理之前至少放一张 `推导` 卡：先假装“不知道有这个定理”，从需求出发做实验、猜规律、验证，再把发现写成定理。固定节奏是：

1. **问题**：一个需要解决的具体计算/判断需求；
2. **尝试**：枚举、试错或观察小例子，找出候选规律；
3. **验证**：用反证、最小性、构造或代数变形检查规律为什么必须成立；
4. **落定理**：把刚才推出来的结论写成定理，随后才是正式证明。

全课程共 18 张推导卡：§1.1、§1.3、§2.1、§2.2 各两张，其余各一张。§2.1 的两张分别从 $6x\equiv4\pmod8$ 推出线性同余的解数，从 $x\equiv2(3),x\equiv3(5)$ 推出 CRT 的“开关叠加”构造。这样学生先经历“为什么需要这个定理”，再看到“定理的正式表述”。

### 定理不悬空：核心定理后的“算法落地”卡

每个核心定理/性质后面都有一张 `算法落地` 卡，固定按五段展开：

1. **需求**：一个具体数字例子，能直接手算；
2. **拆步**：把定理的验证/构造切成 3–5 步；
3. **每步代码**：每步配一小段 C++，让代码链与证明链对齐；
4. **为什么**：解释这一步的动机、构造理由，以及“为什么可以这样”；
5. **竞赛用法**：这道定理在 OI 里对应什么模型、什么时候会踩坑。

例如 §2.1 有两张卡：`6x≡4 (mod 8)` 展示“先除 gcd、再求逆、再抬升”，$x\equiv2(3),x\equiv4(5),x\equiv1(7)$ 则把 CRT 的“造开关、求逆、叠加、验证”拆成 5 步。

### 写作约定

1. **一文件一节**：文件名、`body data-sec`、`<title>` 前缀三者一致。
2. **生成物不手改**：`index.html`、`assets/toc.js`、`assets/search-index.js` 由 `build.py` 重建；正文的 `id="bN"` 也由它注入。

5. **代码块**：用 `<div class="codebox">` + `<pre class="code">`；代码中的 `<`、`&` 必须 HTML 转义。
6. **算法流程图**：用 `<figure class="fig" data-wide>` + `<svg class="dgm">`；节点类名见 `assets/course.css`（`fnode`、`fnode-b`、`fnode-g`、`fnode-r`、`fnode-a`、`ftext`、`fsmall`、`ar`、`ar-d`、`flab`）。

## 六、参考书与对应关系

- **David M. Burton, _Elementary Number Theory_**：整除与 Euclid（Ch. 2）、素数与算术基本定理（Ch. 3）、同余（Ch. 4）、Fermat/Wilson（Ch. 5）、数论函数（Ch. 6）、二次互反律（Ch. 9）、密码学（Ch. 10）、Pell 与连分数（Ch. 15）。
- **潘承洞《数论基础》**：整除与同余的基础训练、二次剩余与互反律、习题中的证明技巧。
- **Niven–Zuckerman–Montgomery, _An Introduction to the Theory of Numbers_**：数论函数与 Dirichlet 卷积（Ch. 4）、同余与伪素数（Ch. 2）。
- **Joseph H. Silverman, _A Friendly Introduction to Number Theory_**：Pell 方程（Ch. 22）、计算实验与猜想（Ch. 1 等）。

书中的章节号可能因版次不同而略有差异；正文的 `.ref` 标签给出的是主题级定位，不依赖某一版的页码。

## 七、给授课者的建议

- **先图后式**：每节的图不是装饰，先让学生看图说出“哪个量在变、哪个量不变”，再回到定义。
- **代码紧跟定理**：讲完 gcd 的正确性立即写 exgcd；讲完 Euler 判别立即写 `legendre`。代码不是额外内容，而是定理的执行版本。
- **手算优先**：1.2 的 240/46、4.2 的 17/31、4.3 的 41/5 都适合课堂逐行演算；先手算再跑程序。
- **区分三种语气**：定义是“把词说清楚”，定理是“保证成立”，猜想是“还没有答案”。5.2 要专门训练这种区分。
- **习题分层**：带“思路”的习题可以当堂做；最后一题通常需要结合本节与前一节，适合课后。
