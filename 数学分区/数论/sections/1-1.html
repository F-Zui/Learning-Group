一整除是乘法的反向阅读

$12=3\cdot 4$ 是一句乘法；反过来读，就是“$3$ 能整除 $12$”。数论把这种“能分成整数份”的关系单独命名，因为整数的许多结构都藏在它里面：约数、公因子、素数、同余，全部从整除出发。

定义（整除）

设 $a,b\in\mathbb{Z}$，且 $a\ne 0$。若存在整数 $q$，使得 $b=aq$，则称 $a$ 整除 $b$，记作 $a\mid b$；否则记作 $a\nmid b$。此时称 $a$ 是 $b$ 的约数（因子），$b$ 是 $a$ 的倍数。

符号的方向很重要：$3\mid 12$ 读作“$3$ 整除 $12$”，不是“$12$ 整除 $3$”。另外，$a\mid b$ 只要求商 $q$ 是整数，不要求 $q$ 为正。因此 $3\mid (-12)$，$-3\mid 12$，$1$ 整除一切整数，而 $0$ 不整除任何非零整数。

定理（整除的基本性质）

设 $a,b,c\in\mathbb{Z}$ 且 $a\ne 0$，则：

（1）若 $a\mid b$ 且 $b\mid c$，则 $a\mid c$；
（2）若 $a\mid b$ 且 $a\mid c$，则对任意 $x,y\in\mathbb{Z}$，$a\mid (bx+cy)$；
（3）若 $a\mid b$ 且 $b\mid a$，则 $a=\pm b$。

证明

（1）由定义写 $b=aq_1$，$c=bq_2$，代入得 $c=a(q_1q_2)$，所以 $a\mid c$。

（2）写 $b=aq_1$，$c=aq_2$，则 $bx+cy=a(q_1x+q_2y)$，括号内是整数，故 $a\mid (bx+cy)$。

（3）写 $b=aq_1$，$a=bq_2$。代入得 $a=aq_1q_2$。因 $a\ne0$，可约去 $a$，得 $q_1q_2=1$。整数乘积为 $1$ 只有两种可能：$q_1=q_2=1$ 或 $q_1=q_2=-1$，所以 $b=a$ 或 $b=-a$。∎

读法

性质（2）说：整除关系对整系数线性组合封闭。这是后面所有“消去”“代入”“构造更小反例”的来源。性质（3）则说明，在整除意义下 $a$ 与 $-a$ 不可区分，所以数论里常把正负号看作“单位”的差别。

二带余除法：把商与余数钉死

整除只覆盖了“刚好分完”的情形。$17$ 除以 $5$ 分不完，剩 $2$；这个“剩”就是余数。带余除法说：只要允许商取整数，任何整数除以正整数，都有唯一的商和余数，而且余数可以限定在一个半开区间里。

定理（带余除法）

设 $a\in\mathbb{Z}$，$b\in\mathbb{Z}_{\gt 0}$。则存在唯一的一对整数 $q,r$，使得

$$a=bq+r,\qquad 0\le r\lt b$$

其中 $q$ 称为商，$r$ 称为余数，记作 $r=a\bmod b$。

证明

存在性。考虑集合 $S=\{a-bk: k\in\mathbb{Z},\ a-bk\ge0\}$。取 $k$ 足够小（例如 $k\lt a/b$），就能让 $a-bk\ge0$，所以 $S$ 非空。由良序原理，$S$ 有最小元 $r=a-bq$，其中 $q\in\mathbb{Z}$，且 $r\ge0$。

若 $r\ge b$，则 $r-b=a-b(q+1)\ge0$ 也在 $S$ 中，且比 $r$ 更小，矛盾。因此 $0\le r\lt b$。

唯一性。若还有 $a=bq'+r'$，$0\le r'\lt b$，两式相减得 $b(q-q')=r'-r$。右边满足 $|r'-r|\lt b$，左边是 $b$ 的倍数；绝对值小于 $b$ 的 $b$ 的倍数只能是 $0$，故 $r'=r$，进而 $q'=q$。∎

这条定理的几何含义是：把数轴按长度 $b$ 切成无数个半开区间 $\dots,[-b,0),[0,b),[b,2b),\dots$，每个整数 $a$ 恰好落在其中一个区间里。$q$ 是区间编号，$r$ 是它到左端点的距离。

代码 1 · 欧几里得除法与负数余数C++17
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 返回 {q, r}，满足 a = b*q + r，0 <= r < b（要求 b > 0）
pair<ll, ll> divmod(ll a, ll b) {
    ll q = a / b, r = a % b;
    if (r < 0) { r += b; --q; }
    return {q, r};
}

int main() {
    auto [q1, r1] = divmod(17, 5);
    auto [q2, r2] = divmod(-17, 5);
    cout << q1 << ' ' << r1 << '\n';  // 3 2
    cout << q2 << ' ' << r2 << '\n';  // -4 3
}

三余数分类：把无限问题压成有限种情形

带余除法最实用的推论是：每个整数除以 $b$ 后的余数只有 $b$ 种。要证明一个关于所有整数的命题，只需对 $r=0,1,\dots,b-1$ 逐一检查。这种“按余数分类”的方法，把无限多个整数压成了有限个抽屉。

例如，平方数除以 $4$ 的余数只可能是 $0$ 或 $1$：偶数平方 $(2k)^2=4k^2$ 余 $0$，奇数平方 $(2k+1)^2=4(k^2+k)+1$ 余 $1$。因此两个平方数之和模 $4$ 只能取 $0,1,2$，绝不可能等于 $3$。一句话就排除了 $x^2+y^2=2023$ 的所有整数解。

提示

选择模数是一门手艺：要证明“被 $3$ 整除”，就看模 $3$；要证明“被 $8$ 整除”，就看模 $8$；要同时处理 $2$ 和 $3$，可以先分别看模 $2$、模 $3$，再用中国剩余定理合并（§2.1）。模数选得越小，分类越少；但太小可能丢失关键信息。

四例题

例 1 标准的商与余数

求 $2025$ 除以 $17$ 的商与余数。

解　估算 $17\times 120=2040$，比 $2025$ 大 $15$，所以取 $119$：

$$2025=17\cdot 119+2,\qquad 0\le 2\lt 17$$

商为 $119$，余数为 $2$。

例 2 用余数排除方程

证明方程 $x^2+y^2=2023$ 没有整数解。

解　对任意整数 $n$，$n^2\bmod 4\in\{0,1\}$。因此 $x^2+y^2\bmod 4$ 只能取

$$0+0=0,\quad 0+1=1,\quad 1+1=2$$

而 $2023=4\cdot 505+3$，余 $3$。左边不可能余 $3$，故方程无整数解。Burton Ch. 2

算法落地：带余除法与“按余数分类”

算法落地从 $-17\div5$ 到 $x^2+y^2=2023$ 的排除覆盖：带余除法 / 余数分类 / 整除性质
需求　先求 $-17$ 除以 $5$ 的商与余数；再用余数说明 $x^2+y^2=2023$ 为什么无整数解。
1先按定义把 $a=bq+r$ 写出来，不急着相信 C++ 的 %

要求 $0\le r\lt5$。$-17$ 落在区间 $[-20,-15)$ 内，左端点是 $5\cdot(-4)=-20$，所以 $q=-4$，$r=-17-(-20)=3$：

$$-17=5\cdot(-4)+3$$ 
long long a = -17, b = 5;
long long q = a / b;       // C++ 截断：-3
long long r = a % b;       // -2
if (r < 0) { r += b; --q; } // q=-4, r=3
为什么商也要减一？　因为等式 $a=bq+r$ 必须始终成立。只把 $r$ 从 $-2$ 改成 $3$，右边会多出 $5$；同时把 $q$ 减一，正好补回这个 $5$。商与余数是同一条等式的两个零件，不能单独改一个。
2把“所有整数”压成有限个余数抽屉

平方数模 $4$ 只有两种可能：偶数平方余 $0$，奇数平方余 $1$。于是 $x^2+y^2$ 模 $4$ 只能是 $0,1,2$，而 $2023\equiv3\pmod4$。

// 枚举两个平方数模 4 的所有组合
for (int x = 0; x < 4; ++x)
    for (int y = 0; y < 4; ++y)
        if ((x * x + y * y) % 4 == 3) cout << "possible";
// 没有任何输出：两个平方数模 4 凑不出 3
为什么只查 $4$ 种情形就够？　每个整数除以 $4$ 的余数必在 $\{0,1,2,3\}$ 中，而平方只依赖这个余数。无限多个整数被压成了 $4$ 个抽屉；只要每个抽屉都不可能，整个方程就不可能。
3把分类结果写成可复用的判定

这类题在竞赛里通常写成“枚举模数 $m$ 的余数，预处理合法余数集合”，再用它快速排除或计数。

bool can[4] = {true, true, true, false};
if (!can[2023 % 4]) cout << "no solution";  // 直接排除
为什么这算“算法思维”？　不是每次都用不等式硬解，而是先把对象按模数分桶，再把问题变成桶上的布尔判断。余数分类、哈希、状态压缩，本质上都是“把无限状态压成有限代表”。
竞赛用法　负数取模统一到 $[0,b)$ 是很多题的第一道坑；余数分类常用于判无解、统计方案数、构造周期。看到“平方和”“整除性”“末位数字”时，先问：模几能把条件压成有限种情况？
负数取模余数分类判无解
如果允许余数取负数，例如规定 $-b/2\lt r\le b/2$，带余除法还唯一吗？
引导　不唯一。以 $b=5$ 为例，$17$ 可以写成 $5\cdot3+2$，也可以写成 $5\cdot4-3$。只要把余数限制在长度为 $b$ 的半开区间里，唯一性就恢复；选哪个区间只是约定，数论默认选 $[0,b)$。

五习题

  1. 求 $-100$ 除以 $7$ 的商与余数，并验证 $a=bq+r$。
    思路　先找不超过 $-100$ 的最大 $7$ 的倍数：$-105=-7\cdot15$。
    答案　$-100=7\cdot(-15)+5$，商 $-15$，余 $5$。
  2. 设 $a,b$ 为非零整数。证明：若 $a\mid b$ 且 $b\mid a$，则 $a=b$ 或 $a=-b$。
    思路　把两个整除写成 $b=aq_1$、$a=bq_2$，约去 $ab$ 得 $q_1q_2=1$。
    答案　$q_1,q_2$ 都是整数且乘积为 $1$，故二者同为 $1$ 或同为 $-1$，分别给出 $b=a$ 或 $b=-a$。
  3. 证明任意三个连续整数之积都能被 $6$ 整除。
    思路　三个连续整数中必有一个偶数、必有一个 $3$ 的倍数；再用整除的线性组合性质。
    答案　设三数为 $n,n+1,n+2$。其中至少一个偶数，故乘积被 $2$ 整除；其中恰有一个模 $3$ 为 $0$，故乘积被 $3$ 整除。因 $2,3$ 互素，乘积被 $6$ 整除。
  4. 证明：对任意整数 $n$，$n^2+n$ 都是偶数；并进一步说明 $n^3-n$ 一定能被 $6$ 整除。
    思路　$n^2+n=n(n+1)$ 是连续两数之积；$n^3-n=(n-1)n(n+1)$ 是连续三数之积。
    答案　连续两数必有一偶，故 $n(n+1)$ 为偶数；连续三数必有一偶且有一数被 $3$ 整除，故 $n^3-n=(n-1)n(n+1)$ 被 $6$ 整除。
一页纸
  • $a\mid b$ 表示存在整数 $q$ 使 $b=aq$；注意方向，且 $0$ 不作除数。
  • 整除对线性组合封闭：$a\mid b,a\mid c\Rightarrow a\mid (bx+cy)$。
  • 带余除法：$a=bq+r$，$0\le r\lt b$，$q,r$ 唯一。
  • 按余数分类，把“所有整数”压成 $b$ 种情形；平方数模 $4$ 只取 $0,1$。
  • C++ 的商向零截断；数论余数要修正到 $[0,b)$，并同步调整商。
