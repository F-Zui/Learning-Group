一二进制幂：把指数拆成平方

计算 $a^{13}$ 最直接的办法是乘 $12$ 次。但 $13=8+4+1=1101_2$，而 $a^2,a^4,a^8$ 都可以由前一个平方得到：$a^2=(a^1)^2$，$a^4=(a^2)^2$，$a^8=(a^4)^2$。于是只需 $3$ 次平方和 $2$ 次乘法，就能拼出 $a^{13}$。

定理（二进制幂）

设 $e=\sum_{i=0}^{k}b_i2^i$，$b_i\in\{0,1\}$。则

$$a^e=\prod_{i:\ b_i=1}a^{2^i}$$

从 $a^{2^0}=a$ 开始反复平方，就能在 $O(\log e)$ 次乘法内得到 $a^e$。

代码 1 · 迭代快速幂（64 位模乘）C++17
using u64 = uint64_t;
using u128 = __uint128_t;

u64 pow_mod(u64 a, u64 e, u64 m) {
    u64 r = 1 % m;
    while (e) {
        if (e % 2) r = (u128)r * a % m;  // 当前位为 1：乘进答案
        a = (u128)a * a % m;                  // 平方，准备下一位
        e /= 2;
    }
    return r;
}

二Fermat 小定理与 Euler 定理

定理（Fermat 小定理）

设 $p$ 是素数，$a$ 是不被 $p$ 整除的整数。则

$$a^{p-1}\equiv1\pmod p$$

等价地，对任意整数 $a$，都有 $a^p\equiv a\pmod p$。

证明

考虑 $1,2,\dots,p-1$ 这 $p-1$ 个非零剩余类。乘以 $a$ 后，它们仍然是这 $p-1$ 个剩余类的一个排列：若 $ai\equiv aj\pmod p$，则 $p\mid a(i-j)$；因 $p\nmid a$，得 $p\mid i-j$，而 $1\le i,j\le p-1$，故 $i=j$。

把排列前后的乘积相等：

$$a^{p-1}(p-1)!\equiv(p-1)!\pmod p$$

因为 $\gcd((p-1)!,p)=1$，可以约去 $(p-1)!$，得到 $a^{p-1}\equiv1\pmod p$。∎

定义（Euler 函数）

对正整数 $m$，$\varphi(m)$ 表示 $1,2,\dots,m$ 中与 $m$ 互素的整数个数。若 $m=p_1^{a_1}\cdots p_k^{a_k}$，则

$$\varphi(m)=m\prod_{i=1}^k\left(1-\frac1{p_i}\right)$$
定理（Euler 定理）

若 $\gcd(a,m)=1$，则 $a^{\varphi(m)}\equiv1\pmod m$。

证明

取模 $m$ 的一个缩剩余系 $r_1,\dots,r_{\varphi(m)}$，即与 $m$ 互素的全部剩余类。因为 $\gcd(a,m)=1$，乘以 $a$ 仍把这些剩余类排列成同一个集合。把两边的乘积相等：

$$a^{\varphi(m)}r_1\cdots r_{\varphi(m)}\equiv r_1\cdots r_{\varphi(m)}\pmod m$$

乘积与 $m$ 互素，故可约去，得到 $a^{\varphi(m)}\equiv1\pmod m$。∎

降幂公式

当 $\gcd(a,m)=1$ 时，$a^e\equiv a^{e\bmod\varphi(m)}\pmod m$。这把指数从 $10^{18}$ 压到 $\varphi(m)$ 以内。注意：底数与模数不互素时不能直接用，因为 Euler 定理的前提不成立；此时要用 CRT 分拆模数，或利用具体周期。

三Wilson 定理与阶乘同余

定理（Wilson）

设 $p$ 是素数，则

$$(p-1)!\equiv-1\pmod p$$

反之，若整数 $n\gt1$ 满足 $(n-1)!\equiv-1\pmod n$，则 $n$ 是素数。

证明

对 $p=2$，$(2-1)!=1\equiv-1\pmod2$。设 $p$ 为奇素数。把 $1,\dots,p-1$ 中的数按乘法逆元配对：$a$ 与 $a^{-1}$ 成对，乘积为 $1$。只有满足 $a\equiv a^{-1}$ 的数需要单独留下，即 $a^2\equiv1$，解得 $a\equiv1$ 或 $a\equiv-1$。

因此所有数乘起来，成对的贡献 $1$，单独的贡献 $1\cdot(-1)=-1$：

$$(p-1)!\equiv1\cdot(-1)\equiv-1\pmod p$$

反过来，若 $n\gt4$ 是合数，则 $n$ 有真因子 $d$ 满足 $1\lt d\lt n$，且 $n\mid(n-1)!$，于是 $(n-1)!\equiv0\not\equiv-1\pmod n$。$n=4$ 时 $3!=6\equiv2\pmod4$。故满足同余的 $n$ 只能是素数。∎

四RSA 与例题

RSA 把“模幂容易、分解难”变成一把锁。取两个大素数 $p,q$，令 $n=pq$，$\varphi(n)=(p-1)(q-1)$。选 $e$ 与 $\varphi(n)$ 互素，公钥是 $(n,e)$；私钥 $d\equiv e^{-1}\pmod{\varphi(n)}$。加密 $c\equiv m^e\pmod n$，解密 $c^d\equiv m\pmod n$。正确性来自 $ed=1+k\varphi(n)$ 与 Euler 定理。

例 1 用周期降幂

计算 $2^{2024}\bmod13$。

解　$13$ 是素数，$2^{12}\equiv1\pmod{13}$。$2024=12\cdot168+8$，所以

$$2^{2024}\equiv2^8=256\equiv9\pmod{13}$$

答案是 $9$。

例 2 手算一组 RSA

取 $p=61$，$q=53$，$e=17$，明文 $m=65$。求密文并验证解密。

解　$n=61\cdot53=3233$，$\varphi(n)=60\cdot52=3120$。$17$ 模 $3120$ 的逆元是 $d=2753$，因为 $17\cdot2753=46801=15\cdot3120+1$。

加密与解密：

$$65^{17}\bmod3233=2790,\qquad 2790^{2753}\bmod3233=65$$

密文为 $2790$，解密回到 $65$。Burton Ch. 10

例 3 Wilson 定理算阶乘

求 $10!\bmod11$。

解　$11$ 是素数，由 Wilson 定理，$10!\equiv-1\equiv10\pmod{11}$。

不用逐个乘，就能直接得到结果；这也是 Wilson 定理在“模素数阶乘”问题中的典型用法。Burton Ch. 5

算法落地：快速幂、降幂、Wilson 与 RSA 是同一条链

算法落地从 $2^{2024}\bmod13$ 到一组 RSA覆盖：二进制幂 / Fermat / Euler / Wilson
需求　依次解决：① $2^{2024}\bmod13$；② $10!\bmod11$；③ 用 $p=61,q=53,e=17$ 加密 $m=65$ 并解密。
1先把指数写成二进制，用“平方 + 乘法”算幂

$2024$ 不需要真的乘 $2023$ 次；快速幂只做约 $\log_2 2024\approx11$ 轮，每轮一次平方，当前位为 $1$ 时再乘一次底数。

long long pow_mod(long long a, long long e, long long m) {
    long long r = 1 % m;
    while (e) {
        if (e % 2) r = (__int128)r * a % m;
        a = (__int128)a * a % m;
        e /= 2;
    }
    return r;
}
为什么平方能省时间？　$a^{2^k}$ 可以由 $a^{2^{k-1}}$ 平方一次得到。把指数拆成二进制，就是把“重复乘 $e$ 次”换成“重复平方 $\log e$ 次，再挑出为 $1$ 的位相乘”。
2用 Fermat 把指数从 $2024$ 压到 $8$

$13$ 是素数，$2^{12}\equiv1$。所以 $2^{2024}\equiv2^{2024\bmod12}=2^8=256\equiv9$。

long long e = 2024;
if (gcd(a, p) == 1) e %= (p - 1);
cout << pow_mod(2, e, 13);   // 9
为什么可以只保留指数余数？　因为 $a^{p-1}\equiv1$，指数每增加 $p-1$ 就多乘一个 $1$。这把“巨大指数”变成了“模 $p-1$ 的余数”；但前提是 $\gcd(a,p)=1$，否则 Fermat 不成立。
3Wilson：把 $10!$ 的配对一次性消掉

模 $11$ 时，$2,\dots,9$ 可以配成逆元对，乘积都是 $1$；只剩 $1$ 与 $10\equiv-1$，所以 $10!\equiv-1$。

long long fact = 1;
for (int i = 1; i < 11; ++i) fact = fact * i % 11;
// fact = 10 ≡ -1 (mod 11)
为什么配对能省掉所有中间项？　每个 $a$ 与 $a^{-1}$ 的乘积是 $1$；只有满足 $a=a^{-1}$ 的 $1$ 和 $-1$ 不配对。Wilson 定理把一整串阶乘压缩成“两个自逆元之积”，这是“用结构替代计算”的典型。
4RSA：加密和解密其实是同一次模幂

$n=3233$，$\varphi(n)=3120$，$d=2753$。加密 $c=65^{17}\bmod3233=2790$；解密 $2790^{2753}\bmod3233=65$。

long long c = pow_mod(m, e, n);   // 2790
long long back = pow_mod(c, d, n); // 65
为什么解密一定回到明文？　$ed=1+k\varphi(n)$，所以 $c^d=m^{ed}=m(m^{\varphi(n)})^k$。当 $\gcd(m,n)=1$ 时 Euler 定理把括号变成 $1$；不互素时按 $p,q$ 分开用 Fermat，再用 CRT 合并，同样成立。
竞赛用法　快速幂是所有模运算的底座；Fermat/Euler 用来降幂、求逆、判素；Wilson 多用于“模素数阶乘”与组合数推导；RSA 是“公钥加密 = 模幂，安全性 = 分解难”的经典模型。注意降幂只在 $\gcd(a,m)=1$ 时可直接用，否则要拆分模数或用扩展 Euler 公式。
快速幂降幂WilsonRSA
若 $\gcd(a,m)\gt1$，还能用 $a^{e}\equiv a^{e\bmod\varphi(m)}$ 吗？
引导　不能直接套。比如 $2^3\equiv0\pmod8$，但 $\varphi(8)=4$，$2^{3\bmod4}=2^3$ 恰好一样只是巧合；换一个指数就会坏。正确做法是把 $m$ 分解成素幂，分别用 Fermat/Euler 处理，再用 CRT 合并，或找出具体的预周期。

五习题

  1. 计算 $3^{2024}\bmod17$。
    思路　$17$ 是素数，$\varphi(17)=16$，先把指数对 $16$ 取余。
    答案　$2024\equiv8\pmod{16}$，$3^8=(3^4)^2=81^2\equiv(-4)^2=16\equiv-1\pmod{17}$，答案为 $16$。
  2. 求 $\varphi(1000)$。
    思路　$1000=2^3\cdot5^3$，用 $\varphi(p^a)=p^a-p^{a-1}$。
    答案　$\varphi(1000)=1000(1-\frac12)(1-\frac15)=1000\cdot\frac12\cdot\frac45=400$。
  3. 用 Wilson 定理的逆命题证明：若 $n\gt4$ 是合数，则 $(n-1)!\not\equiv-1\pmod n$。
    思路　说明 $n\mid(n-1)!$，所以同余只能是 $0$。
    答案　合数 $n\gt4$ 有真因子 $d$，且 $d$ 与 $n/d$ 都出现在 $1,\dots,n-1$ 中（$n=4$ 单独检查），故 $n\mid(n-1)!$，同余为 $0\ne-1$。
  4. 取 $p=5,q=11,e=3$，明文 $m=7$。求 $n,d$、密文，并验证解密。
    思路　$n=55$，$\varphi=40$；求 $3$ 模 $40$ 的逆元，再算两次模幂。
    答案　$n=55$，$d=27$（$3\cdot27=81\equiv1$）；$c=7^3\bmod55=13$，$13^{27}\bmod55=7$。
  5. 求 $3^{2024}$ 的末两位数字。
    思路　末两位就是模 $100$；$\varphi(100)=40$，指数对 $40$ 取余。
    答案　$2024\equiv24\pmod{40}$，$3^{24}=(3^8)^3\equiv61^3\equiv81\pmod{100}$，末两位是 $81$。
一页纸
  • 快速幂：反复平方底数，按指数的二进制位决定是否乘入答案，$O(\log e)$。
  • Fermat：$p\nmid a\Rightarrow a^{p-1}\equiv1\pmod p$。
  • Euler：$\gcd(a,m)=1\Rightarrow a^{\varphi(m)}\equiv1\pmod m$；可降幂。
  • Wilson：$p$ 素数 $\iff(p-1)!\equiv-1\pmod p$（$p\gt1$）。
  • RSA：$ed\equiv1\pmod{\varphi(n)}$，加解密互为逆运算。
