Pell 方程与连分数

从 $x^2-Dy^2=1$ 出发，看连分数如何把“无限接近 $\sqrt D$”变成整数解；学完能展开 $\sqrt D$ 的连分数、递推收敛分数，并求出 Pell 方程的最小正整数解。

一小方程，大解

Pell 方程是

$$x^2-Dy^2=1$$

其中 $D$ 是正整数且不是完全平方数。$D=2$ 时有解 $(3,2)$；$D=3$ 时有解 $(2,1)$；$D=7$ 时有解 $(8,3)$。这些解看起来不大，但 $D=61$ 的最小正整数解是

$$x=1766319049,\qquad y=226153980$$

一个系数只有 $61$ 的方程，最小解却有十位数。这说明 Pell 方程不是“试出来”的，它背后有一条结构性的通道：连分数。

二连分数：把无理数拆成整数层

定义（连分数与收敛分数）

有限连分数记作

$$[a_0;a_1,\dots,a_n]=a_0+\cfrac{1}{a_1+\cfrac{1}{a_2+\cdots+\cfrac{1}{a_n}}}$$

其中 $a_0\in\mathbb{Z}$，$a_1,\dots,a_n$ 为正整数。截断到第 $k$ 层得到的分数 $p_k/q_k=[a_0;\dots,a_k]$ 称为第 $k$ 个收敛分数。

对无理数 $\alpha$，反复取整数部分与倒数，就得到无限连分数。$\sqrt D$ 的连分数一定是周期的：

$$\sqrt D=[a_0;\overline{a_1,\dots,a_L}]$$

例如 $\sqrt2=[1;\overline2]$，$\sqrt3=[1;\overline{1,2}]$，$\sqrt{13}=[3;\overline{1,1,1,1,6}]$。周期长度 $L$ 可以很小，也可以很长，但一定有限。

定理（收敛分数的递推）

令 $p_{-2}=0,p_{-1}=1$，$q_{-2}=1,q_{-1}=0$。对 $k\ge0$，

$$p_k=a_kp_{k-1}+p_{k-2},\qquad q_k=a_kq_{k-1}+q_{k-2}$$

并且 $p_kq_{k-1}-p_{k-1}q_k=(-1)^{k-1}$，所以 $p_k/q_k$ 已经约分。

证明

递推式由连分数的逐层代入直接得到。对行列式做归纳：$k=1$ 时

$$p_1q_0-p_0q_1=(a_1a_0+1)\cdot1-a_0a_1=1=(-1)^0$$

若 $p_kq_{k-1}-p_{k-1}q_k=(-1)^{k-1}$，则

$$p_{k+1}q_k-p_kq_{k+1}=p_{k-1}q_k-p_kq_{k-1}=-(-1)^{k-1}=(-1)^k$$

所以行列式恒为 $\pm1$，分子分母互素。∎

三Pell 方程与收敛分数

定理（Pell 解来自收敛分数）

设 $D$ 为非完全平方正整数，$(x,y)$ 是 $x^2-Dy^2=1$ 的正整数解。则 $x/y$ 是 $\sqrt D$ 的某个收敛分数。

证明

由 $x^2-Dy^2=1$ 得 $(x-\sqrt D y)(x+\sqrt D y)=1$，所以

$$\left|\sqrt D-\frac xy\right|=\frac{1}{y^2\left(\sqrt D+\frac xy\right)}$$

因为 $x/y\gt\sqrt D$，分母大于 $2\sqrt D y^2$，故

$$\left|\sqrt D-\frac xy\right|\lt\frac{1}{2y^2}$$

连分数的“最佳逼近定理”说：若 $|\alpha-p/q|\lt1/(2q^2)$，则 $p/q$ 必是 $\alpha$ 的某个收敛分数。取 $\alpha=\sqrt D$ 即得结论。∎

反过来，Pell 方程的最小解由 $\sqrt D$ 的周期给出。设周期长度为 $L$。若 $L$ 为偶数，第 $L-1$ 个收敛分数给出最小解；若 $L$ 为奇数，第 $L-1$ 个收敛分数给出 $x^2-Dy^2=-1$，把它平方（在 $\mathbb{Z}[\sqrt D]$ 中）就得到最小正解。所有正解都是最小解 $(x_1,y_1)$ 的幂：

$$x_n+y_n\sqrt D=(x_1+y_1\sqrt D)^n,\qquad n=1,2,\dots$$
例 1 $\sqrt2$：最小的 $+1$

求 $x^2-2y^2=1$ 的最小正整数解。

解　$\sqrt2=[1;\overline2]$，收敛分数依次为 $1/1,3/2,7/5,17/12,\dots$。计算：

$$1^2-2\cdot1^2=-1,\qquad3^2-2\cdot2^2=1$$

所以最小解是 $(3,2)$。下一个解是 $(3+2\sqrt2)^2=17+12\sqrt2$，即 $(17,12)$；再下一个是 $(99,70)$。Silverman Ch. 22

例 2 $\sqrt{13}$：奇数周期

求 $x^2-13y^2=1$ 的最小正整数解。

解　$\sqrt{13}=[3;\overline{1,1,1,1,6}]$，周期长度 $L=5$ 为奇数。第 $L-1=4$ 个收敛分数是 $18/5$，而

$$18^2-13\cdot5^2=324-325=-1$$

把它平方：

$$(18+5\sqrt{13})^2=649+180\sqrt{13}$$

所以最小解是 $(649,180)$。验证：$649^2-13\cdot180^2=421201-421200=1$。Burton Ch. 15

算法落地：先用连分数找 $-1$，再平方得到 $+1$

算法落地$x^2-13y^2=1$ 的连分数流水线覆盖：CF 递推 / 收敛分数 / Pell 最小解
需求　求 $x^2-13y^2=1$ 的最小正整数解；要求说清楚“为什么奇数周期要先平方”。
1把 $\sqrt{13}$ 展成周期连分数

$\sqrt{13}=[3;\overline{1,1,1,1,6}]$，周期长度 $L=5$。代码用 $m,d,a$ 三个量迭代，直到 $a=2a_0$。

vector<long long> sqrt_period(long long D) {
    long long a0 = isqrt(D), m = 0, d = 1, a = a0;
    vector<long long> per;
    while (true) {
        m = d * a - m; d = (D - m * m) / d; a = (a0 + m) / d;
        per.push_back(a); if (a == 2 * a0) break;
    }
    return per;   // 13 → 1,1,1,1,6
}
为什么一定会循环？　$\sqrt D$ 的连分数是周期的：三元组 $(m,d,a)$ 只取有限种值，一旦重复就进入循环；对 $\sqrt D$ 而言第一次回到 $a=2a_0$ 就是周期闭合。
2用递推同时生成分子分母

收敛分数 $p_k/q_k$ 满足 $p_k=a_kp_{k-1}+p_{k-2}$、$q_k=a_kq_{k-1}+q_{k-2}$。前几个是 $3/1,4/1,7/2,11/3,18/5,\dots$。

long long pm2 = 0, pm1 = 1, qm2 = 1, qm1 = 0;
for (int k = 0; k <= 2 * L + 1; ++k) {
    long long ak = (k == 0 ? a0 : per[(k - 1) % L]);
    long long p = ak * pm1 + pm2, q = ak * qm1 + qm2;
    if ((__int128)p * p - (__int128)D * q * q == 1) return {p, q};
    pm2 = pm1; pm1 = p; qm2 = qm1; qm1 = q;
}
为什么 Pell 解一定藏在收敛分数里？　由 $x^2-Dy^2=1$ 可推出 $|\sqrt D-x/y|\lt1/(2y^2)$；连分数的最佳逼近定理说，满足这个精度的有理数必是某个收敛分数。所以不需要枚举 $y$，只需顺着收敛分数找。
3奇数周期：先得到 $-1$，平方才变 $+1$

第 $L-1=4$ 个收敛分数是 $18/5$，而 $18^2-13\cdot5^2=-1$。把 $18+5\sqrt{13}$ 平方：

$$(18+5\sqrt{13})^2=(18^2+13\cdot5^2)+2\cdot18\cdot5\sqrt{13}=649+180\sqrt{13}$$

于是 $(649,180)$ 是最小正解。

long long x = 18, y = 5;   // x² - 13y² = -1
long long X = x * x + 13 * y * y;  // 649
long long Y = 2 * x * y;           // 180
// (x + y√D)² = X + Y√D，范数从 -1 变 +1
为什么平方能把 $-1$ 翻成 $+1$？　在 $\mathbb{Z}[\sqrt D]$ 中定义范数 $N(x+y\sqrt D)=x^2-Dy^2$，它满足 $N(\alpha\beta)=N(\alpha)N(\beta)$。$N(18+5\sqrt{13})=-1$，平方后范数变成 $(-1)^2=1$，正好给出 Pell 解。
竞赛用法　Pell 方程用于连分数逼近、无理数有理逼近、以及“最小正整数解可能极大”的构造题。实现时用 __int128 检查 $p^2-Dq^2$，并按周期长度判断是直接取 $L-1$ 还是取 $2L-1$；不要枚举 $y$。
Pell 方程连分数最佳逼近__int128
如果 $D$ 是完全平方数，Pell 方程还有正整数解吗？
引导　没有。设 $D=k^2$，则 $x^2-k^2y^2=(x-ky)(x+ky)=1$。两个整数因子乘积为 $1$，只能同时为 $1$ 或同时为 $-1$，解得 $y=0$，不是正整数解。所以 Pell 方程总要求 $D$ 非平方。

四代码：展开周期并找最小解

代码 1 · √D 的连分数与 Pell 最小解C++17
using ll = long long;
using i128 = __int128_t;

ll isqrt(ll n) {
    ll r = sqrtl((long double)n);
    while ((i128)(r + 1) * (r + 1) <= n) ++r;
    while ((i128)r * r > n) --r;
    return r;
}

// 返回 √D 的周期 [a1,...,aL]
vector<ll> sqrt_period(ll D) {
    ll a0 = isqrt(D), m = 0, d = 1, a = a0;
    vector<ll> per;
    while (true) {
        m = d * a - m;
        d = (D - m * m) / d;
        a = (a0 + m) / d;
        per.push_back(a);
        if (a == 2 * a0) break;
    }
    return per;
}

pair<ll,ll> pell_min(ll D) {
    ll a0 = isqrt(D);
    if (a0 * a0 == D) return {-1, -1};
    vector<ll> per = sqrt_period(D);
    int L = per.size();
    i128 pm2 = 0, pm1 = 1, qm2 = 1, qm1 = 0;
    for (int k = 0; k <= 2 * L + 1; ++k) {
        ll ak = (k == 0) ? a0 : per[(k - 1) % L];
        i128 p = ak * pm1 + pm2;
        i128 q = ak * qm1 + qm2;
        if (p * p - (i128)D * q * q == 1)
            return {(ll)p, (ll)q};
        pm2 = pm1; pm1 = p;
        qm2 = qm1; qm1 = q;
    }
    return {-1, -1};
}

五习题

  1. 求 $x^2-3y^2=1$ 的最小正整数解，并写出下一个解。
    思路　$\sqrt3=[1;\overline{1,2}]$，试收敛分数 $1/1,2/1,5/3,\dots$。
    答案　最小解 $(2,1)$；下一个 $(2+\sqrt3)^2=7+4\sqrt3$，即 $(7,4)$。
  2. 求 $x^2-7y^2=1$ 的最小正整数解。
    思路　$\sqrt7=[2;\overline{1,1,1,4}]$，收敛分数 $2/1,3/1,5/2,8/3$。
    答案　$(8,3)$，因为 $8^2-7\cdot3^2=64-63=1$。
  3. 求 $x^2-5y^2=1$ 的最小正整数解。
    思路　$\sqrt5=[2;\overline4]$，收敛分数 $2/1,9/4$。
    答案　$(9,4)$，因为 $81-5\cdot16=1$。
  4. 证明 $D$ 为完全平方数时，$x^2-Dy^2=1$ 没有正整数解。
    思路　因式分解 $(x-ky)(x+ky)=1$。
    答案　两个整数因子乘积为 $1$，只能同为 $1$ 或同为 $-1$，解得 $y=0$，与 $y\gt0$ 矛盾。
一页纸
  • Pell 方程 $x^2-Dy^2=1$ 要求 $D$ 为非完全平方正整数。
  • $\sqrt D$ 的连分数是周期的；收敛分数由 $p_k=a_kp_{k-1}+p_{k-2}$ 递推。
  • Pell 解一定是 $\sqrt D$ 的收敛分数；最小解由周期长度决定。
  • 所有正解是最小解 $(x_1+y_1\sqrt D)^n$，$n=1,2,\dots$。
  • $D=61$ 的最小解有十位数：不要用枚举，用连分数。
