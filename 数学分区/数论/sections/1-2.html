一最大公因数是一把公共尺子

如果两个整数都能被同一把“尺子”量尽，这把尺子就是公因数。$252$ 与 $105$ 都能被 $21$ 量尽，也都能被 $3$ 量尽；其中最长的那把尺子 $21$，就是最大公因数。数论里几乎所有“约分”“通分”“解一次方程”的问题，最后都会落到这把尺子上。

定义（最大公因数）

设 $a,b\in\mathbb{Z}$，且 $a,b$ 不全为零。若正整数 $d$ 满足 $d\mid a$、$d\mid b$，且任何公因数 $c$ 都满足 $c\le d$，则称 $d$ 为 $a,b$ 的最大公因数，记作 $d=\gcd(a,b)$。若 $\gcd(a,b)=1$，则称 $a,b$ 互素。

定义里“最大”是按数值大小比较的。因为公因数集合有限（它被 $\min(|a|,|b|)$ 限制住），最大公因数一定存在。约定 $\gcd(a,0)=|a|$，这样 Euclid 算法的递归边界可以写得很干净；$\gcd(0,0)$ 没有定义。

推导在知道 Euclid / Bézout 之前需求 → 等价变形 → 组合 → 方程
问题　要求 $\gcd(252,105)$，但不想枚举所有公因数；还希望把 $\gcd$ 写成 $252x+105y$ 的形式，进而解 $240x+46y=2$。这三件事能不能用同一个想法串起来？
1
先做一次带余除法，观察“公因数集合”有没有变

$252=2\cdot105+42$。若 $d$ 同时整除 $252,105$，它当然整除 $42=252-2\cdot105$；反过来，若 $d$ 同时整除 $105,42$，它也整除 $252=2\cdot105+42$。所以

$$\{\text{$252,105$ 的公因数}\}=\{\text{$105,42$ 的公因数}\}$$
关键　最大公因数只由“公因数集合”决定；集合没变，$\gcd$ 就没变。于是可以把大数对换成小数对。
2
重复换对，直到一边变成 $0$

$252\to105\to42\to21\to0$，对应的余数是 $42,21,0$。最后非零余数 $21$ 与 $0$ 的公因数集合是“$21$ 的因数”，最大者就是 $21$。所以 $\gcd(252,105)=21$。

为什么一定会停？　每次余数都严格小于上一轮的除数，且非负；正整数不能无限下降，所以有限步后必出现 $0$。这不是“运气好”，而是良序性在保证终止。
3
反过来问：$\gcd$ 能不能写成 $ax+by$？

把所有 $ax+by$ 的正值收成集合 $S$，取最小元 $d=ax_0+by_0$。用 $d$ 除 $a$：$a=dq+r$，$0\le r\lt d$。而 $r=a-dq=a(1-x_0q)+b(-y_0q)$ 仍是 $a,b$ 的组合；若 $r\gt0$，它比 $d$ 小，违反最小性。所以 $r=0$，$d\mid a$；同理 $d\mid b$。任何公因数都整除 $d$，故 $d=\gcd(a,b)$。

构造的意义　$d$ 不是“先知道 $\gcd$ 再硬凑”，而是“所有线性组合里最小的那个”。这个最小元自动整除 $a,b$，所以它就是最大公因数。
4
再往前一步：$ax+by=c$ 什么时候有解？

任何 $ax+by$ 都被 $g=\gcd(a,b)$ 整除，所以 $g\mid c$ 是必要条件。反过来，若 $c=gk$，把 Bézout 等式 $ax_0+by_0=g$ 两边乘 $k$ 就得到一组解。两组解相减得到 $a\Delta x+b\Delta y=0$，除以 $g$ 后 $\frac ag$ 与 $\frac bg$ 互素，于是步长只能是 $(\frac bg,-\frac ag)$。

验证　必要、充分、通解三步都齐了；所以一次不定方程的解结构完全由 $g$ 和一组特解决定。
于是我们得到三件互相咬合的事：Euclid 算法给出 $g$，Bézout 把 $g$ 写成组合，一次不定方程用这个组合放大求解。下面依次写成三个定理并证明。
定理（Euclid 算法的正确性）

设 $a,b\in\mathbb{Z}$，$b\ne0$，写 $a=bq+r$，其中 $0\le r\lt |b|$。则

$$\gcd(a,b)=\gcd(b,r)$$
证明

设 $d$ 是 $a,b$ 的公因数，则 $d\mid b$，且由 $r=a-bq$ 与整除对线性组合封闭，$d\mid r$。所以 $d$ 也是 $b,r$ 的公因数。

反过来，若 $d$ 是 $b,r$ 的公因数，则由 $a=bq+r$ 得 $d\mid a$，所以 $d$ 也是 $a,b$ 的公因数。两边的公因数集合完全相同，因此最大公因数相同。∎

这条定理把“大数对”换成了“小数对”：$(252,105)\to(105,42)\to(42,21)\to(21,0)$。每一步余数都严格变小，最终必然到 $0$；最后一个非零余数就是 $\gcd$。这个过程可以画成用正方形铺满长方形：每次用短边作正方形，剩下的窄条继续铺。

代码 1 · 递归版 Euclid 算法C++17
long long gcd(long long a, long long b) {
    if (b == 0) return a;      // gcd(a,0)=|a|
    return gcd(b, a % b);        // 余数严格变小
}

// 非递归版：空间 O(1)，适合常数敏感的场景
long long gcd_iter(long long a, long long b) {
    while (b) {
        long long r = a % b;
        a = b; b = r;
    }
    return a < 0 ? -a : a;
}
复杂度

每两步余数至少减半，因此递归层数是 $O(\log\min(|a|,|b|))$。最坏情形出现在相邻 Fibonacci 数：$\gcd(F_{n+1},F_n)$ 需要 $n$ 层左右。这个“最坏输入”后面还会在连分数与 Pell 方程里再次出现。

二Bézout 恒等式：把公共尺子写成组合

Euclid 算法只告诉我们 $\gcd$ 是多少，没有告诉我们它和 $a,b$ 的代数关系。Bézout 恒等式补上这一块：最大公因数不仅能整除 $a,b$，还能被写成 $a,b$ 的整系数线性组合。

定理（Bézout 恒等式）

设 $a,b\in\mathbb{Z}$ 不全为零，$g=\gcd(a,b)$。则存在整数 $x,y$，使得

$$ax+by=g$$

并且 $g$ 是 $a,b$ 的所有正线性组合中最小的那个。

证明

考虑集合 $S=\{ax+by: x,y\in\mathbb{Z},\ ax+by\gt0\}$。取 $x=a,y=b$ 可知 $a^2+b^2\in S$，所以 $S$ 非空。由良序原理，$S$ 有最小元 $d=ax_0+by_0$。

用带余除法写 $a=dq+r$，$0\le r\lt d$。则

$$r=a-dq=a(1-x_0q)+b(-y_0q)$$

也是 $a,b$ 的线性组合。若 $r\gt0$，它就在 $S$ 中且比 $d$ 小，矛盾；故 $r=0$，即 $d\mid a$。同理 $d\mid b$，所以 $d$ 是公因数。

另一方面，任何公因数 $c$ 都整除 $a,b$，从而整除 $ax_0+by_0=d$，故 $c\le d$。因此 $d=\gcd(a,b)$。∎

这个证明还有一个可操作的版本：把 Euclid 算法的每一步倒着代回去，就能把最后的余数写成最初的 $a,b$ 的组合。这就是扩展 Euclid 算法（exgcd）。

代码 2 · 扩展 Euclid：同时求 g、x、yC++17
// 返回 gcd(a,b)，并令 a*x + b*y = g（a,b 非负）
long long exgcd(long long a, long long b,
               long long& x, long long& y) {
    if (b == 0) {
        x = 1; y = 0;          // a*1 + 0*0 = a
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;                    // 由 b*x1 + (a%b)*y1 = g 回代
    y = x1 - (a / b) * y1;
    return g;
}

// 调用示例：exgcd(240, 46, x, y) 得到 g=2, x=-9, y=47

三线性丢番图方程

定理（一次不定方程）

设 $a,b,c\in\mathbb{Z}$，$a,b$ 不全为零，$g=\gcd(a,b)$。方程 $ax+by=c$ 有整数解，当且仅当 $g\mid c$。若有解 $(x_0,y_0)$，则全部解为

$$x=x_0+\frac{b}{g}t,\qquad y=y_0-\frac{a}{g}t,\qquad t\in\mathbb{Z}$$
证明

必要性。任何 $ax+by$ 都被 $g$ 整除，所以 $c$ 也必须被 $g$ 整除。

充分性。由 Bézout 恒等式取 $u,v$ 使 $au+bv=g$。若 $c=gk$，则 $a(uk)+b(vk)=c$，得到一组解。

通解。设 $(x_0,y_0)$ 是一组解。若 $(x,y)$ 也是解，相减得 $a(x-x_0)+b(y-y_0)=0$。两边除以 $g$，得 $\frac ag(x-x_0)=-\frac bg(y-y_0)$。因为 $\gcd(a/g,b/g)=1$，所以 $\frac bg\mid (x-x_0)$，写 $x-x_0=\frac bg t$，代回即得 $y-y_0=-\frac ag t$。∎

通解的结构值得画出来：$(x,y)$ 沿着方向向量 $(\frac bg,-\frac ag)$ 等距滑动。所有整数解是平面上一条直线上等间隔的点，间隔由 $a,b$ 除以 $g$ 后决定。

例 1 先化到互素，再回代

解方程 $240x+46y=2$。

解　先做 Euclid：

$$240=5\cdot46+10,\quad 46=4\cdot10+6,\quad 10=1\cdot6+4,\quad 6=1\cdot4+2$$

回代：

$$2=6-4=2\cdot6-10=2\cdot46-9\cdot10=47\cdot46-9\cdot240$$

所以一组解是 $x_0=-9,\ y_0=47$。通解为

$$x=-9+23t,\qquad y=47-120t,\qquad t\in\mathbb{Z}$$

验证：$240(-9)+46(47)=-2160+2162=2$。Burton Ch. 2

例 2 最大公因数与方程的可解性

求 $\gcd(2024,748)$，并判断 $2024x+748y=44$ 是否有整数解。

解　连续取余：

$$2024=2\cdot748+528,\quad 748=1\cdot528+220,\quad 528=2\cdot220+88$$ $$220=2\cdot88+44,\quad 88=2\cdot44+0$$

最后一个非零余数是 $44$，故 $\gcd(2024,748)=44$。因为 $44\mid44$，方程有解；两边除以 $44$ 得 $46x+17y=1$，可用 exgcd 求出一组特解后再写通解。潘承洞《数论基础》第一章

算法落地：从取余到“解出 $240x+46y=2$”

算法落地Euclid → exgcd → 一次不定方程覆盖：Euclid 正确性 / Bézout / 通解结构
需求　求 $\gcd(240,46)$，并解 $240x+46y=2$；最后写出全部整数解。
1先只保留“余数”，把两个大数压小
$$240=5\cdot46+10,\quad46=4\cdot10+6,\quad10=1\cdot6+4,\quad6=1\cdot4+2,\quad4=2\cdot2+0$$

最后一个非零余数是 $2$，所以 $\gcd(240,46)=2$。

long long gcd(long long a, long long b) {
    while (b) { long long r = a % b; a = b; b = r; }
    return a;
}   // gcd(240,46) = 2
为什么可以丢掉商？　因为 $a=bq+r$ 中，任何同时整除 $a,b$ 的数也整除 $r$，反之亦然。公因数集合没变，所以最大公因数没变；商只影响“怎么走到下一步”，不影响终点。
2把余数倒着代回去，得到 Bézout 系数

从 $2=6-4$ 开始，把每个余数用它上面的式子替换，最后得到

$$2=47\cdot46-9\cdot240$$

即 $x=-9,\ y=47$ 是 $240x+46y=2$ 的一组特解。

long long exgcd(long long a, long long b,
             long long& x, long long& y) {
    if (!b) { x = 1; y = 0; return a; }
    long long x1, y1, g = exgcd(b, a % b, x1, y1);
    x = y1; y = x1 - (a / b) * y1;
    return g;
}   // 返回 g=2, x=-9, y=47
回代公式为什么长这样？　递归层已经保证 $b x_1+(a\bmod b)y_1=g$。把 $a\bmod b=a-(a/b)b$ 代进去，整理成 $a y_1+b(x_1-(a/b)y_1)=g$，所以新的系数就是 $x=y_1$、$y=x_1-(a/b)y_1$。这不是背公式，而是把上一层等式改写成当前层的形式。
3从一组特解滑到全部解

特解 $(-9,47)$ 只满足一个点；通解让 $x$ 每次加 $46/2=23$，$y$ 相应减 $240/2=120$：

$$x=-9+23t,\qquad y=47-120t,\qquad t\in\mathbb{Z}$$ 
long long g = exgcd(a, b, x, y);
if (c % g) { /* 无解 */ }
x *= c / g; y *= c / g;          // 先放大到 c
long long dx = b / g, dy = a / g;  // x += dx, y -= dy
为什么步长是 $b/g$ 与 $a/g$？　为了让 $a\Delta x+b\Delta y=0$。两边除以 $g$ 后 $\frac ag$ 与 $\frac bg$ 互素，最小的整数步长只能是 $\Delta x=\frac bg$、$\Delta y=-\frac ag$。走更小的一步就不再是整数解。
竞赛用法　exgcd 是模逆、线性同余、一次不定方程的同一套底层工具：把 $ax\equiv1\pmod m$ 写成 $ax+my=1$ 即可。求通解时要注意把系数放大到 $c$ 后再取模归一；若 $|a|,|b|$ 很大，乘法用 __int128，并优先把方程除以 $g$ 降低规模。
模逆一次不定方程exgcd通解步长
如果 $\gcd(a,b)\nmid c$，方程无解；那么“无解”能否用同余语言重新表述？
引导　可以。把 $ax+by=c$ 模 $b$ 看，得到 $ax\equiv c\pmod b$。一次不定方程与一次同余方程是同一件事的两种写法，下一章会把它们完全接起来。

四习题

  1. 用 Euclid 算法求 $\gcd(2024,748)$，并用 exgcd 求出一组 $x,y$ 使 $2024x+748y=44$。
    思路　先除以 $44$ 化到 $46x+17y=1$；对 $46,17$ 回代，再把系数乘回 $44$。
    答案　$46=2\cdot17+12$，$17=1\cdot12+5$，$12=2\cdot5+2$，$5=2\cdot2+1$。回代得 $1=19\cdot17-7\cdot46$，故 $x=-7,\ y=19$ 是原方程的一组解。
  2. 解 $17x+13y=1$，写出全部整数解。
    思路　$17=1\cdot13+4$，$13=3\cdot4+1$，回代。
    答案　$1=4\cdot13-3\cdot17$，特解 $x=-3,y=4$；通解 $x=-3+13t,\ y=4-17t$。
  3. 证明 $\gcd(a,b)=\gcd(a,a+b)$。
    思路　证明两边的公因数集合相同：$d\mid a,b\iff d\mid a,a+b$。
    答案　若 $d\mid a,b$，则 $d\mid a+b$；反之若 $d\mid a,a+b$，则 $d\mid (a+b)-a=b$。公因数集合相同，最大者相同。
  4. 设 $m,n$ 为正整数，证明 $\gcd(2^m-1,2^n-1)=2^{\gcd(m,n)}-1$。
    思路　对 $m,n$ 做 Euclid 算法，利用 $2^m-1$ 除以 $2^n-1$ 的余数对应 $2^{m\bmod n}-1$。
    答案　设 $m=qn+r$，则 $2^m-1=(2^n-1)(2^{m-n}+2^{m-2n}+\cdots)+2^r-1$，故两数的 gcd 与 $\gcd(2^n-1,2^r-1)$ 相同。对指数做 Euclid 即得结论。
一页纸
  • $\gcd(a,b)=\gcd(b,a\bmod b)$；最后一个非零余数就是 $\gcd$。
  • Bézout：存在 $x,y$ 使 $ax+by=\gcd(a,b)$；exgcd 同时返回 $g,x,y$。
  • $ax+by=c$ 有解 $\iff \gcd(a,b)\mid c$。
  • 通解沿 $(\frac bg,-\frac ag)$ 等间隔滑动：$x=x_0+\frac bg t,\ y=y_0-\frac ag t$。
  • Euclid 算法最坏输入是相邻 Fibonacci 数，复杂度 $O(\log\min(|a|,|b|))$。
