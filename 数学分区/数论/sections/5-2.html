一猜想是怎样诞生的

数论里有大量“看起来显然、证起来极难”的命题。Goldbach 在 1742 年写信给 Euler：每个大于 $2$ 的偶数是否都能写成两个素数之和？今天计算机已经验证到极其巨大的范围，但没有人给出证明。孪生素数猜想问是否存在无穷多对相差 $2$ 的素数；Collatz 问题问一个简单的分段递推是否总能把正整数带到 $1$。三条问题都只需要四则运算就能陈述，却都还没有完整答案。

定义（猜想、反例、启发式）

猜想是尚未证明或反驳的数学命题。反例是使猜想为假的一个具体实例；找到一个反例就足以否定全称命题。启发式是用概率、密度或局部规律给出的“应该成立”的理由，它不是证明。

计算在数论里有两个正确用途：发现规律，以及检验猜想的小范围情形。它不能替代证明，因为一个全称命题要求对所有整数成立，而程序只检查了有限个。反过来，一个反例可以瞬间结束争论：$9$ 就足以否定“所有大于 $1$ 的奇数都是素数”。

二Goldbach：把偶数拆成两个素数

猜想（强 Goldbach）

每个大于 $2$ 的偶数 $n$ 都可以写成 $n=p+q$，其中 $p,q$ 都是素数。

把偶数从小到大排开，数一数每种拆法的个数，会得到一张不规则的柱状图。$4=2+2$ 只有一种，$10=3+7=5+5$ 有两种，$100$ 有六种。柱子高度整体上升，但局部会上下波动；这正是“启发式”喜欢的形状，却不是证明。

例 1 $100$ 的六种拆法

把 $100$ 写成两个素数之和，列出所有不计顺序的拆法。

解　从小到大试 $p\le50$，检查 $p$ 与 $100-p$ 是否都为素数：

$$100=3+97=11+89=17+83=29+71=41+59=47+53$$

共 $6$ 种。注意 $100=53+47$ 与 $47+53$ 视为同一种，因为加法交换。

代码 1 · 验证 Goldbach 到 NC++17
vector<bool> prime_table(int N) {
    vector<bool> isp(N + 1, true);
    isp[0] = isp[1] = false;
    for (int i = 2; 1LL * i * i <= N; ++i)
        if (isp[i])
            for (long long j = 1LL * i * i; j <= N; j += i) isp[j] = false;
    return isp;
}

bool check_goldbach(int N) {
    vector<bool> isp = prime_table(N);
    for (int n = 4; n <= N; n += 2) {
        bool ok = false;
        for (int p = 2; p <= n / 2; ++p) {
            if (isp[p]) {
                if (isp[n - p]) { ok = true; break; }
            }
        }
        if (!ok) {
            cout << "counterexample: " << n << '\n';
            return false;
        }
    }
    return true;
}

三孪生素数与“任意长合数段”

猜想（孪生素数）

存在无穷多对素数 $(p,p+2)$。

$ (3,5),(5,7),(11,13),(17,19),(29,31)$ 都是孪生素数。与它相邻的一个命题却可以被证明：素数之间的间隔可以任意大，也就是说，存在任意长的连续合数段。证明只用阶乘。

定理（任意长合数段）

对任意正整数 $k$，存在 $k$ 个连续的正整数，它们全都是合数。

证明

令 $N=(k+1)!$，考虑

$$N+2,\ N+3,\ \dots,\ N+(k+1)$$

对每个 $j=2,3,\dots,k+1$，$j\mid N$ 且 $j\mid j$，所以 $j\mid(N+j)$。又 $N+j\gt j$，故 $N+j$ 有真因子 $j$，是合数。这 $k$ 个数连续，证明完成。∎

这条定理说明“素数会变得稀疏”，但它并不回答“是否存在无穷多对间隔为 $2$ 的素数”。任意长间隔与无穷多短间隔可以同时为真：整体越稀疏，局部仍可能反复出现孪生对。这正是数论猜想最难的地方——局部构造不能直接控制全局分布。

四Collatz：简单规则，难倒所有人

问题（Collatz）

从正整数 $n$ 出发，若 $n$ 为偶数则令 $n\leftarrow n/2$，若 $n$ 为奇数则令 $n\leftarrow3n+1$。是否从任何正整数出发，最终都会到达 $1$？

$27$ 是一个著名的“反直觉”例子：它一路冲到 $9232$，经过 $111$ 步才回到 $1$。这给了猜想很强的数值支持，但没有解释为什么所有数都会停。有人验证了极大的范围，仍然只是有限个起点。

例 2 $27$ 的 Collatz 轨迹

写出 $27$ 的前若干项，并说明为什么它不能作为证明。

解　前若干项为

$$\begin{aligned} 27&\to82\to41\to124\to62\to31\to94\to47\\ &\to142\to71\to214\to107\to322\to161\to484\to242\\ &\to121\to364\to182\to91\to\cdots \end{aligned}$$

最终到 $1$，共 $111$ 步，途中最大值 $9232$。

这只是“从 $27$ 出发”的一条轨道。猜想要求“从所有正整数出发”，有限条轨道无论多少条，都不能覆盖无限多个起点。Silverman Ch. 1

为什么一个反例就能否定猜想，而一万个验证实例却不能证明它？
引导　全称命题“对所有 $n$ 成立”要求无限多个情形；一个反例就足以让它为假，而有限个实例永远只覆盖有限个 $n$。这就是“否定靠反例、确认靠证明”的不对称性。

五习题

  1. 写出 $28,30,32$ 的全部 Goldbach 拆法（不计顺序）。
    思路　从 $p=3$ 开始试到 $n/2$，检查 $n-p$ 是否素数。
    答案　$28=5+23=11+17$；$30=7+23=11+19=13+17$；$32=3+29=13+19$。
  2. 用 $8!$ 构造 $7$ 个连续合数。
    思路　取 $N=8!$，看 $N+2$ 到 $N+8$。
    答案　$40322,40323,\dots,40328$；对 $j=2,\dots,8$，$j\mid8!$ 且 $j\mid j$，故 $j\mid(8!+j)$。
  3. 在 $[2,200]$ 中找出一段长度至少 $10$ 的素数间隔。
    思路　列出素数，找相邻差；第一个大于等于 $10$ 的间隔在 $113$ 与 $127$ 之间。
    答案　$113$ 与 $127$ 之间没有素数，间隔为 $14$；$114$ 到 $126$ 全是合数。
  4. “所有大于 $1$ 的奇数都是素数”这句话的反例是什么？一个反例能说明什么？
    思路　最小的奇合数。
    答案　$9=3\cdot3$。一个反例就足以否定全称命题；它不需要“很多个”，只需要一个确实满足条件却使结论失败的实例。
  5. 程序验证 Goldbach 到 $10^{12}$ 是否等于证明了猜想？
    思路　区分有限验证与全称命题。
    答案　不等于。它排除了 $10^{12}$ 以内的反例，但猜想要求所有大于 $2$ 的偶数；有限个实例不能覆盖无限多个。
一页纸
  • 猜想需要证明或反例；有限数值验证既不能证明，也不能代替反例。
  • Goldbach：每个大于 $2$ 的偶数都是两个素数之和；$100$ 有 $6$ 种拆法。
  • 孪生素数猜想仍未解决；但“任意长合数段”可以用 $(k+1)!$ 构造证明。
  • Collatz：$27$ 需要 $111$ 步到 $1$，最大值 $9232$；一条轨道不是证明。
  • 发现靠计算，确认靠证明，否定靠反例——三种力量不能互相替代。
