一数论函数与积性

定义（数论函数与积性）

定义在正整数上、取值在复数（实际题目中通常是整数）中的函数称为数论函数。若对任意 $\gcd(m,n)=1$ 都有

$$f(mn)=f(m)f(n)$$

则称 $f$ 为积性函数；若对任意 $m,n$ 都有 $f(mn)=f(m)f(n)$，则称完全积性。

积性只要求在互素时“可拆”。这条限制刚好匹配算术基本定理：$n=p_1^{a_1}\cdots p_k^{a_k}$ 的各个素幂两两互素，所以积性函数的值完全由它在素幂上的取值决定。只要知道 $f(p^a)$，就能算出 $f(n)$。

函数定义素幂上的值类型
$\tau(n)$$n$ 的正约数个数$\tau(p^a)=a+1$积性
$\sigma(n)$$n$ 的正约数之和$\sigma(p^a)=1+p+\cdots+p^a$积性
$\varphi(n)$$1,\dots,n$ 中与 $n$ 互素的个数$\varphi(p^a)=p^a-p^{a-1}$积性
$\mu(n)$Möbius 函数（§3.2）$\mu(p)=-1,\ \mu(p^a)=0\ (a\ge2)$积性
$\operatorname{id}(n)$$n$$p^a$完全积性
推导在知道“约数和的积性”之前实验 → 笛卡尔积 → 求和拆分 → 定理
问题　$\tau(12)=6$，而 $\tau(4)=3$、$\tau(3)=2$，恰好 $6=3\cdot2$。这是巧合吗？能不能把 $12$ 的约数表拆成 $4$ 的约数与 $3$ 的约数两列，从而把求和也拆开？
1
先把 $12$ 的约数排成一张表

$4$ 的约数是 $1,2,4$，$3$ 的约数是 $1,3$。两两相乘得到

$$1,3;\quad2,6;\quad4,12$$

正好是 $12$ 的全部 $6$ 个约数，且没有重复。原因是 $\gcd(4,3)=1$：若 $d_1d_2=d_1'd_2'$，则 $d_1/d_1'=d_2'/d_2$，左边只含 $2$ 的因子、右边只含 $3$ 的因子，只能都等于 $1$。

2
把“约数和”按这张表重排

对积性函数 $f$，

$$\sum_{d\mid12}f(d)=\sum_{d_1\mid4}\sum_{d_2\mid3}f(d_1d_2)=\sum_{d_1\mid4}\sum_{d_2\mid3}f(d_1)f(d_2)$$

右边可以继续拆成 $\left(\sum_{d_1\mid4}f(d_1)\right)\left(\sum_{d_2\mid3}f(d_2)\right)$。所以 $F(12)=F(4)F(3)$。

关键　“互素”保证了笛卡尔积不重不漏；$f$ 的积性保证了 $f(d_1d_2)$ 能拆成 $f(d_1)f(d_2)$。两个条件各管一半。
3
把 $12$ 换成一般的 $mn$，猜出定理

若 $\gcd(m,n)=1$，$mn$ 的每个约数唯一写成 $d_1d_2$（$d_1\mid m,d_2\mid n$）。于是双重求和可以分离，得到 $F(mn)=F(m)F(n)$。取 $f=1$ 得 $\tau$ 积性，取 $f(n)=n$ 得 $\sigma$ 积性，取 $f=\varphi$ 得 $\sum_{d\mid n}\varphi(d)$ 积性。

验证　$\tau(12)=\tau(4)\tau(3)=3\cdot2=6$；$\sigma(12)=\sigma(4)\sigma(3)=7\cdot4=28$。与直接枚举一致。
于是我们得到：积性函数在互素块上可以“先拆约数、再拆求和”。下面把它写成定理并证明。
定理（约数和的积性）

若 $f$ 是积性函数，则

$$F(n)=\sum_{d\mid n}f(d)$$

也是积性函数。

证明

设 $\gcd(m,n)=1$。$mn$ 的每个约数 $d$ 都能唯一写成 $d=d_1d_2$，其中 $d_1\mid m$，$d_2\mid n$：取 $d_1=\gcd(d,m)$、$d_2=\gcd(d,n)$ 即可，唯一性由互素保证。

于是

$$F(mn)=\sum_{d_1\mid m}\sum_{d_2\mid n}f(d_1d_2)=\sum_{d_1\mid m}\sum_{d_2\mid n}f(d_1)f(d_2)=F(m)F(n)$$

最后一步用了 $f$ 的积性与乘法分配律。∎

把定理用在 $f(n)=1$ 上，得到 $\tau(n)=\sum_{d\mid n}1$ 是积性的；用在 $f(n)=n$ 上，得到 $\sigma(n)$ 是积性的；用在 $f(n)=\varphi(n)$ 上，得到 $\sum_{d\mid n}\varphi(d)$ 是积性的。配合算术基本定理，就得到三个常用公式：

$$\tau(n)=\prod_{i=1}^k(a_i+1),\qquad \sigma(n)=\prod_{i=1}^k\frac{p_i^{a_i+1}-1}{p_i-1},\qquad \varphi(n)=n\prod_{i=1}^k\left(1-\frac1{p_i}\right)$$

二线性筛：一次求出所有函数值

有了公式，逐个分解再求值需要 $O(n\sqrt n)$ 或 $O(n\log n)$。线性筛可以在 $O(n)$ 内递推出所有值：每个合数 $m=i\cdot p$ 只在它的最小素因子 $p$ 处被标记，我们就在这一刻用 $i$ 的函数值推出 $m$ 的函数值。关键是分两种情况：$p$ 是否已经出现在 $i$ 的分解中。

代码 1 · 线性筛同时求 φ、μ、τ、σC++17
const int N = 1000000;
vector<int> lp(N + 1), primes;
vector<int> phi(N + 1), mu(N + 1), tau(N + 1), cnt(N + 1);
vector<long long> sig(N + 1), low(N + 1), ppow(N + 1);

void build() {
    phi[1] = mu[1] = tau[1] = 1;
    sig[1] = low[1] = ppow[1] = 1;
    for (int i = 2; i <= N; ++i) {
        if (lp[i] == 0) {                 // i 是素数
            lp[i] = i; primes.push_back(i);
            phi[i] = i - 1; mu[i] = -1;
            tau[i] = 2; cnt[i] = 1;
            ppow[i] = i; low[i] = i + 1; sig[i] = i + 1;
        }
        for (int p : primes) {
            long long m = 1LL * i * p;
            if (p > lp[i] || m > N) break;
            lp[m] = p;
            if (p == lp[i]) {             // p 已经整除 i
                phi[m] = phi[i] * p;
                mu[m] = 0;
                cnt[m] = cnt[i] + 1;
                tau[m] = tau[i] / (cnt[i] + 1) * (cnt[i] + 2);
                ppow[m] = ppow[i] * p;
                low[m] = low[i] + ppow[m];
                sig[m] = sig[i] / low[i] * low[m];
            } else {                       // p 是新素数
                phi[m] = phi[i] * (p - 1);
                mu[m] = -mu[i];
                cnt[m] = 1;
                tau[m] = tau[i] * 2;
                ppow[m] = p; low[m] = p + 1;
                sig[m] = sig[i] * (p + 1);
            }
        }
    }
}

三例题

例 1 三个函数一起算

设 $n=360=2^3\cdot3^2\cdot5$，求 $\tau(n)$、$\sigma(n)$、$\varphi(n)$。

解　分别用三个公式：

$$\tau(360)=(3+1)(2+1)(1+1)=24$$ $$\sigma(360)=(1+2+4+8)(1+3+9)(1+5)=15\cdot13\cdot6=1170$$ $$\varphi(360)=360\left(1-\frac12\right)\left(1-\frac13\right)\left(1-\frac15\right)=360\cdot\frac12\cdot\frac23\cdot\frac45=96$$

三个结果互相独立：约数个数数的是“指数选择”，约数和算的是“等比和”，$\varphi$ 数的是“不与 $n$ 共享素因子”的数。NZM §4.1

例 2 用积性验证恒等式

验证 $\sum_{d\mid12}\varphi(d)=12$。

解　$12$ 的正约数是 $1,2,3,4,6,12$，对应的 $\varphi$ 值为

$$1,1,2,2,2,4$$

相加得 $1+1+2+2+2+4=12$。这不是巧合：$F(n)=\sum_{d\mid n}\varphi(d)$ 是积性的，且 $F(p^a)=1+(p-1)+(p^2-p)+\cdots+(p^a-p^{a-1})=p^a$，所以 $F(n)=n$。

算法落地：用 $12$ 把四个函数一次算清

算法落地$\varphi(12),\mu(12),\tau(12),\sigma(12)$ 与线性筛覆盖：积性 / 三个公式 / 线性筛递推
需求　不逐个枚举约数，用 $12=2^2\cdot3$ 算出 $\varphi,\mu,\tau,\sigma$；再说明线性筛怎样在 $O(n)$ 内一次求出所有值。
1先把 $12$ 拆成素幂，再让四个函数各取所需

$12=2^2\cdot3^1$，所以

$$\varphi(12)=12\left(1-\frac12\right)\left(1-\frac13\right)=4,\qquad \mu(12)=0\ \text{（有平方因子）}$$ $$\tau(12)=(2+1)(1+1)=6,\qquad \sigma(12)=(1+2+4)(1+3)=28$$ 
// 12 的约数：1,2,3,4,6,12
// φ：与 12 互素的是 1,5,7,11 → 4 个
// μ：12 含 2²，直接为 0
// τ：指数 (2,1) → (2+1)(1+1)=6
// σ：(1+2+4)(1+3)=28
为什么同一个分解能喂四个函数？　因为它们都是积性的：函数在互素的块上可以相乘，而素幂部分只需看指数。分解式就是“把整数变成指数向量”，不同函数只是在这个向量上做不同的乘法。
2线性筛：每个合数只在最小素因子处被算一次

当 $m=i\cdot p$ 且 $p$ 是 $m$ 的最小素因子时，分两种情况：$p\mid i$（指数加一）或 $p\nmid i$（新素数）。

if (p == lp[i]) {          // p 已在 i 中
    phi[i * p] = phi[i] * p;
    mu[i * p] = 0;
    tau[i * p] = tau[i] / (cnt[i] + 1) * (cnt[i] + 2);
} else {                    // p 是新素数
    phi[i * p] = phi[i] * (p - 1);
    mu[i * p] = -mu[i];
    tau[i * p] = tau[i] * 2;
}
为什么只改一个素幂？　$m$ 与 $i$ 只差一个素因子 $p$。若 $p$ 已在 $i$ 中，只有 $p$ 的指数变；若 $p$ 是新的，就多一个 $(p-1)$ 或乘 $2$ 的因子。其余素因子的贡献原封不动，所以可以 $O(1)$ 递推。
3把函数值做成前缀和，回答区间查询
for (int i = 1; i <= N; ++i) {
    pre_phi[i] = pre_phi[i - 1] + phi[i];
    pre_mu[i]  = pre_mu[i - 1] + mu[i];
}
为什么竞赛里要预筛而不是每次分解？　如果询问 $10^5$ 次、每次 $n\le10^7$，逐个分解是 $10^5\sqrt n$；线性筛一次 $O(N)$，之后每次查询 $O(1)$ 或 $O(\sqrt n)$ 分块。把“重复计算”换成“一次预处理”，是数论题最常用的交换。
竞赛用法　$\varphi$ 用于模逆与降幂，$\mu$ 用于反演，$\tau/\sigma$ 用于约数计数与求和。线性筛同时维护 $lp,cnt,ppow,low$ 等辅助数组，就能一次求出多个积性函数；若只要单点值，直接分解更快。
线性筛积性函数前缀和O(n) 预处理
为什么线性筛里必须限制 $p\le \operatorname{lp}(i)$？如果允许更大的 $p$，会重复标记吗？
引导　会。若 $p\gt\operatorname{lp}(i)$，则 $i\cdot p$ 的最小素因子是 $\operatorname{lp}(i)$，不是 $p$。这个合数应该在更小的素因子处被标记；在这里再标一次就违反了“每个合数只标一次”的不变量。

四习题

  1. 对 $2024=2^3\cdot11\cdot23$，求 $\tau(2024)$、$\sigma(2024)$、$\varphi(2024)$。
    思路　直接套三个公式；注意 $2024$ 的素因子是 $2,11,23$。
    答案　$\tau=4\cdot2\cdot2=16$；$\sigma=15\cdot12\cdot24=4320$；$\varphi=2024\cdot\frac12\cdot\frac{10}{11}\cdot\frac{22}{23}=880$。
  2. 证明 $\tau(n)$ 为奇数当且仅当 $n$ 是完全平方数。
    思路　$\tau(n)=\prod(a_i+1)$ 为奇数，等价于每个 $a_i+1$ 都是奇数。
    答案　每个 $a_i+1$ 为奇数 $\iff$ 每个 $a_i$ 为偶数 $\iff$ $n$ 是平方数。约数通常成对 $d\leftrightarrow n/d$，只有 $d=\sqrt n$ 时落单，也给出同一结论。
  3. 用线性筛的递推式，手算 $\varphi(12)$、$\mu(12)$、$\tau(12)$。
    思路　$12=2^2\cdot3$；沿 $4\to12$ 或 $6\to12$ 的路径检查两种分支。
    答案　$12=2^2\cdot3$，$\varphi(12)=12\cdot\frac12\cdot\frac23=4$，$\mu(12)=0$（有平方因子），$\tau(12)=(2+1)(1+1)=6$。
  4. 设 $f$ 是积性函数且不恒为 $0$，证明 $f(1)=1$。
    思路　用 $f(1)=f(1\cdot1)=f(1)^2$。
    答案　$f(1)=f(1)^2$，所以 $f(1)=0$ 或 $1$。若 $f(1)=0$，则对任意 $n$，$f(n)=f(1\cdot n)=f(1)f(n)=0$，与不恒为 $0$ 矛盾；故 $f(1)=1$。
一页纸
  • 积性：$\gcd(m,n)=1\Rightarrow f(mn)=f(m)f(n)$；完全积性不要求互素。
  • $\tau(n)=\prod(a_i+1)$，$\sigma(n)=\prod\frac{p_i^{a_i+1}-1}{p_i-1}$，$\varphi(n)=n\prod(1-\frac1{p_i})$。
  • 若 $f$ 积性，则 $F(n)=\sum_{d\mid n}f(d)$ 也积性。
  • 线性筛在 $m=i\cdot p$ 处递推；分 $p\mid i$ 与 $p\nmid i$ 两种情形。
  • $\sum_{d\mid n}\varphi(d)=n$；这是 Möbius 反演前最重要的恒等式。
