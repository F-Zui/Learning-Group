同余、逆元与中国剩余定理

把“余数相同”变成一种可以加减乘的等价关系；学完能解线性同余、求模逆，并用 CRT 把多个模条件合并成一个。

第 2 章 · 同余 难度 ●●○ 前置：§1.2 Bézout 恒等式 关键词：同余 · 模逆 · 中国剩余定理

一同余是带标签的等式

钟表是最好的同余模型：$10$ 点再过 $4$ 小时是 $2$ 点，不是因为 $10+4=2$，而是因为 $14$ 与 $2$ 相差 $12$ 的倍数。把“相差一个模数的倍数”写成等价关系，就得到同余。

定义（同余）

设 $m\in\mathbb{Z}_{\gt 0}$，$a,b\in\mathbb{Z}$。若 $m\mid(a-b)$，则称 $a$ 与 $b$ 模 $m$ 同余，记作

$$a\equiv b\pmod m$$

否则称 $a$ 与 $b$ 模 $m$ 不同余。模 $m$ 同余把所有整数分成 $m$ 个剩余类，每个类记作 $[a]_m=\{a+km:k\in\mathbb{Z}\}$。

同余是等价关系：自反、对称、传递。它比普通等号“粗”，但在加法与乘法下表现良好。若 $a\equiv b\pmod m$ 且 $c\equiv d\pmod m$，则

$$a+c\equiv b+d\pmod m,\qquad ac\equiv bd\pmod m$$
证明

由假设写 $a-b=mx$，$c-d=my$，其中 $x,y\in\mathbb{Z}$。则

$$(a+c)-(b+d)=(a-b)+(c-d)=m(x+y)$$

所以加法同余成立。乘法方面，

$$ac-bd=a(c-d)+d(a-b)=a(my)+d(mx)=m(ay+dx)$$

所以 $ac\equiv bd\pmod m$。∎

易错

同余式不能随便约去公因子。例如 $2\cdot3\equiv2\cdot1\pmod4$，但 $3\not\equiv1\pmod4$。只有当 $\gcd(c,m)=1$ 时，才能由 $ac\equiv bc\pmod m$ 推出 $a\equiv b\pmod m$。更一般地，可以约去 $c$，但模数要同时除以 $\gcd(c,m)$。

二线性同余与逆元

定理（线性同余的可解性）

设 $m\gt0$，$g=\gcd(a,m)$。同余方程 $ax\equiv b\pmod m$ 有解，当且仅当 $g\mid b$。若有解，则它在模 $m$ 下恰有 $g$ 个不同的解。

证明

同余式等价于存在整数 $y$，使 $ax+my=b$。由 §1.2 的一次不定方程理论，它有解当且仅当 $g\mid b$。

若有解 $x_0$，则全部解为 $x=x_0+\frac mg t$，$t\in\mathbb{Z}$。不同的 $t$ 模 $g$ 给出不同的 $x$，而 $t$ 与 $t+g$ 给出同一个解，所以模 $m$ 下恰有 $g$ 个解。∎

当 $g=1$ 时，方程有唯一解，这个解就是 $a$ 的模逆乘 $b$。若 $ax\equiv1\pmod m$，则称 $x$ 为 $a$ 模 $m$ 的逆元，记作 $a^{-1}$。逆元存在的充要条件是 $\gcd(a,m)=1$；它可以用 exgcd 直接求出。

代码 1 · exgcd 与模逆C++17
long long exgcd(long long a, long long b,
               long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1; y = x1 - (a / b) * y1;
    return g;
}

// 返回 a 在模 m 下的逆元；若不存在返回 -1（要求 m > 0）
long long inv_mod(long long a, long long m) {
    long long x, y;
    long long g = exgcd(a, m, x, y);
    if (g != 1) return -1;
    x %= m;
    if (x < 0) x += m;
    return x;
}

算法落地：$ax\equiv b$ 到底有几个解

算法落地从 $6x\equiv4\pmod8$ 看“先除 gcd，再求逆”覆盖：线性同余可解性 / 解数 / 模逆
需求　解 $6x\equiv4\pmod8$；再用 $3x\equiv5\pmod7$ 对照“唯一解”的情形。
1先算 $g=\gcd(a,m)$，用 $g\mid b$ 判断有没有解

$g=\gcd(6,8)=2$，而 $2\mid4$，所以有解；并且解的个数恰好是 $g=2$。

long long g = gcd(6, 8);      // 2
if (4 % g != 0) { /* 无解 */ }
// 解的个数 = g = 2
为什么 $g$ 同时管“有没有解”和“有几个解”？　$6x+8y$ 能表示的所有数都是 $g=2$ 的倍数，所以 $b$ 不是 $2$ 的倍数就无解。另一方面，$x$ 每增加 $8/2=4$ 就回到同一个同余类，而模 $8$ 下 $0,4$ 给出两个不同的代表，所以有 $2$ 个解。
2把方程除以 $g$，化成“系数与模数互素”的标准形

两边和模数同时除以 $2$：$3x\equiv2\pmod4$。此时 $\gcd(3,4)=1$，可以求逆。

long long a = 6, b = 4, m = 8;
a /= g; b /= g; m /= g;   // 3, 2, 4
long long inv = inv_mod(a, m);  // 3
long long x0 = (__int128)b * inv % m; // 2
为什么可以“除以 $g$”而不改变解？　$ax\equiv b\pmod m$ 等价于 $m\mid(ax-b)$。两边同时除以 $g$ 后，条件是 $(m/g)\mid((a/g)x-b/g)$，这是同一个整除关系的等价改写；只是模数从 $8$ 缩到了 $4$。
3先解缩小的方程，再把 $g$ 个解抬回原模数

$3x\equiv2\pmod4$ 的唯一解是 $x\equiv2\pmod4$。抬回模 $8$，得到 $x=2$ 与 $x=2+4=6$。验证：$6\cdot2=12\equiv4$，$6\cdot6=36\equiv4$。

vector<long long> sol;
for (int t = 0; t < g; ++t)
    sol.push_back(x0 + m * t);   // 2, 6
为什么抬高时每次走 $m/g$？　缩小后的解模 $m/g=4$ 唯一；在原模 $8$ 下，$x$ 与 $x+4$ 都落在同一个模 $4$ 余数类里，但它们是两个不同的模 $8$ 解。走 $g$ 步正好取完所有代表。
竞赛用法　$ax\equiv b\pmod m$ 是模逆、exgcd、CRT 的基本单元。解题时先算 $g$：不整除直接无解；整除就除以 $g$ 求逆，再枚举 $g$ 个抬升解。若题目只要“最小正整数解”，在 $g$ 个解里取最小非负并加上必要的模数即可。
线性同余模逆解数 = gcdexgcd

三中国剩余定理：把多个条件拼起来

同余方程可以联立。例如“除以 $3$ 余 $2$，除以 $5$ 余 $3$，除以 $7$ 余 $2$”同时约束一个整数。中国剩余定理（CRT）说：只要模数两两互素，这些条件不仅相容，而且解在模 $3\cdot5\cdot7$ 下唯一。

定理（中国剩余定理）

设 $m_1,\dots,m_k$ 两两互素，$M=m_1\cdots m_k$。则对任意整数 $a_1,\dots,a_k$，同余组

$$x\equiv a_i\pmod{m_i},\qquad i=1,\dots,k$$

在模 $M$ 下恰有一个解。

证明

构造。令 $M_i=M/m_i$。因为 $m_i$ 与 $M_i$ 互素，存在逆元 $t_i$ 使 $M_it_i\equiv1\pmod{m_i}$。令

$$x=\sum_{i=1}^k a_iM_it_i$$

对固定的 $j$，当 $i\ne j$ 时 $m_j\mid M_i$，所以那些项模 $m_j$ 为 $0$；第 $j$ 项模 $m_j$ 等于 $a_jM_jt_j\equiv a_j$。因此 $x\equiv a_j\pmod{m_j}$，是一个解。

唯一性。若 $x,y$ 都是解，则每个 $m_i\mid(x-y)$。因为 $m_i$ 两两互素，乘积 $M\mid(x-y)$，故 $x\equiv y\pmod M$。∎

代码 2 · 合并两个同余式（允许模数不互素）C++17
// 把 x ≡ a1 (mod m1) 与 x ≡ a2 (mod m2) 合并为 x ≡ a (mod m)
bool merge(long long a1, long long m1,
           long long a2, long long m2,
           long long& a, long long& m) {
    long long g = gcd(m1, m2);
    if ((a2 - a1) % g != 0) return false;  // 条件冲突
    long long m2g = m2 / g, t = 0;
    if (m2g != 1) {
        long long rhs = ((a2 - a1) / g) % m2g;
        if (rhs < 0) rhs += m2g;
        long long inv = inv_mod((m1 / g) % m2g, m2g);
        t = (__int128)rhs * inv % m2g;
    }
    m = m1 / g * m2;                         // 新的模数 = lcm(m1,m2)
    a = (a1 + (__int128)m1 * t) % m;
    if (a < 0) a += m;
    return true;
}

算法落地：把 CRT 构造拆成 5 步

算法落地中国剩余定理 · $x\equiv2(3),x\equiv4(5),x\equiv1(7)$覆盖：CRT 构造 / 模逆 / 唯一性
需求　求同时满足 $x\equiv2\pmod3$、$x\equiv4\pmod5$、$x\equiv1\pmod7$ 的最小非负整数 $x$。
1先把“模数互相独立”检查一遍，算出总模数 $M$

三个模数 $3,5,7$ 两两互素，满足 CRT 的前提。总模数 $M=3\cdot5\cdot7=105$，所以解在模 $105$ 下唯一。

long long m[3] = {3, 5, 7}, a[3] = {2, 4, 1};
long long M = 1;
for (long long x : m) M *= x;   // M = 105
为什么要先检查？　CRT 的“每个余数独立贡献一格”依赖模数两两互素。若 $\gcd(3,6)\gt1$，同一个 $x$ 在模 $3$ 和模 $6$ 下的余数会互相牵制，必须改用合并算法；直接套公式可能得到不存在的“解”。
2为每个方程造一个“只在自家为 1、在别家为 0”的基向量

令 $M_i=M/m_i$，得到 $M_1=35$，$M_2=21$，$M_3=15$。它们分别是另外两个模数的倍数：

$$35\equiv0\pmod5,\quad35\equiv0\pmod7;\qquad21\equiv0\pmod3,\quad21\equiv0\pmod7;\qquad15\equiv0\pmod3,\quad15\equiv0\pmod5$$ 
for (int i = 0; i < 3; ++i) {
    long long Mi = M / m[i];   // 35, 21, 15
    // Mi 在“其它模数”下自动是 0，只差把它在 m[i] 下调成 1
}
为什么这样构造？　我们想要三个互不干扰的“开关”：第 $i$ 个开关只在第 $i$ 个方程上通电。$M_i$ 已经天然满足“在别的方程上为 $0$”，所以只要再乘一个数，把它在自己方程上的余数从 $M_i\bmod m_i$ 调成 $1$。
3求模逆，把每个 $M_i$ 调成自家坐标为 1

求 $t_i\equiv M_i^{-1}\pmod{m_i}$：$35\equiv2\pmod3$，逆元 $t_1=2$；$21\equiv1\pmod5$，$t_2=1$；$15\equiv1\pmod7$，$t_3=1$。

long long t[3];
for (int i = 0; i < 3; ++i) {
    long long Mi = M / m[i];
    t[i] = inv_mod(Mi % m[i], m[i]);   // 2, 1, 1
}
为什么乘逆元就够了？　$M_it_i\equiv1\pmod{m_i}$，而在其它 $m_j$ 下 $M_i\equiv0$，所以 $M_it_i$ 是一个“单位开关”：第 $i$ 位是 $1$，其余位是 $0$。再乘 $a_i$，就把第 $i$ 个方程要求的余数放进去。
4把三个开关叠加，再对总模数取余

构造 $x=\sum a_iM_it_i$：

$$x=2\cdot35\cdot2+4\cdot21\cdot1+1\cdot15\cdot1=140+84+15=239$$ $$239\bmod105=29$$ 
long long x = 0;
for (int i = 0; i < 3; ++i) {
    long long Mi = M / m[i];
    x = (x + (__int128)a[i] * Mi % M * t[i]) % M;
}
// x = 239 % 105 = 29
为什么可以直接相加？　模运算对加法线性：在模 $3$ 下，第 $2,3$ 个开关都是 $0$，只剩 $2\cdot35\cdot2\equiv2$；模 $5$ 下只剩 $4\cdot21\cdot1\equiv4$；模 $7$ 下只剩 $1\cdot15\cdot1\equiv1$。所以一个求和式同时满足三个方程。
5回代验证，并写出全部解

$29\bmod3=2$，$29\bmod5=4$，$29\bmod7=1$。因此最小非负解是 $29$，全部整数解是

$$x=29+105k,\qquad k\in\mathbb{Z}$$ 
for (int i = 0; i < 3; ++i)
    assert(x % m[i] == a[i]);   // 三项都通过
// 通解：x + k*M，取最小非负解再 % M
为什么解在模 $105$ 下唯一？　若 $x,y$ 都满足三个方程，则 $3\mid(x-y)$、$5\mid(x-y)$、$7\mid(x-y)$。三个模数两两互素，所以 $105=3\cdot5\cdot7\mid(x-y)$；差是 $105$ 的倍数，解在模 $105$ 下只能是同一个。
竞赛用法　CRT 用来把多个同余条件合成一个，常见于 exLucas / 扩展组合数、模意义下多模数哈希、以及“分别算出答案模几个小素数，再拼回大模数”的题。若模数不互素，先做兼容性检查 $a_i\equiv a_j\pmod{\gcd(m_i,m_j)}$，再用代码 2 的合并；若 $M$ 超过 long long，要么用 __int128 暂存乘积，要么改用逐条合并并避免直接求总乘积。
exLucas多模数哈希同余方程组合并而非硬套

四例题

例 1 一次同余：先求逆再乘

解 $3x\equiv5\pmod7$。

解　$\gcd(3,7)=1$，所以有唯一解。$3$ 模 $7$ 的逆元是 $5$，因为 $3\cdot5=15\equiv1\pmod7$。两边乘 $5$：

$$x\equiv5\cdot5=25\equiv4\pmod7$$

解为 $x\equiv4\pmod7$。

例 2 模数与系数不互素：两个解

解 $6x\equiv4\pmod8$。

解　$g=\gcd(6,8)=2$，且 $2\mid4$，所以有 $2$ 个解。两边除以 $2$，模数也除以 $2$：

$$3x\equiv2\pmod4$$

$3$ 模 $4$ 的逆元是 $3$，故 $x\equiv6\equiv2\pmod4$。回到模 $8$，解为

$$x\equiv2\pmod8\quad\text{或}\quad x\equiv6\pmod8$$

直接验证：$6\cdot2=12\equiv4$，$6\cdot6=36\equiv4$。Burton Ch. 4

例 3 三个条件的 CRT

解同余组 $x\equiv2\pmod3$，$x\equiv3\pmod5$，$x\equiv2\pmod7$。

解　$M=3\cdot5\cdot7=105$。先合并前两个：$x=2+3k$，代入模 $5$ 得 $2+3k\equiv3$，即 $3k\equiv1\pmod5$。$3$ 的逆元是 $2$，所以 $k\equiv2\pmod5$，取 $k=2$，得 $x\equiv8\pmod{15}$。

再与 $x\equiv2\pmod7$ 合并：$x=8+15t$，模 $7$ 得 $1+t\equiv2$，故 $t\equiv1\pmod7$。取 $t=1$，得

$$x=8+15=23\pmod{105}$$

验证：$23\bmod3=2$，$23\bmod5=3$，$23\bmod7=2$。潘承洞《数论基础》第二章

如果三个模数不两两互素，CRT 的“唯一解”还成立吗？
引导　不一定。模数有公共因子时，条件可能冲突（无解），也可能把解限制在一个比乘积更小的模数上。此时应使用代码 2 的合并算法：先检查 $a_1\equiv a_2\pmod{\gcd(m_1,m_2)}$，再用 $\operatorname{lcm}$ 作为新模数。

五习题

  1. 求 $17$ 模 $31$ 的逆元。
    思路　用 exgcd 解 $17x+31y=1$，或试探 $17\cdot11=187=6\cdot31+1$。
    答案　$11$，因为 $17\cdot11=187\equiv1\pmod{31}$。
  2. 解同余组 $x\equiv1\pmod4$，$x\equiv3\pmod6$。
    思路　先检查相容性：$1\equiv3\pmod{\gcd(4,6)}$ 是否成立？再列举模 $12$ 的候选。
    答案　$\gcd(4,6)=2$，$3-1=2$ 被 $2$ 整除，相容。满足前式的数为 $1,5,9$；其中模 $6$ 余 $3$ 的是 $9$，故 $x\equiv9\pmod{12}$。
  3. 计算 $2^{100}\bmod7$。
    思路　$2^3=8\equiv1\pmod7$，指数按 $3$ 循环。
    答案　$100=3\cdot33+1$，所以 $2^{100}\equiv2^1=2\pmod7$。
  4. 证明：若 $a\equiv b\pmod m$，则 $\gcd(a,m)=\gcd(b,m)$。
    思路　$a=b+km$，证明两边的公因数集合相同。
    答案　任何 $d\mid b,m$ 都整除 $a=b+km$；反之任何 $d\mid a,m$ 都整除 $b=a-km$。公因数集合相同，最大公因数相同。
  5. 用 CRT 构造一个数，使它除以 $5$ 余 $1$、除以 $7$ 余 $2$、除以 $9$ 余 $3$。
    思路　先合并前两个，再与第三个合并；模数两两互素，解模 $315$ 唯一。
    答案　前两个得 $x\equiv16\pmod{35}$。令 $x=16+35t$，模 $9$ 得 $7+8t\equiv3$，即 $8t\equiv5$，逆元 $8$，故 $t\equiv4\pmod9$，$x=16+140=156\pmod{315}$。
一页纸
  • $a\equiv b\pmod m\iff m\mid(a-b)$；同余对加减乘封闭，除法要小心。
  • $ax\equiv b\pmod m$ 有解 $\iff\gcd(a,m)\mid b$；有解时恰有 $\gcd(a,m)$ 个解。
  • 逆元存在 $\iff\gcd(a,m)=1$；用 exgcd 求 $ax+my=1$。
  • CRT：模数两两互素时，同余组在模 $\prod m_i$ 下唯一。
  • 模数不互素时用合并算法，新模数取 $\operatorname{lcm}$。
