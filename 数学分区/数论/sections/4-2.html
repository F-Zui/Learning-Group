一Gauss 引理：数一数越过中线的余数

Euler 判别法把一个符号变成一次模幂，但模幂仍然要做 $O(\log p)$ 次乘法，而且看不出 $\left(\frac pq\right)$ 与 $\left(\frac qp\right)$ 的关系。Gauss 引理换了一个角度：只看 $a,2a,\dots,\frac{p-1}{2}a$ 的最小正余数，数一数有多少个越过 $p/2$。

定义（最小正余数）

设 $p$ 为奇素数，$p\nmid a$。对 $i=1,2,\dots,\frac{p-1}{2}$，把 $ai$ 除以 $p$ 的余数记作 $r_i\in\{1,\dots,p-1\}$，称为 $ai$ 模 $p$ 的最小正余数。

定理（Gauss 引理）

设 $n$ 为 $r_1,\dots,r_{(p-1)/2}$ 中大于 $p/2$ 的个数。则

$$\left(\frac ap\right)=(-1)^n$$
证明

对每个 $i$，令 $s_i=\min(r_i,p-r_i)$。也就是说，越过中线的余数用 $p-r_i$ 折回来。先证明 $s_1,\dots,s_{(p-1)/2}$ 恰好是 $1,2,\dots,\frac{p-1}{2}$ 的一个排列。

它们都在 $1$ 到 $\frac{p-1}{2}$ 之间。若 $s_i=s_j$，则 $ai\equiv\pm aj\pmod p$。若取正号，$p\mid a(i-j)$，因 $p\nmid a$ 得 $i=j$；若取负号，$p\mid a(i+j)$，而 $1\le i+j\le p-1$，不可能。故这些 $s_i$ 两两不同，正好填满 $\frac{p-1}{2}$ 个位置。

把 $ai\equiv r_i$ 全部乘起来：

$$a^{\frac{p-1}{2}}\left(\frac{p-1}{2}\right)!\equiv\prod r_i\equiv(-1)^n\prod s_i=(-1)^n\left(\frac{p-1}{2}\right)!\pmod p$$

阶乘与 $p$ 互素，可以约去。再由 Euler 判别法，$a^{(p-1)/2}\equiv\left(\frac ap\right)$，故 $\left(\frac ap\right)=(-1)^n$。∎

二$\left(\frac2p\right)$：只看 $p$ 模 $8$

定理（$2$ 的 Legendre 符号）

设 $p$ 为奇素数。则

$$\left(\frac2p\right)=(-1)^{\frac{p^2-1}{8}}=\begin{cases}1, & p\equiv\pm1\pmod8,\\ -1, & p\equiv\pm3\pmod8.\end{cases}$$
证明

在 Gauss 引理中取 $a=2$。余数 $2i$ 越过 $p/2$ 当且仅当 $2i\gt p/2$，即 $i\gt p/4$。因此

$$n=\frac{p-1}{2}-\left\lfloor\frac p4\right\rfloor$$

按 $p$ 模 $8$ 分类：

$p$$(p-1)/2$$\lfloor p/4\rfloor$$n$$\left(\frac2p\right)$
$8k+1$$4k$$2k$$2k$$+1$
$8k+3$$4k+1$$2k$$2k+1$$-1$
$8k+5$$4k+2$$2k+1$$2k+1$$-1$
$8k+7$$4k+3$$2k+1$$2k+2$$+1$

表中 $n$ 的奇偶性与 $(-1)^{(p^2-1)/8}$ 完全一致，故结论成立。∎

三二次互反律：把大符号翻成小符号

定理（二次互反律）

设 $p,q$ 为不同的奇素数。则

$$\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}{2}\cdot\frac{q-1}{2}}$$

等价地，若 $p\equiv q\equiv3\pmod4$，则两个符号相反；否则两个符号相同。另有补充公式

$$\left(\frac{-1}p\right)=(-1)^{\frac{p-1}{2}}=\begin{cases}1,&p\equiv1\pmod4,\\ -1,&p\equiv3\pmod4.\end{cases}$$
证明（Gauss 引理 + 数格子）

对 $i=1,\dots,\frac{p-1}{2}$，写 $qi=p\left\lfloor\frac{qi}{p}\right\rfloor+r_i$。由 Gauss 引理，$\left(\frac qp\right)=(-1)^n$，其中 $n$ 是 $r_i\gt p/2$ 的个数。把 $r_i$ 换成 $s_i=\min(r_i,p-r_i)$ 后，$s_i$ 是 $1,\dots,\frac{p-1}{2}$ 的排列。逐项比较 $r_i$ 与 $s_i$：越过中线时 $r_i-(p-r_i)=2r_i-p\equiv1\pmod2$，否则差为 $0$，所以

$$\sum r_i\equiv\sum s_i+n\pmod2$$

把 $qi$ 的等式对 $i$ 求和，并利用 $q\equiv p\equiv1\pmod2$ 与 $\sum s_i=\sum i=\frac{p^2-1}{8}$，得到 $n\equiv\sum_{i}\lfloor qi/p\rfloor\pmod2$。记 $N_p=\sum_{i}\lfloor qi/p\rfloor$，则 $\left(\frac qp\right)=(-1)^{N_p}$。对称地，令 $N_q=\sum_{j=1}^{(q-1)/2}\lfloor pj/q\rfloor$，则 $\left(\frac pq\right)=(-1)^{N_q}$。

现在数矩形 $1\le i\le\frac{p-1}{2}$，$1\le j\le\frac{q-1}{2}$ 中的整点。$N_p$ 数的是直线 $y=\frac qp x$ 下方的点，$N_q$ 数的是直线上方（等价于 $x=\frac pq y$ 左侧）的点。因为 $\gcd(p,q)=1$，直线不经过矩形内的整点，所以两种点恰好把矩形分完：

$$N_p+N_q=\frac{p-1}{2}\cdot\frac{q-1}{2}$$

于是 $\left(\frac pq\right)\left(\frac qp\right)=(-1)^{N_p+N_q}=(-1)^{\frac{p-1}{2}\cdot\frac{q-1}{2}}$。补充公式由 Gauss 引理取 $a=-1$ 直接得到。∎

翻转规则

计算 $\left(\frac pq\right)$ 时，若 $p\equiv1\pmod4$ 或 $q\equiv1\pmod4$，直接翻转 $\left(\frac pq\right)=\left(\frac qp\right)$；只有 $p\equiv q\equiv3\pmod4$ 时要多一个负号。翻转后把 $q$ 对 $p$ 取余，符号的“分子”就变小了。这就是 Jacobi 算法的递归骨架。

四Jacobi 算法与例题

对奇数 $n$（不必是素数），Jacobi 符号 $\left(\frac an\right)$ 用同样的翻转规则定义；当 $n$ 是素数时，它退化为 Legendre 符号。算法反复做三件事：去掉分子中的因子 $2$、交换分子分母、把分子对分母取余。每次取余都让数变小，复杂度 $O(\log n)$。

代码 1 · 迭代 Jacobi 符号C++17
int jacobi(long long a, long long n) {
    if (n <= 0 || n % 2 == 0) return 0;  // 仅讨论正奇数 n
    a %= n; if (a < 0) a += n;
    int ans = 1;
    while (a != 0) {
        while (a % 2 == 0) {              // 去掉因子 2
            a /= 2;
            if (n % 8 == 3 || n % 8 == 5) ans = -ans;
        }
        swap(a, n);                          // 二次互反律：交换
        if (a % 4 == 3) {
            if (n % 4 == 3) ans = -ans;      // 两个 3 mod 4 才翻号
        }
        a %= n;
    }
    return n == 1 ? ans : 0;
}
例 1 翻转两次的符号计算

计算 $\left(\frac{17}{31}\right)$。

解　$17\equiv1\pmod4$，直接翻转：

$$\left(\frac{17}{31}\right)=\left(\frac{31}{17}\right)=\left(\frac{14}{17}\right)=\left(\frac2{17}\right)\left(\frac7{17}\right)$$

$17\equiv1\pmod8$，所以 $\left(\frac2{17}\right)=1$。又 $17\equiv1\pmod4$，

$$\left(\frac7{17}\right)=\left(\frac{17}{7}\right)=\left(\frac37\right)$$

$3\equiv7\equiv3\pmod4$，翻转要加负号：$\left(\frac37\right)=-\left(\frac73\right)=-\left(\frac13\right)=-1$。因此

$$\left(\frac{17}{31}\right)=1\cdot(-1)=-1$$

$17$ 是模 $31$ 的二次非剩余。潘承洞《数论基础》第三章

例 2 用 $-1$ 与 $2$ 的补充公式

计算 $\left(\frac{5}{11}\right)$ 与 $\left(\frac{2}{19}\right)$。

解　$5\equiv1\pmod4$，所以 $\left(\frac5{11}\right)=\left(\frac{11}{5}\right)=\left(\frac15\right)=1$。$19\equiv3\pmod8$，所以 $\left(\frac2{19}\right)=-1$。

这两个例子分别用了“$1\bmod4$ 直接翻转”和“$2$ 的模 $8$ 规则”。Burton Ch. 9

算法落地：把 $\left(\frac{17}{31}\right)$ 一路降到 $\left(\frac13\right)$

算法落地互反律 = 有符号的“辗转相除”覆盖：Gauss 引理 / $(2/p)$ / 互反律
需求　不枚举平方，计算 $\left(\frac{17}{31}\right)$；并说明每一步“为什么能翻、什么时候要加负号”。
1看两个奇素数模 $4$ 的余数，决定翻转是否加符号

$17\equiv1\pmod4$，所以翻转不产生负号：

$$\left(\frac{17}{31}\right)=\left(\frac{31}{17}\right)=\left(\frac{14}{17}\right)$$ 
// 17 % 4 == 1，翻转安全
int s1 = jacobi(17, 31);  // 先记住最终要算的值
int s2 = jacobi(31, 17);  // 与 s1 相同
为什么能翻？　二次互反律说 $\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}{2}\frac{q-1}{2}}$。只要 $p\equiv1\pmod4$，指数里就有一个偶数，乘积为 $1$，两个符号相等；只有 $p\equiv q\equiv3\pmod4$ 时才差一个负号。
2把分子拆成 $2$ 与奇因子，分别套补充公式

$14=2\cdot7$，所以

$$\left(\frac{14}{17}\right)=\left(\frac2{17}\right)\left(\frac7{17}\right)$$

$17\equiv1\pmod8$，故 $\left(\frac2{17}\right)=1$。对 $\left(\frac7{17}\right)$，$17\equiv1\pmod4$，再翻一次：

$$\left(\frac7{17}\right)=\left(\frac{17}{7}\right)=\left(\frac37\right)$$ 
int two = (17 % 8 == 1 || 17 % 8 == 7) ? 1 : -1; // +1
int seven = jacobi(7, 17);  // 继续降维
为什么 $2$ 要单独处理？　互反律只适用于两个奇素数；$2$ 不是奇素数，所以它有独立的补充公式 $\left(\frac2p\right)=(-1)^{(p^2-1)/8}$。先把 $2$ 的因子剥掉，剩下的才是奇素数，才能继续翻转。
3最后两个都是 $3\bmod4$，翻转加负号后到底

$3\equiv7\equiv3\pmod4$，所以

$$\left(\frac37\right)=-\left(\frac73\right)=-\left(\frac13\right)=-1$$

乘起来：$\left(\frac{17}{31}\right)=1\cdot(-1)=-1$，$17$ 是模 $31$ 的二次非剩余。

int ans = jacobi(17, 31);   // -1
// 循环内部：去 2 → 交换 → 两个 3 mod 4 才翻号 → 取余
为什么最后只剩 $\left(\frac13\right)$？　每次翻转后都把大数对小数取余，规模严格变小，和 Euclid 算法一样最终落到 $1$ 或 $0$。$\left(\frac13\right)=1$ 是因为 $1$ 当然是平方；负号来自唯一一次“两个 $3\bmod4$”的翻转。
竞赛用法　Jacobi 符号是 $O(\log p)$ 的“带符号 gcd”，用于快速判定二次剩余、配合 Tonelli–Shanks 求模平方根、以及二次同余方程。实现时先剥 $2$、再交换、再取余；两个 $3\bmod4$ 才翻号，模数非素数时得到的是 Jacobi 而不是 Legendre，不能直接当“是否有平方根”的判据。
二次互反律Jacobi 符号O(log p)模平方根
二次互反律要求 $p,q$ 都是奇素数。计算 $\left(\frac{2}{p}\right)$ 时为什么不能直接翻转？
引导　因为 $2$ 不是奇素数，互反律的“两个奇素数”前提不成立。$2$ 有单独的补充公式 $\left(\frac2p\right)=(-1)^{(p^2-1)/8}$；这也是 Jacobi 算法要先把因子 $2$ 全部去掉的原因。

五习题

  1. 计算 $\left(\frac{3}{13}\right)$、$\left(\frac{5}{13}\right)$。
    思路　$13\equiv1\pmod4$，可以自由翻转；再用 $3$ 或 $5$ 的小符号。
    答案　$\left(\frac3{13}\right)=\left(\frac{13}{3}\right)=\left(\frac13\right)=1$；$\left(\frac5{13}\right)=\left(\frac{13}{5}\right)=\left(\frac35\right)=\left(\frac53\right)=\left(\frac23\right)=-1$。
  2. 计算 $\left(\frac{7}{19}\right)$。
    思路　$7\equiv3$，$19\equiv3\pmod4$，翻转要加负号。
    答案　$\left(\frac7{19}\right)=-\left(\frac{19}{7}\right)=-\left(\frac57\right)$。$5\equiv1\pmod4$，$-\left(\frac75\right)=-\left(\frac25\right)$；$\left(\frac25\right)=-1$，故结果为 $1$。
  3. 用 Gauss 引理计算 $\left(\frac3{11}\right)$，并数一数越线的余数。
    思路　列出 $3,6,9,12,15$ 模 $11$ 的余数，数大于 $5.5$ 的个数。
    答案　余数为 $3,6,9,1,4$，越线的是 $6,9$，$n=2$，所以 $\left(\frac3{11}\right)=1$。
  4. 证明 $\left(\frac{-1}{p}\right)=1$ 当且仅当 $p\equiv1\pmod4$。
    思路　用 Euler 判别法：$(-1)^{(p-1)/2}$ 的符号由指数奇偶决定。
    答案　$(-1)^{(p-1)/2}=1$ 当且仅当 $(p-1)/2$ 为偶数，即 $p\equiv1\pmod4$。
一页纸
  • Gauss 引理：$\left(\frac ap\right)=(-1)^n$，$n$ 是 $ai$ 的余数中大于 $p/2$ 的个数。
  • $\left(\frac2p\right)=(-1)^{(p^2-1)/8}$：$p\equiv\pm1\pmod8$ 为 $+1$，$\pm3$ 为 $-1$。
  • 互反律：$\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}{2}\frac{q-1}{2}}$。
  • 计算时先去掉因子 $2$，再翻转，再取余；两个 $3\bmod4$ 才翻号。
  • Jacobi 算法 $O(\log n)$，对素数 $n$ 就是 Legendre 符号。
