Tonelli–Shanks 模平方根

知道“有解”还不够，还要把解算出来；学完能写 Tonelli–Shanks，在 $O(\log^2 p)$ 内求 $x^2\equiv a\pmod p$，并看懂它为什么总能收敛。

第 4 章 · 二次剩余 难度 ●●● 前置：§4.1 Euler 判别法 关键词：Tonelli–Shanks · 模平方根 · 2-adic 阶

一从“有解”到“求解”

Euler 判别法只回答“有没有解”，不给出 $x$。有一类素数特别容易：若 $p\equiv3\pmod4$，则

$$x=a^{\frac{p+1}{4}}\quad\Longrightarrow\quad x^2=a^{\frac{p+1}{2}}=a\cdot a^{\frac{p-1}{2}}\equiv a\pmod p$$

因为 $a$ 是二次剩余，$a^{(p-1)/2}\equiv1$，所以这个 $x$ 就是平方根。难点在 $p\equiv1\pmod4$：此时 $p-1$ 含有 $2$ 的高次幂，Euler 判别法里的指数 $(p-1)/2$ 仍是偶数，不能直接“开半”。

Tonelli–Shanks 的想法是把 $p-1$ 写成 $q2^s$（$q$ 为奇数），然后在一个 $2$ 的幂次循环里逐层“消掉”一个 $2$ 因子。每转一圈，$t$ 的阶就下降一半，最多 $s$ 圈，因此一定能停。

定理（Tonelli–Shanks 的正确性）

设 $p$ 为奇素数，$a$ 为模 $p$ 的非零二次剩余，$p-1=q2^s$，$q$ 为奇数。取一个二次非剩余 $z$，令

$$c=z^q,\quad x=a^{\frac{q+1}{2}},\quad t=a^q,\quad m=s$$

重复以下步骤直到 $t\equiv1$：找最小的 $i$（$1\le i\lt m$）使 $t^{2^i}\equiv1$，令 $b=c^{2^{m-i-1}}$，再令

$$x\leftarrow xb,\qquad t\leftarrow tb^2,\qquad c\leftarrow b^2,\qquad m\leftarrow i$$

循环结束时 $x^2\equiv a\pmod p$。

证明

不变量。初始时 $x^2=a^{q+1}=a\cdot a^q=at$。每次更新后，新值的平方为 $(xb)^2=a t b^2=a(tb^2)$，所以 $x^2=at$ 始终成立。

阶的下降。因为 $z$ 是二次非剩余，$z^{(p-1)/2}\equiv-1$，所以 $c=z^q$ 的阶恰为 $2^s$。设当前 $c$ 的阶为 $2^m$，$t$ 的阶整除 $2^m$。取最小的 $i$ 使 $t^{2^i}=1$，则 $t$ 的阶为 $2^i$（$t\ne1$）。元素 $b=c^{2^{m-i-1}}$ 的阶为 $2^{i+1}$，故 $b^2$ 的阶为 $2^i$。

在阶为 $2^m$ 的循环群里，阶为 $2^i$ 的元素都落在唯一的阶为 $2^i$ 的子群中；$t$ 与 $b^2$ 都是这个子群的生成元。两个生成元的乘积落在指数为 $2$ 的子群中，所以 $tb^2$ 的阶至多 $2^{i-1}$。于是新的 $m=i$ 严格变小，循环最多 $s$ 次。

当 $t=1$ 时，不变量给出 $x^2=a$。若 $a$ 有平方根，算法必在有限步停止；返回的 $x$ 就是一个平方根。∎

二算法与代码

实现时先处理三种边界：$a\equiv0$ 返回 $0$；$p\equiv3\pmod4$ 走快速分支；其余情况先分解 $p-1=q2^s$，再找一个二次非剩余 $z$。找 $z$ 可以直接从 $2,3,5,\dots$ 试，Euler 判别法为 $-1$ 的就是。

代码 1 · Tonelli–Shanks（64 位）C++17
using ll = long long;
using i128 = __int128_t;

ll mod_pow(ll a, ll e, ll p) {
    ll r = 1 % p;
    while (e) {
        if (e % 2) r = (i128)r * a % p;
        a = (i128)a * a % p;
        e /= 2;
    }
    return r;
}

ll tonelli_shanks(ll a, ll p) {
    a %= p; if (a < 0) a += p;
    if (a == 0) return 0;
    if (p % 4 == 3) return mod_pow(a, (p + 1) / 4, p);

    ll q = p - 1; int s = 0;
    while (q % 2 == 0) { q /= 2; ++s; }

    ll z = 2;
    while (mod_pow(z, (p - 1) / 2, p) != p - 1) ++z;

    ll c = mod_pow(z, q, p);
    ll x = mod_pow(a, (q + 1) / 2, p);
    ll t = mod_pow(a, q, p);
    int m = s;

    while (t != 1) {
        int i = 1;
        ll tt = (i128)t * t % p;
        while (tt != 1) { tt = (i128)tt * tt % p; ++i; }
        ll b = mod_pow(c, 1LL << (m - i - 1), p);
        x = (i128)x * b % p;
        t = (i128)t * b % p * b % p;
        c = (i128)b * b % p;
        m = i;
    }
    return x;
}

三例题：手算 $p=41$

例 在模 41 下求 5 的平方根

求 $x^2\equiv5\pmod{41}$ 的一个解。

解　$p=41\equiv1\pmod4$，不能走快速分支。分解

$$40=5\cdot2^3\quad(q=5,\ s=3)$$

从 $2,3,\dots$ 找非剩余。$3^{20}\equiv40\equiv-1\pmod{41}$，所以取 $z=3$。初始化：

$$c=3^5\equiv38,\quad x=5^3\equiv2,\quad t=5^5\equiv9,\quad m=3$$

第一轮：$t=9$ 的阶是 $4$，最小 $i=2$。$b=c^{2^{3-2-1}}=c=38$，于是

$$x\leftarrow2\cdot38\equiv35,\quad t\leftarrow9\cdot38^2\equiv40,\quad c\leftarrow38^2\equiv9,\quad m\leftarrow2$$

第二轮：$t=40$ 的阶是 $2$，最小 $i=1$。$b=c^{2^{2-1-1}}=c=9$，于是

$$x\leftarrow35\cdot9\equiv28,\quad t\leftarrow40\cdot9^2\equiv1,\quad c\leftarrow9^2\equiv40,\quad m\leftarrow1$$

循环结束，返回 $x=28$。验证：$28^2=784=41\cdot19+5\equiv5\pmod{41}$。另一个根是 $41-28=13$。潘承洞《数论基础》第三章

例 2 快速分支

求 $x^2\equiv3\pmod{13}$ 的一个解。

解　$13\equiv1\pmod4$，仍然不能走 $p\equiv3$ 分支。分解 $12=3\cdot2^2$，取非剩余 $z=2$（$2^6=64\equiv12$）：

$$c=2^3\equiv8,\quad x=3^2=9,\quad t=3^3\equiv1,\quad m=2$$

一开始 $t=1$，循环不执行，直接返回 $9$。验证 $9^2=81\equiv3\pmod{13}$。NZM §2.8

如果 $a$ 是二次非剩余，Tonelli–Shanks 会在哪一步坏掉？
引导　初始化 $t=a^q$ 后，$t$ 的阶不再整除 $2^s$ 的“平方部分”：$a^{(p-1)/2}=-1$，所以 $t^{2^{s-1}}=-1$，$t$ 的阶含有完整的 $2^s$。循环找不到满足 $t^{2^i}=1$ 的 $i\lt m$，算法无法下降。实现中应先做 Euler 判别，确认 $a$ 是 QR。

四习题

  1. 用 $p\equiv3\pmod4$ 的公式求 $x^2\equiv3\pmod{11}$ 的一个解。
    思路　$11\equiv3\pmod4$，$x=3^{(11+1)/4}=3^3$。
    答案　$x=27\equiv5\pmod{11}$，验证 $5^2=25\equiv3$。另一个根是 $11-5=6$。
  2. 用 Tonelli–Shanks 求 $x^2\equiv5\pmod{41}$ 的另一个根。
    思路　二次方程的两个根互为相反数：$x$ 与 $p-x$。
    答案　$41-28=13$，验证 $13^2=169=41\cdot4+5$。
  3. 证明 $p\equiv3\pmod4$ 时，$x=a^{(p+1)/4}$ 确实是 $a$ 的平方根（假设 $a$ 是 QR）。
    思路　平方后利用 Fermat 小定理与 $a^{(p-1)/2}=1$。
    答案　$x^2=a^{(p+1)/2}=a\cdot a^{(p-1)/2}=a$。
  4. 对 $p=17$，$a=2$，写出 $p-1=q2^s$ 中的 $q,s$，并找一个二次非剩余。
    思路　$16=1\cdot2^4$；检查 $3^{(17-1)/2}=3^8$ 是否为 $-1$。
    答案　$q=1,s=4$。$3^8=6561\equiv16\equiv-1\pmod{17}$，故 $z=3$ 是非剩余。
一页纸
  • $p\equiv3\pmod4$：$x=a^{(p+1)/4}$ 直接给出平方根。
  • 一般情形写 $p-1=q2^s$，找一个二次非剩余 $z$，令 $c=z^q$。
  • 不变量 $x^2=at$；每轮用 $b=c^{2^{m-i-1}}$ 把 $t$ 的阶降一半。
  • 循环到 $t=1$ 时返回 $x$；另一个根是 $p-x$。
  • 复杂度 $O(\log^2 p)$；实现前先用 Euler 判别确认 $a$ 是 QR。
