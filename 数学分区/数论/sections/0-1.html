数论的地图与证明工具箱

先看清整门课的地形：整数为什么能被“拆开”，以及良序、归纳、反证这三件工具如何把直觉变成证明。学完能判断一个数论命题该从哪种证明骨架起步。

第 0 章 · 起点 难度 ●○○ 前置：无 关键词：良序原理 · 最小反例 · 无穷递降

一整数不是一条均匀的线

如果把整数只画成数轴，它看起来是一条均匀的线：相邻两个数永远差 $1$，从负到正没有尽头。数论关心的却不是“位置”，而是乘法结构：$12$ 可以被 $3$ 分成四份，$17$ 却分不动；$12=2^2\cdot 3$，$17$ 不能再拆。整除、素数、同余，都是从不同角度观察这套结构。

本课程的主干可以压缩成三扇门。整除问“谁被谁分成整数份”，由此得到带余除法与 Euclid 算法；素数问“哪些数再也分不动”，由此得到算术基本定理；同余问“除以 $m$ 后余数是否相同”，由此得到模运算、逆元与快速幂。再往后，数论函数统计约数与互素，二次剩余研究模世界里的开平方，最后走向 Pell 方程与猜想。

阅读方式

每一节都按“动机 → 定义/定理 → 图像 → 例题 → 算法 → 习题”组织。公式是压缩饼干，图是把饼干泡开的水，代码则是把定理送进计算机的传送带。三者缺一，数论就会变成只能背结论的公式表。

二三件工具：良序、归纳、反证

公理（良序原理）

每个非空的正整数集合都有最小元。也就是说，若 $S\subseteq \mathbb{Z}_{\gt 0}$ 且 $S\ne\varnothing$，则存在 $m\in S$，使得对一切 $s\in S$ 都有 $m\le s$。

这条公理看起来像废话，却是一些证明能够“落地”的原因。它允许我们在反例集合里挑一个最小的反例，然后利用更小的结构制造矛盾。整数的离散性——相邻两个数之间没有别的整数——正是分析学里没有的性质。

定理（大于 $1$ 的整数必有素因子）

设整数 $n\gt 1$，则存在素数 $p$，使得 $p\mid n$。

证明

令 $S=\{d\in\mathbb{Z}_{\gt 0}: d\gt 1,\ d\mid n\}$。因为 $n\in S$，所以 $S$ 非空。由良序原理，$S$ 有最小元 $p$。

若 $p$ 不是素数，则 $p=ab$，其中 $1\lt a\lt p$。由 $a\mid p$ 且 $p\mid n$ 得 $a\mid n$，于是 $a\in S$，这与 $p$ 的最小性矛盾。因此 $p$ 只能是素数。∎

读法

这段证明只做了两件事：把反例收集成一个集合，再取最小元。最小元一出现，任何“还能再拆一层”的可能性都会立刻违反最小性。后面证明算术基本定理、Euclid 引理、Pell 方程的最小解，都会反复使用这个动作。

归纳法是良序原理的另一个面孔：若一个命题对 $1$ 成立，且由“对 $1,\dots,n$ 成立”能推出“对 $n+1$ 成立”，那么它对所有正整数成立。否则，不成立的数会组成非空集合，取最小元 $m$，则 $m-1$ 以前全成立，与递推步骤矛盾。

反证法则适合处理“不存在”与“唯一”两类结论。要证不存在，就假设存在并推出矛盾；要证唯一，就假设有两个对象，再证明它们其实相等。数论里很多“唯一分解”“最小解”的命题，本质都是反证。

三从证明到算法：商与余数

证明告诉我们对象存在，算法告诉我们怎样把它算出来。最小的例子是整数除法。C++ 的 / 向零截断，% 的符号跟随被除数；而数论里的带余除法要求余数始终落在 $[0,b)$。两者在负数上会分叉，必须显式修正。

代码 1 · 把 C++ 的截断除法修正为欧几里得除法C++17
// 要求 b > 0。返回 q = floor(a / b)，r = a - b*q ∈ [0, b)。
pair<long long, long long> floor_div(long long a, long long b) {
    long long q = a / b;
    long long r = a % b;
    if (r < 0) {          // C++ 的余数可能为负
        r += b;            // 把余数推回 [0, b)
        --q;               // 商相应减一，保持 a = b*q + r
    }
    return {q, r};
}
易错

只改余数不改商，是最常见的错误。例如 $-17$ 除以 $5$：C++ 给出 $q=-3,r=-2$；若只写 r+=5 会得到 $r=3$，但 $5\cdot(-3)+3=-12\ne-17$。商必须同时减一，得到 $q=-4,r=3$。

四例题：把证明骨架用起来

例 1 归纳法：前 n 个奇数之和

证明对一切正整数 $n$，都有 $1+3+5+\cdots+(2n-1)=n^2$。

解　当 $n=1$ 时，左边 $=1=1^2$，成立。假设对 $n$ 成立，即前 $n$ 个奇数之和为 $n^2$。那么前 $n+1$ 个奇数之和为

$$n^2+(2n+1)=(n+1)^2$$

由归纳原理，等式对所有正整数成立。Burton Ch. 1

例 2 反证与无穷递降：$\sqrt2$ 不是有理数

证明不存在正整数 $a,b$，使得 $a^2=2b^2$。

解　反设存在。取所有解中 $a$ 最小的一组 $(a,b)$。由 $a^2=2b^2$ 知 $a^2$ 为偶数，所以 $a$ 为偶数，写 $a=2a_1$。代入得 $4a_1^2=2b^2$，即 $b^2=2a_1^2$，故 $b$ 也为偶数，写 $b=2b_1$。

$$a_1^2=2b_1^2,\qquad a_1=\frac a2\lt a$$

于是 $(a_1,b_1)$ 是更小的一组正整数解，与 $a$ 的最小性矛盾。因此原方程无正整数解，$\sqrt2$ 不是有理数。∎

算法落地：最小反例法怎样变成“找最小素因子”

算法落地从 $91$ 的最小素因子看良序原理覆盖：良序原理 / 素因子定理 / 反证
需求　不查素数表，给 $n=91$ 找一个素因子，并说明为什么找到的“第一个”因子一定是素数。
1把“所有可能的因子”看成一个集合，取其中最小者

令 $S=\{d\in\mathbb{Z}_{\gt1}:d\mid91\}$。从 $2$ 开始试，第一个命中的是 $d=7$。这个 $7$ 就是 $S$ 的最小元。

long long n = 91;
for (long long d = 2; d <= n / d; ++d) {
    if (n % d == 0) { cout << d; break; }  // 7
}
为什么可以“取第一个”？　良序原理保证非空正整数集有最小元；从 $2$ 往上扫描，第一次整除的那个数就是最小元。这个动作不是“随便找一个”，而是精确地取到了证明里需要的那个 $p$。
2用反证说明第一个因子不可能是合数

若 $7$ 是合数，写 $7=ab$，其中 $1\lt a\lt7$。那么 $a\mid7$ 且 $7\mid91$，所以 $a\mid91$，即 $a\in S$。但 $a\lt7$，与 $7$ 是最小元矛盾。

// 若 d 是合数，它的某个因子 a 更小且也整除 n
// 这与“d 是第一个命中的因子”矛盾 ⇒ d 必为素数
bool is_prime_d = true;  // 由最小性推出，无需再判
为什么这能证明素数性？　证明只用了两件事：$a\mid d$、$d\mid n$ 推出 $a\mid n$（整除的传递性），以及 $a\lt d$ 违反最小性。没有用到 $91$ 的特殊结构，所以对任何 $n\gt1$ 都成立。
3把“最小因子”接进分解流程

找到最小素因子 $p$ 后，令 $n\leftarrow n/p$，继续找下一个因子。$91/7=13$，$13$ 已是素数，于是 $91=7\cdot13$。

vector<long long> fac;
for (long long p = 2; p <= n / p; ++p)
    while (n % p == 0) { fac.push_back(p); n /= p; }
if (n > 1) fac.push_back(n);   // 7, 13
为什么循环结束后剩下的 $n$ 一定是素数？　若剩下的 $n$ 是合数，它必有不超过 $\sqrt n$ 的素因子，而循环已经试过所有这样的 $p$，矛盾。这正是“最小反例法”在算法里的另一种写法。
竞赛用法　“找第一个因子”就是最小素因子（SPF）的思想：线性筛能批量预处理 SPF，试除适合单个 $n\le10^{12}$，而 $10^{18}$ 要换 Miller–Rabin + Pollard–Rho。良序原理保证你找到的第一个因子一定是素数，所以分解循环不需要额外判素。

引导　整数集合可以无限向下：$\{0,-1,-2,\dots\}$ 没有最小元。最小反例法必须先把讨论范围压到正整数，或压到某个有下界的量（如绝对值、分母）。这正是例 2 中“取 $a$ 最小”能成立的原因。

五习题

  1. 用归纳法证明：对一切正整数 $n$，$3\mid n^3-n$。
    思路　把 $(n+1)^3-(n+1)$ 拆成 $(n^3-n)+3(n^2+n)$，后一项显然是 $3$ 的倍数。
    答案　$n=1$ 时 $0$ 被 $3$ 整除；若 $3\mid n^3-n$，则 $(n+1)^3-(n+1)=(n^3-n)+3n(n+1)$，仍是 $3$ 的倍数。
  2. 证明：若 $n$ 是奇数，则 $n^2\equiv 1\pmod 8$。由此说明 $x^2+y^2=8z+6$ 没有整数解。
    思路　奇数写成 $2k+1$，平方后看它除以 $8$ 的余数；两个平方剩余之和只能取哪些值？
    答案　$(2k+1)^2=4k(k+1)+1$，而 $k(k+1)$ 为偶数，故余 $1$。偶数的平方余 $0$ 或 $4$。两个平方数之和模 $8$ 只能为 $0,1,2,4,5$，不可能是 $6$。
  3. 用良序原理证明：每个大于 $1$ 的整数都可以写成若干个素数之积（先只证存在性）。
    思路　取“不能写成素数乘积”的最小整数 $n$；它若不是素数，就拆成两个更小的因子。
    答案　若 $n$ 不能分解，则 $n$ 非素数，$n=ab$ 且 $1\lt a,b\lt n$。由最小性，$a,b$ 都能写成素数乘积，乘起来就得到 $n$ 的分解，矛盾。
  4. 用无穷递降证明：不存在正整数 $x,y$ 满足 $x^2=3y^2$。
    思路　模仿例 2：先证 $3\mid x$，再代入得到更小的解。
    答案　若 $3\mid x^2$，则 $3\mid x$，写 $x=3x_1$，得 $3x_1^2=y^2$，故 $3\mid y$，写 $y=3y_1$，得到更小的解 $(x_1,y_1)$，无限递降，矛盾。
