欧拉回路与一笔画

判断一张图能否一笔画完所有边，并真的把那条路线构造出来。学完能背诵“全偶回路、两奇路径”的判据，用 Hierholzer 在 $O(V+E)$ 内输出欧拉回路，并把单词接龙、邮递员路线建模成欧拉路。

一回到七桥

第 0 章的七桥问题问的就是一笔画：能不能从某处出发，每条边恰好走一次，最后回到起点。Euler 用“进出成对”否定了它，也顺手给出了完整的判据——这条判据比图论的许多定理都早，是这门学科真正的起点。

把“一笔画”说得精确一点：找一条经过每条边恰好一次的路线。若要求首尾相接，叫欧拉回路；若只要求走遍所有边、不要求回到起点，叫欧拉路径（欧拉迹）。注意它只约束边，不约束点：同一个点可以经过多次。

二判据：度数决定一切

定义（欧拉图）

存在欧拉回路的图称为欧拉图；存在欧拉路径但不存在欧拉回路的图称为半欧拉图。孤立点不影响判断，但所有含边的顶点必须在同一个连通分量里（称为“忽略孤立点后连通”）。

定理（Euler 判据）

设 $G$ 是忽略孤立点后连通的图，则：（1）$G$ 有欧拉回路，当且仅当所有顶点度数为偶数；（2）$G$ 有欧拉路径，当且仅当恰有两个顶点度数为奇数，此时路径必以这两个奇度点为端点。

证明

必要性：沿欧拉回路走一圈，每次进入一个点必从另一条边离开，进出成对，所以每个点贡献的度数都是偶数。若是一条从 $a$ 到 $b$ 的欧拉路径，则 $a,b$ 各多出一次“只出不进/只进不出”，度数为奇，其余点仍为偶。

充分性：设所有点度数为偶且图连通。从任意点出发，只要还有未走的边就继续走；由于每个点度数为偶，走进一个点后一定还能走出去，所以最终一定回到起点，得到一条闭迹。若它没有覆盖所有边，由于图连通，某个已访问顶点上还挂着未走的边，从那里再走一条闭迹，把它插入原来的回路（Hierholzer 的思想）。重复直到覆盖所有边。恰有两个奇度点时，在它们之间加一条虚拟边，化成全偶情形得到回路，再删掉虚拟边即得路径。∎

读法

判据只看两件事：奇度点的个数与连通性。0 个奇度点 → 回路；2 个 → 路径；4 个及以上或图不连通 → 无解。度数从哪来、边多长，都不影响结论。

三Hierholzer：把回路拼起来

判据解决“有没有”，Hierholzer 解决“怎么走”。它的想法正是充分性证明里的“插入”：随便走，走到走不动就回退，每退回一个点就把它记进答案；等所有边都走完，把答案反过来输出即可。

代码 1 · Hierholzer 求欧拉路径（无向图，边用编号访问）C++17
struct Edge { int to, nxt; };
vector<Edge> e;                 // 边表：e[2i] 与 e[2i+1] 互为反向
vector<int> head(N, -1);
bool used[400005];
vector<int> ans;               // 倒序记录经过的点

void addEdge(int u, int v) {
    e.push_back({v, head[u]}); head[u] = e.size() - 1;
    e.push_back({u, head[v]}); head[v] = e.size() - 1;
}

void dfs(int u) {
    for (int& i = head[u]; i != -1; ) {   // 引用：边用完就摘掉
        int id = i;
        i = e[id].nxt;                       // 先跳到下一条，防止递归改坏
        if (used[id]) continue;
        used[id] = used[id ^ 1] = true;     // 反向边也标记
        dfs(e[id].to);
    }
    ans.push_back(u);                        // 无处可走时记录，最后倒序输出
}

// 调用：先判连通与奇度点；选起点 start 后 dfs(start)，再 reverse(ans)
易错

答案必须倒序输出：ans 是在“无路可走”时压入的，正序是路径的逆。无向图要同时标记正反两条边编号，否则会来回走同一条边。递归写法在长链上会爆栈，可以用显式栈模拟。最后别忘了先检查连通性与奇度点个数。

四例题

例 1 单词接龙

给 $n$ 个单词，问能否把它们排成一列，使前一个单词的末字母等于后一个单词的首字母。

解　把 26 个字母作为顶点，每个单词作为一条从首字母到末字母的有向边（自环也保留）。能用完全部单词排列，等价于这张有向图存在欧拉路径；判据是：忽略孤立点后弱连通，且至多一个点出度 = 入度 + 1（起点）、至多一个点入度 = 出度 + 1（终点），其余点入度 = 出度。

注意单词是边不是点：同一个单词只能用一次，正好对应“每条边走一次”。建图后跑 Hierholzer 即可输出顺序。

例 2 中国邮递员问题

邮递员要从邮局出发，走遍所有街道并回到邮局，求最短路线。这与欧拉回路有什么关系？

解　若街道图是欧拉图（全偶度），任意欧拉回路都是答案。否则必须重复走一些街道：把奇度点两两配对，用最短路把它们连起来，把这条最短路上的每条边“复制”一份，图就变成全偶度，再求欧拉回路。配对方式用最小权完美匹配（奇度点通常很少，可状压 DP）。

这个问题是“带权欧拉回路”的经典扩展，本质是把非欧拉图补成欧拉图，代价最小。

五习题

  1. $K_5$ 是欧拉图吗？$K_6$ 呢？
    思路　$K_n$ 每个点度数是 $n-1$，看奇偶。
    答案　$K_5$ 每点 4 度，全偶，是欧拉图。$K_6$ 每点 5 度，6 个奇度点，不是欧拉图，也没有欧拉路径。
  2. 一个连通图恰有 4 个奇度点，能否加两条边使它变成欧拉图？
    思路　加一条边会改变两个端点的度数的奇偶性。
    答案　可以，只要把 4 个奇度点两两配对连边（允许重边时），每条新边让两个奇度点变偶。若要求新增边必须是无重边的简单边，需要检查这两对点之间是否已有边。
  3. 为什么 Hierholzer 输出的答案要倒序？
    思路　看 ans.push_back(u) 发生的位置。
    答案　点是在“所有边都走完、准备回溯”时才入答案的，此时它是路径的末端；回溯到起点时，答案里的顺序正好是行走顺序的逆序，所以要 reverse。
  4. 有向图的欧拉回路判据是什么？和入度、出度有什么关系？
    思路　沿回路每个点的进入次数等于离开次数。
    答案　忽略孤立点后弱连通，且每个点入度 = 出度，则存在欧拉回路。若存在欧拉路径（不闭合），则至多一个点出度 = 入度 + 1、至多一个点入度 = 出度 + 1，其余点入度 = 出度。
  5. 一张图有两个连通分量，每个分量都有欧拉回路。整张图有欧拉回路吗？
    思路　欧拉回路必须一条路线走完所有边。
    答案　没有。一条连续路线无法从一个分量跳到另一个分量；判据里“忽略孤立点后连通”这一条不满足。
如果要求“每条边恰好走两次”，判据会变成什么？
引导　把每条边复制成两条平行边，所有点的度数翻倍，全变偶数，所以任何连通图都满足。换句话说，“每条边走两次”总能做到，问题退化成构造；这也解释了为什么中国邮递员问题里“复制最短路”的思路可行。
进阶 · 欧拉回路计数与 BEST 定理（West Ch. 7）

有向欧拉图的欧拉回路条数由 BEST 定理给出：对每个顶点 $v$，记 $d_v$ 为出度，$\mathrm{ec}(G)=t_w(G)\cdot\prod_v(d_v-1)!$，其中 $t_w(G)$ 是以某个点为根的“入树”个数（可用矩阵树定理计算）。这一定理把“走法计数”与“生成树计数”联系起来，是组合计数里少见的精确公式。

一页纸
  • 欧拉回路：全偶度 + 连通；欧拉路径：恰两奇度 + 连通。
  • 有向图：回路要求每点入度 = 出度；路径允许一出一进相差 1。
  • Hierholzer：走边入栈、无路出栈，答案倒序输出，$O(V+E)$。
  • 非欧拉图补成欧拉图 = 奇度点配对 + 复制最短路（中国邮递员）。
