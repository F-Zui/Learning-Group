一网络哪里最脆弱

一张通信网里，大多数节点坏掉不影响整体连通，但总有那么几个节点，一旦停机，网络就裂成好几块；也总有那么几条线路，一旦被挖断，两地就再也联系不上。前者叫割点，后者叫桥。

找它们最笨的办法是：逐点删掉、重新数连通块。$n$ 个点就要跑 $n$ 次 DFS，$O(n(n+m))$。这一节要做的，是一次 DFS 全部找出来。诀窍是给每个点记两个时间戳：什么时候被访问（dfn），以及从它出发最多能“回到多早”（low）。

二割点、桥与双连通

定义（割点与桥）

若删去顶点 $v$ 后图的连通分量数增加，称 $v$ 为割点（割顶）。若删去边 $e$ 后连通分量数增加，称 $e$ 为桥。没有割点的连通图称为点双连通的，没有桥的连通图称为边双连通的。

桥有一个更结构化的刻画：一条边是桥，当且仅当它不属于任何一个圈。因为若 $e=uv$ 在某个圈上，删掉它以后 $u$ 还能沿圈的另一半走到 $v$，连通性不变；反之若删掉 $e$ 后仍连通，那条替代路径加上 $e$ 就构成一个圈。

定理（Tarjan 判据）

设 $T$ 是 DFS 树。对非根顶点 $u$ 及其孩子 $v$：$u$ 是割点当且仅当存在孩子 $v$ 使 $\mathrm{low}(v)\ge\mathrm{dfn}(u)$；边 $uv$ 是桥当且仅当 $\mathrm{low}(v)\gt\mathrm{dfn}(u)$。对根 $u$：$u$ 是割点当且仅当它有两个或更多孩子。

证明

先说明 low 的含义：$\mathrm{low}(u)$ 是从 $u$ 的子树出发、只经过一条返祖边所能到达的最小 dfn。它衡量“$u$ 以下的部分能不能绕回 $u$ 的祖先”。

若 $\mathrm{low}(v)\ge\mathrm{dfn}(u)$，说明 $v$ 的子树里没有边能绕回 $u$ 的上方，所有从 $v$ 子树通往外界（$u$ 的祖先方向）的路都必须经过 $u$。删去 $u$ 后，$v$ 的子树与外部分离，连通分量增加，故 $u$ 是割点。反之若 $\mathrm{low}(v)\lt\mathrm{dfn}(u)$，则 $v$ 子树能绕回 $u$ 的祖先，删去 $u$ 不影响它与其他部分的连通；对所有孩子都如此时 $u$ 不是割点。

桥的判据同理，只是要求“严格大于”：$\mathrm{low}(v)\gt\mathrm{dfn}(u)$ 表示连一条绕过 $uv$ 的边都没有，删去 $uv$ 后 $v$ 子树彻底孤立。根的特殊之处在于它没有祖先，只能用“孩子个数”判断：一个孩子时删掉根不会断开（也没有祖先可断），两个孩子则分属不同子树、无法互相到达。∎

读法

把 DFS 想成“往下挖”，low 就是“往上能爬多高”。如果某个孩子往下挖完后，爬不回当前点或更高的地方，那么当前点就是它的唯一出口——这正是割点。桥更严格：连爬到当前点都不行，必须更高。

三代码与逻辑图

代码 1 · Tarjan 求割点与桥（无向连通图）C++17
vector<int> g[N];
int dfn[N], low[N], timer;
bool isCut[N];

void tarjan(int u, int fa) {
    dfn[u] = low[u] = ++timer;
    int child = 0;
    for (int v : g[u]) {
        if (v == fa) continue;        // 简单图：父边直接跳过
        if (dfn[v]) {                  // 已访问：返祖边
            low[u] = min(low[u], dfn[v]);
        } else {                       // 树边：继续深入
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) isCut[u] = true;  // 割点
            if (low[v] > dfn[u])  addBridge(u, v); // 桥
            ++child;
        }
    }
    if (fa == 0 && child < 2) isCut[u] = false;  // 根的特判
}
易错

用“跳过父节点编号”的方法在有重边的图上会出错：两条 $u$—$v$ 的边构成一个二元环，$u$—$v$ 本不该是桥，但代码会把两条边都当父边跳过。正确做法是记录边的编号，只跳过“进入 $u$ 的那一条边”。另外，多连通分量时外层要对每个未访问点调用一次 `tarjan`，否则漏点。

四例题

例 1 读 dfn / low 判断割点

在上面那张图中，验证 3、4 是割点，而 1 不是；并指出所有桥。

解　$3$ 的孩子是 4，$\mathrm{low}(4)=4\ge\mathrm{dfn}(3)=3$，故 3 是割点；$4$ 的孩子是 5，$\mathrm{low}(5)=4\ge\mathrm{dfn}(4)=4$，故 4 是割点。根 1 只有一个孩子 2，按根的特判不是割点（删掉 1 后 2—3—4—5—6 仍连通）。

桥要满足 $\mathrm{low}(v)\gt\mathrm{dfn}(u)$：$3$—$4$ 满足 $4\gt3$，是桥。$4$—$5$ 不满足：$\mathrm{low}(5)=4$ 并不大于 $\mathrm{dfn}(4)=4$，因为 $5$ 能经 $6$ 绕回 $4$，这条边在三角形 $4$—$5$—$6$ 里。所以图中唯一的桥是 $3$—$4$。

例 2 加边消除桥

一个连通图有 $k$ 座桥，把它们全部“消掉”至少需要加几条边？

解　先把每个边双连通分量缩成一个点，得到一棵树，树边就是原来的桥。在树上加边，每加一条连接两个叶子的边，就会让这条路径上所有桥进入同一个环，从而不再是桥。要把这棵树变成无桥图，最少需要 $\lceil L/2\rceil$ 条新边，其中 $L$ 是树的叶子数：每加一条边就形成一条“叶子到叶子”的路径，路径上的桥全部进入同一个环；而每条新边最多让两片叶子“配对”，所以下界是 $\lceil L/2\rceil$。注意这里用的是叶子数，不是桥的条数——一条长链的桥很多，但两片叶子加一条边就全解决了。

这是“修路使任意两点都有两条边不相交路径”的经典题，缩点后按叶子数计算即可。

五习题

  1. 一棵树的所有边都是桥吗？哪些点是割点？
    思路　树中任意一条边都不在任何圈上。
    答案　所有边都是桥（删掉任一边即分成两块）。度数大于 1 的点都是割点，叶子不是；只有两个点的树，两个点都不是割点（删掉一个只剩单点，分量数不增加）。
  2. 为什么“根是割点”不能用 $\mathrm{low}(v)\ge\mathrm{dfn}(u)$ 判断？
    思路　根没有祖先，low 的比较失去意义。
    答案　根的每个孩子都满足 $\mathrm{low}(v)\ge\mathrm{dfn}(root)=1$（因为 low 最小是 1），会把根误判为割点。正确判据是孩子数：删掉根后，不同孩子的子树互不相连，所以根是割点当且仅当孩子数至少 2。
  3. 边双连通图一定点双连通吗？反过来呢？
    思路　用“两个三角形共享一个顶点”的图检验。
    答案　都不一定。两个三角形只共享一个顶点：没有桥（边双连通），但共享点是割点（不是点双连通）。反过来，$K_2$ 有桥但不是点双连通；更一般地，点双连通蕴含边双连通（没有割点就不会有桥），反之不成立。
  4. 有重边时，Tarjan 的“跳过父亲”为什么会误判？怎么改？
    思路　两条平行边构成一个长度为 2 的圈。
    答案　按点跳过会把两条平行边都略过，于是 low 无法通过第二条边回到父亲，误把 $u$—$v$ 判成桥。改成按边编号：递归时传入进入边的编号，只跳过这一条，其他通向父亲的边按返祖边处理。
  5. 给定一张无向图，如何求出所有“删除后会使图不连通的边集”？
    思路　这其实是求所有桥，而不只是一条。
    答案　跑一次 Tarjan，收集所有满足 $\mathrm{low}(v)\gt\mathrm{dfn}(u)$ 的树边即为全部桥。若图本身不连通，先对每个连通块分别处理；输出时注意按输入编号去重。
能否用割点算法求出“删去后使 $s$ 与 $t$ 不连通的点”（$s$-$t$ 割点）？
引导　可以，但不能直接套全局割点：需要从 $s$ 开始 DFS，只保留能到达 $t$ 的分支，判断条件仍是 $\mathrm{low}(v)\ge\mathrm{dfn}(u)$ 且 $t$ 在 $v$ 的子树里。等价地，由 Menger 定理，$s$-$t$ 割点个数等于内部点不相交的 $s$-$t$ 路径最大条数，可以用最大流（拆点）求。
进阶 · Menger 定理与点双连通分量（West Ch. 4）

Menger 定理：$u,v$ 之间内部点不相交的路径最大条数，等于使 $u,v$ 分离所需删去的最少点数。它把“连通度”这个几何概念翻译成“路径条数”这个计数概念，是网络可靠性理论的基石。点双连通分量可以用 Tarjan 的边栈求出：每遇到一条树边或返祖边就压栈，当 $\mathrm{low}(v)\ge\mathrm{dfn}(u)$ 时弹栈到 $uv$，弹出的一组边就是一个点双连通分量。

一页纸
  • 割点：删去后连通块变多；桥：删去后连通块变多。
  • 边是桥 $\iff$ 它不在任何圈上。
  • $\mathrm{low}(u)$ = 子树能绕回的最小 dfn；一次 DFS 全部算出。
  • 非根割点：存在孩子 $v$ 使 $\mathrm{low}(v)\ge\mathrm{dfn}(u)$；根：孩子数 ≥ 2。
