一七桥问题：一次“画法”的胜利

1736 年，Euler 面对 Königsberg 城的一道市民谜题：河心有一座小岛，岛与南北两岸、以及东边的陆地之间一共架了七座桥。能不能从某处出发，每座桥恰好走一次，最后回到起点？

Euler 的回答是“不能”。而他的理由与桥的长短、陆地的形状、河水的走向毫无关系。他把四块陆地画成四个点，把每座桥画成连接两点的线，于是谜题变成：在这个由点和线组成的图形上，能否一笔画完所有线、每条线只走一次、最后回到出发点？

每次走进一块陆地，必须从另一座桥走出去；若最后还要回到起点，进出就必须成对出现。因此每个顶点在路线中“被用掉”的边数一定是偶数。四个点的度数全是奇数，矛盾。

定理（回路必须全偶）

设连通图 $G$ 中每个点都是偶数度。若存在一条从某点出发、走遍每条边恰好一次并回到出发点的路线，则所有顶点的度数都是偶数。

证明

把这条路线看成边的序列 $e_1,e_2,\dots,e_m$，起点与终点相同。对任一点 $v$，路线每“经过”它一次，就贡献两条与 $v$ 关联的边：一条进、一条出；起点与终点重合，也按“进一次、出一次”计。于是 $v$ 的度必为 $2$ 的倍数。∎

读法

这条定理只用了“进与出成对”这一个想法，却把七桥问题彻底解决了。图论的力量来自抽象：一旦把桥变成边，几何细节全部消失，剩下的是可以逐个数出来的整数——度数。

二图：只保留连接关系

定义（简单无向图）

设 $V$ 是非空有限集合，$E$ 是由 $V$ 的二元子集组成的集合，则称有序对 $G=(V,E)$ 为简单无向图。$V$ 中的元素叫顶点，$E$ 中的元素叫边。$|V|$ 称为图的阶，$|E|$ 称为边数，习惯记 $n=|V|$、$m=|E|$。

若 $e=\lbrace u,v\rbrace$，就写 $e=uv$，称 $u,v$ 是 $e$ 的端点，$u$ 与 $v$ 相邻，边 $e$ 与 $u$、$v$ 关联。没有边相连的两个点称为不相邻。

“简单”两个字排除了两种退化情形：两点之间最多一条边（没有重边），点不能连到自己（没有自环）。七桥问题里 A 与 C 之间有两座桥，所以那张图不是简单图，而是多重图。为了处理方向与权重，还要两个变体：

定义（有向图与带权图）

若 $E$ 由 $V$ 的有序对组成，则称 $G$ 为有向图，边 $uv$ 表示从 $u$ 指向 $v$，$u$ 是起点、$v$ 是终点。若每条边 $e$ 还附带一个实数 $w(e)$，则称为带权图，$w(e)$ 叫边权，常用来表示距离、时间、费用或容量。

易错

图不是画出来的形状。同一个图可以有无数种画法：把顶点挪个位置、把边拉弯，只要“谁和谁相连”不变，它还是同一个图。判断两张图是否相同，看的是连接关系，不是视觉上的相似。下一节会用“同构”把这个直觉写成定义。

把这张“术语表”过一遍就够了，后面每一节都只会用到这些词：

术语记号一句话含义
阶 / 边数$n=|V|,\ m=|E|$点的个数 / 边的条数
相邻$u\sim v$存在边连接 $u$ 与 $v$
度$\deg(v)$与 $v$ 关联的边数（自环计 2）

三三种建模，一张地图

图论之所以有用，是因为大量“看似无关”的问题，抽象之后都落在同一批结构上。下面三种是最常见的入口：

人 = 顶点，朋友关系 = 边 → 社交网络 车站 = 顶点，线路 = 带权边 → 最短路径 课程 = 顶点，冲突 = 边 → 着色排课

关键在于先决定顶点是什么、边是什么，再问问题。顶点选错，问题就会变得无从下手；顶点选对，剩下的往往只是套用后面几章的一个定理。例如“最少需要几个机房同时开课”是着色问题，“物流最多能运多少”是网络流问题，“先修哪门课”是拓扑排序问题。

四计算机怎么存一张图

数学上写 $G=(V,E)$ 就够了，程序里必须选一种具体存法。两种最常用的结构各有取舍：

存法空间查一条边遍历某点的邻居适合
邻接矩阵 a[u][v]$O(n^2)$$O(1)$$O(n)$稠密图，$n\le 5000$
邻接表 g[u]$O(n+m)$$O(\deg u)$$O(\deg u)$稀疏图，$n,m\le 10^6$

绝大多数竞赛图都是稀疏的（$m$ 与 $n$ 同阶），所以邻接表是默认选择。下面的程序读入一张无向图，再用深度优先搜索（DFS）把每个连通块走一遍——这正是后面所有“一次 DFS 扫全图”算法的骨架。

代码 1 · 邻接表建图 + DFS 数连通块C++17
// 邻接表：g[u] 里存 u 的全部邻居；无向图每条边存两次
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
vector<int> g[N];
bool vis[N];

void dfs(int u) {
    vis[u] = true;                 // 进入即标记，防止绕圈
    for (int v : g[u])             // 枚举 u 的每条出边
        if (!vis[v]) dfs(v);      // 没去过才继续深入
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n, m; cin >> n >> m;
    for (int i = 0; i < m; ++i) {
        int u, v; cin >> u >> v;
        g[u].push_back(v);             // 两个方向都存
        g[v].push_back(u);
    }
    int cnt = 0;
    for (int u = 1; u <= n; ++u)
        if (!vis[u]) { ++cnt; dfs(u); }  // 每找到一个新起点，就是一块
    cout << "连通块个数: " << cnt << '\n';
}
易错

递归深度等于图的最长链长度。一张 $10^5$ 个点的链状图会让 DFS 递归栈溢出；竞赛里要么开大栈（ulimit -s 或编译选项），要么改成手写栈。另外，无向图存边必须存两次，否则遍历会漏掉一半邻居。

五例题

例 1 把赛程抽象成完全图

$n$ 支球队进行单循环赛，每两队恰好比赛一场。用图来建模，比赛总场数是多少？若每天同一支球队最多打一场，至少需要几天？

解　把每支球队作为一个顶点，一场比赛作为一条边。因为任意两队都比赛，所以这是完全图 $K_n$，边数为

$$\binom{n}{2}=\frac{n(n-1)}{2}$$

“同一天同一队最多打一场”相当于把边分组，每组内的边两两没有公共端点——这叫匹配（第 2 章）。把全部边分到若干个匹配中，最少需要的组数称为边色数（第 3 章）。对 $K_n$，当 $n$ 为奇数时答案是 $n$ 天，偶数时是 $n-1$ 天。

例 2 度数相同，图却不同

图 $G_1$ 是一个六边形的六个顶点与六条边；$G_2$ 是两个互不相连的三角形。它们的点数、边数、度数序列是否相同？它们是同一个图吗？

解　两者都是 $6$ 个点、每个点度数为 $2$、度数序列都是 $(2,2,2,2,2,2)$。但 $G_1$ 是连通的，$G_2$ 分成两块；连通与否在“连接关系”层面就能区分，所以它们不是同一个图。

这说明度数序列不足以决定一个图。要精确说“两个图相同”，需要存在一个保持相邻关系的双射，也就是下一节的同构。

六习题

  1. 某城市有 5 个地铁站，3 条线路：1 号线依次经过 A、B、C；2 号线经过 C、D、E；3 号线经过 A、E。若要“换乘次数最少”地从 A 到 D，应把顶点和边取成什么？
    思路　顶点取车站，边取“同一条线路上相邻的两站”，换乘次数就是路径上“换线”的次数，不能直接当作边数。
    答案　若只求经过站数最少，取车站为顶点、相邻站为边，A→B→C→D 经过 3 条边。若要精确计换乘，需把“线路-车站”也建成二部图（第 2 章），边权为 0/1，再跑 0-1 BFS。
  2. 在七桥问题中再修一座桥（连接两块陆地），能否做到“每座桥恰好走一次并回到起点”？
    思路　加一条边会让两个端点的度数各加 1，奇度点的个数怎么变？
    答案　不能。四个点原本全是奇度（3,3,3,5），加一条边只改变两个端点，奇度点从 4 个变成 2 个，仍然不是“全偶”。至少要加两条桥，且分别连接两对奇度点，才可能全偶。
  3. 无向图的邻接矩阵有什么对称性？有向图呢？带权图的邻接矩阵对角线元素通常取什么值？
    思路　从“边 $uv$ 与 $vu$ 是同一条边”出发。
    答案　无向图的邻接矩阵关于主对角线对称，$a_{uv}=a_{vu}$；有向图一般不具对称性。带权图常把无边处记为 $+\infty$、对角线记为 $0$，这样最短路算法可以直接在矩阵上运行。
  4. 完全图 $K_n$ 有多少条边？$K_5$ 与它的补图各是什么？
    思路　每对顶点之间恰好一条边，数点对即可。
    答案　$\binom{n}{2}=n(n-1)/2$ 条。$K_5$ 有 10 条边，它的补图没有边，是 5 个孤立点。
  5. 为什么建图时通常从 1 开始编号？如果输入里出现编号 0，程序要改哪里？
    思路　看 vis 数组与顶点数组的下标范围。
    答案　从 1 开始可以让下标与编号一致，避免“第 0 个点”与“未初始化”混淆。若输入含 0，则数组要开到 $n+1$，循环写成 for (int u = 0; u < n; ++u)，或统一给编号加 1。
如果允许“每座桥最多走一次”而不是“恰好一次”，七桥问题会有解吗？
引导　条件一放松，“进出成对”的约束就消失了：可以走到某块陆地后不再离开。这时问题变成是否存在一条欧拉迹（第 4.2 节），判据是奇度点不超过 2 个。原图有 4 个奇度点，仍然无解——但只放宽度数的条件，并不能自动得到解，还要检查连通性。
进阶 · Euler 的原始论证与“图”这个词（Wilson Ch. 1）

Euler 在 1736 年的论文里并没有画出现代意义上的图，他用的是“陆地与桥的对应表”。把论证翻译成今天的语言，就是第 4.2 节的欧拉回路判据：连通且所有顶点为偶度。Wilson 的书第一章完整复述了这段历史，并指出同一个论证可以回答“邮递员如何少走路”这类问题。

一页纸
  • 图 $G=(V,E)$ 只记录“谁和谁相连”，顶点位置、边长都不重要。
  • 先定顶点与边，再问问题：建模选错，后面全是无用功。
  • 无向图邻接表要存两次边；稀疏图用邻接表，稠密图才用邻接矩阵。
  • DFS 的两个时刻——进入与回溯——是第 4 章全部算法的地基。
