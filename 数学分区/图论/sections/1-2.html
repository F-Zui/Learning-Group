路、圈与连通性

区分“走过”“不重复地走过”与“简单路径”，用 BFS 一次算出连通块、最短距离与二分图判定。学完能把“能不能到达”“最少几步”和“有没有奇圈”用同一段代码解决。

一从“挨着”到“走得到”

上一节只关心两点之间有没有一条边。现实问题却总是“能不能过去”：地铁能不能从 A 站坐到 Z 站，社交网络里两个人隔几个人，迷宫有没有出口。这些问的都是一连串边，而不是单条边。

“一连串边”有很多种走法，图论把它们分成几档：允许重复点、允许重复边、两者都不允许。名字要分清，否则定理的条件会读错——这是初学者最常踩的坑。

二途径、迹、路与圈

定义（四种走法）

设 $G=(V,E)$。形如 $v_0e_1v_1e_2\cdots e_kv_k$ 的序列，其中 $e_i=v_{i-1}v_i$，称为一条途径（walk），$k$ 是它的长度。若 $e_1,\dots,e_k$ 互不相同，称为迹（trail）；若 $v_0,\dots,v_k$ 互不相同，称为路（path，也叫简单路径）。起点与终点重合的迹若除起终点外顶点互异，称为圈（cycle）；长度为奇数的圈叫奇圈。

若 $u$ 到 $v$ 存在路，称 $u$ 与 $v$ 连通；若图中任意两点都连通，称 $G$ 为连通图。连通关系是等价关系，它把 $V$ 分成若干连通分量。$u,v$ 之间最短路的长度称为距离 $d(u,v)$。

读法

三种走法是逐层加严的：途径什么都可以重复；迹只要求边不重复（一笔画走的就是迹）；路要求点也不重复。定理里写“存在一条路”时，通常可以先把途径缩短成路——这就是下面这条引理。

引理（路可以变短）

若 $u$ 与 $v$ 之间存在途径，则存在一条从 $u$ 到 $v$ 的路，且其长度不超过原途径。

证明

在所有 $u\to v$ 的途径中取一条最短的。若它某个顶点重复出现，即 $v_i=v_j$（$i\lt j$），则把中间那一段 $v_ie_{i+1}\cdots e_jv_j$ 整段删去，剩下的仍是一条 $u\to v$ 的途径，长度严格更短，与最短性矛盾。所以最短途径没有重复顶点，它就是路。∎

三二分图：用两种颜色说清结构

定义（二分图）

若 $V$ 能分成两个互不相交的集合 $X,Y$，使得每条边的两个端点分别落在 $X$ 与 $Y$ 中（同一集合内部没有边），则称 $G$ 为二分图，$(X,Y)$ 称为它的一个二划分。

二分图是“能用两种颜色染好”的图：把 $X$ 染黑、$Y$ 染白，每条边两端异色。它什么时候存在？判据只与圈有关。

定理（König：二分图与奇圈）

图 $G$ 是二分图，当且仅当 $G$ 中不含奇圈。

证明

（必要性）设 $(X,Y)$ 是二划分。沿圈走一圈，顶点必在 $X,Y$ 之间交替，回到起点时交替了偶数次，故圈长为偶数。

（充分性）设 $G$ 无奇圈。对每个连通分量取一个起点 $s$，按 $d(s,v)$ 的奇偶把顶点分成 $X$（偶）与 $Y$（奇）。任取边 $uv$，由 BFS 的性质 $|d(s,u)-d(s,v)|\le1$。若 $u,v$ 同属 $X$ 或同属 $Y$，则 $d(s,u)$ 与 $d(s,v)$ 同奇偶，只能相等；于是从 $s$ 到 $u$、$s$ 到 $v$ 的两条最短路加上边 $uv$ 构成一个长度为奇数的闭途径，其中必含奇圈，矛盾。故每条边都跨 $X,Y$，$G$ 是二分图。∎

这个证明顺带给出了算法：从任意点出发做 BFS，按层数奇偶染色，一旦发现一条边两端同色，就找到了奇圈。下面把三件事——连通块、最短距离、二分图判定——合到同一段 BFS 里。

四BFS：一层一层往外推

代码 1 · BFS：最短路 + 连通块 + 二分图判定C++17
vector<int> g[N];
int dist[N], col[N];        // dist 未访问时为 -1；col 取 0/1

// 从 s 出发遍历一个连通块；返回这个块是否二分
bool bfs(int s) {
    queue<int> q;
    dist[s] = 0; col[s] = 0;
    q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (dist[v] == -1) {            // 第一次到达：入队的下一个层次
                dist[v] = dist[u] + 1;
                col[v] = col[u] ^ 1;       // 相邻层异色
                q.push(v);
            } else if (col[v] == col[u]) {
                return false;             // 同层同色边 → 奇圈
            }
        }
    }
    return true;
}

// 主程序：先标 dist = -1，再对每个未访问点调用并计数连通块
int comp = 0;
for (int i = 1; i <= n; ++i)
    if (dist[i] == -1) { ++comp; if (!bfs(i)) puts("有奇圈"); }
易错

判断二分图时，不能只检查“新点”的染色，还要检查已经访问过的边。上面的代码里 else if (col[v] == col[u]) 处理的就是这类边；少了这一句，含奇圈的图也会被判成二分图。另外，BFS 只能在无权图上求最短路，带权图要换 Dijkstra。

五例题

例 1 用分层证明“相邻层”

设 $s$ 是连通图 $G$ 的一个顶点，$L_i=\lbrace v: d(s,v)=i\rbrace$。证明：对任意边 $uv$，$|i-j|\le 1$，其中 $i=d(s,u)$，$j=d(s,v)$。

解　不妨设 $i\le j$。取一条从 $s$ 到 $u$ 的最短路（长度 $i$），再接上边 $uv$，得到一条从 $s$ 到 $v$ 的长度为 $i+1$ 的途径。途径的长度不会小于最短路的长度，所以 $j\le i+1$。又已知 $i\le j$，于是 $0\le j-i\le1$，即 $|i-j|\le1$。∎

例 2 棋盘上的马

国际象棋的棋盘按黑白交替染色，马每次走“日”字。证明：马每走一步都会从一种颜色跳到另一种颜色。

解　把 64 个格子作为顶点，马能一步到达的两格连边。马走“日”是横 2 纵 1 或横 1 纵 2，两种走法都改变格子坐标之和的奇偶性（$2+1=3$ 与 $1+2=3$ 都是奇数），所以必然换色。

因此棋盘图是二分图，二划分正是黑白两色。马回到原格所需的步数必为偶数——这解释了为什么“马从角上出发，奇数步回不到角上”。

六习题

  1. 一个图有 8 个点、9 条边，且连通，它至少有几个圈？
    思路　树是连通且无圈的图，$n$ 个点最多 $n-1$ 条边；每多一条边就多一个圈（确切说多一个圈秩）。
    答案　至少 $9-8+1=2$ 个独立圈。一般地，连通图的“圈秩”是 $m-n+1$，它是最少的独立圈个数。
  2. 证明：若 $G$ 不连通，则 $G$ 的补图 $\overline{G}$ 一定连通。
    思路　取两个点，若它们分属不同的连通块，补图里直接相邻；若都在同一块，找一块外的点中转。
    答案　设 $u,v$ 属于不同连通块，则 $uv\notin E(G)$，故 $uv\in E(\overline G)$，直接连通。若 $u,v$ 同属一块 $C$，取另一块中的点 $w$，则 $uw,vw\notin E(G)$（跨块无边），故 $uw,vw\in E(\overline G)$，$u\to w\to v$ 连通。所以 $\overline G$ 连通。
  3. 判断 $C_5$（五边形）与 $K_{2,3}$ 是否为二分图。
    思路　找奇圈，或尝试二划分。
    答案　$C_5$ 含长度 5 的奇圈，不是二分图。$K_{2,3}$ 按两侧划分为 $X$（2 个点）与 $Y$（3 个点），所有边都跨两侧，是二分图。
  4. 一张网格图有 $(n+1)\times(m+1)$ 个格点，相邻格点连边。从 $(0,0)$ 到 $(n,m)$ 的最短路有多长？有多少条？
    思路　每步只能横或纵走一格，路径长度固定；不同路径就是横纵步的排列。
    答案　长度 $n+m$；路径数为 $\binom{n+m}{n}$，因为要在 $n+m$ 步中选出 $n$ 步向右。
  5. 为什么 BFS 第一次访问某个点时，得到的距离就是最短距离？
    思路　用队列的“先进先出”说明出队顺序按距离非减。
    答案　队列中点的距离单调不减，且每次扩展只把距离加 1。若存在更短的到达方式，它必然先于当前层被处理，与“第一次访问”矛盾。这正是分层性质 $|d(u)-d(v)|\le1$ 的另一种说法。
如果图中有重边，BFS 的“第一次访问”还成立吗？自环呢？
引导　重边不影响距离，只会让同一条边被枚举两次；自环会让 $u$ 与自己同色，从而被判成“有奇圈”——长度为 1 的圈。多数定义要求圈长至少 3，所以含自环的图通常直接不算简单图，需要单独约定。
进阶 · 距离、直径与“六度分隔”（Wilson Ch. 2）

连通图的直径是 $\max_{u,v}d(u,v)$，半径是 $\min_u\max_v d(u,v)$，两者满足 $\mathrm{rad}(G)\le\mathrm{diam}(G)\le2\,\mathrm{rad}(G)$。社交网络的“六度分隔”说的就是直径很小；真实网络常用“小世界”模型刻画，而竞赛里更常见的是求直径的两次 BFS 技巧（只对树成立）。

一页纸
  • 途径可重复点边，迹只不重复边，路两者都不重复；圈是闭合且简单的迹。
  • 连通关系是等价关系，等价类就是连通分量。
  • BFS 分层：每条边只连接同层或相邻层，所以第一次访问即最短。
  • $G$ 是二分图 $\iff$ $G$ 无奇圈；判定方法是 BFS 黑白染色。
