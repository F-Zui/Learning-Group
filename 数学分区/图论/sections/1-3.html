树与生成树

用最少的边把 n 个点连成一片，得到树；在带权图上挑一棵总权最小的生成树，就是 Kruskal 算法。学完能一眼认出树、手算最小生成树，并说清为什么贪心不会错。

一最省钱的连通方式

要在 $n$ 个城市之间修路，使任意两城都能互相到达，最少要修几条？答案不是 $\binom{n}{2}$，而是 $n-1$：把城市排成一条链，或者连成一棵“树”，就已经连通了，再多修一条都是浪费。

“刚好连通、没有多余”的图就是树。它简单到几乎没有结构，却同时是数据结构（并查集、线段树、Trie）和算法（生成树、树形 DP、LCA）的基础。更重要的，它是“连通”与“无圈”这两个条件刚好平衡的临界状态——少一条边就断开，多一条边就出现圈。

二树的四张面孔

定义（树与森林）

连通且不含圈的图称为树；不含圈的图称为森林，它的每个连通分量都是一棵树。叶子是度为 $1$ 的顶点（只有一个点的树，那个点也算叶子）。若 $H$ 是 $G$ 的生成子图且为树，称 $H$ 为 $G$ 的生成树。

定理（树的等价刻画）

设 $T$ 是 $n$ 个顶点的简单图，则下列四条等价：

（a）$T$ 连通且无圈；（b）$T$ 中任意两点恰有一条路；（c）$T$ 连通且 $m=n-1$；（d）$T$ 无圈且 $m=n-1$。

证明

（a）$\Rightarrow$（b）　连通给出存在性；若有两条不同的 $u\to v$ 路，取它们从 $u$ 出发最后一个公共点 $x$ 与回到 $v$ 前的第一个公共点 $y$，两段 $x\to y$ 的路内部不相交，合起来就是一个圈，矛盾。

（b）$\Rightarrow$（a）　唯一路显然推出连通。若含圈，圈上两点之间有两条不同的路，矛盾。

（a）$\Rightarrow$（c）　对 $n$ 归纳。$n=1$ 时 $m=0$。设 $n\ge2$，取 $T$ 中最长路 $v_0v_1\cdots v_k$。$v_0$ 的邻居必在路中（否则路可加长），而它除 $v_1$ 外不能再连别的 $v_i$（否则 $v_0v_1\cdots v_iv_0$ 成圈），故 $\deg(v_0)=1$，是叶子。删去 $v_0$ 后仍是树，由归纳假设它有 $n-2$ 条边，加回 $v_0$ 得 $m=n-1$。

（c）$\Rightarrow$（a）　若含圈，从圈上删去一条边，图仍连通，但只剩 $n-2$ 条边；而任何连通图至少有 $n-1$ 条边（由（a）$\Rightarrow$（c）对生成树使用），矛盾。故无圈。

（c）与（d）等价　只需证（d）$\Rightarrow$（c）。设 $T$ 有 $c$ 个连通分量，每个分量都是树，由（a）$\Rightarrow$（c）得 $m=n-c$；又 $m=n-1$，故 $c=1$，即连通。∎

读法

这张“四张面孔”表是后面反复引用的工具：看到连通无圈就想到 $n-1$ 条边，看到 $n-1$ 条边连通就想到无圈。许多证明只要在这四个说法之间换一次说法就完成了。比如“树至少两片叶子”，用（a）$\Rightarrow$（c）的归纳过程就顺手证完了。

三生成树与 Kruskal

任意连通图都含有生成树：随便找一条圈，删去圈上一条边，连通性不变；重复到没有圈为止。剩下的边数必然是 $n-1$。带权图上生成树有很多棵，我们通常要总权最小的那一棵，称为最小生成树（MST）。

Kruskal 的想法朴素到不像算法：把所有边按权重从小到大排序，依次尝试加入；只要这条边连接了两个还没连通的部分，就保留它，否则跳过。直觉是“最便宜的边先用”，而正确性来自一条被称为割性质的引理。

代码 1 · Kruskal + 并查集求最小生成树C++17
struct Edge { int u, v, w; };
int fa[N];

int find(int x) {                     // 路径压缩
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

long long kruskal(int n, vector<Edge>& e) {
    sort(e.begin(), e.end(),
         [](const Edge& a, const Edge& b) { return a.w < b.w; });
    for (int i = 1; i <= n; ++i) fa[i] = i;
    long long ans = 0;
    int cnt = 0;                          // 已选边数
    for (auto& ed : e) {
        int ru = find(ed.u), rv = find(ed.v);
        if (ru == rv) continue;            // 已连通：加进去会成圈
        fa[ru] = rv;                         // 合并两个集合
        ans += ed.w; ++cnt;
        if (cnt == n - 1) break;         // 树已成型
    }
    return cnt == n - 1 ? ans : -1;     // -1 表示图不连通
}
定理（Kruskal 正确性）

若 $G$ 连通，Kruskal 结束时选出的 $n-1$ 条边构成一棵最小生成树。

证明

先证算法得到的是一棵生成树。每次只在两端属于不同连通块时加边，所以已选边始终构成森林；算法一直加到 $n-1$ 条，森林就连成了一棵树。

再证最优。设算法依次选出 $e_1,\dots,e_{n-1}$，取一棵最小生成树 $T$，使 $T$ 与算法前缀 $e_1,\dots,e_k$ 的公共前缀尽可能长。若 $k\lt n-1$，令 $e=e_{k+1}=uv$。由算法可知 $u,v$ 在前缀构成的森林 $F$ 中属于不同连通块。把 $e$ 加入 $T$ 得到唯一的圈 $C$；圈上除 $e$ 外的边都在 $T$ 中，而 $u,v$ 在 $F$ 中不连通，所以 $C$ 上必有一条边 $f\notin F$，且 $f\ne e$。算法在第 $k+1$ 步时 $f$ 仍未被选中，由贪心顺序得 $w(e)\le w(f)$。于是 $T'=T-f+e$ 仍是生成树，总权不增，故也是最小生成树，且它与算法的公共前缀延长到 $e_1,\dots,e_{k+1}$，与 $k$ 的最大性矛盾。因此 $k=n-1$，算法结果就是 $T$。∎

易错

贪心只在“最小生成树”问题上正确，换成“最小生成森林”“斯坦纳树”或“最长路径”都会失效。另一个常见错误是并查集只写 fa[u]=v 而不做 find，这会把两棵子树接错根，答案偏大。Kruskal 不要求图连通，若不连通应返回森林或报告“不存在生成树”。

四有多少棵生成树

$K_n$ 有 $n^{n-2}$ 棵不同的生成树（Cayley 公式）。$n=4$ 时是 $16$ 棵，$n=5$ 时是 $125$ 棵。这个公式有一个漂亮的组合证明：把每棵树编码成一条长度为 $n-2$ 的序列（Prüfer 序列），编码与解码互逆，而序列的每一位都可以独立取 $1..n$，于是恰好 $n^{n-2}$ 个。

进阶 · Prüfer 编码与矩阵树定理（West Ch. 2）

编码规则：每次删去编号最小的叶子，把它的邻居写进序列，重复到只剩两个点；解码时按序列反推。序列与树一一对应，所以带标号树的个数是 $n^{n-2}$。若把“生成树计数”推广到任意图，则有矩阵树定理：生成树个数等于 Laplacian 矩阵任意一个主子式的行列式。竞赛里的“生成树计数”题通常直接用矩阵树定理加高斯消元。

五例题

例 1 用度数和反推叶子数

一棵树有 2 个度为 3 的顶点、3 个度为 2 的顶点，其余都是叶子。它有多少片叶子？

解　设叶子有 $L$ 片，则 $n=2+3+L=5+L$，边数 $m=n-1=4+L$。由握手定理：

$$2\cdot3+3\cdot2+1\cdot L=2(4+L)\ \Rightarrow\ 12+L=8+2L$$

解得 $L=4$，共 $9$ 个顶点、$8$ 条边。

例 2 手算 Kruskal

对上面那幅带权图，若把 $DE$ 的权从 $1$ 改成 $9$，最小生成树的总权是多少？

解　新的排序是 $AD=2$、$BC=3$、$AB=4$、$BE=5$、$CF=6$、$EF=7$、$BD=8$、$DE=9$。依次：$AD$ 收、$BC$ 收、$AB$ 收、$BE$ 收（此时 $A,B,C,D,E$ 已连通，未成圈），$CF$ 收，凑满 $5$ 条边。总权 $2+3+4+5+6=20$。

注意 $DE$ 变贵之后，$E$ 改用 $BE$ 接入，总权从 $16$ 涨到 $20$——最小生成树会随权重改变而换结构。

六习题

  1. 证明：$n\ge2$ 的树至少有两片叶子。
    思路　取最长路 $v_0\cdots v_k$，证明两个端点度都是 1。
    答案　$v_0$ 的邻居都在路中（否则路可延长），除 $v_1$ 外若还连 $v_i$，则 $v_0v_1\cdots v_iv_0$ 成圈，所以 $\deg(v_0)=1$；同理 $\deg(v_k)=1$。
  2. 一棵树有 10 个顶点，其中 4 个是叶子，其余顶点的度至少为 2。可能吗？各点度数和是多少？
    思路　先算边数，再看剩下的度如何分配。
    答案　$m=9$，度数和 $18$。叶子贡献 $4$ 度，剩下 $14$ 度分给 $6$ 个度至少为 $2$ 的点，最小需要 $12$，可行（如 $3,3,2,2,2,2$ 加四个 $1$ 的和为 $18$）。
  3. $K_4$ 有多少棵不同的生成树？用 Cayley 公式验证。
    思路　$n^{n-2}$，代入 $n=4$。
    答案　$4^{2}=16$ 棵。也可以直接数：$K_4$ 有 $6$ 条边，生成树取其中 $3$ 条且连通，共 $16$ 种。
  4. 为什么 Kruskal 遇到“两端已连通”的边一定要跳过？如果强行加入会怎样？
    思路　加入一条两端已连通的边，会在这条边与已有路径之间形成什么？
    答案　会形成一个圈，不再是一棵树；而生成树要求 $n-1$ 条边且无圈，多出的边只会增加总权（边权非负时），所以要跳过。
  5. 一个连通图有 $n$ 个点、$m$ 条边，它的生成树有多少条非树边？这个数有什么名字？
    思路　生成树有 $n-1$ 条边，其余边都在树外。
    答案　$m-(n-1)=m-n+1$ 条，称为图的圈秩（或零化度）。它也是“至少要删多少条边才能变成树”的答案。
如果所有边权都相同，Kruskal 会给出什么样的生成树？答案唯一吗？
引导　此时任何生成树总权都相同（都是 $n-1$ 条边），Kruskal 只是按输入顺序随便挑一棵。最小生成树不唯一，但最小总权唯一；若要求“字典序最小”的生成树，需要给边加第二关键字排序。
一页纸
  • 树 = 连通 + 无圈；等价于任意两点唯一路，等价于连通且 $m=n-1$。
  • 森林的边数是 $n-c$，$c$ 是连通分量数。
  • Kruskal：按权排序，不成圈就加入，凑够 $n-1$ 条边即停，$O(m\log m)$。
  • 带标号树的个数是 $n^{n-2}$；非树边有 $m-n+1$ 条。
