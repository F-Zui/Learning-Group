拓扑排序与强连通分量

在有向图上排出一个满足所有依赖的顺序（拓扑排序），再把互相可达的点压成一个点（强连通分量缩点）。学完能用 Kahn 判环、用 Tarjan 缩点，并在缩点后的 DAG 上做 DP。

一先修课与依赖

选课有先修关系：想学数据结构，得先学程序设计；想学算法，得先学数据结构与离散数学。若把这些关系画成有向边（先修课 → 后续课），问“存不存在一个合法的修课顺序”，就是问这张有向图有没有拓扑序。

依赖图里最怕的是环：A 依赖 B、B 依赖 C、C 又依赖 A，谁也不能先修。所以拓扑排序的第一个用途反而是判环。而现实中的图往往有成片的环（互相依赖的一组任务），这时要先把环“缩”成一个点，再看整体顺序——这就是强连通分量。

二DAG 与拓扑序

定义（拓扑序）

有向图 $G$ 的一个拓扑序是顶点的一个线性排列 $v_1,\dots,v_n$，使得对每条有向边 $v_i\to v_j$ 都有 $i\lt j$（先修的点排在前面）。不含有向环的有向图称为有向无环图（DAG）。

定理（拓扑序的存在性）

有向图存在拓扑序，当且仅当它是有向无环图。

证明

（必要性）若有有向环 $v_1\to v_2\to\cdots\to v_k\to v_1$，拓扑序要求 $v_1$ 在 $v_2$ 前、$v_2$ 在 $v_3$ 前……一路推回 $v_1$ 在 $v_1$ 前，矛盾。

（充分性）DAG 中一定存在入度为 0 的点：否则从任一点出发沿入边一路反向走，有限个点必然重复，形成有向环。把这样的点删去，剩下的仍是 DAG，归纳即可得到一个顺序；每一步删去的点都只依赖已经排好的点，所以这个顺序满足所有边。∎

三Kahn：每次取一个入度为 0 的点

证明里“删掉入度为 0 的点”直接给出算法：把所有入度为 0 的点放进队列，每次取出一个放进答案，并把它的出边删掉（后继入度减 1），入度减到 0 的后继入队。若最后答案不足 $n$ 个点，说明剩下的点都在环里。

代码 1 · Kahn 拓扑排序（同时判环）C++17
vector<int> g[N];
int indeg[N], n;
vector<int> topo;

bool kahn() {
    queue<int> q;
    for (int u = 1; u <= n; ++u)
        if (indeg[u] == 0) q.push(u);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (int v : g[u])
            if (--indeg[v] == 0) q.push(v);
    }
    return (int)topo.size() == n;   // false 表示有环
}

四强连通分量与缩点

定义（强连通与强连通分量）

有向图中若 $u$ 能到达 $v$ 且 $v$ 能到达 $u$，称 $u,v$ 强连通。强连通关系是等价关系，它的等价类称为强连通分量（SCC）。把每个 SCC 缩成一个点、SCC 之间的边保留，得到的图称为缩点图。

定理（缩点图是 DAG）

把每个强连通分量缩成一个点后，得到的图是有向无环图。

证明

若缩点图有环 $S_1\to S_2\to\cdots\to S_k\to S_1$，则 $S_1$ 中的点到 $S_2$、…、$S_k$ 再到回 $S_1$，这些点互相可达，应属于同一个强连通分量，与“缩成不同的点”矛盾。∎

代码 2 · Tarjan 求强连通分量（一次 DFS）C++17
vector<int> g[N];
int dfn[N], low[N], timer;
int scc[N], cnt;               // scc[u]：u 所属分量编号
int stk[N], top;
bool inStk[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++timer;
    stk[++top] = u; inStk[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {                    // 树边：递归
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (inStk[v]) {          // 仍在栈中：更新 low
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (low[u] == dfn[u]) {            // u 是分量的「根」
        ++cnt;
        while (true) {
            int v = stk[top--];
            inStk[v] = false;
            scc[v] = cnt;
            if (v == u) break;
        }
    }
}
读法

与 4.1 的割点算法相比，Tarjan 求 SCC 只多了一个栈和一句 inStk 判断。栈里放的是“还没归属任何一个 SCC 的点”；当某个点满足 $\mathrm{low}(u)=\mathrm{dfn}(u)$ 时，它就是当前分量的根，栈顶到它之间的所有点恰好构成这个分量，一起弹出。注意 else if 只能对还在栈里的邻居用 dfn 更新 low——已经出栈的点属于别的分量，不能连回去。

易错

两个高频错误：第一，漏掉 inStk[v] 判断，对所有已访问邻居都用 dfn[v] 更新 low，会把已经出栈、属于别的分量的点错误地连回来，导致分量合并；第二，对仍在栈中的邻居要用 dfn[v] 而不是 low[v] 更新——用 low 会把“间接可达”误当成“直接回到”，在交叉边上把不该合并的分量并掉。另外，递归深度可能爆栈，必要时改显式栈。

五例题

例 1 拓扑序判环

课程依赖为 $1\to2$、$1\to3$、$2\to4$、$3\to4$、$4\to5$。给出一个拓扑序；若再加入 $5\to1$，会怎样？

解　入度为 0 的只有 1，取出 1 后 2、3 入度归零，依次取出即可得到 $1,2,3,4,5$（$2,3$ 可交换）。加入 $5\to1$ 后形成 $1\to2\to4\to5\to1$ 的环，Kahn 只能取出部分点，答案长度小于 5，说明有环。

例 2 缩点后求最长路

一张有向图带点权，每个点可以重复经过，求一条路径能获得的最大点权和。

解　有环时“重复经过”会让答案无限大，所以先把每个 SCC 缩成一个点，点权改为分量内点权之和。缩点图是 DAG，在 DAG 上按拓扑序做 DP：$f[v]=\max_{(u,v)\in E}f[u]+w[v]$，初始 $f[v]=w[v]$，答案取所有 $f$ 的最大值。

这是“环上可以一直绕”与“DAG 上不能回头”的分界线：缩点把前者压成一个可整体取用的点，剩下的问题就变成第 1 章的最长路。

六习题

  1. 一个 DAG 至少有一个入度为 0 的点、至少有一个出度为 0 的点，为什么？
    思路　沿着入边（或出边）一直走，有限个点必然重复，重复即出环。
    答案　若每个点入度都大于 0，从任一点沿入边反向走，$n$ 步内必重复，形成一个有向环，与 DAG 矛盾；出度同理。
  2. 拓扑序唯一吗？什么情况下唯一？
    思路　看 Kahn 算法每一步可选的点有几个。
    答案　一般不唯一。若每一步入度为 0 的点都恰好只有一个，则拓扑序唯一；等价地，图必须是一条链（每层只有一个点）。
  3. 强连通分量里的任意两点之间，最多需要走多长？这与 SCC 的直径有关吗？
    思路　强连通只保证“能到”，不限制距离。
    答案　没有统一上界，可以接近 SCC 的点数。强连通只保证双向可达，不保证短；求“最远的最短路”就是 SCC 内部的直径问题。
  4. 为什么缩点后的图一定是 DAG？如果缩点后还有环会怎样？
    思路　环上的所有点互相可达。
    答案　缩点后的环意味着这些分量之间互相可达，于是它们本应属于同一个 SCC，与“已经缩到最大”矛盾。所以缩点图必然无环。
  5. Kahn 算法与 Tarjan 都能判环，各适合什么场景？
    思路　一个只看整体顺序，一个能拆出局部环。
    答案　Kahn 适合“判断有无环 + 输出顺序”，实现简单、常数小；Tarjan 适合“需要知道哪些点成环、需要缩点”的场景。两者复杂度都是 $O(V+E)$。
如果拓扑排序要求“字典序最小”，Kahn 算法要怎么改？
引导　把队列换成小根堆：每次取出编号最小的零入度点。这样得到的确实是字典序最小的拓扑序——每一步都选了当前能选的最小点，且选它不会让后续可选集合变差。若要求“逆字典序最大”，可以用反图 + 大根堆。
进阶 · 2-SAT 与 SCC 缩点（Bondy & Murty Ch. 9）

2-SAT（每个子句最多两个文字的可满足性问题）可以建“蕴含图”：文字 $x$ 与 $\lnot x$ 各一个点，子句 $(a\lor b)$ 化成 $\lnot a\to b$ 与 $\lnot b\to a$。公式可满足，当且仅当不存在某个 $x$ 使 $x$ 与 $\lnot x$ 在同一个 SCC 里。缩点后按拓扑序倒序给每个变量赋值即可构造解。这是 SCC 最经典的非图论应用。

一页纸
  • 拓扑序：每条边都从前指向后；存在 $\iff$ 无有向环。
  • Kahn：入度 0 入队，删边减度，答案不足 $n$ 即有环，$O(V+E)$。
  • SCC：互相可达的极大点集；缩点后必为 DAG。
  • Tarjan SCC：low 相等时弹栈成一个分量；只对“在栈中”的邻居用 dfn 更新。
