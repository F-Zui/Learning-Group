顶点着色与贪心

把“相邻的点不能同色”写成约束，用色数衡量一张图最少需要几种颜色；用贪心给出 $O(V^2+E)$ 的可行解，并说清它为什么有时比最优解多一种颜色。学完能把排课、分配、冲突回避化成着色问题。

一冲突只发生在相邻的点上

考试要排考场：同一门课的学生不能同时在两门考试的教室里出现，于是“有共同学生的两门课”不能安排在同一个时间段。把课程看成顶点、冲突看成边，问题就变成：给每个顶点一种颜色，使相邻顶点颜色不同，最少要几种颜色？

这就是顶点着色。它最常见的变体还有：给手机基站分配频段（相邻基站不能同频）、给编译器的变量分配寄存器（同时活跃的变量不能共用一个寄存器）、给地图上的国家上色（相邻国家不同色）。它们共用同一套语言，只是“相邻”的含义不同。

二色数与团数

定义（正常着色与色数）

映射 $c:V\to\lbrace1,\dots,k\rbrace$ 若满足对任意 $uv\in E$ 都有 $c(u)\ne c(v)$，称为正常 $k$-着色。使正常着色存在的最小 $k$ 称为图 $G$ 的色数，记作 $\chi(G)$。若 $\chi(G)\le k$，称 $G$ 是 $k$-可着色的。

定义（团与独立集）

两两相邻的顶点集合称为团，最大的团的大小称为团数 $\omega(G)$。两两不相邻的顶点集合称为独立集。正常着色等价于：把 $V$ 划分成 $\chi(G)$ 个独立集（同一颜色类内部没有边）。

定理（团数下界）

对任意图 $G$，$\chi(G)\ge\omega(G)$。特别地，$K_n$ 的色数是 $n$，含三角形的图至少需要 3 色。

证明

设团 $Q$ 的大小为 $\omega(G)$。$Q$ 中任意两点相邻，正常着色必须给它们互不相同的颜色，所以至少需要 $|Q|$ 种颜色。取最大的团即得 $\chi(G)\ge\omega(G)$。∎

易错

$\chi\ge\omega$ 只是下界，两者不相等。Mycielski 构造能把色数任意抬高而不产生三角形：从 5 个点的 $C_5$（$\chi=3$）出发构造一次，得到 11 个点的 Grötzsch 图，它没有三角形却需要 4 色。所以“图里没有三角形”推不出“两色就够”。

三贪心：拿到一个能用的解

求色数是 NP 难的（判定 $\chi\le3$ 就已经 NP 完全），所以竞赛里通常只要求构造一个合法着色，不要求最优。最直接的办法是贪心：按某个顺序依次处理顶点，每个点染上“邻居已经用过的最小颜色之外”的最小颜色。

定理（贪心上界）

对任意图 $G$，贪心着色最多使用 $\Delta(G)+1$ 种颜色，其中 $\Delta(G)$ 是最大度。因此 $\chi(G)\le\Delta(G)+1$。

证明

处理顶点 $u$ 时，它至多有 $\deg(u)\le\Delta$ 个邻居已经染色，因此这些邻居最多占用 $\Delta$ 种颜色。在 $1,2,\dots,\Delta+1$ 中必有一种没被占用，贪心总能给 $u$ 分配颜色。故总颜色数不超过 $\Delta+1$。∎

四Welsh–Powell：把大度点先安排

贪心的效果依赖顺序。Welsh–Powell 的做法是按度数从大到小排序：大度点最难安排，趁颜色还空着先给它定下来，后面小度点更容易找到空位。它是一个启发式，不保证最优，但常常比随机顺序好。

代码 1 · Welsh–Powell 贪心着色C++17
vector<int> g[N];
int col[N];

int welshPowell(int n) {
    vector<int> ord(n);
    iota(ord.begin(), ord.end(), 1);
    sort(ord.begin(), ord.end(), [](int x, int y) {
        return g[x].size() > g[y].size();   // 度数降序
    });
    fill(col, col + n + 1, 0);
    int used = 0;
    for (int u : ord) {
        vector<char> taken(n + 2, false);   // 邻居用过的颜色
        for (int v : g[u])
            if (col[v]) taken[col[v]] = true;
        int c = 1;
        while (taken[c]) ++c;                 // 最小可用色
        col[u] = c;
        used = max(used, c);
    }
    return used;
}
易错

贪心得到的颜色数依赖顺序，可能严格大于 $\chi$。例如二分图只需 2 色，但如果先给一侧的点都染 1，另一侧的点可能被迫用到更多颜色。要“保证最优”，只能枚举或整数规划；竞赛里若要求最优，题目一定给了特殊结构（树、区间图、二分图）。

五例题

例 1 三个图的色数

求 $C_5$、$K_4$、一棵有 10 个点的树各自的色数。

解　$C_5$ 含奇圈，不是二分图，$\chi\ge3$；用 3 色可以交替染好，故 $\chi=3$。$K_4$ 中任意两点相邻，$\chi=4$。树是二分图（无圈，当然无奇圈），$\chi=2$（$n\ge2$ 时）；只有单个点时 $\chi=1$。

例 2 排课：把冲突图染出来

5 门课的冲突关系为 $1\text{-}2,1\text{-}3,2\text{-}3,3\text{-}4,4\text{-}5,2\text{-}5$。最少需要几个时间段？

解　$1,2,3$ 两两冲突（三角形），至少 3 个时间段。尝试 3 色：$1$ 用 A，$2$ 用 B，$3$ 用 C；$4$ 只与 $3$ 冲突，可用 A；$5$ 与 $4$（A）和 $2$（B）冲突，只能用 C。检查 $3$ 与 $5$ 不冲突，A、B、C 均无冲突。故 3 个时间段足够，答案 $\chi=3$。

六习题

  1. 证明：$\chi(G)\ge\omega(G)$，并举例说明可以严格大于。
    思路　团内两两相邻；严格大于的例子用奇圈。
    答案　团内两点必须异色，故需 $|Q|$ 色。取 $C_5$：$\omega=2$（无三角形）而 $\chi=3$，严格大于。
  2. 为什么树的色数不超过 2？
    思路　树无圈，自然无奇圈；用 1.2 节的二分图判据。
    答案　树是二分图（无奇圈），二分图的二划分给出 2-着色；$n\ge2$ 时不可能 1 色，故 $\chi=2$。
  3. 贪心着色最多用 $\Delta+1$ 色，能否举一个恰好用到 $\Delta+1$ 色的图？
    思路　考虑完全图，或奇圈（$\Delta=2$，色数 3）。
    答案　$K_{\Delta+1}$ 的色数正是 $\Delta+1$；$C_5$ 是最小的例子（$\Delta=2$，$\chi=3$）。Brooks 定理说：除完全图与奇圈外，总有 $\chi\le\Delta$。
  4. 把“地图上相邻国家不同色”建模成图：顶点和边分别是什么？为什么它是平面图？
    思路　每个国家取一个首都作为顶点。
    答案　顶点是国家，边是“两国接壤”。把每个国家缩成一个点后，边可以画成不交叉的曲线（沿国界线走），所以得到平面图；四色定理正是说平面图 $\chi\le4$。
  5. 一个图有 100 个点、最大度 5，贪心最坏会用多少色？实际可能比这少很多吗？
    思路　$\Delta+1$ 上界，以及二分图/树的情形。
    答案　最多 6 色。若图是二分图或森林，实际只需 2 色；上界只保证“不超过”，差距可以很大。
如果允许“相邻点同色，但每条边要付罚款”，问题会变成什么？
引导　这不再是纯着色，而是带惩罚的优化问题，可以写成整数规划或用最小割求解（每条边一个惩罚项，二元变量表示颜色选择）。若只允许两种颜色，它恰好等价于“最小割”——把点分到两侧，割边就是同色的冲突边。这是图割在图像分割里的经典用法。
进阶 · Brooks 定理与完美图（West Ch. 5）

Brooks 定理：若连通图 $G$ 既不是完全图也不是奇圈，则 $\chi(G)\le\Delta(G)$。证明思路是找一条“两个邻居已经异色”的顶点最后染，让贪心最多用到 $\Delta$ 色。另一条线索是完美图：满足“每个导出子图都有 $\chi=\omega$”的图，二分图、区间图、弦图都是完美图，这类图上色数可以在多项式时间内求出。

一页纸
  • 正常着色 = 相邻异色；色数 $\chi$ 是最少的颜色数。
  • $\omega\le\chi\le\Delta+1$；两个界都可能取不到等号。
  • 贪心按任意顺序都能给出合法解；Welsh–Powell 按度数降序。
  • 求最优色数是 NP 难的；树/二分图 $\chi\le2$，奇圈 $\chi=3$。
