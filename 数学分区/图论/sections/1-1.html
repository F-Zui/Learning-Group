顶点、边与度：握手定理

一一个顶点被几条边牵着

建模完成之后，第一个能算的量就是“每个点连了几条边”。这个数小得可以写在顶点旁边，却已经能回答很多问题：一个班里能不能每个人都恰好认识 3 个人？一个图能不能被一笔画完？一颗树最多有几个叶子？

把它写成定义就是度。不要小看这一个整数——它是整门课里出现频率最高的统计量，几乎每个定理的条件或结论里都有它。

二度、度序列与握手定理

定义（度与度序列）

图 $G=(V,E)$ 中与顶点 $v$ 关联的边数称为 $v$ 的度，记作 $\deg(v)$。自环对度的贡献记为 $2$。若把全部顶点的度按从大到小排成一列 $d_1\ge d_2\ge\cdots\ge d_n$，称为 $G$ 的度序列。所有顶点度数都等于 $k$ 的图称为$k$-正则图。

下面这张图有 5 个顶点、6 条边，每个顶点旁边的数字就是它的度。请注意 C 点：它连着四条边，度是 4；而整张图的度加起来是 $12$，恰好是边数的两倍。

定理（握手定理）

对任意图 $G=(V,E)$，有

$$\sum_{v\in V}\deg(v)=2|E|$$
证明

把 $(v,e)$ 这样的有序对称为一次“点与边的关联”，其中 $e$ 与 $v$ 关联，数一数这种对的总数。一方面，按顶点分组数：顶点 $v$ 参与的关联有 $\deg(v)$ 次，合计 $\sum_v\deg(v)$。另一方面，按边分组数：每条边 $e=uv$ 恰好与两个端点关联，贡献 $2$ 次，合计 $2|E|$。两种数法数的是同一个集合，故相等。∎

读法

证明里没有用任何图的特殊性质，只用了“同一件事数两遍”（double counting）。这是图论最常用的证明手法：把一个量按两种方式统计，等式自然出现。后面第 5 章的 Turán 定理还会再用一次。

握手定理立刻给出两个推论，它们比定理本身更常用：

推论

（1）任意图中，奇度顶点的个数必为偶数。（2）若 $G$ 是 $k$-正则图且 $n$ 个顶点，则 $kn$ 为偶数，边数 $m=kn/2$。

证明

（1）$\sum_v\deg(v)=2m$ 是偶数。若奇度顶点有奇数个，则总和中奇数项有奇数个，和会是奇数，矛盾。（2）直接由 $\sum_v\deg(v)=kn=2m$ 得到。∎

易错

“度数为偶数和”不代表每个点都是偶数度，也不代表图存在。例如 $(3,3,1,1)$ 的总和是 $8$，满足奇偶性，却画不出来（下一节会验证）。握手定理只是必要条件，它能否定，不能肯定。

三度序列能不能画出来

给定一串非负整数，怎么判断它是不是某张简单图的度序列？这个问题叫可图化问题。最直接的算法是 Havel 和 Hakimi 在 1955 年前后给出的贪心：

算法（Havel–Hakimi）

把度序列从大到小排好。取最大的度 $k$，让这个顶点与后面 $k$ 个度最大的顶点相连，然后把这 $k$ 个顶点的度各减 $1$、删掉这个顶点，重新排序，重复上述步骤。若过程中出现负数，则不可图化；若序列被全部消成 $0$，则可图化。

直觉是：度最大的点最“难安排”，先把它要的邻居一次性配给它，剩下的问题规模就小了一点。可以证明（Havel–Hakimi 定理）这样做不丢失解：若原序列可图化，就一定存在一个图让最大度顶点恰好连向接下来最大的那几个点。下面这张对比图给出两个四点的例子。

把上面的“接不上就重排”过程写成代码，就是 Havel–Hakimi 算法。它每一轮排序一次、删一个点，复杂度 $O(n^2\log n)$，对竞赛里常见的 $n\le 2000$ 足够。

代码 1 · Havel–Hakimi 判定度序列C++17
// 返回 d 是否为某个简单无向图的度序列（会原地修改 d）
bool havelHakimi(vector<int> d) {
    for (;;) {
        sort(d.rbegin(), d.rend());                  // 1. 降序
        while (!d.empty() && d.back() == 0) d.pop_back(); // 0 度点不影响
        if (d.empty()) return true;               // 全部消完：可图化
        int k = d[0];
        if (k > (int)d.size() - 1) return false;   // 2. 邻居不够
        d.erase(d.begin());                          // 3. 删掉这个点
        for (int i = 0; i < k; ++i) {
            if (d[i] == 0) return false;            // 4. 减出负数
            --d[i];
        }
    }
}

四同构：两个图什么时候是同一个

度序列是图的“指纹”，但它不是“身份证”。下面两个图都是 6 个点、9 条边、每个点度数为 3，度序列一模一样，结构却完全不同：左边不含三角形，右边含两个三角形。

定义（同构）

若存在双射 $\varphi:V(G)\to V(H)$，使得对任意 $u,v\in V(G)$，$uv\in E(G)$ 当且仅当 $\varphi(u)\varphi(v)\in E(H)$，则称 $G$ 与 $H$ 同构，记作 $G\cong H$。$\varphi$ 称为同构映射。

读法

同构就是“把顶点换名字，邻接关系一个字都不改”。所以一个图的性质若只依赖邻接关系（点数、边数、度序列、连通性、是否含三角形、色数），就一定被同构保持；这些量称为同构不变量。判断不同构，只需找出一个不变量不同；判断同构，则必须真的把映射构造出来。

找同构没有已知的多项式算法（它是 NP 问题，虽然 2015 年 Babai 给出了拟多项式算法），竞赛里通常只需要用不变量排除掉大多数的“伪相同”。实践顺序是：先比点数、边数，再比度序列，再比连通分量数和三角形个数，最后才尝试构造映射。

五例题

例 1 用 Havel–Hakimi 跑一遍

判断 $(4,3,3,3,1)$ 是否可图化。

解　按算法逐轮操作：

$$\begin{aligned}(4,3,3,3,1) &\longrightarrow (2,2,2,0)\\(2,2,2,0) &\longrightarrow (1,1,0)\\(1,1,0) &\longrightarrow (0,0)\end{aligned}$$

序列被消成 $0$，说明可图化。对应的图有 5 个点、$14/2=7$ 条边，最大度的点连着其余四个点，与序列吻合。

例 2 握手定理的直接应用

某班有 9 名学生，每人恰好认识 3 名同班同学（认识关系是相互的）。这可能吗？若有 10 名学生呢？

解　把学生看成顶点，“认识”看成无向边，则每人度数都是 3，是 3-正则图。由推论，$3n$ 必须是偶数，所以 $n$ 必须为偶数。9 人不可能；10 人时 $m=3\times10/2=15$，存在这样的图（例如 Petersen 图），所以可能。

注意：握手定理只能排除奇数 $n$，它不保证 10 人时一定构造得出来——构造还需要另做，这里给出的 Petersen 图就是构造。

六习题

  1. 证明：任意图中，度数为奇数的顶点有偶数个。
    思路　把 $\sum_v\deg(v)=2m$ 按“偶数度项”和“奇数度项”拆开看奇偶性。
    答案　总和为偶数，偶数度项之和为偶数，故奇数度项之和也为偶数；若干个奇数相加为偶数，说明奇数项个数为偶数。
  2. 判断 $(3,3,3,1)$ 是否可图化。
    思路　从最大度 3 出发，让第一个点连后三个点。
    答案　$(3,3,3,1)\to(2,2,0)\to(1,-1)$，出现负数，不可图化。总和 $10$ 是偶数，说明只看奇偶性是不够的。
  3. $K_n$ 中每个顶点的度是多少？边数呢？$K_{n}$ 是几正则图？
    思路　每个点与其余 $n-1$ 个点都相邻。
    答案　每个点度为 $n-1$，所以 $K_n$ 是 $(n-1)$-正则图；边数 $n(n-1)/2$。
  4. 一个 4-正则图有 12 个顶点，它有多少条边？若它还是连通的，删除一条边后各点度数如何变化？
    思路　先用 $kn=2m$，再想删边影响哪两个点。
    答案　$m=4\times12/2=24$。删除边 $uv$ 后，$u,v$ 的度各减 1，其余不变，此时图有一个点度为 3、一个点度为 3、其余为 4；若这条边是桥，图会分裂成两块。
  5. 构造两个 6 个点、6 条边、度序列都是 $(2,2,2,2,2,2)$ 但不同构的图。
    思路　一个连通、一个不连通；连通的那个还可以换形状。
    答案　$C_6$（六边形）与两个互不相交的三角形 $2K_3$。前者连通，后者有两个连通分量，故不同构。
如果只知道一个图的度序列，能确定它的连通分量个数吗？
引导　不能。$(2,2,2,2,2,2)$ 既可以是连通的 $C_6$，也可以是两块三角形；甚至同一个图删掉不同边也会改变分量数。度序列只记录“每个点连了几条”，而“谁和谁连”才是结构——这也正是同构要补上的信息。
进阶 · Erdős–Gallai 定理与可图化的完整判据（West Ch. 1）

Havel–Hakimi 是构造性判据，逐轮执行即可。另一个等价判据是 Erdős–Gallai 不等式：非增序列 $d_1\ge\cdots\ge d_n$ 可图化，当且仅当总和为偶数且对每个 $k=1,\dots,n$ 都有 $$\sum_{i=1}^{k}d_i\le k(k-1)+\sum_{i=k+1}^{n}\min(d_i,k)$$ 它的直观是：前 $k$ 个点内部最多贡献 $k(k-1)$ 个度，剩下的度只能来自后面的点，而每个后面的点最多向这 $k$ 个点贡献 $k$ 个度。West 的第 1 章给出了完整证明。

一页纸
  • $\deg(v)$ 是与 $v$ 关联的边数；所有度加起来等于边数的两倍。
  • 奇度顶点必为偶数个；$k$-正则图的边数是 $kn/2$。
  • Havel–Hakimi：最大度先连、逐个减一、出现负数即失败。
  • 度序列相同不足以说明同构；同构要求存在保持邻接的双射。
