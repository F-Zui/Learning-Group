## 课时1　函数的概念

**课时定位**　本章研究的是"函数的极限"，所以必须先说清楚"函数"这件事。这一讲没有新思想，但定义域的求法会在此后每一章反复使用。

**学习目标**　能说清函数的三要素；能熟练求出由表达式确定的定义域；能用配方法与反解法求简单函数的值域。

**预计用时**　2 小时

### 一、区间与邻域

**（一）区间**

设 $a, b ∈ R$ 且 $a < b$。

1. 开区间：$(a, b) = {x | a < x < b}$
2. 闭区间：$[a, b] = {x | a ≤ x ≤ b}$
3. 半开半闭区间：$(a, b]$ 与 $[a, b)$

$a$、$b$ 称为区间的端点。此外引进无穷区间：

$(a, +∞) = {x | x > a}$，$(−∞, b) = {x | x < b}$，$(−∞, +∞) = R$

注意：$+∞$ 与 $−∞$ 只是记号，**不是数**，所以含无穷的一侧永远取开。

**（二）邻域**

设 $a$ 是实数，$δ > 0$。数集 ${x | |x − a| < δ}$ 称为点 $a$ 的 **$δ$ 邻域**，记作 $U(a, δ)$，即

$$ U(a, δ) = (a − δ, a + δ) $$

$a$ 称为邻域的中心，$δ$ 称为半径。挖掉中心后得到的数集

$$ U°(a, δ) = {x | 0 < |x − a| < δ} = (a − δ, a) ∪ (a, a + δ) $$

称为点 $a$ 的**去心 $δ$ 邻域**。两者的区别如图 1.1.1 所示：邻域把中心 $a$ 也算在内，去心邻域则把中心挖掉。

![[fig1_1_1]]

:::难点 为什么要引入"邻域"？
因为我们后面要研究的不是"$x$ 等于某个数时函数值是多少"，而是"**当 $x$ 无限接近 $a$ 时函数值趋近于什么**"。"接近 $a$"这件事必须被量化，否则无法进入数学推理。

邻域的精髓在于：**它不固定**。$δ$ 可以取 $0.1$，也可以取 $0.0001$。正因为 $δ$ 是**任意的正数**，我们才能用它表达"要多近就有多近"。请记住这句——**$δ$ 的任意性，是后面全部极限定义的发动机**。

还要特别注意：**邻域永远是一个开区间**，两个端点取不到。这不是技术细节，而是本质要求：极限只关心 $a$ 附近的情况，从不关心 $a$ 这一点本身。
:::

### 二、函数的定义

**定义 1.1**　设数集 $D ⊆ R$。若对每一个 $x ∈ D$，按照某个确定的对应法则 $f$，都有**唯一确定**的实数 $y$ 与之对应，则称 $f$ 为定义在 $D$ 上的函数，记作 $y = f(x)$，$x ∈ D$。其中 $D$ 称为**定义域**，记作 $D_f$；数集 ${y | y = f(x), x ∈ D}$ 称为**值域**，记作 $R_f$。

这个定义里藏着三个必须咬住不放的要点：

**要点 1："对每一个 $x ∈ D$"**　定义域内的每个点都必须有对应的函数值，不允许漏点。

**要点 2："唯一确定的 $y$"**　这是"函数"区别于"一般对应关系"的关键，一个 $x$ 不能对应两个 $y$。

**要点 3：定义域是函数的组成部分。**　这一点最容易被忽视。写 $y = x²$ 其实是不完整的；完整的写法是 $y = x², x ∈ R$。换成 $y = x², x ∈ [0, 1]$，那就是**另一个函数**了。

:::难点 判断两个函数是否相同
两个函数相同，当且仅当**定义域相同**且**对应法则相同**，与自变量、因变量用什么字母表示无关。

因此 $y = x (x ∈ R)$ 与 $y = x²/x (x ≠ 0)$ **不是**同一个函数——后者的定义域少了一个点 $x = 0$。

==凡有约分、开方、取对数，都必须回头检查定义域是否被改变。== 很多同学化简时习惯性约分，这一步会悄悄改掉定义域。
:::

**（三）分段函数**

在定义域的不同部分用不同表达式表示的函数称为**分段函数**。例如绝对值函数可写为：当 $x ≥ 0$ 时 $|x| = x$；当 $x < 0$ 时 $|x| = −x$。

:::易错 分段函数是"一个"函数
分段函数是**一个**函数，只是表达式被分成几段。求值时必须看清 $x$ 落在哪一段；在**分界点**处要单独判断，不能想当然地代入某一段。这是课时 13 讨论连续性、课时 17 讨论可导性时的核心考点。
:::

### 三、定义域的求法

定义域由实际问题决定，或由表达式自然确定。由表达式确定时，只需列出所有使表达式有意义的条件，再取**交集**。常用限制有五条：

| 表达式类型 | 限制条件 |
|---|---|
| 分式 $1/g(x)$ | $g(x) ≠ 0$ |
| 偶次根式 $√(g(x))$ | $g(x) ≥ 0$ |
| 对数 $logₐ g(x)$ | $g(x) > 0$，且 $a > 0, a ≠ 1$ |
| 反正弦、反余弦 | $−1 ≤ g(x) ≤ 1$ |
| 正切 $tan g(x)$ | $g(x) ≠ π/2 + kπ (k ∈ Z)$ |

:::例题 例 1　求 $y = √(4 − x²) + 1/(x − 1)$ 的定义域
**解**　需要同时满足两个条件：

1. $4 − x² ≥ 0$，即 $(2 − x)(2 + x) ≥ 0$，解得 $−2 ≤ x ≤ 2$；
2. $x − 1 ≠ 0$，即 $x ≠ 1$。

取交集得定义域 $[−2, 1) ∪ (1, 2]$。

**要点**　两个条件之间是"且"，所以取**交集**。写答案时要把被挖掉的点和断开的两段表达清楚，不能写成 $[−2, 2]$。
:::

:::例题 例 2　求 $y = ln(x² − 3x + 2) + arcsin(x/3)$ 的定义域
**解**　对数要求真数为正：

$x² − 3x + 2 > 0 ⟹ (x − 1)(x − 2) > 0 ⟹ x < 1$ 或 $x > 2$。

反正弦要求自变量落在 $[−1, 1]$ 内：

$−1 ≤ x/3 ≤ 1 ⟹ −3 ≤ x ≤ 3$。

两者取交集，得定义域 $[−3, 1) ∪ (2, 3]$。

**要点**　解二次不等式先因式分解再定号，比直接套求根公式更不易出错；最后一定画数轴取交集。
:::

### 四、值域的求法

值域通常比定义域难求。本章只要求掌握三种最基本的办法。

**方法 1：观察法。**　利用 $√{ } ≥ 0$、$x² ≥ 0$、$|x| ≥ 0$ 这类显然的非负性。

**方法 2：配方加单调性。**　二次函数基本都用它。

**方法 3：反解 $x$。**　从 $y = f(x)$ 中把 $x$ 解出来，再看为使 $x$ 有意义 $y$ 必须满足什么条件。它的完整形式（判别式法）见例 4。

:::例题 例 3　求 $y = x² − 2x + 3$（$x ∈ [0, 3]$）的值域
**解**　配方得 $y = (x − 1)² + 2$。

这是开口向上的抛物线，顶点 $x = 1$ 落在区间 $[0, 3]$ 内部，故最小值在 $x = 1$ 取得：$yₘᵢₙ = 2$。

最大值在离顶点较远的端点取得。比较两端：$x = 0$ 时 $y = 3$；$x = 3$ 时 $y = 6$。故 $yₘₐₓ = 6$。

值域为 $[2, 6]$。
:::

:::难点 闭区间上二次函数的最值
**顶点在区间内**：最小值在顶点，最大值在离顶点较远的那个端点。
**顶点在区间外**：函数在整个区间上单调，最值都在端点。

很多同学一见二次函数就只算顶点，这是错的。==必须先判断顶点是否落在给定区间内。==
:::

:::例题 例 4　求 $y = (x² − x + 1)/(x² + x + 1)$ 的值域
**解**　先看分母：$x² + x + 1 = (x + 1/2)² + 3/4 > 0$，对一切 $x$ 成立，故函数处处有定义。

把 $y$ 当作常数，去分母：

$$ y(x² + x + 1) = x² − x + 1 $$

整理成关于 $x$ 的二次方程：

$$ (y − 1)x² + (y + 1)x + (y − 1) = 0　　(∗) $$

原问题等价于：**存在实数 $x$ 使 $(∗)$ 成立**。

**当 $y ≠ 1$ 时**，$(∗)$ 是二次方程，有实根当且仅当判别式非负：

$$ Δ = (y + 1)² − 4(y − 1)² ≥ 0 $$

展开得 $y² + 2y + 1 − 4y² + 8y − 4 ≥ 0$，即 $−3y² + 10y − 3 ≥ 0$，即 $3y² − 10y + 3 ≤ 0$。

因式分解 $(3y − 1)(y − 3) ≤ 0$，得 $1/3 ≤ y ≤ 3$。

**当 $y = 1$ 时**，$(∗)$ 退化为 $2x = 0$，有实根 $x = 0$，故 $y = 1$ 确实取得到。

综上，值域为 $[1/3, 3]$。
:::

:::易错 判别式法的两个陷阱
**陷阱一：忘记讨论二次项系数为零。**　当 $y = 1$ 时 $(∗)$ 不再是二次方程，"$Δ ≥ 0$" 这个条件失效，必须单独验证。==凡是二次项系数含参数，都要先讨论系数是否为零。==

**陷阱二：只求 $Δ ≥ 0$ 就下结论。**　去分母的前提是分母不为零。本题分母恒正，所以安全；若分母可能为零，必须另行排除。
:::

## 课时2　函数的四种特性与反函数

**课时定位**　这一讲建立描述函数"整体行为"的四个词汇，并引入反函数。其中**有界性**是本章的隐藏主角——课时 5 的"收敛数列必有界"、课时 14 的"闭区间上连续函数必有界"，用的都是它。

**学习目标**　能准确叙述有界、单调、奇偶、周期的定义；能判断给定函数的这些性质；能判断反函数是否存在并求出反函数。

**预计用时**　3 小时

### 一、有界性

**定义 1.2**　设函数 $f(x)$ 的定义域为 $D$，数集 $X ⊆ D$。

1. 若存在 $M > 0$，使得对一切 $x ∈ X$ 都有 $|f(x)| ≤ M$，则称 $f(x)$ 在 $X$ 上**有界**；
2. 否则称 $f(x)$ 在 $X$ 上**无界**。

:::难点 有界性的真正含义
"有界"是一个**整体性**断言：它说的是"**存在一个统一的 $M$，把所有函数值一次圈住**"。注意这个 $M$ 必须对整个 $X$ 通用，不能对不同的 $x$ 换不同的 $M$。

因此，要否定有界性（证明无界），必须证明：**对任意给定的 $M > 0$，都能找到某个 $x ∈ X$ 使 $|f(x)| > M$**。这就是"任意—存在"结构的又一次出现，与极限定义同源。

把有界性拆开看，它等价于两条同时成立：

1. **有上界**：存在 $M₁$，使 $f(x) ≤ M₁$ 对一切 $x ∈ X$ 成立；
2. **有下界**：存在 $M₂$，使 $f(x) ≥ M₂$ 对一切 $x ∈ X$ 成立。

==有界 ⟺ 既有上界又有下界。==
:::

**例**　$y = sin x$ 在 $R$ 上有界，因为 $|sin x| ≤ 1$。

**例**　$y = 1/x$ 在 $(0, 1)$ 上**无界**（$x$ 越接近 $0$，$1/x$ 越大）；但在 $[1, +∞)$ 上**有界**（$0 < 1/x ≤ 1$）。

:::难点 有界性依赖于区间
同一个函数，在一个区间上有界，在另一个区间上可能无界。所以"$f$ 有界"这句话本身是不完整的，**必须问清楚是在哪个区间上有界**。

这个观念在课时 14 会兑现：闭区间上连续的函数一定有界——"闭区间"这三个字是绝对不能丢的。$y = 1/x$ 在 $(0,1)$ 上连续却无界，正是因为区间不闭。
:::

:::易错 关于 $M$ 的两个误解
**误解一：以为 $M$ 唯一。**　$M$ 不唯一。若 $|f(x)| ≤ M$ 成立，则对任何 $M' > M$ 也成立。证明有界时，找到一个"够用"的 $M$ 即可，**不需要找最小的那个**。

**误解二：把"有界"与"能取到最大值"混为一谈。**　有界只要求函数值被圈住，不要求最大值被取到。例如 $y = x$ 在 $(0,1)$ 上有界（$|x| < 1$），但取不到最大值。
:::

### 二、单调性

**定义 1.3**　设 $f$ 在区间 $I$ 上有定义。若对 $I$ 上任意两点 $x₁ < x₂$，都有 $f(x₁) < f(x₂)$，则称 $f$ 在 $I$ 上**单调增加**；若都有 $f(x₁) > f(x₂)$，则称 $f$ 在 $I$ 上**单调减少**。单调增加与单调减少统称**单调**。

:::难点 "任意"二字不能换成"存在"
定义里 $x₁, x₂$ 是 $I$ 上**任意**两点。如果只对某一对特殊的两点验证了 $f(x₁) < f(x₂)$，那是不能说明单调的。这是初学者最常见的逻辑错误。

用定义证明单调性的标准写法是：
**任取** $x₁, x₂ ∈ I$ 且 $x₁ < x₂$，**作差** $f(x₂) − f(x₁)$，**判断符号**。
:::

**单调性的一个核心用途：证明不等式。**　要证当 $x > a$ 时 $f(x) > g(x)$，只需令

$$ F(x) = f(x) − g(x) $$

证明 $F$ 在 $[a, +∞)$ 上单调增加，且 $F(a) ≥ 0$。这样由 $x > a$ 得 $F(x) ≥ F(a) ≥ 0$，即 $f(x) ≥ g(x)$。这个思路在课时 32 会用导数系统化，成为证明不等式的标准武器。

### 三、奇偶性

**定义 1.4**　设 $f$ 的定义域 $D$ **关于原点对称**。

1. 若对一切 $x ∈ D$ 都有 $f(−x) = f(x)$，称 $f$ 为**偶函数**，图像关于 $y$ 轴对称；
2. 若对一切 $x ∈ D$ 都有 $f(−x) = −f(x)$，称 $f$ 为**奇函数**，图像关于原点对称。

:::易错 判断奇偶性前必须先查定义域
"定义域关于原点对称"是奇偶性有意义的前提。例如 $f(x) = x²$，$x ∈ [−1, 2]$：虽然形式上 $f(−x) = f(x)$ 成立，但定义域不对称（$x = 2$ 在定义域内而 $x = −2$ 不在），所以它**既不是奇函数也不是偶函数**。

正确的判断顺序永远是：**先查定义域是否对称，再验证 $f(−x)$ 与 $f(x)$ 的关系。**
:::

**运算规律**（在公共定义域上）：

1. 奇 $×$ 奇 $=$ 偶；偶 $×$ 偶 $=$ 偶；奇 $×$ 偶 $=$ 奇
2. 奇 $±$ 奇 $=$ 奇；偶 $±$ 偶 $=$ 偶
3. 复合函数 $f[g(x)]$：只要内层 $g$ 是偶函数，复合结果就是偶函数

:::提示 奇函数的一个免费结论
若奇函数 $f$ 在 $x = 0$ 处有定义，则必有 $f(0) = 0$。

理由：取 $x = 0$ 代入 $f(−x) = −f(x)$，得 $f(0) = −f(0)$，故 $2f(0) = 0$，即 $f(0) = 0$。

这个结论在求参数题里经常直接省掉一半计算。
:::

### 四、周期性

**定义 1.5**　若存在 $T > 0$，使得对一切 $x ∈ D$ 都有 $x + T ∈ D$，且

$$ f(x + T) = f(x) $$

则称 $f$ 为**周期函数**，$T$ 称为 $f$ 的**周期**。若在所有正周期中存在最小的一个，则称它为**最小正周期**。

:::难点 周期不唯一，且未必存在最小正周期
**第一层：周期有无穷多个。**　若 $T$ 是周期，则 $2T, 3T, …$ 与 $T/2, T/3, …$（若仍在定义域内可行）也都是周期。例如 $sin x$ 的周期有 $2π, 4π, 6π, …$。所以我们通常只关心**最小正周期**，$sin x$ 的最小正周期是 $2π$。

**第二层：不是所有周期函数都有最小正周期。**　两个经典反例：

1. 常数函数 $f(x) = 1$：任何正数 $T$ 都满足 $f(x+T) = f(x)$，故没有最小正周期。
2. 狄利克雷函数 $D(x)$：当 $x$ 为有理数时取 $1$，当 $x$ 为无理数时取 $0$。任何正有理数 $T$ 都是它的周期（有理数加有理数仍是有理数），而正有理数中没有最小者，故无最小正周期。

==因此"周期函数一定有最小正周期"是错的。==
:::

### 五、反函数

**定义 1.6**　设 $f$ 的定义域为 $D$，值域为 $R_f$。若对每一个 $y ∈ R_f$，在 $D$ 中都有**唯一**的 $x$ 使 $f(x) = y$，则得到一个定义在 $R_f$ 上的函数，称为 $f$ 的**反函数**，记作 $x = f⁻¹(y)$，习惯上写作 $y = f⁻¹(x)$。

:::难点 反函数存在的条件：单调
关键在"**唯一**"两个字。若 $f$ 是**单调**函数，那么不同的 $x$ 一定给出不同的 $f(x)$，于是每个 $y$ 至多对应一个 $x$；而 $y$ 取遍值域时又至少对应一个 $x$。两者合起来，唯一性自动成立。

==所以：单调函数必有反函数。==

反过来，不单调的函数往往在同一个 $y$ 上对应多个 $x$，反函数就不存在。例如 $y = x²$ 在 $R$ 上没有反函数（$y = 4$ 同时对应 $x = 2$ 与 $x = −2$）；但若把它限制在 $[0, +∞)$ 上，它就单调增加，反函数 $y = √x$ 存在。

==这说明：反函数是否存在，与"在哪个区间上看"有关。==
:::

**$f$ 与 $f⁻¹$ 的三条基本关系**：

1. **定义域与值域互换**：$D_(f⁻¹) = R_f$，$R_(f⁻¹) = D_f$。
2. **图像关于直线 $y = x$ 对称**。原因：点 $(a, b)$ 在 $f$ 的图像上 $⟺ b = f(a) ⟺ a = f⁻¹(b) ⟺$ 点 $(b, a)$ 在 $f⁻¹$ 的图像上，而 $(a,b)$ 与 $(b,a)$ 正是关于 $y = x$ 对称的一对点。
3. **恒等式**：$f⁻¹[f(x)] = x$（$x ∈ D_f$），$f[f⁻¹(y)] = y$（$y ∈ R_f$）。

:::易错 $f⁻¹(x)$ 与 $[f(x)]⁻¹$ 完全是两回事
前者表示**反函数**，后者表示**倒数**。

最典型的是三角函数记号：$sin⁻¹x$ 表示反正弦函数 $arcsin x$，而 $(sin x)⁻¹ = 1/sin x = csc x$。

这是历史遗留的记号冲突，读题时必须结合上下文判断。==建议：本课程一律用 $arcsin x$，不用 $sin⁻¹x$，以免混淆。==
:::

**求反函数的标准步骤**：

1. 由 $y = f(x)$ 解出 $x = f⁻¹(y)$；
2. 交换字母，写成 $y = f⁻¹(x)$；
3. **写出定义域**——即原函数的值域。这一步最容易被漏掉。

:::例题 例 1　求 $y = (2x + 1)/(x − 3)$ 的反函数及其定义域
**解**　原函数定义域为 $x ≠ 3$。

由 $y = (2x + 1)/(x − 3)$ 去分母：$y(x − 3) = 2x + 1$，即 $yx − 3y = 2x + 1$。

把含 $x$ 的项归并：$x(y − 2) = 3y + 1$，故

$$ x = (3y + 1)/(y − 2)　(y ≠ 2) $$

交换字母得反函数 $y = (3x + 1)/(x − 2)$，其定义域为 $x ≠ 2$。

**要点**　反函数的定义域 $x ≠ 2$ 正好是原函数的值域（原函数取不到 $y = 2$，因为 $(2x+1)/(x−3) = 2$ 会导出 $2x + 1 = 2x − 6$，矛盾）。==这个对应关系可以反过来用作校验。==
:::

## 课时3　复合函数与初等函数

**课时定位**　这一讲把"函数"这个工具箱整理清楚。复合函数是后面链式法则（课时 19）与换元积分（课时 41）的操作对象；初等函数则决定了课时 14 那条"可以直接代入求极限"的便利规则。

**学习目标**　能判断复合函数是否有定义并求出其定义域；能把复杂表达式分解为基本初等函数的复合；能默写五类基本初等函数的图像与性质；掌握双曲函数的定义与基本恒等式。

**预计用时**　3 小时

### 一、复合函数

**定义 1.7**　设 $y = f(u)$ 的定义域为 $D_f$，$u = g(x)$ 的定义域为 $D_g$、值域为 $R_g$。若 $R_g ∩ D_f ≠ ∅$，则称

$$ y = f[g(x)] $$

为由 $f$ 与 $g$ 复合而成的**复合函数**，$u$ 称为**中间变量**。

:::难点 复合函数的定义域怎么定
$f[g(x)]$ 有意义，需要**两个条件同时成立**：

1. $x ∈ D_g$，即 $g(x)$ 本身要算得出来；
2. $g(x) ∈ D_f$，即 $g$ 的输出要落在 $f$ 的定义域里。

**第 2 条是最容易漏掉的。**　很多同学只检查第 1 条，结果定义域求大了。

举一个能暴露问题的例子：$f(u) = ln u$，$g(x) = x − 2$。则 $f[g(x)] = ln(x − 2)$。$g$ 的定义域是 $R$，但还必须要求 $x − 2 > 0$，所以复合函数的定义域是 $x > 2$，**不是** $R$。
:::

:::难点 复合函数的分解：链式法则的地基
把一个复杂表达式拆成几个简单函数的复合，是后续所有求导与积分的基本功。分解的要领只有一句：==由外向内，一层一层剥。==

举例：$y = sin²(2x + 1)$ 可分解为

$$ y = u²,　u = sin v,　v = 2x + 1 $$

检验分解是否正确的方法：把最内层逐层代回去，看能否还原成原式。
:::

:::易错 复合不可交换
$f[g(x)]$ 与 $g[f(x)]$ 一般是完全不同的函数。

例如 $f(x) = x²$，$g(x) = x + 1$：$f[g(x)] = (x + 1)²$，而 $g[f(x)] = x² + 1$。两者不但表达式不同，定义域也可能不同。

此外，$f[g(x)]$ 有意义也**不蕴含** $g[f(x)]$ 有意义。
:::

### 二、基本初等函数

以下五类函数称为**基本初等函数**，它们是构造一切初等函数的"零件"：

1. **幂函数**　$y = x^μ$（$μ$ 为常数）
2. **指数函数**　$y = a^x$（$a > 0$，$a ≠ 1$），特别地 $y = e^x$
3. **对数函数**　$y = logₐ x$（$a > 0$，$a ≠ 1$），特别地 $y = ln x$
4. **三角函数**　$y = sin x$，$cos x$，$tan x$，$cot x$，$sec x$，$csc x$
5. **反三角函数**　$y = arcsin x$，$arccos x$，$arctan x$，$arccot x$

:::提示 关于"零件"的硬性要求
这五类函数的**图像、定义域、值域、单调性、奇偶性、特殊值**，必须做到"看到名字就能画出来"。

这不是死记硬背的要求，而是效率要求：后面求定义域、判断单调性、讨论极限、做换元，都要瞬间调用这些信息。**建议专门花 30 分钟默写一遍**，把不熟的那几个挑出来重点补。
:::

**一张必须记住的对照表**（$a > 1$ 的情形）：

| 函数 | 定义域 | 值域 | 单调性 | 奇偶性 |
|---|---|---|---|---|
| $y = a^x$ | $R$ | $(0, +∞)$ | 单调增加 | 非奇非偶 |
| $y = logₐ x$ | $(0, +∞)$ | $R$ | 单调增加 | 非奇非偶 |
| $y = arcsin x$ | $[−1, 1]$ | $[−π/2, π/2]$ | 单调增加 | 奇函数 |
| $y = arccos x$ | $[−1, 1]$ | $[0, π]$ | 单调减少 | 非奇非偶 |
| $y = arctan x$ | $R$ | $(−π/2, π/2)$ | 单调增加 | 奇函数 |

:::难点 反三角函数的值域为什么必须记住
因为反三角函数的值域是**人为规定**的，目的是让反函数唯一。$sin x$ 在 $R$ 上不单调，反函数不存在；限制在 $[−π/2, π/2]$ 上才单调增加，于是有了 $arcsin x$，其值域就是 $[−π/2, π/2]$。

这个"主值区间"的规定直接决定了后面很多等式能否成立。例如 $arcsin(sin 3π/4) = π/4$，**不是** $3π/4$，因为 $3π/4$ 超出了 $arcsin$ 的值域。==凡是遇到反三角函数，第一反应就是检查自变量是否落在主值区间内。==
:::

### 三、初等函数

**定义 1.8**　由常数和基本初等函数经过**有限次**的四则运算和**有限次**的复合步骤所构成、并可用**一个式子**表示的函数，称为**初等函数**。

例如 $y = √(1 − x²)$、$y = ln(x + √(1 + x²))$、$y = e^(sin x)$ 都是初等函数。

:::难点 为什么要单独定义"初等函数"
因为课时 14 有一条极好用的结论：==初等函数在其定义区间上是连续的。==

它的实际价值在于：**求极限时可以直接代入**。只要 $f$ 是初等函数且 $x₀$ 在其定义区间内，就有

$$ lim(x→x₀) f(x) = f(x₀) $$

这一条能把大量看似复杂的极限计算变成"代个值"。

反过来说，**分段函数一般不是初等函数**（因为它不能用"一个式子"表示，例如 $|x|$）。所以分段函数在**分界点**处不能直接代入，必须回到定义去讨论——这正是课时 13 与课时 17 反复强调分界点要单独处理的原因。
:::

### 四、双曲函数（补充内容）

教材在第一章只作简要介绍，但双曲函数在后续的积分换元与微分方程中会反复出现，这里一次讲清楚。

**定义**：

$$ sh x = (e^x − e^(−x))/2,　ch x = (e^x + e^(−x))/2,　th x = sh x / ch x $$

分别称为**双曲正弦**、**双曲余弦**、**双曲正切**。

**基本性质**：

1. **平方关系**　$ch²x − sh²x = 1$（把定义代入即可验证，注意中间项恰好抵消）
2. **加法公式**　$sh(x ± y) = sh x ch y ± ch x sh y$
3. **加法公式**　$ch(x ± y) = ch x ch y ± sh x sh y$
4. **奇偶性**　$sh x$ 是奇函数且在 $R$ 上单调增加；$ch x$ 是偶函数且在 $[0, +∞)$ 上单调增加
5. **下界**　$ch x ≥ 1$ 对一切实数 $x$ 成立，且仅在 $x = 0$ 处取等号

**反双曲函数**：

$$ arsh x = ln(x + √(x² + 1)),　x ∈ R $$
$$ arch x = ln(x + √(x² − 1)),　x ≥ 1 $$
$$ arth x = (1/2) ln((1 + x)/(1 − x)),　|x| < 1 $$

:::难点 第 3 条加法公式里的符号
请对照三角函数的 $cos(x ± y) = cos x cos y ∓ sin x sin y$。

三角函数里，$cos$ 的展开式**符号相反**（$+$ 对 $−$）；双曲函数里，$ch$ 的展开式**符号相同**（$+$ 对 $+$）。

这不是笔误，根源在于双曲函数是用指数函数定义的，而指数函数满足 $e^(x+y) = e^x e^y$（符号永远相加）。==记忆口诀：双曲函数不"变号"。==
:::

:::提示 为什么叫"双曲"函数
因为点 $(ch t, sh t)$ 满足 $x² − y² = 1$，正好落在等轴双曲线上，参数 $t$ 对应双曲线上的"面积"参数——这与 $(cos t, sin t)$ 落在单位圆上有完全的类比。

但要清醒地看到差别：==双曲函数**没有周期性**，$sh x$ 与 $ch x$ 在 $x → +∞$ 时都无界。== 所以一切关于形状与有界性的结论都不能从三角函数照搬。
:::

## 课时4　数列极限的定义

**课时定位**　这是全书的**第一道真正的门槛**。ε-N 语言是数学分析特有的思维方式，几乎没有人能靠"读懂"就掌握，必须自己动手写过若干个证明才能真正理解。本讲请务必放慢。

**学习目标**　能用自己的话复述 ε-N 定义的三层逻辑结构；能写出"任给 ε > 0 ……取 N = …… 则当 n > N 时 ……"的完整证明；掌握"放大法"这一核心技巧。

**预计用时**　4 小时

### 一、数列及其表示

**定义 1.9**　若按照某一法则，对每个 $n ∈ N_+$ 对应着一个确定的实数 $xₙ$，这些实数按 $n$ 从小到大的次序排成一列

$$ x₁, x₂, …, xₙ, … $$

就称为**数列**，记作 ${xₙ}$。$xₙ$ 称为数列的**通项**（一般项）。

从函数的角度看，数列不过就是定义在正整数集上的函数 $xₙ = f(n)$。所以数列也可以画图像——那是一条由孤立点组成的"曲线"。

**例**　$1/2, 2/3, 3/4, …, n/(n+1), …$，通项 $xₙ = n/(n+1)$。

**例**　$1, −1, 1, −1, …$，通项 $xₙ = (−1)ⁿ⁺¹$。

:::提示 数列极限研究的是什么
研究的不是某一项等于多少，而是**当 $n$ 无限增大时，$xₙ$ 的整体变化趋势**。

所以看到 ${xₙ}$，脑子里要浮现的是"这串数最终往哪儿走"，而不是"第 100 项是多少"。
:::

### 二、为什么需要 ε-N 语言

先看直观的说法："当 $n$ 无限增大时，$xₙ$ 无限接近于 $a$"。

这句话有致命缺陷：**什么叫"无限接近"？**

如果我们规定"$xₙ$ 与 $a$ 的距离小于 $0.1$"，那显然不够——一个数列可能在前 100 项之内跑出这个范围。
改成"距离小于 $0.0001$"？还是不够，因为总可以要求更小。
我们不可能把"任意小的精度"逐个写出来，因为它有无穷多个。

**正确的思路是：不指定具体多小，而是要求"任意小"。**

具体地说：随便你给出一个多小的正数 $ε$（$0.1$ 也好，$10⁻¹⁰⁰$ 也好），我都能保证"从某一项往后，所有的 $xₙ$ 与 $a$ 的距离都小于 $ε$"。

==这就是"无限接近"的严格含义：不是我接近到一个固定的程度，而是无论你要求多严，我最终都能满足。==

### 三、数列极限的 ε-N 定义

**定义 1.10**　设 ${xₙ}$ 为一数列，$a$ 为常数。若对**任意给定**的正数 $ε$（不论它多么小），总**存在**正整数 $N$，使得当 $n > N$ 时，都有

$$ |xₙ − a| < ε $$

成立，则称常数 $a$ 是数列 ${xₙ}$ 的**极限**，或称数列 ${xₙ}$ **收敛**于 $a$，记作

$$ lim(n→∞) xₙ = a　或　xₙ → a (n → ∞) $$

若这样的常数 $a$ 不存在，则称数列 ${xₙ}$ **发散**。

**符号化写法**：

$$ ∀ε > 0, ∃N ∈ N_+, ∀n > N: |xₙ − a| < ε $$

:::难点 逐字拆解 ε-N 定义（本讲最重要的一段）
**第一层：「对任意给定的 $ε > 0$」。**　$ε$ 是**任意**的，代表"要多小有多小"的精度要求。证明时必须把 $ε$ 当作"一个已经给定但数值未知的正数"来处理，**不能代入某个具体值**。这是初学者最容易犯的错。

**第二层：「总存在正整数 $N$」。**　$N$ 是**存在**的，它的作用是回答"从哪一项开始"。请特别注意：**$N$ 依赖于 $ε$**。$ε$ 越小，$N$ 通常越大。严格写出来是 $N(ε)$，只是习惯上省略。另外，$N$ 的选取**不唯一**，够用即可。

**第三层：「当 $n > N$ 时，都有 $|xₙ − a| < ε$」。**　这是**恒成立**的要求：从第 $N+1$ 项起，后面**所有**项都要落进 $(a − ε, a + ε)$，一项都不能漏。注意 "都有" 二字，它把"无穷多项"一次全部管住了。

三层合起来读就是：==不管你要求多严（$∀ε$），我都能找到一个起点（$∃N$），从这个起点之后全部达标（$∀n > N$）。==
:::

:::难点 几何意义：邻域语言
把绝对值不等式展开：

$$ |xₙ − a| < ε　⟺　a − ε < xₙ < a + ε　⟺　xₙ ∈ (a − ε, a + ε) $$

所以定义说的是：**对 $a$ 的任意一个 $ε$ 邻域，数列从某一项开始，后面所有项都落在这个邻域内。**

换一个等价的说法（后面经常用）：**数列 ${xₙ}$ 收敛于 $a$，等价于对 $a$ 的任意邻域，数列中落在该邻域外的项只有有限多个。**

这个"只有有限多项在外"的说法非常有力，因为"有限"意味着可以取最大值——课时 5 证明"收敛数列有界"时用的正是这一点。

ε-N 定义的几何含义如图 1.4.1 所示：不论把精度 $ε$ 取得多小，数列总只有有限多项落在带外。

![[fig1_4_1]]
:::

:::提示 为什么 $n > N$ 与 $n ≥ N$ 没有区别
把 $N$ 换成 $N − 1$，两个条件就互相转化了。所以取哪一种纯粹是记号约定，关键是要表达出"**从某一项之后全都成立**"。

同理，"存在 $N$"也可以换成"存在 $N₀$"或"存在正数 $M$"，只要表达的是"某个门槛"就行。
:::

### 四、用定义证明极限：标准三步

:::提示 证明的固定框架
**第一步**：任给 $ε > 0$。（起手式，必须写）

**第二步**：从 $|xₙ − a| < ε$ 出发**反推**，写成"要使 $|xₙ − a| < ε$，只需 $n > $ 某个只含 $ε$ 的式子"。这一步通常在草稿纸上完成，叫**分析**。

**第三步**：取 $N = [$那个式子$]$（取整），则当 $n > N$ 时反推回去，得 $|xₙ − a| < ε$。结论成立。

**核心技巧是「放大法」**：把 $|xₙ − a|$ 放大成一个**结构更简单、更容易解不等式、且仍然趋于 $0$** 的量。放大的方向必须是"往大了放"，这样才能保证原式更小。
:::

:::例题 例 1　证明 $lim(n→∞) (n + 1)/n = 1$
**分析**　$|xₙ − 1| = |(n+1)/n − 1| = |1/n| = 1/n$。

要使 $1/n < ε$，只需 $n > 1/ε$。

**证明**　任给 $ε > 0$，取 $N = [1/ε]$。则当 $n > N$ 时，有 $n > 1/ε$，于是

$$ |xₙ − 1| = 1/n < ε $$

所以 $lim(n→∞) (n + 1)/n = 1$。

**要点**　这是最"干净"的情况：不需要放大，直接解不等式即可。$N$ 取 $[1/ε]$ 就已经够用（$[·]$ 表示取整）。
:::

:::例题 例 2　证明 $lim(n→∞) (sin n)/n = 0$
**分析**　$|xₙ − 0| = |sin n|/n$。这里 $sin n$ 的符号与大小都在变，无法直接解不等式。

**放大**：利用 $|sin n| ≤ 1$，得

$$ |xₙ − 0| = |sin n|/n ≤ 1/n $$

于是只需 $1/n < ε$，即 $n > 1/ε$。

**证明**　任给 $ε > 0$，取 $N = [1/ε]$。则当 $n > N$ 时，

$$ |(sin n)/n − 0| ≤ 1/n < ε $$

所以 $lim(n→∞) (sin n)/n = 0$。

**要点**　==放大的方向不能搞反。== 我们要的是"$|xₙ − a| ≤$ 某个趋于 $0$ 的量"，只有这样，当那个量小于 $ε$ 时，原式才一定小于 $ε$。如果放大后反而更小，逻辑就断了。
:::

:::例题 例 3　证明 $lim(n→∞) (3n² + n)/(2n² − 1) = 3/2$
**分析**　先通分：

$$ |xₙ − 3/2| = |(2(3n² + n) − 3(2n² − 1)) / (2(2n² − 1))| = (2n + 3)/(2(2n² − 1)) $$

分子分母都含 $n$，直接解不等式较麻烦，用放大法。

当 $n ≥ 1$ 时：分母 $2(2n² − 1) = 4n² − 2 ≥ 2n²$（因为 $4n² − 2 − 2n² = 2n² − 2 ≥ 0$）；分子 $2n + 3 ≤ 5n$。

于是

$$ (2n + 3)/(2(2n² − 1)) ≤ 5n/(2n²) = 5/(2n) $$

要使 $5/(2n) < ε$，只需 $n > 5/(2ε)$。

**证明**　任给 $ε > 0$，取 $N = [5/(2ε)]$。则当 $n > N$ 时，$n > 5/(2ε)$，故

$$ |xₙ − 3/2| ≤ 5/(2n) < ε $$

所以 $lim(n→∞) (3n² + n)/(2n² − 1) = 3/2$。

**要点**　==有理式极限的放大套路：分母往小了放，分子往大了放。== 这样整个分式才能被放大。此外注意放大时用的 $n ≥ 1$ 这类条件，要写清楚它在什么范围内成立。
:::

:::易错 用定义证明极限的三个典型错误
**错误 1：把结论当作前提。**　定义证明必须从"任给 $ε > 0$"出发去**推导**出不等式，不能反过来假设 $|xₙ − a| < ε$ 已经成立。

**错误 2：$N$ 依赖于 $n$。**　$N$ 只能依赖于 $ε$，绝不能含 $n$。若写出"取 $N = n$"，整个证明就作废了。

**错误 3：放大越界。**　放大必须保证不等号方向正确，且放大后的量仍趋于 $0$。如果放成了"$|xₙ − a| ≤ 1$"，那这个界太松，永远推不出小于 $ε$。
:::

:::提示 尽可以"奢侈"地取 $N$
定义只要求 $N$ **存在**，不要求它最小。所以例 1 中取 $N = [1/ε] + 1$、甚至 $N = [1/ε] + 100$ 都完全合法。

因此在放大时不必精打细算，宁可放得宽松一些，只要保证 $n > N$ 时不等式一定成立即可。**把精力放在"逻辑链是否闭合"上，而不是"$N$ 是否最小"上。**
:::

## 课时5　收敛数列的性质

**课时定位**　上一讲定义了"收敛"，这一讲考察收敛能**带来**什么。四个性质中，有界性与子数列性质是后续判断收敛、证明发散的主力工具。

**学习目标**　能独立证明唯一性、有界性、保号性；能说清"收敛必有界，有界未必收敛"；能用子数列性质证明数列发散。

**预计用时**　3 小时

### 一、唯一性

**定理 1.1**　若数列 ${xₙ}$ 收敛，则它的极限唯一。

**证明（反证法）**　设 $lim xₙ = a$ 且 $lim xₙ = b$，且 $a ≠ b$。

取 $ε = |a − b|/2 > 0$。

由 $lim xₙ = a$，存在 $N₁$，当 $n > N₁$ 时 $|xₙ − a| < ε$。
由 $lim xₙ = b$，存在 $N₂$，当 $n > N₂$ 时 $|xₙ − b| < ε$。

取 $N = max{N₁, N₂}$。当 $n > N$ 时，两式同时成立，于是由三角不等式

$$ |a − b| = |(xₙ − b) − (xₙ − a)| ≤ |xₙ − b| + |xₙ − a| < ε + ε = |a − b| $$

得到 $|a − b| < |a − b|$，矛盾。故 $a = b$。　$∎$

:::难点 为什么要取 $ε = |a − b|/2$
因为要制造矛盾，必须让 $a$ 与 $b$ 的 $ε$ 邻域**够不着**——如果两个邻域有重叠，$xₙ$ 就可以同时落在两个里面，矛盾就制造不出来。

取 $ε = |a − b|/2$ 恰好让两个邻域"相切"，从而任何一点都不可能同时属于两者。取 $ε = |a − b|/3$ 也可以，只要小于 $|a − b|/2$。

==这是"证明两个数相等"的一类通用手法：正着证不了，就反设它们不等，用它们距离的一半制造矛盾。==
:::

### 二、有界性

**定理 1.2**　若数列 ${xₙ}$ 收敛，则数列 ${xₙ}$ **一定有界**。

**证明**　设 $lim(n→∞) xₙ = a$。取 $ε = 1$，则存在正整数 $N$，当 $n > N$ 时

$$ |xₙ − a| < 1　⟹　|xₙ| < |a| + 1 $$

数列中可能不满足这个界的只有前 $N$ 项（**有限多项**）。取

$$ M = max{ |x₁|, |x₂|, …, |x_N|, |a| + 1 } $$

则对一切 $n ∈ N_+$ 都有 $|xₙ| ≤ M$，故 ${xₙ}$ 有界。　$∎$

:::难点 这个证明的套路："尾巴 + 有限项"
请注意这个证明的结构，它极其典型：

1. **任取一个具体的 $ε$**（这里取 $ε = 1$）。定义保证"对任意 $ε$"都成立，所以当然可以取一个方便的固定值。
2. **把"尾巴"（$n > N$ 的部分）控制住**，得到 $|xₙ| < |a| + 1$。
3. **把开头有限项单独处理**，取它们的最大值。

为什么第 3 步可行？因为"有界"要求的是**全体项**有一个统一的界，而定义只保证了尾巴。剩下的有限项虽然可能很大，但**有限个数一定有最大值**——这正是"有限"二字的全部价值。

=="尾巴用极限控制，有限项用最大值兜底"——这个套路在后面证明有界性、一致性时反复出现。==
:::

:::易错 逆命题不成立：有界推不出收敛
**"有界 ⟹ 收敛" 是错误的。**

反例：$xₙ = (−1)ⁿ⁺¹$，即 $1, −1, 1, −1, …$。显然 $|xₙ| = 1$，有界；但它在 $−1$ 与 $1$ 之间反复跳跃，不趋于任何常数，故发散。

所以必须把这对关系刻在脑子里：

==收敛 ⟹ 有界；有界 ⇏ 收敛。==

"有界"只是收敛的**必要条件**，不是充分条件。它在证明中的作用是"排除一部分数列"（无界的必发散），而不是"判定收敛"。
:::

两种情形如图 1.5.1 所示：左图的收敛数列尾部被圈住；右图的数列虽然有界，却因为奇数项与偶数项跑向不同的值而发散。

![[fig1_5_1]]

### 三、保号性

**定理 1.3**　若 $lim(n→∞) xₙ = a$，且 $a > 0$（或 $a < 0$），则存在正整数 $N$，当 $n > N$ 时，$xₙ > 0$（或 $xₙ < 0$）。

**证明（以 $a > 0$ 为例）**　取 $ε = a/2 > 0$，则存在 $N$，当 $n > N$ 时

$$ |xₙ − a| < a/2　⟹　a/2 < xₙ < 3a/2 $$

特别地 $xₙ > a/2 > 0$。　$∎$

**推论 1.1**　若 $lim(n→∞) xₙ = a$，且从某一项起 $xₙ ≥ 0$，则 $a ≥ 0$。

:::难点 推论中为什么是 $a ≥ 0$，不能写成 $a > 0$
因为极限运算会把**严格**不等号"磨掉"。

反例：$xₙ = 1/n$，对一切 $n$ 都有 $xₙ > 0$，但 $lim xₙ = 0$，并不是正数。

道理很直观：数列可以从正的一侧无限逼近 $0$，极限就落在边界上。所以：

==极限保持**非严格**不等式（$≥$、$≤$），不保持**严格**不等式（$>$、$<$）。==

这个区别在做含参数的极限题时是一个高频扣分点。
:::

### 四、子数列

**定义 1.11**　在数列 ${xₙ}$ 中任意抽取无穷多项，并**保持它们在原数列中的先后次序**，这样得到的一个数列称为原数列的**子数列**，记作 ${x_(nₖ)}$，其中

$$ n₁ < n₂ < … < nₖ < … $$

请特别注意 $nₖ ≥ k$ 这个显然但关键的事实：第 $k$ 个被抽出的项，其下标至少是 $k$。

**定理 1.4**　若 $lim(n→∞) xₙ = a$，则 ${xₙ}$ 的**任一**子数列都收敛，且极限也是 $a$。

**证明**　任给 $ε > 0$。由 $lim xₙ = a$，存在 $N$，当 $n > N$ 时 $|xₙ − a| < ε$。

当 $k > N$ 时，由 $nₖ ≥ k > N$，得 $|x_(nₖ) − a| < ε$。

所以 $lim(k→∞) x_(nₖ) = a$。　$∎$

**推论 1.2（判断发散的有力工具）**　若数列 ${xₙ}$ 有两个子数列收敛于**不同**的极限，则 ${xₙ}$ 发散。

:::难点 子数列性质为什么好用
因为它把"证明收敛"的难度转移到了更容易处理的子列上，同时给出了一条**证明发散**的捷径。

**用它证明发散的例子**：$xₙ = (−1)ⁿ⁺¹$。

- 取奇数项构成的子数列：$x₁, x₃, x₅, …$ 恒等于 $1$，收敛于 $1$；
- 取偶数项构成的子数列：$x₂, x₄, x₆, …$ 恒等于 $−1$，收敛于 $−1$。

两个子列的极限不同。若原数列收敛于 $a$，则按定理 1.4 两个子列都应收敛于 $a$，矛盾。故 ${xₙ}$ 发散。

**这也解释了"有界但不收敛"的内在机制**：数列本身被限制在一个有界范围内，但不同的子列跑向了不同的值。==所以"有界"只是说它跑不远，"收敛"才要求它跑向同一个地方。==
:::

:::提示 一个常用的等价判据
反过来，如果**奇数项子列与偶数项子列都收敛于同一个极限 $a$**，那么原数列也收敛于 $a$。

理由：任给 $ε > 0$，存在 $N₁$ 使 $k > N₁$ 时 $|x₂ₖ − a| < ε$，存在 $N₂$ 使 $k > N₂$ 时 $|x₂ₖ₋₁ − a| < ε$。取 $N = max{2N₁, 2N₂ + 1}$，则 $n > N$ 时不论 $n$ 是奇是偶都有 $|xₙ − a| < ε$。

这个判据在课时 5 的挑战题中会让你亲手证明一遍，它是后面处理递归数列的常用工具。
:::

## 课时6　函数极限的定义（一）：$x → x₀$ 时的 ε-δ 定义

**课时定位**　把 ε-N 升级为 ε-δ。**如果你的 ε-N 已经想清楚，这一讲会非常轻松**，因为两者的逻辑结构完全一样，变的只是"门槛"的形式。

**学习目标**　能写出并复述 ε-δ 定义；能说清"$0 < |x − x₀|$"为什么必须排除 $x₀$；能用定义证明简单函数的极限，并掌握"先限制 δ 再处理 ε"的两步走技巧。

**预计用时**　4 小时

### 一、从数列极限到函数极限

数列极限只处理一种趋近方式：$n$ 一步一步往前走，趋于 $+∞$。

函数极限要处理 $x → x₀$，这带来一个本质区别：

==$x$ 趋近 $x₀$ 的方式有**无穷多种**——可以从左边来，从右边来，也可以忽左忽右来回震荡。==

数列只有一个方向，函数有无数个方向。定义必须一次把所有方向都管住。这就是为什么 ε-δ 定义中写的是"$0 < |x − x₀| < δ$"而不是某种单向的条件。

### 二、$x → x₀$ 时函数的极限

**定义 1.12**　设函数 $f(x)$ 在点 $x₀$ 的某个**去心邻域**内有定义。若存在常数 $A$，使得对任意给定的 $ε > 0$，总存在 $δ > 0$，使得当

$$ 0 < |x − x₀| < δ $$

时，都有

$$ |f(x) − A| < ε $$

则称 $A$ 为函数 $f(x)$ 当 $x → x₀$ 时的**极限**，记作

$$ lim(x→x₀) f(x) = A　或　f(x) → A (x → x₀) $$

**符号化写法**：

$$ ∀ε > 0, ∃δ > 0, ∀x (0 < |x − x₀| < δ): |f(x) − A| < ε $$

:::难点 ε-δ 就是 ε-N 换了件衣服
把两个定义并排放在一起：

**数列**：$∀ε > 0, ∃N, ∀n > N: |xₙ − a| < ε$
**函数**：$∀ε > 0, ∃δ > 0, ∀x (0 < |x − x₀| < δ): |f(x) − A| < ε$

结构**完全一致**：任意给定精度 $ε$，存在一个"门槛"，跨过门槛后所有值都被控制在精度之内。

差别只有一处：

1. 数列的门槛是项的序号 $N$，条件写作 $n > N$——"序号足够大"；
2. 函数的门槛是自变量的接近程度 $δ$，条件写作 $0 < |x − x₀| < δ$——"距离足够近"。

==抓住这个对应，ε-δ 就不需要从头学。你只需要把"$n$ 足够大"翻译成"$x$ 足够近"。==
:::

:::难点 为什么必须写 $0 < |x − x₀|$
因为 $0 < |x − x₀|$ 恰好排除了 $x = x₀$ 这一点，这正是"**去心**邻域"的含义。

**为什么必须排除？**　因为极限研究的是**趋势**，与 $f$ 在 $x₀$ 处**有没有定义、取值是多少完全无关**。

看两个例子：

1. $f(x) = (x² − 1)/(x − 1)$ 在 $x = 1$ 处**没有定义**。但当 $x ≠ 1$ 时 $f(x) = x + 1$，所以 $lim(x→1) f(x) = 2$。
2. $g(x) = (x² − 1)/(x − 1) (x ≠ 1)$，另外规定 $g(1) = 100$。此时 $lim(x→1) g(x)$ 仍然是 $2$。

==一句话记住：极限只看"附近"，不看"这一点"。==

这个观念在课时 13 讨论连续性时会兑现：连续恰恰就是要求"极限值等于函数值"，也就是要求"这一点"和"附近"对得上。
:::

:::难点 $δ$ 依赖 $ε$，且 $δ$ 不唯一
**$δ$ 依赖 $ε$。**　$ε$ 是精度要求，$δ$ 是"要多近才算够近"。要求越严（$ε$ 越小），$δ$ 通常也越小。严格写是 $δ(ε)$。

**$δ$ 不唯一。**　若某个 $δ$ 满足要求，则任何更小的 $δ' < δ$ 也满足要求（条件变强了，结论自然还是对的）。所以证明时只需找一个"够用"的 $δ$，**不需要找最大的那个**。
:::

:::难点 几何意义：水平带与垂直带
把两个不等式都展开：

$$ |f(x) − A| < ε　⟺　A − ε < f(x) < A + ε $$

即函数图像落在两条水平直线 $y = A ± ε$ 之间。

$$ 0 < |x − x₀| < δ　⟺　x 落在 x₀ 的去心 δ 邻域内 $$

即图像被限制在两条竖直直线 $x = x₀ ± δ$ 之间（并挖掉 $x₀$ 本身）。

所以定义在几何上说的是：

==对任意给定的**水平带**（高度 $2ε$），总能找到 $x₀$ 附近的一个**竖直带**，使得竖直带内（除去中心）的函数图像整段落在水平带里。==

"总能找到竖直带"——这就是"任意 $ε$"对应的"存在 $δ$"。$ε$ 越窄，竖直带也得越窄。完整的几何图示见图 1.6.1。

![[fig1_6_1]]
:::

### 三、用定义证明函数极限

步骤与 ε-N 完全平行：任给 $ε > 0$ → 反推 $|x − x₀|$ 的条件 → 取 $δ$ → 验证。

:::例题 例 1　证明 $lim(x→1) (2x + 1) = 3$
**分析**　$|f(x) − 3| = |2x + 1 − 3| = 2|x − 1|$。

要使 $2|x − 1| < ε$，只需 $|x − 1| < ε/2$。

**证明**　任给 $ε > 0$，取 $δ = ε/2$。则当 $0 < |x − 1| < δ$ 时，

$$ |(2x + 1) − 3| = 2|x − 1| < 2δ = ε $$

故 $lim(x→1) (2x + 1) = 3$。

**要点**　这是一次函数的标准情形：不需要放大，直接解出 $δ = ε/k$（$k$ 是斜率绝对值）。
:::

:::例题 例 2　证明 $lim(x→−1) (x² − 1)/(x + 1) = −2$
**分析**　在去心邻域 $0 < |x + 1|$ 内，$x ≠ −1$，可以约分：

$$ (x² − 1)/(x + 1) = (x − 1)(x + 1)/(x + 1) = x − 1 $$

于是 $|f(x) − (−2)| = |x − 1 + 2| = |x + 1|$。

要使 $|x + 1| < ε$，只需 $δ = ε$。

**证明**　任给 $ε > 0$，取 $δ = ε$。则当 $0 < |x + 1| < δ$ 时，$x ≠ −1$，可以约分，得

$$ |(x² − 1)/(x + 1) − (−2)| = |x + 1| < ε $$

故 $lim(x→−1)(x² − 1)/(x + 1) = −2$。
:::

:::易错 约分的前提是 $x ≠ −1$
这个约分**只有在去心邻域内才合法**，因为那里保证了 $x ≠ −1$。

如果误以为在 $x = −1$ 处也能约分，就等于默认了函数在 $x = −1$ 有定义——而它其实没有。==这正是"$0 < |x − x₀|$"这个条件在具体计算中的价值。==
:::

:::例题 例 3　证明 $lim(x→2) x² = 4$
**分析**　$|x² − 4| = |x − 2| · |x + 2|$。

困难在于 $|x + 2|$ **不是常数**，它随 $x$ 变化。不能直接解出 $δ$。

**技巧：先把 $|x + 2|$ 摁住。**　预先假定 $δ ≤ 1$。那么当 $|x − 2| < 1$ 时，

$$ 1 < x < 3　⟹　|x + 2| = x + 2 < 5 $$

于是

$$ |x² − 4| = |x − 2| · |x + 2| < 5|x − 2| $$

要使 $5|x − 2| < ε$，只需 $|x − 2| < ε/5$。

**证明**　任给 $ε > 0$，取 $δ = min{1, ε/5}$。则当 $0 < |x − 2| < δ$ 时：

由 $δ ≤ 1$ 得 $|x − 2| < 1$，故 $|x + 2| < 5$；
由 $δ ≤ ε/5$ 得 $|x − 2| < ε/5$。

于是

$$ |x² − 4| = |x − 2| · |x + 2| < (ε/5) · 5 = ε $$

故 $lim(x→2) x² = 4$。
:::

:::难点 为什么要取 $δ = min{1, ε/5}$
因为证明过程中同时需要两个条件：

1. $|x − 2| < 1$ —— 这是为了得到放大系数 $5$，把变化的因子变成常数；
2. $|x − 2| < ε/5$ —— 这是为了让最终结果小于 $ε$。

取 $δ$ 为两者的**较小值**，就能保证两条同时成立。缺了第 1 条，$|x + 2| < 5$ 就不成立，放大链条断裂。

==这是用定义证明函数极限的**标准两步走**：先限定一个范围把变化因子摁成常数，再处理 $ε$。只要放大过程中出现了依赖 $x$ 的因子，就必须走这一步。==
:::

:::易错 用定义证明函数极限的三个常见错误
**错误 1：$δ$ 依赖于 $x$。**　$δ$ 只能依赖 $ε$（以及 $x₀$），绝不能含 $x$。写出"取 $δ = ε/(x+2)$"就完全错了。

**错误 2：漏掉"任给 $ε > 0$"。**　这是定义的起手式，也是证明的逻辑起点，不能省。

**错误 3：放大系数依赖 $x$ 却直接取 $δ = ε/5$。**　当放大系数含 $x$ 时，必须先通过限制 $δ$ 把它变成常数，再取 $min$。跳过这一步，$|x + 2| < 5$ 就是没有根据的。
:::

## 课时7　函数极限的定义（二）：$x → ∞$、单侧极限与存在判据

**课时定位**　补齐极限定义的最后几块拼图。本讲的核心结论是"双侧极限存在 ⟺ 左右极限都存在且相等"，它是**判断极限不存在**的主要武器。

**学习目标**　能区分四种极限记号；能用左右极限判定双侧极限的存在性；熟悉四类经典的"左右极限不等或不存在"的模型。

**预计用时**　3 小时

### 一、$x → ∞$ 时函数的极限

**定义 1.13**　设函数 $f(x)$ 当 $|x|$ 充分大时有定义。若存在常数 $A$，使得对任意给定的 $ε > 0$，总存在正数 $X$，使得当 $|x| > X$ 时，都有

$$ |f(x) − A| < ε $$

则称 $A$ 为函数 $f(x)$ 当 $x → ∞$ 时的**极限**，记作 $lim(x→∞) f(x) = A$。

**符号化写法**：

$$ ∀ε > 0, ∃X > 0, ∀x (|x| > X): |f(x) − A| < ε $$

:::难点 $|x| > X$ 意味着"两侧同时趋近"
条件 $|x| > X$ 等价于 $x > X$ **或** $x < −X$。所以 $lim(x→∞)$ 是**双侧**的：$x$ 既可能趋向 $+∞$，也可能趋向 $−∞$。

若要单独考察某一侧，只需改动条件：

- $x → +∞$：条件改为 $x > X$；
- $x → −∞$：条件改为 $x < −X$。

与 ε-N 对照可以发现：这一条其实就是把数列极限中的"$n > N$"换成了"$|x| > X$"。**数列极限本身就是 $x → +∞$ 的离散版本。**
:::

### 二、单侧极限

**定义 1.14（右极限）**　设 $f$ 在 $x₀$ 的某个右半去心邻域内有定义。若存在常数 $A$，对任意 $ε > 0$，总存在 $δ > 0$，使得当

$$ x₀ < x < x₀ + δ $$

时，都有 $|f(x) − A| < ε$，则称 $A$ 为 $f(x)$ 当 $x → x₀^+$ 时的**右极限**，记作

$$ lim(x→x₀^+) f(x) = A　或　f(x₀^+) = A $$

**定义 1.15（左极限）**　把上式中的 $x₀ < x < x₀ + δ$ 换成 $x₀ − δ < x < x₀$，即得**左极限** $lim(x→x₀^−) f(x) = A$，也记作 $f(x₀^−) = A$。

:::难点 四个极限记号必须分清
| 记号 | 含义 | 自变量条件 |
|---|---|---|
| $lim(x→x₀)$ | 双侧极限 | $0 < \|x − x₀\| < δ$ |
| $lim(x→x₀^+)$ | 右极限 | $x₀ < x < x₀ + δ$ |
| $lim(x→x₀^−)$ | 左极限 | $x₀ − δ < x < x₀$ |
| $lim(x→∞)$ | 趋于无穷 | $\|x\| > X$ |

注意：单侧极限的定义里**没有** $0 <$ 这一条，因为"$x₀ < x$"已经自动排除了 $x = x₀$。
:::

### 三、极限存在的充要条件

**定理 1.5**　$lim(x→x₀) f(x) = A$ 的充要条件是

$$ f(x₀^+) = A　且　f(x₀^−) = A $$

**证明**　**必要性**：若双侧极限为 $A$，则任给 $ε > 0$ 存在 $δ > 0$ 使 $0 < |x − x₀| < δ$ 时 $|f(x) − A| < ε$。这个 $δ$ 当然也适用于 $x₀ < x < x₀ + δ$ 与 $x₀ − δ < x < x₀$ 两种情形，故左右极限都是 $A$。

**充分性**：设左右极限都为 $A$。任给 $ε > 0$，由右极限存在 $δ₁ > 0$，使 $x₀ < x < x₀ + δ₁$ 时 $|f(x) − A| < ε$；由左极限存在 $δ₂ > 0$，使 $x₀ − δ₂ < x < x₀$ 时 $|f(x) − A| < ε$。

取 $δ = min{δ₁, δ₂}$。当 $0 < |x − x₀| < δ$ 时，$x$ 要么在右侧要么在左侧，两种情形都有 $|f(x) − A| < ε$。故双侧极限为 $A$。　$∎$

:::难点 这个定理的真正用途：判断极限**不存在**
定理的正面用途（由左右极限推双侧）其实很少用，因为能用的时候通常也能直接用定义。

它真正的价值在于**逆否命题**：

==若 $f(x₀^+) ≠ f(x₀^−)$，或者其中某个单侧极限不存在，则 $lim(x→x₀) f(x)$ 不存在。==

这是判断"极限不存在"的标准手段。**凡是遇到分段函数在分界点、含绝对值的函数在零点、含 $1/x$ 或 $arctan(1/x)$ 的函数在零点，第一反应就应该是分左右。**
:::

:::难点 四个必须牢记的经典模型
这四个模型是考试与后续章节的高频考点，务必记熟它们的左右行为。

**模型 1：$f(x) = |x|/x$，在 $x → 0$ 处。**
当 $x > 0$ 时 $f(x) = 1$；当 $x < 0$ 时 $f(x) = −1$。故 $f(0^+) = 1$，$f(0^−) = −1$，不等，极限不存在。

**模型 2：$f(x) = e^(1/x)$，在 $x → 0$ 处。**
当 $x → 0^+$ 时 $1/x → +∞$，故 $e^(1/x) → +∞$（右极限不存在，趋于无穷）；
当 $x → 0^−$ 时 $1/x → −∞$，故 $e^(1/x) → 0$（左极限为 $0$）。
两者一个不存在、一个为 $0$，极限不存在。

**模型 3：$f(x) = arctan(1/x)$，在 $x → 0$ 处。**
当 $x → 0^+$ 时 $1/x → +∞$，$arctan → π/2$；
当 $x → 0^−$ 时 $1/x → −∞$，$arctan → −π/2$。
左右极限存在但**不相等**，极限不存在。

**模型 4：$f(x) = sin(1/x)$，在 $x → 0$ 处。**
当 $x → 0$ 时 $1/x$ 在 $(0, +∞)$ 上无限增大，$sin(1/x)$ 在 $[−1, 1]$ 上无限次振荡，**两个单侧极限都不存在**（不是无穷，而是振荡）。
==注意这个模型的特殊性：它既不是"左右不等"，也不是"趋于无穷"，而是"根本不收敛"。==
:::

:::例题 例 1　设 $f(x) = x − 1 (x < 0)$，$f(x) = 0 (x = 0)$，$f(x) = x + 1 (x > 0)$。讨论 $lim(x→0) f(x)$ 是否存在
**解**　分左右计算：

$$ f(0^+) = lim(x→0^+) (x + 1) = 1,　f(0^−) = lim(x→0^−) (x − 1) = −1 $$

左右极限都存在但不相等，故 $lim(x→0) f(x)$ **不存在**。

**要点**　注意 $f(0) = 0$ 这个值对极限毫无影响。==极限只看两侧的趋势，不看该点的函数值。== 这一点在课时 13 讲间断点时还会用到。
:::

:::例题 例 2　讨论 $lim(x→0) e^(1/x)$ 是否存在
**解**　当 $x → 0^+$ 时 $1/x → +∞$，故 $e^(1/x) → +∞$，右极限不存在（不是有限实数）。

当 $x → 0^−$ 时 $1/x → −∞$，故 $e^(1/x) → 0$，左极限为 $0$。

由定理 1.5，极限**不存在**。

**要点**　"右极限不存在"与"右极限等于无穷"是同一件事的两种说法。极限存在的前提是极限是一个**有限实数**，所以趋于无穷一律算作不存在。
:::

## 课时8　无穷小与无穷大

**课时定位**　这一讲引入两个"辅助概念"。它们的价值不在于自身，而在于**为后面的极限计算提供语言**：课时 12 的等价无穷小替换、课时 9 的运算法则证明，都建立在本讲之上。

**学习目标**　能准确说出"无穷小是变量不是数"；掌握"有界 × 无穷小 = 无穷小"及其用法；能严格区分"无穷大"与"无界"。

**预计用时**　3 小时

### 一、无穷小

**定义 1.16**　若 $lim(x→x₀) f(x) = 0$（或 $lim(x→∞) f(x) = 0$），则称 $f(x)$ 为当 $x → x₀$（或 $x → ∞$）时的**无穷小**。

:::易错 无穷小是"变量"，不是"很小的数"
这是概念性错误的重灾区，必须一次纠正到位。

$0.0000001$ 是一个很小的**数**，但它**不是**无穷小——因为它是一个固定的常数，不会"趋于 $0$"。

反过来，$f(x) = x$ 在 $x → 0$ 时是无穷小，尽管 $x$ 可以取到 $1000$ 这样并不小的值。==无穷小的本质是"以 $0$ 为极限"，而不是"数值小"。==
:::

:::易错 "无穷小"必须指明趋近过程
同一个函数在不同的极限过程中，是不是无穷小可能完全不同。

以 $f(x) = x$ 为例：

1. 当 $x → 0$ 时，$lim x = 0$，故 $f(x)$ 是无穷小；
2. 当 $x → 1$ 时，$lim x = 1 ≠ 0$，故 $f(x)$ **不是**无穷小；
3. 当 $x → ∞$ 时，$x → ∞$，故 $f(x)$ **不是**无穷小。

所以完整的说法必须是"$f(x)$ 是当 $x → 0$ 时的无穷小"。==脱离极限过程谈"无穷小"是没有意义的。==
:::

### 二、无穷小与极限的关系

**定理 1.6**　$lim(x→x₀) f(x) = A$ 的充要条件是

$$ f(x) = A + α(x) $$

其中 $α(x)$ 是当 $x → x₀$ 时的无穷小。

**证明**　**必要性**：设 $lim f(x) = A$，令 $α(x) = f(x) − A$。则 $|α(x)| = |f(x) − A|$，由极限定义，任给 $ε > 0$ 存在 $δ > 0$，当 $0 < |x − x₀| < δ$ 时 $|α(x)| < ε$，即 $lim α(x) = 0$。

**充分性**：设 $f(x) = A + α(x)$ 且 $lim α(x) = 0$。由 $|f(x) − A| = |α(x)|$，任给 $ε > 0$ 存在 $δ > 0$ 使 $0 < |x − x₀| < δ$ 时 $|f(x) − A| < ε$，故 $lim f(x) = A$。　$∎$

:::难点 这个定理的价值：把"求极限"变成"做分解"
它给出了一个重要的思维模型：==$f(x) → A$ 意味着 $f(x)$ 与 $A$ 之间只差一个"可以任意小"的量。==

所以处理极限问题时，最有用的动作是**把函数拆成"主项 + 无穷小"**：

$$ f(x) = A（主项，决定极限） + α(x)（无穷小，可忽略） $$

例如 $lim(x→0) (1 + x)^(1/x) = e$ 可以理解为：$(1+x)^(1/x)$ 与 $e$ 的差是一个趋于 $0$ 的量。

这个视角在课时 12（无穷小的比较）与课时 30（泰勒公式）中会被反复强化——泰勒公式本质上就是**把函数系统地拆成"多项式主项 + 高阶无穷小"**。
:::

### 三、无穷小的性质

**定理 1.7**　在同一极限过程中：

1. **有限个**无穷小的和仍是无穷小；
2. **有界函数**与无穷小的乘积仍是无穷小；
3. 常数与无穷小的乘积仍是无穷小（这是性质 2 的特例）。

:::难点 性质 1 中的"有限个"绝不能省略
无穷多个无穷小之和**不一定**是无穷小。

反例：把 $n$ 个 $1/n$ 相加。

每一项 $1/n$ 当 $n → ∞$ 时都是无穷小；但它们的和恒等于 $n · (1/n) = 1$，并不是无穷小。

根源在于：无穷多个"小"累积起来，可能不再小。==这是"有限"与"无限"的分水岭，也是后面无穷级数要专门处理的问题（课时 127）。==
:::

:::难点 性质 2 的证明：把两个概念"焊"在一起
设 $|g(x)| ≤ M$ 在某个去心邻域内成立，$α(x)$ 是无穷小。

则 $|g(x)α(x)| ≤ M|α(x)|$。

任给 $ε > 0$。若 $M > 0$，取 $ε' = ε/M$。由 $α$ 是无穷小，存在 $δ > 0$，当 $0 < |x − x₀| < δ$ 时 $|α(x)| < ε'$。于是

$$ |g(x)α(x)| ≤ M|α(x)| < M · (ε/M) = ε $$

故 $g(x)α(x)$ 是无穷小。　$∎$

（若 $M = 0$ 则 $g ≡ 0$，结论显然。）

这个证明的价值在于：==它把"有界"和"无穷小"两个独立概念组合起来，成为处理**振荡因子**的标准手段。==

**立即应用**：$lim(x→0) x·sin(1/x) = 0$。因为 $x$ 是无穷小，而 $sin(1/x)$ 有界（$|sin(1/x)| ≤ 1$）。

请注意对比：$lim(x→0) sin(1/x)$ 本身**不存在**（课时 7 的模型 4）；但乘上一个无穷小之后，乘积的极限就存在且为 $0$。==这是"有界"这个条件发挥作用的最典型场合。==
:::

### 四、无穷大

**定义 1.17**　设 $f(x)$ 在 $x₀$ 的某个去心邻域内有定义。若对任意给定的 $M > 0$，总存在 $δ > 0$，使得当 $0 < |x − x₀| < δ$ 时，都有

$$ |f(x)| > M $$

则称 $f(x)$ 是当 $x → x₀$ 时的**无穷大**，记作 $lim(x→x₀) f(x) = ∞$。

:::难点 "极限为 ∞"意味着极限**不存在**
记号 $lim(x→x₀) f(x) = ∞$ 中的等号是**习惯写法**，并不表示极限存在。

严格地说，此时极限是**不存在**的（因为 $∞$ 不是实数）。我们只是用一个符号来描述它"无限增大"的趋势。

所以在判断题里遇到"极限为 $∞$"，正确的理解是：==极限不存在，但以一种可描述的方式不存在。==

此外还要注意 $lim f(x) = ∞$ 与 $lim f(x) = +∞$ 的区别：前者只要求 $|f(x)|$ 无限增大（可以正负震荡），后者要求 $f(x)$ 本身无限增大。
:::

:::难点 无穷大与无界：一字之差，天壤之别
这是本章最易混淆的一对概念，必须精确区分。

**无穷大**：$|f(x)|$ 在趋近过程中**最终**会超过任意给定的 $M$。要求"**从某一刻起，之后一直**超过 $M$"。

**无界**：对任意 $M$，**存在**某处的 $x$ 使 $|f(x)| > M$。**不要求"之后一直"**。

所以：

==无穷大 ⟹ 无界，但无界 ⇏ 无穷大。==

**经典反例**：$f(x) = (1/x)·sin(1/x)$，当 $x → 0$。

1. **它无界**：取 $xₖ = 1/(π/2 + 2kπ)$，则 $sin(1/xₖ) = 1$，$f(xₖ) = 1/xₖ = π/2 + 2kπ → +∞$。所以 $|f|$ 可以任意大。
2. **它不是无穷大**：对任何去心邻域，总能找到点使 $sin(1/x) = 0$，此时 $f(x) = 0$，不满足 $|f(x)| > M$。所以不可能"从某一刻起一直超过 $M$"。

==这个反例精确划出了两个概念的界限：无界允许"偶尔冲高又落回"，无穷大要求"一直保持在高位"。==
:::

**定理 1.8（无穷小与无穷大的关系）**　在同一极限过程中：

1. 若 $f(x)$ 是无穷大，则 $1/f(x)$ 是无穷小；
2. 若 $f(x)$ 是无穷小且 $f(x) ≠ 0$，则 $1/f(x)$ 是无穷大。

:::易错 第 2 条为什么必须加 "$f(x) ≠ 0$"
因为无穷小的定义允许 $f(x)$ 取到 $0$（例如 $f(x) ≡ 0$ 就是无穷小），此时 $1/f(x)$ 根本没有意义。

即使在 $f(x)$ 只是**偶尔**取 $0$ 的情形下，倒数也会在某处无定义，从而谈不上是无穷大。

==所以"无穷小"与"无穷大"之间并不是无条件互推的，那个附加条件不可省略。==
:::

5. 判断下列命题的正误：对的给出证明，错的举出反例。
(1) 若 $f(x)$ 当 $x → x₀$ 时无界，则 $lim(x→x₀) f(x) = ∞$；
(2) 若 $lim(x→x₀) f(x) = ∞$，则 $f(x)$ 当 $x → x₀$ 时无界；
(3) 两个无穷大之和一定是无穷大。

## 课时9　极限的运算法则

**课时定位**　这一讲是"从理论走向计算"的转折点。前八讲建立的严格定义，从这里开始被压缩成几条好用的规则。但请务必记住：**每条规则都有前提，前提不满足时规则失效。**

**学习目标**　能默写四则运算法则并说明其前提；能熟练处理有理式的 $∞/∞$ 与 $0/0$ 型极限；能说出复合函数极限法则中附加条件的意义。

**预计用时**　3 小时

### 一、四则运算法则

**定理 1.9**　设在同一极限过程中 $lim f(x) = A$，$lim g(x) = B$（$A, B$ 都是有限实数），则

1. $lim [f(x) ± g(x)] = A ± B$
2. $lim [f(x) · g(x)] = A · B$
3. 若 $B ≠ 0$，则 $lim [f(x) / g(x)] = A / B$

**推论**：

1. $lim [c · f(x)] = cA$（$c$ 为常数）
2. $lim [f(x)]ⁿ = Aⁿ$（$n$ 为正整数）
3. $lim ⁿ√(f(x)) = ⁿ√A$（在根式有意义的前提下）

:::难点 乘积法则的证明思路：把乘积化成"无穷小 × 有界"
直接展开是行不通的，需要做一个"加一项减一项"的技巧：

$$ f(x)g(x) − AB = f(x)g(x) − Ag(x) + Ag(x) − AB = g(x)[f(x) − A] + A[g(x) − B] $$

现在逐项分析：

1. $f(x) − A$ 与 $g(x) − B$ 都是无穷小（定理 1.6）；
2. $g(x)$ 是**有界**的——因为收敛的 $g(x)$ 在某个去心邻域内有界（这是课时 5 有界性证明思路的直接搬用）；
3. 常数 $A$ 当然有界。

于是两项都是"**有界量 × 无穷小**"，由定理 1.7 都是无穷小，其和也是无穷小。

再由定理 1.6 反推：$f(x)g(x) − AB$ 是无穷小，故 $lim f(x)g(x) = AB$。　$∎$

==这个证明是本章的典范：把不熟悉的乘积极限，转化为已经证明过的"有界 × 无穷小"。==
:::

:::易错 使用法则前必须逐条核验前提
三条法则都有一个共同前提：**各自的极限必须存在且有限**。商的情形还要求分母极限非零。

最常见的错误是"极限不存在却硬套法则"。例如考虑 $lim(x→0) (sin x)/x$：

分子极限是 $0$，分母极限也是 $0$。若硬套商的法则，会得到 $0/0$ 这个无意义的式子。

**法则失效不等于极限不存在。**　这个极限其实等于 $1$，但它必须用课时 10 的夹逼准则来求。==所以看到 $0/0$ 或 $∞/∞$，第一反应是"法则失效"，而不是"极限不存在"。==
:::

### 二、复合函数的极限运算法则

**定理 1.10**　设 $lim(x→x₀) g(x) = u₀$，且存在 $x₀$ 的某个去心邻域，在其中 $g(x) ≠ u₀$；又设 $lim(u→u₀) f(u) = A$。则

$$ lim(x→x₀) f[g(x)] = A $$

:::难点 附加条件 "$g(x) ≠ u₀$" 为什么不可少
因为 $f$ 在 $u₀$ 处的极限只与 $u₀$ **附近但不等于 $u₀$** 的取值有关（去心邻域！）。

如果 $g(x)$ 在 $x₀$ 附近频繁取到 $u₀$，那么 $f[g(x)]$ 就会频繁取到 $f(u₀)$ 这个值，而 $f(u₀)$ 与极限 $A$ **完全可以不同**（回想课时 6：极限与函数在该点的值无关）。

**反例**　取 $f(u) = 0 (u ≠ 0)$，$f(0) = 1$；取 $g(x) ≡ 0$。

则 $lim(u→0) f(u) = 0 = A$，但 $f[g(x)] ≡ f(0) = 1$，故 $lim(x→x₀) f[g(x)] = 1 ≠ A$。

==两条逻辑链断在了同一个地方：去心邻域把"这一点"排除在外，而 $g$ 却偏偏只走"这一点"。==
:::

:::提示 实际计算中的简化
做计算题时不必每次都核对这个条件。原因是：**实际遇到的 $f$ 大多是初等函数**，而初等函数在其定义区间内连续（课时 14 的结论），此时 $f(u₀)$ 恰好等于 $lim(u→u₀) f(u)$，条件自动满足。

所以可以放心地"先算内层极限，再代入外层函数"。但在**理论证明**中必须知道这个条件的存在——它是严谨性的一部分。
:::

### 三、$x → ∞$ 时有理式极限的一般方法

**方法**：分子分母**同除以分母的最高次幂**。

**一般结论**　设 $a₀ ≠ 0$，$b₀ ≠ 0$，则

$$ lim(x→∞) (a₀ x^m + a₁ x^(m−1) + … + aₘ) / (b₀ xⁿ + b₁ xⁿ⁻¹ + … + bₙ) $$

其中 $a₀ ≠ 0$，$b₀ ≠ 0$。则极限值由 $m$ 与 $n$ 的大小关系决定：

| 情形 | 极限值 | 说明 |
|---|---|---|
| $m < n$ | $0$ | 分子次数低，被分母"压住" |
| $m = n$ | $a₀ / b₀$ | 最高次项系数之比 |
| $m > n$ | $∞$（即极限不存在） | 分子次数高，发散到无穷 |

:::难点 不要死记结论，要理解来源
同除以最高次幂之后，分子分母中所有低次项都变成 $1/xᵏ$ 的形式，当 $x → ∞$ 时它们**全是无穷小**（这正是"无穷小与极限的关系"与四则运算的直接应用）。

于是整个式子只剩下最高次项主导：

$$ (a₀ x^m)/(b₀ xⁿ) = (a₀/b₀) · x^(m−n) $$

剩下的判断就一目了然了：

1. $m < n$：指数为负，$x^(m−n) → 0$，极限为 $0$；
2. $m = n$：指数为 $0$，$x⁰ = 1$，极限为 $a₀/b₀$；
3. $m > n$：指数为正，$x^(m−n) → +∞$，故整体趋于 $∞$。

**例**　$lim(x→∞) (3x² + 2x − 1)/(2x² + 5) = 3/2$。（分子分母同除以 $x²$：$(3 + 2/x − 1/x²)/(2 + 5/x²) → 3/2$。）
:::

### 四、两类未定式的处理：$0/0$ 与 $∞/∞$

当分子分母极限同时为 $0$（记作 $0/0$）或同时为 $∞$（记作 $∞/∞$）时，**商的法则失效**，但极限未必不存在。三种基本处理手段：

**手段 1：因式分解，约去零因子。**　适用于有理式。

**手段 2：有理化。**　适用于含根式的差。

**手段 3：通分。**　适用于分式之差。

:::例题 例 1　求 $lim(x→2) (x² − 4)/(x − 2)$
**解**　这是 $0/0$ 型。分解分子：$x² − 4 = (x − 2)(x + 2)$。

在去心邻域 $x ≠ 2$ 内可以约去零因子：

$$ (x² − 4)/(x − 2) = (x − 2)(x + 2)/(x − 2) = x + 2 $$

于是 $lim(x→2) (x² − 4)/(x − 2) = lim(x→2) (x + 2) = 4$。

**要点**　约分的合法性来自"极限只看去心邻域"。==在 $x ≠ 2$ 的前提下，两个函数取值完全相同，所以极限相同。==
:::

:::例题 例 2　求 $lim(x→0) (√(1 + x) − 1)/x$
**解**　这是 $0/0$ 型，且分子含根式之差，用**有理化**。

分子分母同乘 $√(1 + x) + 1$：

$$ (√(1+x) − 1)/x = [(√(1+x) − 1)(√(1+x) + 1)] / [x(√(1+x) + 1)] = [(1 + x) − 1] / [x(√(1+x) + 1)] $$

$$ = x / [x(√(1+x) + 1)] = 1/(√(1+x) + 1) $$

于是 $lim(x→0) (√(1+x) − 1)/x = 1/(1 + 1) = 1/2$。

**要点**　有理化用的是平方差公式 $(√a − √b)(√a + √b) = a − b$。==它的作用是把"根式之差"变成"多项式之差"，从而暴露出可约的零因子。==
:::

:::例题 例 3　求 $lim(x→1) [1/(1 − x) − 3/(1 − x³)]$
**解**　两项都趋于无穷，这是 $∞ − ∞$ 型。用**通分**。

注意 $1 − x³ = (1 − x)(1 + x + x²)$，故

$$ 1/(1 − x) − 3/(1 − x³) = [(1 + x + x²) − 3] / (1 − x³) = (x² + x − 2)/[(1 − x)(1 + x + x²)] $$

分解分子：$x² + x − 2 = (x + 2)(x − 1) = −(x + 2)(1 − x)$。于是

$$ = −(x + 2)(1 − x) / [(1 − x)(1 + x + x²)] = −(x + 2)/(1 + x + x²) $$

于是 $lim(x→1) [1/(1 − x) − 3/(1 − x³)] = −(1 + 2)/(1 + 1 + 1) = −3/3 = −1$。

**要点**　$∞ − ∞$ 型的破解思路是"**通分变成 $0/0$ 型**"，然后按 $0/0$ 的办法处理。==所有未定式处理的共同目标是：把"看不出"的形式，转化为"能约分"的形式。==
:::

## 课时10　夹逼准则与第一个重要极限

**课时定位**　前九讲建立了定义与运算法则，但它们只能处理"能算出来"的极限。本讲引入第一条**存在性判据**——夹逼准则，并用它攻克第一个无法直接计算的重要极限。

**学习目标**　能复述夹逼准则的条件并说明其用途；能独立完成 $lim(x→0)(sin x)/x = 1$ 的证明；能熟练处理与之相关的各类变形。

**预计用时**　3 小时

### 一、夹逼准则

**定理 1.11（数列形式）**　若数列 ${xₙ}, {yₙ}, {zₙ}$ 满足：

1. 从某一项起有 $yₙ ≤ xₙ ≤ zₙ$（即存在 $N₀$，当 $n > N₀$ 时成立）；
2. $lim(n→∞) yₙ = a$ 且 $lim(n→∞) zₙ = a$，

则 $lim(n→∞) xₙ = a$。

**证明**　任给 $ε > 0$。

由 $lim yₙ = a$，存在 $N₁$，当 $n > N₁$ 时 $a − ε < yₙ < a + ε$。
由 $lim zₙ = a$，存在 $N₂$，当 $n > N₂$ 时 $a − ε < zₙ < a + ε$。

取 $N = max{N₀, N₁, N₂}$。当 $n > N$ 时三条同时成立，于是

$$ a − ε < yₙ ≤ xₙ ≤ zₙ < a + ε $$

即 $|xₙ − a| < ε$。故 $lim xₙ = a$。　$∎$

**定理 1.12（函数形式）**　若在 $x₀$ 的某去心邻域内有 $g(x) ≤ f(x) ≤ h(x)$，且 $lim(x→x₀) g(x) = lim(x→x₀) h(x) = A$，则 $lim(x→x₀) f(x) = A$。

:::难点 夹逼准则的适用特征：能"夹住"
使用它需要完成两个动作：

1. **构造两条边界**——找到 $yₙ$（或 $g$）总在下面、$zₙ$（或 $h$）总在上面；
2. **证明两条边界收敛到同一个极限**。

难点几乎总在第一步。构造边界的原则是：==要足够贴近 $xₙ$（夹得住），又要足够简单（算得出极限）。== 这两条往往互相拉扯，需要一点技巧。

**几何直观**：$xₙ$ 被上下两条"夹板"夹住。如果两块夹板在某处合拢（同趋于 $a$），那么夹在中间的 $xₙ$ 除了跟着去 $a$ 之外别无选择。

**方法论价值**：==当无法直接确定一个量时，就把它"控制"在两个已知量之间。== 这是分析学中最常用的间接手段之一，本讲与课时 51、106、127 都会反复用到。
:::

:::提示 用夹逼准则时的常见配套技巧
1. **舍大取小、舍小取大**：求 $n$ 项和式的极限时，把每一项都换成最大项或最小项，得到上下界。例如 $n/(n² + n) ≤ Σₖ₌₁ⁿ n/(n² + k) ≤ n/(n² + 1)$。
2. **利用 $|sin θ| ≤ 1$、$x² ≥ 0$ 这类显然的界**。
3. **注意两条边界的极限必须相等**——这是整个准则的落脚点。若两条边界的极限不等，夹逼准则给不出任何结论。
:::

### 二、第一个重要极限

**定理 1.13**

$$ lim(x→0) (sin x)/x = 1 $$

:::难点 证明的核心：面积比较
证明的关键在于比较三块图形的面积。它们的位置关系如图 1.10.2 所示，请对照该图阅读下面的推导。

![[fig1_10_2]]
**第一步：建立不等式。**

在单位圆中，设圆心角 $x$ 满足 $0 < x < π/2$。记圆心为 $O$，圆与 $x$ 轴正半轴交于点 $A(1, 0)$，角 $x$ 的终边与圆交于点 $B(cos x, sin x)$。过 $A$ 作圆的切线，与 $OB$ 的延长线交于点 $D$。

比较三块图形的面积：

1. **三角形 $OAB$**：底为 $1$，高为 $sin x$，面积 $= (1/2)·1·sin x = (sin x)/2$；
2. **扇形 $OAB$**：面积 $= (1/2)·r²·x = x/2$（**这里用了弧度制**）；
3. **三角形 $OAD$**：底 $OA = 1$，高为 $tan x$，面积 $= (1/2)·1·tan x = (tan x)/2$。

由于三角形 $OAB$ 含于扇形 $OAB$，扇形 $OAB$ 又含于三角形 $OAD$，所以

$$ (sin x)/2 < x/2 < (tan x)/2 $$

三边同乘 $2$，得 $sin x < x < tan x$。

**第二步：化为 $(sin x)/x$ 的夹逼形式。**

由 $sin x < x$ 得 $(sin x)/x < 1$（因为 $0 < x$，故 $sin x > 0$）。

由 $x < tan x = (sin x)/(cos x)$ 得 $x·cos x < sin x$，即 $cos x < (sin x)/x$。

合起来：

$$ cos x < (sin x)/x < 1 $$

**第三步：取极限。**

当 $x → 0^+$ 时，$cos x → 1$，而右边恒为 $1$。由夹逼准则，

$$ lim(x→0^+) (sin x)/x = 1 $$

**第四步：推广到双侧。**

注意 $(sin x)/x$ 是**偶函数**：$sin(−x)/(−x) = (−sin x)/(−x) = (sin x)/x$。所以左极限与右极限相等。由定理 1.5，

$$ lim(x→0) (sin x)/x = 1　∎ $$
:::

:::难点 为什么角度必须用弧度制
上面的扇形面积公式 $S = (1/2) r² x$ **只在 $x$ 用弧度时成立**。

若改用角度制（记角度为 $θ$），扇形面积是 $S = π r² θ / 360$。代入单位圆后，中间的不等式变成

$$ (sin θ)/2 < π θ/360 < (tan θ)/2 $$

于是 $(sin θ)/θ$ 被夹在 $π/180$ 附近，极限值为 $π/180 ≈ 0.01745$，**不再是 $1$**。

==所以"角度必须用弧度制"不是便于计算的约定，而是这个极限成立的前提条件。== 这就是为什么高等数学中一切三角函数都以弧度为自变量——只有这样，$sin$ 的导数才是干净的 $cos$（课时 18）。
:::

:::难点 这个极限的意义
它断言：==当 $x → 0$ 时，$sin x$ 与 $x$ 趋于 $0$ 的"速度完全相同"（比值为 $1$）。==

由此得到两个重要后果：

1. **近似公式**　当 $|x|$ 很小时，$sin x ≈ x$。这是小角度近似的理论基础，在物理与工程中应用极广。
2. **求导的起点**　$(sin x)' = cos x$ 的推导中，关键一步正是用到了这个极限（课时 18 会看到）。

同时它也说明 $sin x$ 在 $0$ 附近的行为"像"恒等函数 $x$，这正是课时 12 中 $sin x ~ x$ 的来源。
:::

:::易错 三个高频错误
**错误 1：把 $0/0$ 当成"极限不存在"。**　$lim(x→0)(sin x)/x$ 是 $0/0$ 型，商的法则失效，但**极限存在且等于 $1$**。"法则失效"与"极限不存在"完全是两件事。

**错误 2：与 $lim(x→0) sin(1/x)$ 混淆。**　前者存在（等于 $1$）；后者**不存在**（振荡，见课时 7 模型 4）。两个极限外形相似，性质截然相反。

**错误 3：忽略系数。**　$lim(x→0) (sin kx)/x = k$，**不是** $1$。正确做法是先配系数：

$$ (sin kx)/x = k · (sin kx)/(kx) → k · 1 = k $$

==凡是遇到 $sin$ 后面跟的不是 $x$ 本身，第一件事就是"配系数"，把角度凑成与分母一致。==
:::

:::例题 例 1　求 $lim(x→0) (tan x)/x$
**解**　拆成两个已知因子的乘积：

$$ (tan x)/x = (sin x)/x · 1/(cos x) $$

当 $x → 0$ 时，第一个因子趋于 $1$，第二个因子趋于 $1/1 = 1$。由乘积法则，极限为 $1$。

**要点**　==把不认识的函数拆成"认识的函数 × 简单因子"，是处理三角极限的通用套路。==
:::

:::例题 例 2　求 $lim(x→0) (sin 3x)/x$
**解**　配系数：

$$ (sin 3x)/x = 3 · (sin 3x)/(3x) $$

令 $u = 3x$，当 $x → 0$ 时 $u → 0$，故 $(sin u)/u → 1$。于是极限为 $3 · 1 = 3$。

**要点**　==配系数的本质是"凑出重要极限的标准形"。==
:::

:::例题 例 3　求 $lim(x→0) (1 − cos x)/x²$
**解**　这个极限不能直接套重要极限，需要先用**降幂公式**：

$$ 1 − cos x = 2 sin²(x/2) $$

于是 $(1 − cos x)/x² = 2 sin²(x/2)/x²$。

再配系数。令 $u = x/2$，则 $x = 2u$，$x² = 4u²$：

$$ 2 sin²u/(4u²) = (1/2) · (sin u / u)² → (1/2) · 1² = 1/2 $$

**要点**　这个结果 $1 − cos x ~ x²/2$ 是课时 12 等价无穷小表中的重要一条，**请记住它的推导过程**，因为它演示了"降幂 + 配系数"的标准配合。
:::

:::例题 例 4　求 $lim(x→0) (arcsin x)/x$
**解**　作变量代换。令 $t = arcsin x$，则 $x = sin t$，且当 $x → 0$ 时 $t → 0$。于是

$$ (arcsin x)/x = t/(sin t) = 1 / [(sin t)/t] → 1/1 = 1 $$

**要点**　==换元的目的永远是"把陌生的形式变成熟悉的形式"。== 这里把反三角换成了三角，问题立刻化解。
:::

## 课时11　单调有界准则与第二个重要极限

**课时定位**　第二条存在性判据。它与夹逼准则的分工是：**夹逼准则需要先知道边界的极限，而单调有界准则只要能判断"单调"和"有界"，就能断言极限存在——哪怕不知道极限是多少。**

**学习目标**　能复述单调有界准则；能按"证单调、证有界、解方程求极限"三步处理递推数列；掌握第二个重要极限的三种形式与 $1^∞$ 型的标准处理。

**预计用时**　4 小时

### 一、单调有界准则

**定理 1.14**　单调有界数列必有极限。具体地：

1. 单调**增加**且有**上界**的数列必有极限，且极限不超过该上界；
2. 单调**减少**且有**下界**的数列必有极限，且极限不低于该下界。

:::难点 这条准则的深刻之处
它的证明依赖实数系的**完备性**（确界原理），超出本课程范围。但直观理解并不难：

一个单调增加的数列，就像一个只会往上走的人。如果同时给他设了一个"天花板"（上界），那么他最终必然被"卡"在某个位置附近，再也冲不上去。这个"卡住的位置"就是极限。

==真正的要点是：它**不需要预先知道极限是什么**，就能断言极限存在。== 这是它与夹逼准则最大的分工差别：

1. 夹逼准则：需要先算出两条边界的极限；
2. 单调有界准则：只要判断"单调"和"有界"两件事。

**代价是**：它只告诉你极限存在，不告诉你极限等于多少。不过在递推数列问题中，极限值往往可以通过"在递推式两边取极限"解方程得到。
:::

:::提示 使用时的三个动作
**动作一：证单调。**　常用三种方法：

1. **作差**：计算 $xₙ₊₁ − xₙ$，判断符号；
2. **作商**：计算 $xₙ₊₁/xₙ$，与 $1$ 比较（要求各项同号）；
3. **数学归纳法**：先猜出单调性，再归纳证明。

**动作二：证有界。**　常用**数学归纳法**给出上界或下界。诀窍是先"猜"一个界（往往就是极限的候选值），再用归纳法验证。

**动作三：求极限值。**　设 $lim xₙ = a$，在递推式两边令 $n → ∞$ 取极限，解出 $a$。注意要**舍去不合理的根**（例如落在有界范围之外的根）。
:::

### 二、第二个重要极限

**定理 1.15**

$$ lim(n→∞) (1 + 1/n)ⁿ = e $$

其中 $e$ 是一个无理数，$e ≈ 2.718281828459045…$

**等价形式**（三种形式必须一起记住）：

$$ lim(x→∞) (1 + 1/x)^x = e,　lim(x→0) (1 + x)^(1/x) = e $$

:::难点 证明思路：单调 + 有界
设 $xₙ = (1 + 1/n)ⁿ$。由单调有界准则，只需证明它单调增加且有上界。

**第一步：证明 ${xₙ}$ 单调增加。**

用二项式定理展开：

$$ xₙ = Σₖ₌₀ⁿ C(n, k) (1/n)ᵏ = Σₖ₌₀ⁿ (1/k!) · [1·(1 − 1/n)(1 − 2/n)…(1 − (k−1)/n)] $$

这一步是把组合数 $C(n,k) = n(n−1)…(n−k+1)/k!$ 中的每个因子都除以一个 $n$ 得到的。

现在比较 $xₙ$ 与 $xₙ₊₁$：

1. 和式中的每一项，方括号里都是若干个 $(1 − j/n)$ 相乘的形式。当 $n$ 增大时，每个 $(1 − j/n)$ 都**变大**（更接近 $1$）；
2. 而且 $xₙ₊₁$ 比 $xₙ$ **多出一项**（$k = n+1$ 那一项是正的）。

两者合起来，得 $xₙ < xₙ₊₁$，即 ${xₙ}$ 单调增加。

**第二步：证明 ${xₙ}$ 有上界。**

上面和式中方括号内的每个因子都小于 $1$，所以方括号整体小于 $1$。于是

$$ xₙ < Σₖ₌₀ⁿ 1/k! $$

再用 $k! = 1·2·3… k ≥ 2ᵏ⁻¹$（$k ≥ 1$），得 $1/k! ≤ 1/2ᵏ⁻¹$。于是

$$ xₙ < 1 + 1 + 1/2 + 1/2² + … + 1/2ⁿ⁻¹ < 1 + 2 = 3 $$

（这是公比为 $1/2$ 的等比级数求和，总和不超过 $2$。）

所以 $xₙ < 3$，有上界。

由单调有界准则，${xₙ}$ 收敛。把这个极限**定义为** $e$。　$∎$
:::

:::难点 为什么把这个极限命名为 $e$
因为它出现的频率实在太高：连续复利、人口增长、放射性衰变、化学反应速率、概率论中的泊松分布……几乎所有"变化率与自身成正比"的现象都会导出这个极限。

可以进一步证明（用泰勒级数，课时 135）$e = Σₖ₌₀^(∞) 1/k!$，由此算出 $e ≈ 2.71828$。

==$e$ 的特殊性在于：以 $e$ 为底的指数函数 $e^x$ 的导数恰好等于它自己。== 这是所有底数中独一无二的性质，也是它在微积分中地位特殊的原因（课时 18 会兑现）。
:::

:::难点 三种形式的等价性
$$ lim(n→∞)(1 + 1/n)ⁿ = e,　lim(x→∞)(1 + 1/x)^x = e,　lim(x→0)(1 + x)^(1/x) = e $$

前两个只是把离散变量 $n$ 换成了连续变量 $x$。

第三个通过对数变换与前两个沟通：令 $x = 1/t$，则 $x → 0$ 对应 $t → ∞$，且

$$ (1 + x)^(1/x) = (1 + 1/t)^(t) → e $$

==题目中三种形式都会出现，必须能瞬间识别。== 识别的关键特征是：**底数趋于 $1$，指数趋于 $∞$，且底数中"多出来的部分"与指数互为倒数。**
:::

:::难点 $1^∞$ 型的标准处理套路
凡形如 $[1 + α(x)]^(β(x))$，其中 $α(x) → 0$、$β(x) → ∞$ 的极限，都称为 $1^∞$ 型。

**处理套路**（把它"凑"成第二个重要极限）：

$$ [1 + α(x)]^(β(x)) = { [1 + α(x)]^(1/α(x)) }^(α(x)β(x)) $$

内层 $[1 + α(x)]^(1/α(x)) → e$（这正是第二个重要极限的形式），所以

$$ lim [1 + α(x)]^(β(x)) = e^(lim α(x)β(x)) $$

==**核心结论**：$1^∞$ 型的极限等于 $e^A$，其中 $A = lim α(x)·β(x)$，而 $α$ 是底数中"减去 $1$"后剩下的部分。==

**例**　$lim(x→∞) (1 + 2/x)^x$。这里 $α = 2/x$，$β = x$，$αβ = 2$。故极限 $= e²$。

==这一步把"$1^∞$ 型"的问题转化成了"求 $αβ$ 的普通极限"，难度大幅下降。==
:::

:::例题 例 1　求 $lim(x→∞) (1 + 1/x)^(2x)$
**解**　把它看成第二个重要极限的幂：

$$ (1 + 1/x)^(2x) = [(1 + 1/x)^x]² → e² $$

**要点**　==指数中的常数因子可以直接提到外面。== 这是最省事的做法。
:::

:::例题 例 2　求 $lim(x→0) (1 − x)^(1/x)$
**解**　用 $1^∞$ 型套路。把底数写成 $1 + α$ 的形式：$1 − x = 1 + (−x)$，故 $α = −x$，$β = 1/x$。

$$ αβ = (−x)·(1/x) = −1 $$

故极限 $= e⁻¹ = 1/e$。

**要点**　==关键是正确识别 $α$——它是底数减去 $1$ 之后的部分。== 本题中底数是 $1 − x$，所以 $α = −x$ 而不是 $x$。
:::

:::例题 例 3　求 $lim(x→∞) [(x + 3)/(x + 1)]^(x)$
**解**　先把底数改写成 $1 + α$ 的形式：

$$ (x + 3)/(x + 1) = 1 + 2/(x + 1) $$

故 $α = 2/(x + 1)$，$β = x$。于是

$$ αβ = 2x/(x + 1) → 2 $$

故极限 $= e²$。

**要点**　==当底数是一个分式时，第一步永远是"做除法把它写成 $1 + $ 真分式"的形式。== 即 $(x+a)/(x+b) = 1 + (a−b)/(x+b)$。
:::

## 课时12　无穷小的比较与等价无穷小替换

**课时定位**　本讲把"无穷小"这个笼统概念**分层**，从而得到一个极其高效的计算工具——等价无穷小替换。它是全书使用频率最高的计算技巧之一，也是**误用率最高**的技巧之一。

**学习目标**　能用阶的概念比较无穷小；背熟常用等价无穷小表；能在乘除结构中正确替换；能说清加减法中为什么不能随意替换。

**预计用时**　3 小时

### 一、为什么要比较无穷小

当 $x → 0$ 时，$x$、$x²$、$sin x$、$1 − cos x$ **都是无穷小**。但它们趋于 $0$ 的**快慢**差别很大：

1. $x²$ 比 $x$ 快得多（$x²/x = x → 0$）；
2. $sin x$ 与 $x$ 快慢相当（$sin x / x → 1$）；
3. $1 − cos x$ 与 $x²$ 快慢相当（$(1 − cos x)/x² → 1/2$）。

为了精确刻画这种差别，需要引入"阶"的概念。==这正是"无穷小"这个笼统概念所缺少的那一层结构。==

### 二、无穷小的比较

**定义 1.18**　设 $α$、$β$ 都是同一极限过程中的无穷小，且在该过程的去心邻域内 $β ≠ 0$。

1. 若 $lim α/β = 0$，则称 $α$ 是比 $β$ **高阶**的无穷小，记作 $α = o(β)$；
2. 若 $lim α/β = ∞$，则称 $α$ 是比 $β$ **低阶**的无穷小；
3. 若 $lim α/β = c$（$c ≠ 0$ 为常数），则称 $α$ 与 $β$ 是**同阶**无穷小；
4. 特别地，若 $lim α/β = 1$，则称 $α$ 与 $β$ 是**等价**无穷小，记作 $α ~ β$；
5. 若 $lim α/βᵏ = c$（$c ≠ 0$），则称 $α$ 是关于 $β$ 的 **$k$ 阶**无穷小。

:::难点 阶的高低反映"趋于 $0$ 的速度"
以 $x → 0$ 为例，取参照量 $β = x$：

| 无穷小 | 与 $x$ 的比值 | 阶 | 直观含义 |
|---|---|---|---|
| $x²$ | $x → 0$ | 比 $x$ 高阶 | 趋于 $0$ **更快** |
| $√x$ | $1/√x → ∞$ | 比 $x$ 低阶 | 趋于 $0$ **更慢** |
| $sin x$ | $→ 1$ | 与 $x$ 等价 | 速度**相同** |
| $1 − cos x$ | $(1−cos x)/x² → 1/2$ | 关于 $x$ 的 **2 阶** | 比 $x$ 快，与 $x²$ 同速 |

==一句话记住：**阶数越高，趋于 $0$ 越快。**==

**$o(β)$ 这个记号为什么有用？**　它把"快得多"这件事写成了一个可以在等式中操作的符号。例如 $x² + o(x²)$ 表示"$x²$ 加上一个比 $x²$ 更快趋于 $0$ 的量"，这在课时 30 的泰勒公式中会成为主要语言。
:::

### 三、等价无穷小替换定理

**定理 1.16**　设在同一极限过程中 $α ~ α'$，$β ~ β'$，且 $lim α'/β'$ 存在，则

$$ lim α/β = lim α'/β' $$

**证明**　把 $α/β$ 拆成三个因子的乘积：

$$ α/β = (α/α') · (α'/β') · (β'/β) $$

因为 $α ~ α'$，所以 $α/α' → 1$；因为 $β ~ β'$，所以 $β'/β → 1$（注意 $β'/β = 1/(β/β')$，而 $β/β' → 1$）。

由乘积法则，

$$ lim α/β = 1 · lim α'/β' · 1 = lim α'/β'　∎ $$

:::难点 定理的实质：只在**乘除**结构中替换
请注意定理的表述——它讨论的是 $α/β$ 这个**商**的极限。

==所以定理保证的是：**在乘除运算中，因子可以用等价无穷小替换。**== 它**没有**对加减法作出任何承诺。这一点是本讲最关键的界限，下面会专门讨论。
:::

### 四、常用等价无穷小表（当 $x → 0$ 时）

这张表必须背熟，它是后续所有极限计算与积分计算的基本功。

| 等价关系 | 所属类型 |
|---|---|
| $sin x ~ x$ | 三角类 |
| $tan x ~ x$ | 三角类 |
| $arcsin x ~ x$ | 反三角类 |
| $arctan x ~ x$ | 反三角类 |
| $1 − cos x ~ x²/2$ | 三角类（二阶） |
| $ln(1 + x) ~ x$ | 对数类 |
| $e^x − 1 ~ x$ | 指数类 |
| $a^x − 1 ~ x·ln a$（$a > 0, a ≠ 1$） | 指数类 |
| $(1 + x)^a − 1 ~ a x$（$a$ 为常数） | 幂函数类 |
| $ⁿ√(1 + x) − 1 ~ x/n$ | 幂函数类（上一条取 $a = 1/n$） |

:::提示 记忆技巧：按"家族"记
这张表不是十件孤立的事，而是三个家族：

1. **三角与反三角家族**：$sin x$、$tan x$、$arcsin x$、$arctan x$ **全都等价于 $x$**。这不是巧合，而是它们都是 $x$ 的一阶近似。成员 $1 − cos x$ 例外，它是**二阶**的 $x²/2$。
2. **对数与指数家族**：$ln(1+x) ~ x$ 与 $e^x − 1 ~ x$ 互为反函数关系，本质是同一个极限的两个方向。一般指数 $a^x − 1$ 多出一个系数 $ln a$。
3. **幂函数家族**：$(1+x)^a − 1 ~ ax$。这一条是"万能"的：取 $a = 1/2$ 得 $√(1+x) − 1 ~ x/2$，取 $a = −1$ 得 $1/(1+x) − 1 ~ −x$。

==先记住家族规律，个别成员再单独强化，比死记十行更牢固。==
:::

### 五、等价替换的使用规则

:::易错 加减法中不能随意替换——本节最重要的警告
定理只保证**乘除**结构可以替换。在**加减**结构中替换**可能出错**。

**反例**　求 $lim(x→0) (tan x − sin x)/x³$。

**错误做法**：因为 $tan x ~ x$，$sin x ~ x$，所以 $tan x − sin x ~ x − x = 0$，于是极限为 $0$。

**正确结果**：先做变形

$$ tan x − sin x = sin x · (1/cos x − 1) = sin x · (1 − cos x)/cos x $$

再用等价替换（现在是**乘除**结构）：

$$ sin x · (1 − cos x)/cos x ~ x · (x²/2) / 1 = x³/2 $$

所以 $lim(x→0) (tan x − sin x)/x³ = (x³/2)/x³ = 1/2$。

**错误的原因**：$tan x$ 与 $sin x$ 都替换成了 $x$，但它们的**差**是比 $x$ 更高阶的无穷小。替换过程把"差的阶"这个关键信息丢掉了，于是得到 $x − x = 0$ 这个无意义的结论。
:::

:::难点 为什么加减不能替换：深层原因
等价无穷小 $α ~ α'$ 的含义是

$$ α = α'(1 + o(1)) $$

也就是"$α$ 等于 $α'$ 加上一个相对误差趋于 $0$ 的部分"。

当两个这样的量相减时：

$$ α − β = α'(1 + o(1)) − β'(1 + o(1)) $$

如果 $α' = β'$（例如都是 $x$），那么

$$ α − β = α' · o(1) − β' · o(1) $$

**主项 $α'$ 被消掉了**，剩下的完全由那些被丢弃的 $o(1)$ 项决定。而 $o(1)$ 的具体形态恰恰是替换时丢掉的。

==一句话：等价替换保留的是"主项"，而减法会消掉主项，让原本被丢弃的次项**升格**为主项。==

**数值类比**：$1.0001 − 1.0002 ≈ −0.0001$。如果先把两个数都近似成 $1$，就会得到 $1 − 1 = 0$——误差比差值本身还大。等价替换在加减法中失效，正是同一个道理。
:::

:::提示 什么时候加减法中可以替换
有一个可用的**充分条件**：若 $α ~ α'$，$β ~ β'$，且 $lim α'/β' = c ≠ 1$（即两者**不等价**），则在加减中替换是安全的。

原因是此时主项不会被完全消掉。

**但在实际做题时，更稳妥的做法是**：==遇到加减结构，先用代数变形把它变成乘除结构，再做替换。== 常用变形手段：

1. **提取公因子**（如上面反例中提出 $sin x$）；
2. **有理化**（含根式之差时）；
3. **通分**（分式之差时）；
4. **和差化积**（三角函数之差时）。
:::

:::例题 例 1　求 $lim(x→0) (tan 2x)/(sin 5x)$
**解**　这是**乘除**结构，可以直接替换。

$$ tan 2x ~ 2x,　sin 5x ~ 5x $$

故 $lim(x→0) (tan 2x)/(sin 5x) = lim(x→0) (2x)/(5x) = 2/5$。

**要点**　替换时要把系数一并带上，这是最常见的失分点。
:::

:::例题 例 2　求 $lim(x→0) (1 − cos x)/(x·sin x)$
**解**　全部是**乘除**结构，可以直接替换：

$$ 1 − cos x ~ x²/2,　sin x ~ x $$

故 $lim = (x²/2)/(x · x) = (x²/2)/x² = 1/2$。

**要点**　分母 $x·sin x$ 是一个乘积，其中 $sin x$ 可以独立替换——因为它是**因子**。
:::

:::例题 例 3　求 $lim(x→0) (e^(2x) − 1)/(ln(1 + 3x))$
**解**　分子用 $e^u − 1 ~ u$（取 $u = 2x$），分母用 $ln(1 + v) ~ v$（取 $v = 3x$）：

$$ e^(2x) − 1 ~ 2x,　ln(1 + 3x) ~ 3x $$

故 $lim = (2x)/(3x) = 2/3$。

**要点**　注意替换前要先确认 $u → 0$、$v → 0$。==等价无穷小表中的 $x$ 是一个"占位符"，可以换成任何趋于 $0$ 的量。==
:::

:::例题 例 4（加减陷阱）　求 $lim(x→0) (tan x − sin x)/x³$
**解**　先变形，把减法化为乘法：

$$ tan x − sin x = sin x(1/cos x − 1) = sin x · (1 − cos x)/cos x $$

现在是乘除结构，可以替换：

$$ sin x · (1 − cos x)/cos x ~ x · (x²/2)/1 = x³/2 $$

故 $lim = (x³/2)/x³ = 1/2$。

**要点**　==这一步"提出公因子把减法变乘法"的动作，是破解所有加减陷阱的通用钥匙。请把它变成条件反射。==
:::

## 课时13　函数的连续性与间断点

**课时定位**　前十二讲都在讨论"$x$ 接近 $x₀$ 时 $f(x)$ 趋于什么"。本讲加入一个新要求：**这个极限值是否恰好等于 $f(x₀)$？** 回答"是"就是连续，回答"否"就是间断。

**学习目标**　能说出连续的三个要素；能用左右极限判断分段函数在分界点的连续性；能准确对间断点分类。

**预计用时**　3 小时

### 一、函数连续性的定义

**定义 1.19（增量形式）**　设函数 $y = f(x)$ 在点 $x₀$ 的某邻域内有定义。若

$$ lim(Δx→0) Δy = lim(Δx→0) [f(x₀ + Δx) − f(x₀)] = 0 $$

则称 $f(x)$ 在点 $x₀$ **连续**。

**定义 1.20（极限形式）**　设 $f$ 在 $x₀$ 的某邻域内有定义。若

$$ lim(x→x₀) f(x) = f(x₀) $$

则称 $f(x)$ 在点 $x₀$ **连续**。

这两个定义是等价的（令 $x = x₀ + Δx$ 即可互相转化），但**极限形式更实用**，因为它把问题归结为"算两个量，看是否相等"。

:::难点 极限形式揭示的"三个要素"
等式 $lim(x→x₀) f(x) = f(x₀)$ 要想成立，必须**同时**满足三件事：

1. $f$ 在 $x₀$ 处**有定义**（即 $f(x₀)$ 存在）——否则右边无意义；
2. $lim(x→x₀) f(x)$ **存在**（即左右极限存在且相等）——否则左边无意义；
3. 两者**相等**。

==三者缺一不可。特别提醒第 3 条：即使 1、2 都满足，只要极限值不等于函数值，函数在该点仍然不连续。== 这一点在下面的例 5 中会看到。
:::

:::难点 为什么"连续"要用极限来定义
因为连续的本质是"**函数值跟着自变量一起变**"——自变量变化很小时，函数值的变化也很小。

这正是 $lim(Δx→0) Δy = 0$ 的含义。请注意这里**没有任何"很小"的模糊说法**：ε-δ 语言已经自动把它精确化了——任给 $ε > 0$，存在 $δ > 0$，当 $|Δx| < δ$ 时 $|Δy| < ε$。

这也解释了为什么连续函数的图像可以"一笔画成"：中间没有断裂，因为任何微小的横向移动都只带来微小的纵向移动。
:::

### 二、左连续与右连续

**定义 1.21**　若 $lim(x→x₀^+) f(x) = f(x₀)$，称 $f$ 在 $x₀$ **右连续**；若 $lim(x→x₀^−) f(x) = f(x₀)$，称 $f$ 在 $x₀$ **左连续**。

**定理 1.17**　$f$ 在 $x₀$ 连续的充要条件是 $f$ 在 $x₀$ **既左连续又右连续**。

这个结论直接来自课时 7 的定理 1.5（双侧极限存在的充要条件），它是**判断分段函数在分界点连续性**的标准方法。

:::提示 判断分段函数在分界点连续性的固定三步
设分界点为 $x₀$：

1. **算函数值**：求 $f(x₀)$；
2. **算左右极限**：求 $f(x₀^+)$ 与 $f(x₀^−)$；
3. **比对三个数**：$f(x₀^+)$、$f(x₀^−)$、$f(x₀)$ 是否全部相等。

==三步中任何一步"算不出来"或"对不上"，就是不连续。== 这个流程在含参数的连续性题目中会反复使用。
:::

### 三、间断点及其分类

**定义 1.22**　若 $f$ 在点 $x₀$ 处不连续，则称 $x₀$ 为 $f(x)$ 的**间断点**。

间断点按左右极限的情况分类：

| 大类 | 子类 | 判定特征 |
|---|---|---|
| **第一类** | 可去间断点 | 左右极限**存在且相等**，但不等于 $f(x₀)$，或 $f$ 在 $x₀$ 无定义 |
| **第一类** | 跳跃间断点 | 左右极限**都存在但不相等** |
| **第二类** | 无穷间断点 | 至少有一侧极限为 $∞$ |
| **第二类** | 振荡间断点 | 因振荡而极限不存在（不是趋于无穷） |

:::难点 判别只需回答两个问题
整个分类的判别流程可以压缩成两问：

==**第一问：左右极限都存在吗？**==
　都存在 → **第一类**；至少一个不存在 → **第二类**。

==**第二问（针对第一类）：左右极限相等吗？**==
　相等 → **可去间断点**；不相等 → **跳跃间断点**。

（第二类再细看：若某侧趋于 $∞$ 就是无穷间断点，否则通常是振荡间断点。）

==请把这张表与课时 7 的"四个经典模型"对照记忆——那四个模型恰好是四类间断点的标准范例。==

四类间断点的图像特征如图 1.13.1 所示，建议与上表逐一对应。

![[fig1_13_1]]
:::

:::难点 "可去间断点"为什么叫"可去"
因为它可以**通过修改（或补充）$f$ 在 $x₀$ 处的定义**，使函数在该点变得连续——只需令

$$ f(x₀) = lim(x→x₀) f(x) $$

例如 $f(x) = (x² − 1)/(x − 1)$ 在 $x = 1$ 无定义，但 $lim(x→1) f(x) = 2$。补充定义 $f(1) = 2$，函数就在 $x = 1$ 处连续了。这个"洞"被补上了，所以叫**可去**。

==而跳跃间断点是"去不掉"的：无论怎样定义 $f(x₀)$，都不可能让左右两边同时接上。== 这正是两类间断点的本质差别。
:::

:::例题 例 1　考察 $f(x) = (x² − 1)/(x − 1)$ 在 $x = 1$ 处
**解**　$f$ 在 $x = 1$ 处无定义（分母为零），故 $x = 1$ 是间断点。

计算极限：在 $x ≠ 1$ 时 $f(x) = x + 1$，故 $lim(x→1) f(x) = 2$，左右极限存在且相等。

故 $x = 1$ 是**可去间断点**。

**要点**　"无定义"本身就足以构成间断，不需要再看极限。极限的作用是**继续判断类型**。
:::

:::例题 例 2　考察 $f(x) = |x|/x$ 在 $x = 0$ 处
**解**　$f$ 在 $x = 0$ 无定义。

$f(0^+) = 1$（因为 $x > 0$ 时 $|x|/x = 1$），$f(0^−) = −1$（因为 $x < 0$ 时 $|x|/x = −1$）。

左右极限都存在但不相等，故 $x = 0$ 是**跳跃间断点**。

**要点**　这是课时 7 模型 1 的直接兑现。
:::

:::例题 例 3　考察 $f(x) = 1/x$ 在 $x = 0$ 处
**解**　$f$ 在 $x = 0$ 无定义。

$lim(x→0^+) 1/x = +∞$，$lim(x→0^−) 1/x = −∞$。

左右极限都不存在（趋于无穷），故 $x = 0$ 是**无穷间断点**（属于第二类）。

**要点**　==趋于无穷算作"极限不存在"。== 所以不要因为"两侧都趋于无穷"就误判为"极限相等"。
:::

:::例题 例 4　考察 $f(x) = sin(1/x)$ 在 $x = 0$ 处
**解**　$f$ 在 $x = 0$ 无定义。

当 $x → 0$ 时 $1/x$ 无限增大，$sin(1/x)$ 在 $[−1, 1]$ 上无限次振荡，两个单侧极限都**不存在**。

故 $x = 0$ 是**振荡间断点**（属于第二类）。

**要点**　==注意与无穷间断点的区别：这里函数值并没有无限增大，它始终被限制在 $[−1,1]$ 内，只是"不收敛"。==
:::

:::例题 例 5　考察 $f(x) = x (x ≠ 1)$，$f(1) = 0$ 在 $x = 1$ 处
**解**　$f$ 在 $x = 1$ 有定义，$f(1) = 0$。

但 $lim(x→1) f(x) = lim(x→1) x = 1$。

极限存在，却**不等于**函数值（$1 ≠ 0$）。故 $x = 1$ 是**可去间断点**。

**要点**　==这个例子专门用来打掉"有定义就连续"的错觉。== 连续要求的是"极限值**等于**函数值"，而不是"有定义"或"极限存在"。
:::

## 课时14　连续函数的运算与闭区间上连续函数的性质

**课时定位**　本讲给出本章最有实用价值的两个结论：**初等函数在定义区间上连续**（于是求极限可以直接代值），以及**闭区间上连续函数的四个基本定理**（于是不解方程也能断定根存在）。

**学习目标**　能说出"极限可以直接代入"的适用条件；能复述四个基本定理并说明"闭区间"三字的必要性；能用零点定理证明方程根的存在性与不动点问题。

**预计用时**　3 小时

### 一、连续函数的四则运算

**定理 1.18**　若 $f$、$g$ 在 $x₀$ 连续，则 $f ± g$、$f · g$、$f/g$（要求 $g(x₀) ≠ 0$）都在 $x₀$ 连续。

**证明**　以乘积为例。由极限的乘积法则（定理 1.9）与连续性定义，

$$ lim(x→x₀) [f(x)g(x)] = [lim f(x)]·[lim g(x)] = f(x₀)·g(x₀) $$

这正是 $fg$ 在 $x₀$ 连续的定义。其余情形同理。　$∎$

==这个定理的意义是：**"连续"这个性质对四则运算是封闭的**——连续函数经过加减乘除（除数非零）仍然是连续函数。== 这是后面"初等函数连续"结论的第一块基石。

### 二、反函数与复合函数的连续性

**定理 1.19**　若 $f$ 在区间 $I$ 上单调且连续，则其反函数 $f⁻¹$ 在对应的区间上也单调且连续。

直观理解：反函数的图像只是原图像关于直线 $y = x$ 翻转。翻转不会把"连续"翻断，也不会改变单调性。

**定理 1.20**　设 $lim(x→x₀) g(x) = u₀$，且 $f$ 在 $u₀$ **连续**，则

$$ lim(x→x₀) f[g(x)] = f(u₀) = f[ lim(x→x₀) g(x) ] $$

:::难点 定理 1.20 的价值：极限符号可以"搬进"连续函数内部
这个等式的意思是：==当外层函数连续时，求极限与求函数值可以交换次序。==

请对比课时 9 的复合函数极限法则（定理 1.10）——那里额外要求"$g(x) ≠ u₀$"这个附加条件。而在这里，因为 $f$ 在 $u₀$ **连续**，有 $f(u₀) = A$，所以那个附加条件自动消失。

==这正是"连续"这个概念带来的第一个实质性便利：它让一条本来有附加条件的定理变得无条件可用。==
:::

### 三、初等函数的连续性

**定理 1.21**　初等函数在其**定义区间**上连续。

:::难点 这个定理的意义：求极限可以直接代入
它给出了一条极好用的计算规则：

==若 $f$ 是初等函数，且 $x₀$ 在其定义区间内，则 $lim(x→x₀) f(x) = f(x₀)$。==

也就是说，**求初等函数在定义区间内某点的极限，直接代值即可，不需要任何技巧。**

**例**　$lim(x→π/4) sin(2x) = sin(π/2) = 1$。
**例**　$lim(x→0) ln(1 + cos x) = ln(1 + 1) = ln 2$。
**例**　$lim(x→1) (x² + 3x − 1)/(x + 2) = (1 + 3 − 1)/(1 + 2) = 1$。
:::

:::难点 这个定理为什么成立
初等函数是由常数与基本初等函数经过**有限次**四则运算和**有限次**复合得到的。所以证明分两步走：

1. 证明五类**基本初等函数**在其定义区间上连续（这需要逐个验证，是分析学的基础工作）；
2. 用定理 1.18（四则运算保持连续）与定理 1.20（复合保持连续）**逐层传递**，把连续性从"零件"传到"整机"。

==请注意"有限次"这个条件不可省略。== 第四章的无穷级数会产生"无穷次运算"得到的函数（例如傅里叶级数），它们就可能不连续——课时 138 会看到，傅里叶级数在间断点处收敛到左右极限的平均值，而不是函数值本身。
:::

:::易错 "定义区间"与"定义域"不是一回事
**定义区间**指包含在定义域内的**区间**（即有长度的连续部分）。

一个函数的定义域可能完全不含区间。例如

$$ f(x) = √(x² − 1) + √(1 − x²) $$

要两项同时有意义，必须 $x² = 1$，故定义域只有两个孤立点 $x = ±1$，不含任何区间。

==在孤立点处谈"连续性"意义不大，因为无法讨论"$x$ 接近 $x₀$"这件事。== 所以定理 1.21 的表述用的是"定义区间"而不是"定义域"。
:::

### 四、闭区间上连续函数的性质

以下四个定理统称为**闭区间上连续函数的基本定理**，是后续证明方程根存在性、求最值的理论依据。

**定理 1.22（有界性定理）**　若 $f$ 在闭区间 $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上**有界**。

**定理 1.23（最值定理）**　若 $f$ 在闭区间 $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上**必能取到最大值和最小值**。

**定理 1.24（零点定理）**　若 $f$ 在 $[a, b]$ 上连续，且 $f(a)·f(b) < 0$，则存在 $ξ ∈ (a, b)$，使 $f(ξ) = 0$。

**定理 1.25（介值定理）**　若 $f$ 在 $[a, b]$ 上连续，$m$ 与 $M$ 分别是 $f$ 在 $[a, b]$ 上的最小值与最大值，则对任意 $μ$ 满足 $m ≤ μ ≤ M$，存在 $ξ ∈ [a, b]$，使 $f(ξ) = μ$。

**推论**　闭区间上的连续函数必能取到介于它的任意两个函数值之间的一切值。

:::难点 "闭区间"三个字绝不能丢
这是四个定理共同的命门，必须用反例把界限刻清楚。

**反例 1**　$f(x) = 1/x$ 在 $(0, 1]$ 上连续，但**无界**（$x → 0^+$ 时 $1/x → +∞$）。
问题出在左端点 $0$ 是开的——函数在端点附近"跑掉了"。

**反例 2**　$f(x) = x$ 在 $(0, 1)$ 上连续且有界，但**取不到最大值也取不到最小值**（$0$ 与 $1$ 都不在定义域内，函数值只能无限接近它们）。
这个反例说明**最值定理**比有界性定理更强：有界只保证"被圈住"，最值定理保证"圈住它的边界能被摸到"。

==精确的对比：闭区间上连续 ⟹ 有界且能取到最值；开区间上这两个结论都可能不成立。==
:::

:::难点 零点定理：证明"方程有根"的标准工具
它的价值在于：==不需要解方程，就能断定根存在。==

**应用步骤**：

1. 把方程化为 $f(x) = 0$ 的形式，构造出 $f$；
2. 找出两个点 $a, b$，使 $f(a)$ 与 $f(b)$ **异号**；
3. 由零点定理断言 $(a, b)$ 内至少有一个根。

**几何直观**　$f(a) < 0 < f(b)$ 意味着图像从 $x$ 轴下方出发、到上方结束。连续曲线要"跨过" $x$ 轴，就**必然**与 $x$ 轴相交——==它不能"跳过" $x$ 轴，因为连续意味着不能断。== 如图 1.14.1 所示。

![[fig1_14_1]]

**例**　证明方程 $x³ − 4x² + 1 = 0$ 在 $(0, 1)$ 内至少有一个根。

令 $f(x) = x³ − 4x² + 1$（多项式，处处连续）。计算端点值：

$$ f(0) = 1 > 0,　f(1) = 1 − 4 + 1 = −2 < 0 $$

由零点定理，存在 $ξ ∈ (0, 1)$ 使 $f(ξ) = 0$，即该方程在 $(0,1)$ 内至少有一个根。　$∎$
:::

:::难点 四个定理之间的逻辑关系
它们不是四个彼此独立的结论，而是层层递进的一条链：

==有界性定理 → 最值定理 → 介值定理 → 零点定理==

1. **最有界性**先保证函数值不会跑到无穷远（这是一个"整体"性质的断言）；
2. **最值定理**在此基础上进一步断言：那个上界和下界**能被取到**，于是有了 $m$ 和 $M$；
3. **介值定理**利用 $m$ 与 $M$，断言函数能取遍两者之间的一切值；
4. **零点定理**是介值定理在 $μ = 0$ 时的特例。

因此严格说来零点定理不必单独记住。==但它的应用实在太频繁，值得作为一个独立工具熟练到条件反射的程度。==
:::

:::例题 例 1　证明方程 $x·2^x = 1$ 在 $(0, 1)$ 内至少有一个根
**解**　令 $f(x) = x·2^x − 1$。它是初等函数，在 $[0, 1]$ 上连续。

$$ f(0) = 0 − 1 = −1 < 0,　f(1) = 1·2 − 1 = 1 > 0 $$

由零点定理，存在 $ξ ∈ (0, 1)$ 使 $f(ξ) = 0$，即 $ξ·2^ξ = 1$。　$∎$

**要点**　==构造 $f$ 的方法：把方程移项成"右边为 $0$"的形式，左边就是 $f$。==
:::

:::例题 例 2（不动点问题）　设 $f$ 在 $[0, 1]$ 上连续，且 $0 ≤ f(x) ≤ 1$。证明存在 $ξ ∈ [0, 1]$ 使 $f(ξ) = ξ$
**分析**　要证 $f(ξ) = ξ$，即证 $f(ξ) − ξ = 0$。于是构造

$$ g(x) = f(x) − x $$

$g$ 在 $[0,1]$ 上连续（两个连续函数之差）。

**证明**　计算端点值：

$$ g(0) = f(0) − 0 = f(0) ≥ 0　（由 0 ≤ f(x) ≤ 1） $$
$$ g(1) = f(1) − 1 ≤ 0　（由 f(1) ≤ 1） $$

分两种情形：

1. 若 $g(0) = 0$，取 $ξ = 0$ 即可；若 $g(1) = 0$，取 $ξ = 1$ 即可。
2. 否则 $g(0) > 0$ 且 $g(1) < 0$。由零点定理，存在 $ξ ∈ (0, 1)$ 使 $g(ξ) = 0$，即 $f(ξ) = ξ$。　$∎$

**要点**　==满足 $f(ξ) = ξ$ 的点称为 $f$ 的**不动点**。== 这个例题的结论有很强的直观含义：把 $[0,1]$ 连续地"映到"自己内部，必然有一个点停在原地。请特别注意"**先算端点值再分情形讨论**"这个结构——它是零点定理类证明的固定套路。
:::

## 课时15　【总结回顾】第一章　函数与极限

**课时定位**　本章共引入了 18 组核心知识点。本讲不引入新内容，只做三件事：把全部知识点凝练成"内容—意义与用法—小结"三行式清单；把散落的方法重排成一张决策表；用双倍题量做一次综合检验。

**建议用时**　4 小时（其中复习 2 小时，做题 2 小时）

### 一、全章知识点清单

1. **区间与邻域**
   I. **内容**　开区间、闭区间、半开半闭区间、无穷区间；点 $a$ 的 $δ$ 邻域 $U(a, δ) = (a − δ, a + δ)$，去心 $δ$ 邻域 $U°(a, δ) = {x | 0 < |x − a| < δ}$。
   II. **意义与用法**　邻域是描述"局部"的语言工具。$δ$ 的**任意性**正是极限定义中"要多近有多近"的载体；去心邻域则是"极限与函数在该点的取值无关"这一事实的形式化表达。
   III. **小结**　邻域 $=$ 开区间 $+$ 可变半径；去心 $=$ 挖掉中心那一点。

2. **函数的概念与定义域**
   I. **内容**　函数的三要素：定义域、值域、对应法则；分段函数；定义域的五类限制（分母非零、偶次根号下非负、对数真数为正、反三角自变量在 $[−1,1]$、正切避开 $π/2 + kπ$）。
   II. **意义与用法**　讨论任何函数的第一步都是确定定义域。判断两个函数是否相同，只看定义域与对应法则，与字母无关。
   III. **小结**　定义域是函数的**组成部分**，不是附属品；凡有约分、开方、取对数，都要回头复查定义域。

3. **函数的四种特性**
   I. **内容**　有界性（存在 $M$ 使 $|f(x)| ≤ M$）、单调性（任取 $x₁ < x₂$ 比较函数值）、奇偶性（定义域对称且 $f(−x) = ±f(x)$）、周期性（$f(x + T) = f(x)$）。
   II. **意义与用法**　有界性是课时 5、14 两个"有界性定理"的核心概念；单调性既保证反函数存在，又是证明不等式的手段；奇偶性可简化对称区间上的积分（课时 55）。
   III. **小结**　四种特性都必须在**指定区间上**讨论——脱离区间谈有界、谈单调都是不完整的。

4. **反函数**
   I. **内容**　反函数存在的条件是 $f$ **单调**；$D_(f⁻¹) = R_f$，$R_(f⁻¹) = D_f$；图像关于 $y = x$ 对称；$f⁻¹[f(x)] = x$。
   II. **意义与用法**　求反函数三步：解出 $x$、交换字母、**写出定义域**。反函数的定义域恰是原函数的值域，可用来反向校验答案。
   III. **小结**　单调 ⟹ 有反函数；$f⁻¹(x)$ 是反函数，不是倒数。

5. **复合函数**
   I. **内容**　$y = f[g(x)]$ 有意义要求 $x ∈ D_g$ **且** $g(x) ∈ D_f$。分解要领："由外向内，一层一层剥"。
   II. **意义与用法**　复合是链式法则（课时 19）与换元积分（课时 41）的操作对象；求复合函数定义域必须同时满足两个条件，第二条最易漏。
   III. **小结**　复合不可交换；定义域取两个条件的**交集**。

6. **基本初等函数与初等函数**
   I. **内容**　五类基本初等函数：幂、指数、对数、三角、反三角。初等函数 $=$ 常数与基本初等函数经**有限次**四则运算与复合、可用**一个式子**表示的函数。
   II. **意义与用法**　定理"初等函数在其定义区间上连续"让求极限可以直接代值。分段函数一般**不是**初等函数，故分界点必须单独讨论。
   III. **小结**　五类基本初等函数的图像与性质要能默写；"有限次""一个式子"两个限定词不可省。

7. **数列极限的 ε-N 定义**
   I. **内容**　$∀ε > 0, ∃N, ∀n > N: |xₙ − a| < ε$。三层结构：$ε$ 任意、$N$ 存在且依赖 $ε$、之后**所有**项都成立。
   II. **意义与用法**　它是"无限接近"的严格化。证明的标准三步：任给 $ε$ → 反推 $N$ → 验证。核心技巧是**放大法**（分母往小放、分子往大放）。
   III. **小结**　$ε$ 管精度，$N$ 管起点，"$n > N$"管全部；$N$ 只依赖 $ε$，**绝不能依赖 $n$**。

8. **收敛数列的四大性质**
   I. **内容**　唯一性、有界性、保号性、子数列收敛性（任一子列收敛于同一极限）。
   II. **意义与用法**　有界性给出"收敛 ⟹ 有界"；子数列性质是判断**发散**的有力工具——两个子列极限不同即可断言发散；保号性用于判断极限的符号。
   III. **小结**　收敛 ⟹ 有界；有界 **⇏** 收敛；极限保持**非严格**不等式，不保持严格不等式。

9. **函数极限的 ε-δ 定义与单侧极限**
   I. **内容**　$∀ε > 0, ∃δ > 0, ∀x (0 < |x − x₀| < δ): |f(x) − A| < ε$。另有 $x → ∞$（$|x| > X$）、$x → x₀^+$、$x → x₀^−$ 三种变体。
   II. **意义与用法**　与 ε-N 逻辑结构完全一致，只是把"$n$ 足够大"换成"$x$ 足够近"。$0 < |x − x₀|$ 排除了 $x₀$ 本身，体现"极限与该点取值无关"。
   III. **小结**　$δ$ 依赖 $ε$ 且不唯一；放大系数依赖 $x$ 时，必须先取 $δ ≤$ 某个常数把它摁住。

10. **极限存在的充要条件**
    I. **内容**　$lim(x→x₀) f(x) = A$ ⟺ $f(x₀^+) = f(x₀^−) = A$。
    II. **意义与用法**　正面用于合并单侧极限；**逆否命题用于判断极限不存在**——左右极限不等或某侧不存在，即可断言双侧极限不存在。
    III. **小结**　四个经典模型必须记熟：$|x|/x$（跳跃）、$e^(1/x)$（一侧无穷）、$arctan(1/x)$（左右不等）、$sin(1/x)$（振荡）。

11. **无穷小与无穷大**
    I. **内容**　以 $0$ 为极限的变量称为无穷小；$f(x) → A$ ⟺ $f(x) = A + α(x)$（$α$ 为无穷小）；有界 $×$ 无穷小 $=$ 无穷小；$|f(x)|$ 无限增大称为无穷大。
    II. **意义与用法**　无穷小是描述"误差"的语言，是泰勒公式（课时 30）的素材；"有界 $×$ 无穷小"是处理振荡因子的标准手段。无穷大与无界的区别在于是否"从某一刻起**一直**超过 $M$"。
    III. **小结**　无穷小是**变量**不是数；无穷大 ⟹ 无界，无界 **⇏** 无穷大；无穷小与无穷大互推需要"不为零"这个附加条件。

12. **极限的运算法则**
    I. **内容**　四则运算法则（各自极限存在且有限、商的分母极限非零）；复合函数的极限法则（附加条件 $g(x) ≠ u₀$）。
    II. **意义与用法**　把严格定义压缩成好用规则。前提不满足时法则失效，但==**"法则失效"不等于"极限不存在"**==（如 $0/0$ 型）。$0/0$ 与 $∞/∞$ 靠因式分解、有理化、通分处理。
    III. **小结**　用之前先核验前提；未定式的处理目标是"化为能约分的形式"。

13. **夹逼准则与第一个重要极限**
    I. **内容**　若 $g ≤ f ≤ h$ 且 $g$、$h$ 同趋于 $A$，则 $f$ 也趋于 $A$。结合面积比较证得 $lim(x→0)(sin x)/x = 1$。
    II. **意义与用法**　夹逼准则是"无法直接确定时，把它控制住"的间接方法。第一个重要极限派生出 $sin x ~ x$ 以及全部三角函数的求导公式（课时 18）。
    III. **小结**　用弧度制是前提；遇到 $sin kx$ 先配系数；$0/0$ 型不等于极限不存在。

14. **单调有界准则与第二个重要极限**
    I. **内容**　单调有界数列必有极限。由此**定义** $e = lim(n→∞)(1 + 1/n)ⁿ$，并有三种等价形式。
    II. **意义与用法**　它不需要预知极限值就能断言存在；代价是不给出极限值，但在递推数列中可"在递推式两边取极限"补上。$1^∞$ 型极限等于 $e^A$，其中 $A = lim αβ$。
    III. **小结**　三步走：证单调、证有界、解方程；$1^∞$ 型先识别 $α$（底数减去 $1$ 剩下的部分）。

15. **无穷小的比较与等价无穷小替换**
    I. **内容**　高阶、低阶、同阶、等价、$k$ 阶的定义；等价替换定理 $lim α/β = lim α'/β'$；常用等价无穷小表（三个家族）。
    II. **意义与用法**　替换能极大简化**乘除**结构的极限计算。但**加减**结构中不能随意替换——减法会消掉主项，让被丢弃的次项升格为主项。
    III. **小结**　乘除可换、加减慎换；遇到加减先**提取公因子**化为乘除。

16. **函数的连续性与间断点**
    I. **内容**　连续 $= lim(x→x₀) f(x) = f(x₀)$，要求有定义、极限存在、两者相等三者同时成立。间断点分**第一类**（可去、跳跃）与**第二类**（无穷、振荡）。
    II. **意义与用法**　判断分界点连续性的三步法：算 $f(x₀)$、算左右极限、比对三个数。可去间断点可通过补充定义消除，跳跃间断点不能。
    III. **小结**　判别只需两问——左右极限**存在**吗？**相等**吗？

17. **连续函数的运算与初等函数的连续性**
    I. **内容**　连续函数的四则运算仍连续；复合时若外层连续，则 $lim f[g(x)] = f[lim g(x)]$；初等函数在其**定义区间**上连续。
    II. **意义与用法**　得到"求极限可直接代值"这条最便利的规则；极限符号可以**搬进**连续函数内部（对比课时 9 的附加条件，这里自动消失）。
    III. **小结**　连续对四则运算与复合**封闭**；"有限次"与"定义区间"两个限定词都不可省。

18. **闭区间上连续函数的四个基本定理**
    I. **内容**　有界性定理、最值定理、介值定理、零点定理（介值定理的推论）。
    II. **意义与用法**　零点定理是证明方程根存在与不动点问题的标准工具，步骤为"构造 $f$、找异号端点、下结论"。
    III. **小结**　逻辑链：有界性 → 最值 → 介值 → 零点；==**"闭区间"三个字不能丢**==，开区间上最值定理与零点定理都可能失效。

## 附录一　第一章课后练习参考答案

> **使用说明**　本附录给出全部练习的关键步骤与最终结果。证明题给出完整论证；计算题给出关键变形与答案。**建议先独立完成，再对照检查**——直接看答案会跳过"卡住—想通"这个最重要的学习环节。

### 课时1

1. 需要 $x + 3 ≥ 0$ 且 $x² − x − 6 ≠ 0$。前者给 $x ≥ −3$；后者即 $(x − 3)(x + 2) ≠ 0$，给 $x ≠ 3$ 且 $x ≠ −2$。取交集得定义域 $[−3, −2) ∪ (−2, 3) ∪ (3, +∞)$。

2. $f(x + 1) = 2(x + 1) + 1 = 2x + 3$；$f(f(x)) = 2(2x + 1) + 1 = 4x + 3$。

3. 对数要求 $x² − 3x + 2 > 0$，即 $(x − 1)(x − 2) > 0$，得 $x < 1$ 或 $x > 2$；反正弦要求 $−1 ≤ x/3 ≤ 1$，即 $−3 ≤ x ≤ 3$。取交集得 $[−3, 1) ∪ (2, 3]$。

4. $f(1/x) = (1/x)/(1 + 1/x²) = x/(x² + 1) = f(x)$，与原函数相同。

值域：由 $x/(1 + x²) ≤ 1/2$ ⟺ $2x ≤ 1 + x²$ ⟺ $(x − 1)² ≥ 0$（恒成立，等号在 $x = 1$ 取得）；同理 $x/(1 + x²) ≥ −1/2$。故值域为 $[−1/2, 1/2]$。

5. 用判别式法（见课时1例4）。把 $y$ 视为常数去分母得 $(y − 1)x² + (y + 1)x + (y − 1) = 0$。$y ≠ 1$ 时要求 $Δ = (y+1)² − 4(y−1)² ≥ 0$，解得 $1/3 ≤ y ≤ 3$；$y = 1$ 时方程有实根 $x = 0$，可取得。故值域为 $[1/3, 3]$。

### 课时2

1. 任给 $M > 0$，取 $x = 1/(M + 1) ∈ (0, 1)$。则 $1/x = M + 1 > M$。由于 $M$ 任意，$f$ 在 $(0,1)$ 上无界。

2. 定义域：$(1 − x)/(1 + x) > 0$ ⟺ $(1 − x)(1 + x) > 0$ ⟺ $−1 < x < 1$，关于原点对称。

奇偶性：$f(−x) = ln((1 + x)/(1 − x)) = ln[((1 − x)/(1 + x))⁻¹] = −ln((1 − x)/(1 + x)) = −f(x)$。故为**奇函数**。

3. **结论：$f$ 在 $(−∞, 0)$ 上单调增加。**

证明：任取 $x₁ < x₂ < 0$，则 $−x₁ > −x₂ > 0$。由 $f$ 在 $(0, +∞)$ 上单调增加，得 $f(−x₁) > f(−x₂)$。又 $f$ 为奇函数，故 $−f(x₁) > −f(x₂)$，即 $f(x₁) < f(x₂)$。所以 $f$ 在 $(−∞, 0)$ 上单调增加。　$∎$

【结论提炼】奇函数在关于原点对称的两个区间上**单调性相同**；偶函数则**单调性相反**。

$$ c(a + d) = 0,　b(a + d) = 0,　a² + bc = bc + d² $$

### 课时1

#### 挑战题　求 $y = (x² − x + 1)/(x² + x + 1)$ 的值域

**思路**　求分式的值域，若从函数出发分析单调性会很麻烦。改用**反向思考**：不问"$x$ 取什么值时 $y$ 是多少"，而问"$y$ 取什么值时，方程有实根 $x$"。这就把值域问题转成了**二次方程有实根的条件**问题，即判别式法。

**详解**

1. **先确认分母恒不为零。**　$x² + x + 1 = (x + 1/2)² + 3/4 > 0$ 对一切 $x$ 成立，所以函数在整个 $R$ 上有定义。

2. **把 $y$ 当作已知常数，去分母。**　由 $y = (x² − x + 1)/(x² + x + 1)$ 得

$$ y(x² + x + 1) = x² − x + 1 $$

3. **整理成关于 $x$ 的方程。**　移项并按 $x$ 的幂次归并：

$$ (y − 1)x² + (y + 1)x + (y − 1) = 0　　(∗) $$

4. **转化问题。**　$y$ 属于值域 $\iff$ 存在实数 $x$ 使 $(∗)$ 成立。

5. **分类讨论二次项系数（关键一步）。**

   当 $y ≠ 1$ 时，$(∗)$ 是二次方程，有实根 $\iff Δ ≥ 0$：

$$ Δ = (y + 1)² − 4(y − 1)² = y² + 2y + 1 − 4y² + 8y − 4 = −3y² + 10y − 3 $$

   令 $Δ ≥ 0$，即 $3y² − 10y + 3 ≤ 0$，因式分解得 $(3y − 1)(y − 3) ≤ 0$，解得

$$ 1/3 ≤ y ≤ 3 $$

   当 $y = 1$ 时，$(∗)$ 退化为 $2x = 0$，有实根 $x = 0$，故 $y = 1$ 确实可取到。

6. **合并结论。**　值域为 $[1/3, 3]$。

**答案**　$[1/3, 3]$。

**易错提醒**　$y = 1$ 必须单独讨论。当二次项系数含参数时，"$Δ ≥ 0$"这个条件在系数为零时**完全失效**——此时方程退化，可能仍有解。漏掉这一步是本题最常见的失分点。

### 课时2

#### 进阶题3　奇函数在对称区间上的单调性

**思路**　已知 $f$ 在 $(0, +∞)$ 上单调增加，要研究 $(−∞, 0)$。两段区间之间的桥梁是**奇函数关系** $f(−x) = −f(x)$。所以应该把 $(−∞,0)$ 上的两个点"翻"到正半轴去，用已知条件，再翻回来。

**详解**

1. 任取 $x_1 < x_2 < 0$。

2. 两边同乘 $−1$ 并反转不等号，得 $−x_1 > −x_2 > 0$，即两个点都落在了已知区间 $(0, +∞)$ 内。

3. 由 $f$ 在 $(0, +∞)$ 上单调增加，得

$$ f(−x_1) > f(−x_2) $$

4. 用奇函数性质把两边的自变量"翻"回来：$f(−x_1) = −f(x_1)$，$f(−x_2) = −f(x_2)$。代入得

$$ −f(x_1) > −f(x_2) $$

5. 两边同乘 $−1$ 并反转不等号：

$$ f(x_1) < f(x_2) $$

6. 由于 $x_1 < x_2$ 是任取的，故 $f$ 在 $(−∞, 0)$ 上单调**增加**。

**答案**　单调增加。

**结论提炼**　==奇函数在关于原点对称的两个区间上单调性相同；偶函数则单调性相反。== 这个结论可以直接用，但答题时应写出上面的推理。

#### 挑战题　若 $f(x + T) = −f(x)$（$T > 0$），证明 $f$ 是周期函数

**思路**　目标是要凑出 $f(x + P) = f(x)$ 的形式。条件给的是"$+T$ 变号"，那么再加一次 $T$ 就会再变一次号，两次变号恰好抵消。所以先猜 $P = 2T$，再验证。

**详解**

1. **明确目标。**　要证存在正数 $P$ 使 $f(x + P) = f(x)$ 对定义域内一切 $x$ 成立。

2. **对 $x + T$ 再用一次已知条件。**　已知条件对定义域内**任意**的自变量都成立，所以把自变量换成 $x + T$ 也成立：

$$ f((x + T) + T) = −f(x + T) $$

   即 $f(x + 2T) = −f(x + T)$。

3. **代入第一次的条件。**　由 $f(x + T) = −f(x)$ 得

$$ f(x + 2T) = −f(x + T) = −(−f(x)) = f(x) $$

4. **验证周期定义的其他要求。**　$2T > 0$（因为 $T > 0$），满足周期的正性要求。故 $2T$ 是 $f$ 的一个周期。

**答案**　$2T$ 是 $f$ 的一个周期。

**易错提醒**　不要把 $T$ 当成周期。$T$ 满足的是 $f(x+T) = −f(x)$，这称为**反周期**；只有当 $f$ 恒为零时 $T$ 才恰好也是周期。另外要记得验证 $2T > 0$——周期的定义要求正数。

### 课时3

#### 挑战题　求 $f[f(x)] = x$ 恒成立的充要条件（$f(x) = (ax+b)/(cx+d)$，$ad − bc ≠ 0$）

**思路**　"恒成立"意味着两边作为 $x$ 的多项式**逐项系数相等**。所以先把 $f[f(x)]$ 算成一个分式，再与 $x$ 比较。

**详解**

1. **计算 $f[f(x)]$。**　把 $f(x) = (ax+b)/(cx+d)$ 代入 $f$ 的自变量位置：

$$ f[f(x)] = [a·(ax+b)/(cx+d) + b] / [c·(ax+b)/(cx+d) + d] $$

2. **分子分母同乘 $cx+d$，化简。**　

   分子：$a(ax + b) + b(cx + d) = (a² + bc)x + b(a + d)$

   分母：$c(ax + b) + d(cx + d) = c(a + d)x + (bc + d²)$

   所以

$$ f[f(x)] = [(a² + bc)x + b(a + d)] / [c(a + d)x + (bc + d²)] $$

3. **写出恒等条件。**　要求 $f[f(x)] = x$ 对定义域内一切 $x$ 成立，即

$$ (a² + bc)x + b(a + d) = x·[c(a + d)x + (bc + d²)] $$

   右边展开：

$$ (a² + bc)x + b(a + d) = c(a + d)x² + (bc + d²)x $$

4. **比较各项系数。**　两边都是多项式，恒等 $\iff$ 对应系数相等：

$$ c(a + d) = 0,　a² + bc = bc + d²,　b(a + d) = 0 $$

   由第二式立即得 $a² = d²$，即 $d = a$ 或 $d = −a$。

5. **分两种情形讨论。**

   **情形一：$d = −a$。**　此时 $a + d = 0$，第一式与第三式自动成立，恒等条件全部满足。（还需 $ad − bc = −a² − bc ≠ 0$，即 $f$ 不是退化的。）

   **情形二：$d = a$。**　此时需 $c·2a = 0$ 且 $b·2a = 0$，即 $ab = 0$ 且 $ac = 0$。

   - 若 $a ≠ 0$，则 $b = c = 0$，于是 $f(x) = ax/a = x$，即 $f$ 是恒等函数；
   - 若 $a = 0$，则 $d = 0$，此时 $f(x) = b/(cx)$，可直接验证 $f[f(x)] = b/[c·b/(cx)] = x$ ✓。（注意这个情形也满足 $a + d = 0$，已被情形一覆盖。）

6. **汇总结论。**　充要条件是 $a + d = 0$，或 $f(x) ≡ x$。

**答案**　$a + d = 0$，或 $f(x) ≡ x$。

**背景**　满足 $f[f(x)] = x$ 的函数称为**对合函数**，几何上它的图像关于直线 $y = x$ 对称，$f$ 与 $f^{−1}$ 重合。

**易错提醒**　只写 $a + d = 0$ 会漏掉恒等函数 $f(x) = x$——它显然满足 $f[f(x)] = x$，但此时 $a + d = 2a ≠ 0$。

### 课时4

#### 挑战题　判断命题：若对任意 $ε > 0$ 都存在 $N$，使 $n > N$ 时 $|x_n − a| < 2ε$，则 $lim(n→∞) x_n = a$

**思路**　极限定义要求"对任意精度 $ε'$，都能做到小于 $ε'$"。题设给的是"小于 $2ε$"。关键在于：$ε$ 是**任意**的，所以 $ε$ 可以取成 $ε'/2$，这样 $2ε$ 就恰好等于 $ε'$。常数倍不改变任意性。

**详解**

1. **明确要证什么。**　按定义，需证：对任意给定的 $ε' > 0$，存在正整数 $N$，使 $n > N$ 时 $|x_n − a| < ε'$。

2. **任给 $ε' > 0$。**　这是证明的起手式。

3. **构造合适的 $ε$。**　令

$$ ε = ε'/2 $$

   由于 $ε' > 0$，所以 $ε > 0$，符合题设对 $ε$ 的要求（题设说"对任意 $ε>0$"）。

4. **调用题设。**　对上面这个 $ε$，题设保证存在正整数 $N$，使得当 $n > N$ 时

$$ |x_n − a| < 2ε $$

5. **换算。**　把 $2ε = 2·(ε'/2) = ε'$ 代入，得 $|x_n − a| < ε'$。

6. **这就是极限定义。**　由 $ε'$ 的任意性，$lim(n→∞) x_n = a$ 成立。

**答案**　命题**正确**。

**结论提炼**　==极限定义中的"任意 $ε$"可以在证明过程中被自由替换为任意正数，只要最终能推出所需的不等式。== 类似地，"$< 100ε$""$< ε/2$"（这是一个更强的条件）也都不改变结论。

**易错提醒**　不要因为题设写的是"$2ε$"而不是"$ε$"就判定命题错误。判定的标准应当是：能否对**每个**精度要求都给出保证。

### 课时5

#### 进阶题3　用反证法证明收敛数列的极限唯一

**思路**　"证明两个数相等"这类结论，正着往往无从下手，标准做法是**反设它们不等**，再用定义制造矛盾。制造矛盾的关键是取它们距离的一半作为 $ε$，让两个邻域互不相交。

**详解**

1. **反设。**　设 $lim\ x_n = a$ 且 $lim\ x_n = b$，且 $a ≠ b$。

2. **取 $ε = |a − b|/2$。**　由于 $a ≠ b$，这个 $ε > 0$，可以作为定义中的精度。

3. **由第一个极限取门槛。**　存在 $N_1$，当 $n > N_1$ 时 $|x_n − a| < ε$。

4. **由第二个极限取门槛。**　存在 $N_2$，当 $n > N_2$ 时 $|x_n − b| < ε$。

5. **同时启用两个门槛。**　取 $N = max\{N_1, N_2\}$。当 $n > N$ 时两个不等式同时成立。

6. **用三角不等式制造矛盾。**　

$$ |a − b| = |(x_n − b) − (x_n − a)| ≤ |x_n − b| + |x_n − a| < ε + ε = 2ε = |a − b| $$

   得到 $|a − b| < |a − b|$，这是一个矛盾。

7. **结论。**　反设不成立，故 $a = b$，极限唯一。

**易错提醒**　$ε$ 必须取成 $|a − b|/2$ 或更小。若取 $ε = |a − b|$，两个邻域会重叠，$x_n$ 可以同时落进两个邻域，就推不出矛盾了。

#### 挑战题　奇、偶子列都收敛于 $a$，证明原数列收敛于 $a$

**思路**　数列的每一项非奇即偶，所以只要把两种情形的门槛分别对齐，取较大者，就能覆盖全部项。这是一个"分类讨论 + 取最大值"的标准配合。

**详解**

1. **任给 $ε > 0$。**

2. **由偶数项子列的极限取门槛。**　由 $lim(k→∞) x_{2k} = a$，存在正整数 $N_1$，当 $k > N_1$ 时

$$ |x_{2k} − a| < ε $$

3. **由奇数项子列的极限取门槛。**　由 $lim(k→∞) x_{2k−1} = a$，存在正整数 $N_2$，当 $k > N_2$ 时

$$ |x_{2k−1} − a| < ε $$

4. **把"项序号 $k$"的门槛换算成"下标 $n$"的门槛。**　

   - $k > N_1$ 对应 $n = 2k > 2N_1$；
   - $k > N_2$ 对应 $n = 2k − 1 > 2N_2 − 1$。

   为保险可取 $N = max\{2N_1,\ 2N_2 + 1\}$，这样 $n > N$ 时两个条件都必然满足。

5. **分类验证。**　设 $n > N$：

   - **若 $n$ 为偶数**，写 $n = 2k$，则 $k = n/2 > N$，从而 $k > N_1$，故 $|x_n − a| < ε$；
   - **若 $n$ 为奇数**，写 $n = 2k − 1$，则 $k = (n+1)/2 > N_2$，故 $|x_n − a| < ε$。

6. **两种情况都成立**，且 $n$ 非奇即偶，故对一切 $n > N$ 都有 $|x_n − a| < ε$。

7. 所以 $lim(n→∞) x_n = a$。

**结论提炼**　==一个数列收敛，当且仅当它的奇数项子列与偶数项子列都收敛于同一极限。== 这个判据在判断分段定义的数列、递归数列时非常好用。

**易错提醒**　取 $N$ 时容易忘记奇偶换算（$2N_1$ 与 $2N_2+1$），直接写 $N = max\{N_1, N_2\}$ 是不够的。

### 课时6

#### 进阶题4　用 ε-δ 定义证明 $lim(x→x_0) √x = √x_0$（$x_0 > 0$）

**思路**　根式之差无法直接放缩，标准手法是**分子有理化**，把它变成"分子有界、分母有正下界"的形式，从而得到一个只含 $|x − x_0|$ 的估计。

**详解**

1. **先处理定义域。**　由于 $x_0 > 0$，只要 $x$ 离 $x_0$ 足够近就仍有 $x > 0$，$√x$ 有意义。这一点稍后通过限制 $δ$ 来保证。

2. **有理化。**　

$$ |√x − √x_0| = |(√x − √x_0)(√x + √x_0)| / (√x + √x_0) = |x − x_0| / (√x + √x_0) $$

3. **给分母找一个正下界。**　只要 $x ≥ 0$，就有 $√x ≥ 0$，故 $√x + √x_0 ≥ √x_0 > 0$。于是

$$ |√x − √x_0| ≤ |x − x_0| / √x_0 $$

4. **确定 $δ$。**　要使 $|x − x_0|/√x_0 < ε$，只需 $|x − x_0| < ε√x_0$。

   同时要保证 $x > 0$：只要 $|x − x_0| < x_0$ 即可（此时 $x > x_0 − x_0 = 0$）。

   两条件合并，取

$$ δ = min\{x_0,\ ε·√x_0\} $$

5. **写出完整证明。**　任给 $ε > 0$，取 $δ = min\{x_0, ε√x_0\}$。当 $0 < |x − x_0| < δ$ 时：

   由 $δ ≤ x_0$ 得 $x > 0$，故 $√x$ 有意义；由 $δ ≤ ε√x_0$ 得

$$ |√x − √x_0| ≤ |x − x_0|/√x_0 < δ/√x_0 ≤ ε $$

   故 $lim(x→x_0) √x = √x_0$。

**结论提炼**　==遇到根式之差，先有理化；有理化后分母出现的正下界（这里是 $√x_0$）就是天然的"放大系数"。==

**易错提醒**　必须同时取 $min\{x_0, ·\}$。若只取 $δ = ε√x_0$，当 $ε$ 较大时 $δ$ 可能超过 $x_0$，此时 $x$ 可能取到负值，$√x$ 无意义，证明链条断裂。

#### 挑战题　用 ε-δ 定义证明 $lim(x→0) x·sin(1/x) = 0$

**思路**　$sin(1/x)$ 在 $x → 0$ 时剧烈振荡，直接解不等式是不可能的。破解之道是**把振荡因子用有界性压住**：$|sin(1/x)| ≤ 1$，于是整个表达式被 $|x|$ 控制。

**详解**

1. **先做放缩。**　

$$ |f(x) − 0| = |x·sin(1/x)| = |x|·|sin(1/x)| $$

2. **用有界性去掉振荡因子。**　对一切 $x ≠ 0$ 都有 $|sin(1/x)| ≤ 1$，故

$$ |x·sin(1/x)| ≤ |x| $$

3. **确定 $δ$。**　要使 $|x| < ε$，取 $δ = ε$ 即可。

4. **写出完整证明。**　任给 $ε > 0$，取 $δ = ε$。当 $0 < |x − 0| < δ$ 时，

$$ |x·sin(1/x) − 0| = |x|·|sin(1/x)| ≤ |x| < δ = ε $$

   故 $lim(x→0) x·sin(1/x) = 0$。

**结论提炼**　=="有界函数 × 无穷小 = 无穷小"是用定义证明振荡型极限的核心工具。==

**对照提醒**　$lim(x→0) sin(1/x)$ 本身**不存在**（振荡，课时7模型4），但乘上无穷小 $x$ 之后极限存在且为 $0$。这个对比说明：极限的"坏行为"可以被另一个因子压制。

### 课时7

#### 挑战题　讨论 $lim(x→0) (e^{1/x} − 1)/(e^{1/x} + 1)$ 是否存在

**思路**　表达式里出现 $e^{1/x}$，而 $1/x$ 在 $0$ 的两侧符号相反，趋势完全不同。所以第一反应就是**分左右**。

**详解**

1. **先看右极限 $x → 0^+$。**　此时 $1/x → +∞$，故 $e^{1/x} → +∞$。

   分子分母都是无穷，不能直接用商的法则。把分子分母**同除以 $e^{1/x}$**：

$$ (e^{1/x} − 1)/(e^{1/x} + 1) = (1 − e^{−1/x})/(1 + e^{−1/x}) $$

   当 $x → 0^+$ 时 $−1/x → −∞$，故 $e^{−1/x} → 0$。于是

$$ f(0^+) = (1 − 0)/(1 + 0) = 1 $$

2. **再看左极限 $x → 0^−$。**　此时 $1/x → −∞$，故 $e^{1/x} → 0$。直接代入：

$$ f(0^−) = (0 − 1)/(0 + 1) = −1 $$

3. **比较两个单侧极限。**　$f(0^+) = 1$，$f(0^−) = −1$，两者都存在但不相等。

4. 由课时7定理1.5，$lim(x→0) f(x)$ **不存在**。

**结论提炼**　=="同除以 $e^{1/x}$"是处理含 $e^{1/x}$ 的 $∞/∞$ 型的标准手法。== 另外要分清：$x→0^+$ 时 $e^{1/x}→+∞$，$x→0^−$ 时 $e^{1/x}→0$——这条差别是本题的全部关键。

**易错提醒**　不要写 $e^{1/0} = e^∞$ 就下结论；必须严格分左右并分别求值。

### 课时8

#### 进阶题4　证明 $f(x) = (1/x)·sin(1/x)$ 在 $x → 0$ 时无界但不是无穷大

**思路**　"无界"与"无穷大"的差别在于：无界只要**存在**某些点冲到任意高；无穷大要求**从某一刻起一直**保持在高位。所以要构造两列点——一列让函数值冲高，另一列让函数值回落。

**详解**

**第一部分：证明 $f$ 无界。**

1. 取一列特殊的点，让 $sin(1/x) = 1$。由 $sin\ θ = 1$ 得 $θ = π/2 + 2kπ$。令

$$ x_k = 1/(π/2 + 2kπ),　k = 1, 2, 3, \ldots $$

2. 当 $k → ∞$ 时 $x_k → 0^+$，说明这些点确实落在 $x = 0$ 的附近。

3. 在这些点上

$$ f(x_k) = (1/x_k)·sin(1/x_k) = (π/2 + 2kπ)·1 = π/2 + 2kπ → +∞ $$

4. 因此，任给 $M > 0$，只要 $k$ 充分大就有 $|f(x_k)| > M$。按"无界"的定义，$f$ 在 $x→0$ 时无界。

**第二部分：证明 $f$ 不是无穷大。**

5. 再取另一列点，让 $sin(1/x) = 0$。由 $sin\ θ = 0$ 得 $θ = kπ$。令

$$ t_k = 1/(kπ),　k = 1, 2, 3, \ldots $$

6. 同样有 $t_k → 0^+$。

7. 但在这些点上

$$ f(t_k) = (1/t_k)·sin(1/t_k) = kπ·sin(kπ) = 0 $$

8. 于是对任意给定的 $M > 0$，也**无论 $δ > 0$ 取得多小**，在去心邻域 $0 < |x| < δ$ 内总存在这样的点 $t_k$ 使 $f(t_k) = 0 < M$。

9. 这说明 $f$ 不可能"从某一刻起一直超过 $M$"，即 $f$ 不是无穷大。

**结论提炼**　==无界只要求"存在"取到任意大的值；无穷大要求"最终恒大于"任意给定的界。== 前者允许偶尔冲高又落回，后者不允许。

### 课时9

#### 挑战题　设 $lim\ f(x) = A$，$lim\ g(x) = B$，$A < B$，证明存在 $δ > 0$ 使 $0<|x−x_0|<δ$ 时 $f(x) < g(x)$

**思路**　要在 $A$ 与 $B$ 之间"插一根杆子"，把 $f$ 和 $g$ 分到两边。最自然的选择是中点 $(A+B)/2$。而要把函数值推到中点的一侧，只需要取 $ε$ 为两点距离的**一半**。

**详解**

1. **取 $ε = (B − A)/2$。**　因为 $A < B$，所以 $ε > 0$，可以作为极限定义中的精度。

2. **把 $f(x)$ 压到中点以下。**　由 $lim\ f(x) = A$，存在 $δ_1 > 0$，当 $0 < |x − x_0| < δ_1$ 时 $|f(x) − A| < ε$，于是

$$ f(x) < A + ε = A + (B − A)/2 = (A + B)/2 $$

3. **把 $g(x)$ 推到中点以上。**　由 $lim\ g(x) = B$，存在 $δ_2 > 0$，当 $0 < |x − x_0| < δ_2$ 时 $|g(x) − B| < ε$，于是

$$ g(x) > B − ε = B − (B − A)/2 = (A + B)/2 $$

4. **同时启用两个门槛。**　取 $δ = min\{δ_1, δ_2\}$。当 $0 < |x − x_0| < δ$ 时两个估计同时成立，串起来得

$$ f(x) < (A + B)/2 < g(x) $$

5. 这就是所需结论。

**结论提炼**　==在两个极限之间取中点作为"隔离带"，取 $ε$ 为距离的一半——这与课时5唯一性证明是同一个技巧。== 它的直观含义是：**两个函数若极限不同，那么在原点的某个邻域内它们的大小关系就被"锁定"了。**

**易错提醒**　$ε$ 必须严格小于 $|A − B|/2$ 或恰好取一半。若取得过大，两个估计的区间会重叠，串不起不等式。

### 课时10

#### 挑战题　求 $lim(x→0) (tan\ x − sin\ x)/x³$

**思路**　分子是**减法**，而等价无穷小替换只在**乘除**结构中可靠。若分别把 $tan\ x$ 和 $sin\ x$ 换成 $x$，会得到 $x − x = 0$，把"差的阶"这一关键信息丢掉了。正确的做法是先**提取公因子，把减法变成乘法**。

**详解**

1. **变形：把减法化为乘法。**　

$$ tan\ x − sin\ x = sin\ x/cos\ x − sin\ x = sin\ x·(1/cos\ x − 1) = sin\ x·(1 − cos\ x)/cos\ x $$

2. **现在是乘除结构，可以逐因子替换。**　当 $x → 0$ 时：

$$ sin\ x ~ x,　1 − cos\ x ~ x²/2,　cos\ x → 1 $$

   于是

$$ tan\ x − sin\ x ~ x · (x²/2) / 1 = x³/2 $$

3. **回到原式。**　

$$ (tan\ x − sin\ x)/x³ ~ (x³/2)/x³ = 1/2 $$

4. 所以极限为 $1/2$。

**交叉验证（用泰勒展开）**　$tan\ x = x + x³/3 + o(x³)$，$sin\ x = x − x³/6 + o(x³)$，相减得

$$ tan\ x − sin\ x = (x³/3 + x³/6) + o(x³) = x³/2 + o(x³) $$

   除以 $x³$ 得 $1/2$，与上面的结果一致。

**错误做法为什么错**　$tan\ x ~ x$ 与 $sin\ x ~ x$ 都只保证"主项相同"。在减法中主项被消掉，剩下的完全由被丢弃的次项决定——而次项恰恰是替换时扔掉的。==朴素地替换相当于用 $1.0001 ≈ 1$、$1.0002 ≈ 1$ 算出"两者之差为零"，误差比差值本身还大。==

**结论提炼**　==破解加减陷阱的通用钥匙：提取公因子（本题）、有理化（根式之差）、通分（分式之差）。==

### 课时11

#### 进阶题3　设 $x_1 = √2$，$x_{n+1} = √(2 + x_n)$，证明收敛并求极限

**思路**　递推数列用**单调有界准则**。难点在于"有界"——先通过解极限方程猜出上界，再用数学归纳法验证。单调性则通过比较 $x_{n+1}$ 与 $x_n$ 的平方来判定（避开根式）。

**详解**

1. **猜上界。**　设极限存在且为 $a$，在递推式两边取极限得 $a = √(2 + a)$，即 $a² − a − 2 = 0$，解得 $a = 2$ 或 $a = −1$。由于 $x_n > 0$，取 $a = 2$。于是猜测上界为 $2$。

2. **用归纳法证明 $x_n < 2$ 对一切 $n$ 成立。**

   - 奠基：$x_1 = √2 ≈ 1.414 < 2$ ✓
   - 归纳：设 $x_n < 2$，则 $x_{n+1} = √(2 + x_n) < √(2 + 2) = √4 = 2$ ✓

3. **证明单调增加。**　直接比较 $x_{n+1}$ 与 $x_n$ 含根式不便，改比较它们的平方（两者都非负，比较平方等价）：

$$ x_{n+1}² − x_n² = (2 + x_n) − x_n² = −(x_n² − x_n − 2) = −(x_n − 2)(x_n + 1) $$

   由第 2 步知 $x_n < 2$，故 $x_n − 2 < 0$；又 $x_n + 1 > 0$。所以

$$ x_{n+1}² − x_n² = −(负数)·(正数) > 0 $$

   即 $x_{n+1}² > x_n²$，从而 $x_{n+1} > x_n$。故 $\{x_n\}$ 单调增加。

4. **应用单调有界准则。**　$\{x_n\}$ 单调增加且有上界 $2$，故收敛。

5. **求极限值。**　设 $lim\ x_n = a$。在递推式 $x_{n+1} = √(2 + x_n)$ 两边令 $n → ∞$：

   左边 $x_{n+1} → a$；右边由 $√{\ }$ 的连续性得 $√(2 + a)$。于是

$$ a = √(2 + a)　⟹　a² = 2 + a　⟹　a² − a − 2 = 0 $$

   解得 $a = 2$ 或 $a = −1$。由 $x_n > 0$ 知 $a ≥ 0$，舍去 $a = −1$。故

$$ lim(n→∞) x_n = 2 $$

**结论提炼**　==递推数列三步走：猜上界（解极限方程）→ 归纳法验证上界 → 比较平方证单调 → 递推式取极限求值。== 最后一步务必舍去不合理的根。

**易错提醒**　直接写"设极限为 $a$，解方程得 $a=2$"是不完整的——**必须先证明极限存在**（单调有界），否则"设极限为 $a$"这一步没有依据。

#### 挑战题　设 $x_1 = 1$，$x_{n+1} = 1 + x_n/(1 + x_n)$，证明收敛并求极限

**思路**　与上一题同构，但这次的"上界"不是猜出来的整数，而是黄金比 $φ = (1+√5)/2$。处理技巧是：先用归纳法证明 $x_n < φ$，再借助 $φ² = φ + 1$ 这一恒等式完成单调性的证明。

**详解**

1. **先证有界。**　显然 $x_n > 0$。又 $x_n/(1 + x_n) < 1$，故 $x_{n+1} < 2$。所以 $0 < x_n < 2$。

2. **猜出更精确的上界。**　设极限为 $a$，在递推式两边取极限：

$$ a = 1 + a/(1 + a)　⟹　a(1 + a) = (1 + a) + a　⟹　a² − a − 1 = 0 $$

   解得 $a = (1 + √5)/2$（舍去负根 $(1 − √5)/2$）。记

$$ φ = (1 + √5)/2 ≈ 1.618 $$

   它满足关键的恒等式 $φ² = φ + 1$，等价地 $φ/(1 + φ) = 1/φ = φ − 1$。

3. **归纳法证明 $x_n < φ$。**

   记 $g(t) = 1 + t/(1 + t)$。它在 $[0, +∞)$ 上单调增加（可用定义直接验证）。

   - 奠基：$x_1 = 1 < φ$ ✓
   - 归纳：设 $x_n < φ$，则

$$ x_{n+1} = g(x_n) < g(φ) = 1 + φ/(1 + φ) = 1 + (φ − 1) = φ $$

   故 $x_n < φ$ 对一切 $n$ 成立。

4. **证明单调增加。**　

$$ x_{n+1} − x_n = 1 + x_n/(1 + x_n) − x_n = [1 + x_n − x_n²]/(1 + x_n) $$

   分母 $1 + x_n > 0$。分子 $1 + x_n − x_n² > 0$ $\iff$ $x_n² − x_n − 1 < 0$。而由第 3 步 $x_n < φ$，且二次函数 $t² − t − 1$ 在 $[0, φ)$ 上取负值，故分子为正。

   于是 $x_{n+1} − x_n > 0$，即 $\{x_n\}$ 单调增加。

5. **应用单调有界准则。**　$\{x_n\}$ 单调增加且有上界 $φ$，故收敛。

6. **求极限值。**　设 $lim\ x_n = a$，在递推式两边取极限得 $a = 1 + a/(1 + a)$，即 $a² − a − 1 = 0$，故

$$ lim(n→∞) x_n = (1 + √5)/2 = φ $$

**结论提炼**　本题的极限是**黄金比**。它出现的根源是递推式 $a = 1 + 1/a$（连分数形式），这正是黄金比的定义式。

**易错提醒**　第 3 步的"归纳法验证上界"不可省略。若只由第 2 步解出 $φ$ 就直接宣称 $x_n < φ$，是**没有根据的**——解方程得到的是"极限的候选值"，不是"上界"。

### 课时12

#### 挑战题　求 $lim(x→0) (tan\ x − sin\ x)/x³$ 并说明为什么不能分别替换

**思路与详解**　见附录二课时10挑战题——两题完全相同。这里补充"为什么不能替换"的完整论证。

**为什么不能分别作等价替换**

1. 等价无穷小 $α ~ α'$ 的含义是 $α = α'(1 + o(1))$，也就是"$α$ 与 $α'$ 相差一个相对误差趋于 $0$ 的部分"。

2. 当两个这样的量相减时：

$$ α − β = α'(1 + o(1)) − β'(1 + o(1)) $$

3. 在本题中 $α' = β' = x$（因为 $tan\ x ~ x$、$sin\ x ~ x$），代入得

$$ tan\ x − sin\ x = x·o(1) − x·o(1) $$

   主项 $x$ 被完全消掉，剩下的只由那些 $o(1)$ 项决定。

4. 而这些 $o(1)$ 项的具体形态，恰恰是替换时**丢弃**的部分。所以分别替换后得到 $x − x = 0$，丢失了全部有效信息。

**正确的边界**　==等价替换在乘除结构中安全，在加减结构中会丢失关键信息。== 若一定要在加减中使用，有一条可以用的充分条件：当 $α ~ α'$、$β ~ β'$ 且 $lim\ α'/β' = c ≠ 1$（两者不等价）时，主项不会被消尽，替换是安全的。但更稳妥的做法永远是：**先变形为乘除结构，再替换。**

#### 挑战题　判断 $f(x) = x·sin(1/x)$（$x ≠ 0$），$f(0) = 0$ 在 $x = 0$ 处的连续性；若改为 $f(x) = sin(1/x)$ 结论如何？

**思路**　第一问验证连续的定义式 $lim(x→0) f(x) = f(0)$；关键工具是"有界 × 无穷小"。第二问则要证明极限不存在，用振荡间断点的标准构造。

**详解**

**第一问：$f(x) = x·sin(1/x)$ 在 $x = 0$ 处连续。**

1. 需要验证 $lim(x→0) f(x) = f(0) = 0$。

2. 做估计：

$$ |f(x) − f(0)| = |x·sin(1/x) − 0| = |x|·|sin(1/x)| ≤ |x|·1 = |x| $$

3. 当 $x → 0$ 时 $|x| → 0$。由夹逼准则（或直接 ε-δ 论证）得 $lim(x→0) f(x) = 0$。

4. 极限存在且等于函数值 $f(0) = 0$，故 $f$ 在 $x = 0$ 处**连续**。

**第二问：改为 $f(x) = sin(1/x)$ 后结论不成立。**

5. 当 $x → 0$ 时 $1/x$ 无限增大，$sin(1/x)$ 在 $[−1, 1]$ 上无限次振荡。

7. 因此左右极限都不存在，$x = 0$ 是**振荡间断点**（第二类），函数在 $x = 0$ 处**不连续**。

**结论提炼**　==两个函数只相差一个因子 $x$，连续性却完全不同。== 根源在于：$x$ 作为无穷小，把有界的振荡量"压"到了 $0$——这正是"有界函数 × 无穷小 = 无穷小"这条性质的威力。

### 课时14

#### 进阶题4　不动点定理：$f$ 在 $[0,1]$ 上连续且 $0 ≤ f(x) ≤ 1$，证明存在 $ξ$ 使 $f(ξ) = ξ$

**思路**　零点定理只能处理 $g(ξ) = 0$ 的形式，所以要把目标等式移项，构造辅助函数 $g(x) = f(x) − x$。然后去找两个使 $g$ **异号**的端点。

**详解**

1. **构造辅助函数。**　要证 $f(ξ) − ξ = 0$，令

$$ g(x) = f(x) − x,　x ∈ [0, 1] $$

2. **确认 $g$ 连续。**　$f$ 连续，$x$ 也连续，两个连续函数之差仍连续。

3. **计算端点值。**　

$$ g(0) = f(0) − 0 = f(0) ≥ 0　（因为 0 ≤ f(x) ≤ 1） $$

$$ g(1) = f(1) − 1 ≤ 0　（因为 f(1) ≤ 1） $$

4. **分情形讨论。**

   - 若 $g(0) = 0$，则 $f(0) = 0$，取 $ξ = 0$ 即可；
   - 若 $g(1) = 0$，则 $f(1) = 1$，取 $ξ = 1$ 即可；
   - 否则必有 $g(0) > 0$ 且 $g(1) < 0$，两端点异号。由零点定理，存在 $ξ ∈ (0, 1)$ 使 $g(ξ) = 0$，即 $f(ξ) = ξ$。

5. 三种情形都找到了满足要求的 $ξ$，命题得证。

**直观含义**　把 $[0,1]$ 这条线段连续地"映到"自己内部（不允许撕断），必然有至少一个点停在原地不动。满足 $f(ξ) = ξ$ 的点称为 $f$ 的**不动点**。

**结论提炼**　==零点定理类证明的固定套路：移项构造 $g$ → 计算端点值 → 若异号则用零点定理，否则端点本身就是解。==

#### 挑战题　$f$ 在 $[0,1]$ 上连续且 $f(0) = f(1)$，证明存在 $ξ ∈ [0, 1/2]$ 使 $f(ξ) = f(ξ + 1/2)$

**思路**　目标等式两边都有 $f$，无法直接移项成一个零点问题。但只要把 $ξ$ 看成变量、把右端整体移到左边，就可以构造辅助函数 $g(x) = f(x) − f(x + 1/2)$。本题的**灵魂**在于发现 $g(1/2) = −g(0)$——端点值**自动异号**。

**详解**

1. **构造辅助函数。**　令

$$ g(x) = f(x) − f(x + 1/2),　x ∈ [0, 1/2] $$

2. **确认 $g$ 有定义且连续。**　当 $x ∈ [0, 1/2]$ 时 $x + 1/2 ∈ [1/2, 1] ⊆ [0, 1]$，所以 $f(x + 1/2)$ 有意义，$g$ 在 $[0, 1/2]$ 上有定义；它是两个连续函数之差，故连续。

3. **计算两个端点值（关键一步）。**　

$$ g(0) = f(0) − f(1/2) $$

$$ g(1/2) = f(1/2) − f(1) = f(1/2) − f(0) = −g(0) $$

   最后一步用了已知条件 $f(0) = f(1)$。

4. **因此 $g(0)$ 与 $g(1/2)$ 互为相反数。**

   - 若 $g(0) = 0$，则 $g(0) = 0$，取 $ξ = 0$，此时 $f(0) = f(1/2)$ ✓；
   - 否则 $g(0)$ 与 $g(1/2)$ 一正一负，**自动异号**。由零点定理，存在 $ξ ∈ (0, 1/2)$ 使 $g(ξ) = 0$，即

$$ f(ξ) = f(ξ + 1/2) $$

5. 命题得证。

**结论提炼**　==本题的灵魂是"构造 $g$ 之后端点值自动异号"。== 这类问题的通用策略是：把结论中的 $\xi$ 换成变量 $x$，移项构造辅助函数，然后寄希望于端点值天然异号——而这一点往往由题目的额外条件（如 $f(0) = f(1)$）来保证。

**推广**　把 $1/2$ 换成 $1/n$（$n$ 为正整数），结论依然成立，证明方法完全相同，只需把辅助函数改为 $g(x) = f(x) − f(x + 1/n)$，$x ∈ [0, (n−1)/n]$。
