02 / How to read

同一套阅读体验

不用安装，也不需要联网。

01

打开课程

双击本页或任一课程目录；每门课的目录、侧栏、检索与上下节导航都在本地 HTML 里，MathJax 也已内置。

02

独立进度

三门课各用独立的 localStorage 键；在任意一门勾选，不会改动另外两门。目录页底部可导出、导入、重置。

03

本地服务

如果浏览器限制 file:// 的本地存储，在仓库根目录运行 python -m http.server 8000，再打开 http://localhost:8000/数学分区/。
