# 算竞教程 · 重构版说明

## 这是什么

把原 `30days`（25 个 HTML、按"天"粗分）重构成 **60 节按算法应用划分**的课程。每节 = 一个完整算法应用的闭环：

```
新函数拆解 → 例题（题面 → 思路 → 完整代码 → 逐行拆解）→ 易错点
→ 数学补给 → 举一反三思考题 → 自测清单 → 节末挑战题（提示 → 思路 → 题解 → 拆解）
```

## 目录结构

```
算竞教程/
├─ index.html          总目录（全文检索、勾选完成情况、难度分组）
├─ 01.html … 60.html   60 节课（每节带侧边栏）
├─ sol-xinsheng.html   2025 新生赛（初赛）题解
├─ sol-yuesai2025.html 2025 月赛题解
├─ sol-gdut2026.html   GDUT 2026 月赛题解
└─ assets/
   ├─ style.css
   ├─ app.js              侧边栏 + 勾选状态 + 全文检索
```

纯静态，双击 `index.html` 即可阅读，不需要服务器、不需要联网（题目链接除外）。

## 全文检索

目录页顶部检索框，**输入关键词后按回车**（或点「检索」）。

**排序规则**：先列「章节标题命中」的节（标题或标签含关键词），再列「正文命中」，正文按所在节顺序排列。

**正文命中**的每条结果都是三行：

```
04  一维数组与遍历  › 初值为什么取 a[0]        ← 所在节标题 + 小标题
终止：循环结束时 k = n，mx = max(a[0..n-1])…   ← 上一行（灰）
三步就是全部。以后学[前缀和]、单调栈、DP…      ← 命中行，关键词高亮
推论 1（数个数）：区间 [l, r] 内整数个数…       ← 下一行（灰）
```

**点击结果** → 跳到对应节，自动展开折叠的 `<details>`（题解代码块），滚动到该段落并让关键词闪烁高亮。

> **高亮会在下一次点击屏幕时清除**（按 `Esc` 也可以）。想多看一会儿就先别点。

其他细节：

- `Esc` 或右侧 `×` 退出检索，恢复目录；
- URL 会带上 `?q=关键词#b123`，可以直接分享/收藏某处命中；返回上一页时检索词自动恢复；
- 索引按需加载——不检索就不会读那 2.1 MB；
- 单次最多显示 240 条正文命中，超出会提示把关键词写具体些。

## 右侧「本节目录」

每页右侧有一块可以**打开/收起**、**独立滚动**的面板：

- 顶部是本节的内容概述（就是页面开头那段提要）；
- 下面是本节全部细分小标题，按层级缩进：L1 是例题 / 数学补给 / 举一反三 / 挑战题 / 挑战 2，L2 是「新函数拆解」「逐行拆解」「自己动手复现」这类小节；
- 点任意一条 → 直接滚到那里，并高亮当前条；
- 往下读时目录会**自动跟着高亮**当前所在小节；
- 宽屏（≥1440px）默认展开，窄屏默认收起，右下角浮动按钮 `≡ 本节目录` 随时打开；展开/收起状态会被记住。

## 勾选与侧边栏

**目录页勾选**：每行右侧有两个复选框。

| 勾选 | 结果 |
|---|---|
| `已学` | 该节标题前出现 ⭐ |
| `已学` + `挑战2` | ⭐ 变成 🌟 |
| 都不勾 | 不显示标记 |

第 1~25 节默认已勾「已学」（对应你 30days 阶段的实际进度），可以自己取消；第 21 节起才有「挑战2」复选框。

**侧边栏**：每页左下角「☰ 章节」按钮（宽屏 ≥1180px 时自动常驻左侧，宽 332px）。

- 列出全部 60 节 + 题解，按组分类，**列表可上下滚动**（组标题吸顶）；
- 当前页高亮，打开时自动滚到视野内；
- 每行右侧有真实复选框：`☑ ⭐` 表示已学，`☑ 🌟` 表示完成挑战 2，**在任何一页都能改任何一节的完成状态**；
- 顶部实时显示「已学 x/60 · 挑战2 y/40」。

所有状态存在浏览器 `localStorage`（键名 `ac_learned_<节号>` / `ac_ch2_<节号>`，值为 `'1'` / `'0'`）。
**未设置过**时取课程表默认值（第 1~25 节默认已学）；**手动取消会显式存 `'0'`**，所以取消不会被弹回。
如果浏览器禁用了 `file://` 下的 localStorage，会自动退化到内存存储（本次会话有效）。

## 思考点：先想，再核对

每节末尾的「举一反三 · 想清楚这些再往下走」有 4~6 个问题。**每个问题下面都有一条折叠的「想好了？点开核对思路与解析」**。

解析固定三段：

1. **结论** —— 直接回答，能算出数就给具体数；
2. **理由** —— 落到本节讲过的机制上，具体到变量、上界、复杂度、溢出范围；
3. **常见错路** —— 学生最容易走的那个错误方向，以及错在哪。

用法：先自己在纸上写答案，再点开对。**对不上的不是答案，而是判断依据**——那才是要回去重看的地方。全 60 节共 290 条。

### 自测

任意页面加 `?selftest=1`（如 `26.html?selftest=1`）会在加载后跑一遍
「勾选 → 读回 → 取消 → 读回」，把结果写进网页标题，便于确认勾选链路是否正常。
目录页加 `?selftest=1` 还会额外跑一次检索并报告命中数。

## 挑战 2（第 21 节起）

每节末尾在普通挑战题之后多一道 **挑战 2**：

- 难度 ≥ 绿题（洛谷「普及+/提高」「提高+/省选-」，或 Codeforces 1600+、AtCoder ABC 的 E/F、牛客提高组）；
- 来自可提交判题的 OJ，页面里给直接链接（洛谷 / Codeforces / AtCoder / 牛客都有）；
- 算法范围不超出该节及之前所学，**但允许把多个已学算法组合起来**——这是它比普通挑战题难的地方；
- 同样是「提示 → 思路 → 代码 → 拆解 → 易错点」五段式，提示不剧透做法。

## 分组与难度曲线

| 组 | 节 | 主题 |
|---|---|---|
| 一 | 1–5 | 起步：输入输出、循环、图形、数组 + 回顾 |
| 二 | 6–10 | 数组的两种用法：桶计数、二维网格、字符串 + 回顾 |
| 三 | 11–15 | 函数、结构体、排序、枚举 + 回顾 |
| 四 | 16–20 | 贪心、前缀和差分、双指针 + 回顾 |
| 五 | 21–25 | 递归、递推、DFS 枚举与回溯 + 回顾 |
| 六 | 26–30 | BFS、二分、容器 + 回顾 |
| 七 | 31–35 | 动态规划（线性 → 背包 → 区间/树形 → 状压）+ **模拟赛一** |
| 八 | 36–40 | 数论：筛法、同余、组合、期望 + 回顾 |
| 九 | 41–45 | 图论：遍历、最短路、生成树、拓扑 + 回顾 |
| 十 | 46–50 | 树状数组、线段树、单调栈/队列、堆 + **模拟赛二** |
| 十一 | 51–55 | 哈希、Trie、KMP、ST 表、二分图 + 回顾 |
| 十二 | 56–60 | 分治/CDQ、根号分治与莫队、博弈、几何 + 总复习 |

排序原则：同一算法的进阶（如 LIS 的 O(n log n)、背包的多重/分组）一律放在基础之后；
难度曲线按「知识点依赖」而非原课时顺序排，保证每节的前置都已学过。

## 回顾章与模拟赛

- 回顾章（5/10/15/20/25/30/40/45/55/60）：5 道黄题以上的综合题，覆盖此前若干节。
- 模拟赛一（35 节）：4 题 120 分钟，普及/提高- 难度。
- 模拟赛二（50 节）：5 题 150 分钟，提高- 到 提高 难度。
- 每道题都是「先提示 → 再思路 → 再代码 → 再拆解」，提示和题解直接放在题目下方，不集中到最后。

## 题解文档

三份 PDF 题面各自的题解，格式同节末挑战题。过于简单的题（入门及以下）已跳过并在文档开头列明理由。
GDUT 2026 那份 PDF 的字体缺少 ToUnicode 映射，直接复制题目会得到乱码，因此只覆盖了能从样例与结构可靠还原题意的题。

## 修改与重新生成

源码在 `build_tools/site/`：

```
site/
├─ curriculum.py     60 节总表（标题、难度、⭐ 默认值、标签）
├─ dsl.py            内容 DSL（P/C/EX/IDEA/EXPLAIN/FN/CH/LESSON…）
├─ render.py         HTML 渲染器、代码高亮、侧边栏与勾选状态
├─ searchindex.py    构建期索引：正文块锚点 id + 全文文本 + 右侧目录小标题
├─ build.py          构建脚本（生成 assets/toc.js 与 assets/search-index.js）
├─ assets_src/app.js 侧边栏、勾选、全文检索、右侧目录的前端逻辑（构建时复制到 assets/）
├─ check_think.py    检查 think / think_a 是否一一对应
├─ lessons/lXX.py    每节内容
├─ solutions/        题解内容
├─ audit.py          结构审计：每节是否缺例题/挑战题/数学补给
├─ check_one.py      单节检查：结构 + 是否用了已做过的题 + 编译全部完整程序
├─ compile_check.py  全量编译检查（60 节）
├─ compile_check_sol.py  题解代码编译检查
└─ done_check.py     已做过的 118 道题清单
```

重新生成 / 自检：

```bash
cd build_tools/site
python build.py                 # 输出到 ../../算竞教程
python audit.py                 # 结构审计
python check_one.py 21 22 23    # 单节：结构 + 已做题 + 编译
python compile_check.py         # 全量编译（较慢，约 10 分钟）
```

`check_one.py` 需要 g++，默认路径写在脚本里，可自行修改。
