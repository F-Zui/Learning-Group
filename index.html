02 / How to open

双击就能读

不需要安装、构建或联网。

01

打开页面

双击根目录的 index.html，或从 GitHub Pages 进入。每门课的目录、侧边栏与上下节导航都在本地 HTML 里。

02

勾选进度

每节课的复选框存在浏览器的 localStorage。微积分目录页底部可以导出、导入、重置；算竞教程在任何一页都能改任何一节的状态。

03

需要本地服务时

如果浏览器禁用了 file:// 下的本地存储，在根目录运行 python -m http.server 8000，再打开 http://localhost:8000/。

03 / Sources

页面是生成物

改课程请改源码，再重新构建。

微积分精讲 math/

课程结构在 math/tools/site/curriculum.py；build.py 由它重建目录页与 assets/toc.js，check.py 检查单节的图、例题、习题与链接。写作规范见 math/AUTHORING.md，单节内容在 math/sections/ 手写。

算竞教程 build_tools/

60 节总表在 build_tools/site/curriculum.py，每节内容在 lessons/lXX.py；build.py 生成 01.html…60.html 与侧栏数据，audit.py / check_one.py 负责结构与编译检查。

算竞教程的 60 个页面是生成物；微积分的目录页与侧栏数据是生成物，单节页面是手写内容。
