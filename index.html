02 / How to open

双击就能读

不需要安装、构建或联网。

01

打开页面

双击根目录的 index.html，或从 GitHub Pages 进入。每门课的目录、侧边栏与上下节导航都在本地 HTML 里。

02

勾选进度

每节课的复选框存在浏览器的 localStorage。数学分区的三门课都在目录页底部提供导出、导入、重置；算竞教程在任何一页都能改任何一节的状态。

03

需要本地服务时

如果浏览器禁用了 file:// 下的本地存储，在根目录运行 python -m http.server 8000，再打开 http://localhost:8000/。

03 / Sources

页面是生成物

改课程请改源码，再重新构建。

数学分区 3 门课程

三门课各自维护构建脚本：微积分的结构在 数学分区/高等数学-积分学/tools/site/curriculum.py，图论与数论在各自的 tools/curriculum.py；build.py 重建目录页、侧栏与检索索引，单节页面分别写在三个 sections/。微积分写作规范见 数学分区/高等数学-积分学/AUTHORING.md。

算竞教程 tools/

60 节总表在 算竞教程/tools/curriculum.py，每节内容在 lessons/lXX.py；build.py 生成 sections/01.html…60.html 与侧栏数据，audit.py / check_one.py 负责结构与编译检查。

算竞教程的 60 个页面是生成物；数学分区三门课的目录页、侧栏与检索索引由各自 build.py 生成，单节内容手写。本页与 数学分区/index.html 是手工导航。
