# 微积分精讲 · 课程纲要

> 63 节 ｜ 3 部分 ｜ 12 章 ｜ 每节独立 HTML，目录与侧栏可勾选进度。
> 交付形态：`index.html`（目录）+ `sections/X-Y.html`（每一节）。

## 一、设计原则

1. **图像先行**：每个新概念先给图，再给式，再给定义。图不是装饰，是论证的一部分。
2. **符号优先**：能用公式、表格、不等式说清的，不写句子。正文段落不超过 3 句。
3. **证明分层**：基础证明放正文（Abbott 级），进阶证明折叠在 `.deep` 里（Rudin / Apostol 级），不打断主线。
4. **题解内嵌**：每道习题下面紧跟「思路 → 答案」，不把答案堆到章末。
5. **进度可视**：目录与侧栏同一份进度，勾选即完成，完成节标 ⭐。

## 三、三条主线

- **极限线**：§2.1–2.6 建立 ε-N / ε-δ，§5.1–5.2 升级为黎曼和与 FTC，§7.2、§11.1–11.5、§12.1–12.3 反复回到「用有限逼近无限」。
- **局部线性化线**：§3.1–3.5 用直线代替曲线，§3.7 升级为多项式，§9.2–9.4 升维为切平面与梯度。
- **统一公式线**：FTC、Green、Gauss、Stokes 是同一个定理的四张面孔，在 §11.5 收束。

## 五、每节的标准结构

| 区块 | 作用 | 硬性要求 |
|---|---|---|
| 标题 + lede | 一句话点出机制 | 1–2 句 |
| 定义 / 定理 | 严格陈述，条件写全 | 每个新概念至少 1 个 |
| 证明 / 为什么 | 补跳步，或讲动机 | 至少 1 个 |
| 图 | 解释几何与机制 | ≥4 幅 |
| 例题 | 标准、变式、应用、易错 | ≥4 个 |
| 思考点 | 一两句发问 + 引导 | ≥2 个 |
| 习题 | 先思路后答案 | ≥6 道 |
| 一页纸 | 4–6 条结论 | 1 个 |
